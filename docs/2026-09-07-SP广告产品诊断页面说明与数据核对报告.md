# SP 广告产品诊断页面说明与数据核对报告

## 页面说明

“广告效果分析 > 产品诊断”按“店铺＋站点＋MSKU”展示产品经营表现、SP 广告表现和最新广告建议。页面只提供分析及人工处理参考，不会修改广告。

- 统计周期支持近 7、14、30、90 天，默认近 30 天。
- 广告归因窗口独立支持 1、7、14、30 天，默认 7 天。
- 页面一次只选择一种币种，默认选择产品数最多的 EUR。
- 默认先显示存在明确处理动作的产品，再按广告花费降序。
- “需处理”包括竞价提价、降价、竞价人工复核、建议新增、建议否定和否词人工审核。
- 竞价保持、数据不足、词已存在和未达到规则阈值不计入需处理产品数，但详情会保留这些记录。
- 点击详情中的竞价、加词或否词入口，会保留当前店铺、站点和 MSKU 条件并切换到相应建议页。

经营指标来自 `dashboard_product_performance_daily`，SP 广告指标来自 `dashboard_sp_product_ad_daily`。广告建议直接引用最新成功建议批次，不在产品诊断中重新计算。经营表中的广告字段没有用于本页。

## 数据边界

- 经营数据未匹配的 1 个产品继续保留，页面显示“经营数据未匹配”。
- 库存取周期内最近一个已匹配经营日期的 FBA 可售库存，不跨日期求和。
- 比率均使用汇总后的分子与分母计算；分母为零时返回空值并显示“—”。
- 不同币种不直接相加。页面摘要、趋势、表格和导出使用同一币种条件。
- 当前版本没有诊断评分、高 ACOS 阈值、自动调价或广告执行功能。

## 更新命令

试运行：

```powershell
.venv\Scripts\python.exe -m etl.sp_product_diagnosis_update --dry-run
```

正式更新：

```powershell
.venv\Scripts\python.exe -m etl.sp_product_diagnosis_update
```

指定截止日重建：

```powershell
.venv\Scripts\python.exe -m etl.sp_product_diagnosis_update --cutoff-date 2026-09-06
```

更新任务使用数据库锁阻止并发发布。数据和快照在同一事务中写入；失败批次记录错误，页面继续读取上一次成功批次。
