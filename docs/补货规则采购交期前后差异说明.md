# 采购交期导致补货数量增加的原因说明

## 一、先说结论

本次使用2026年8月3日快照，对比旧规则和测试分支新规则的最终补货数量。

为保证数据可以直接比较，本报告采用以下口径：

- 只比较新旧结果中都存在的同一批商品。
- 新旧规则都使用最终补货数量 `replenish_qty`，不混用计算量和可执行量。
- 剔除371条新旧预测日销不一致的记录，这部分暂按异常数据处理，不纳入分析。
- 最终纳入比较的日销一致记录共3,320条。

在这个口径下：

| 指标 | 旧规则 | 新规则 | 差额 |
|---|---:|---:|---:|
| 最终补货数量 | 5,288件 | 10,017件 | **增加4,729件** |

增加4,729件，主要不是因为原来补货的商品统一多补了10天，而是因为一批原来不补货的商品，在新规则下提前进入了补货层。

## 二、增加的4,729件是怎么组成的

| 类型 | 商品数 | 旧规则补货量 | 新规则补货量 | 增减 |
|---|---:|---:|---:|---:|
| 旧规则不补，新规则补 | 25个 | 0件 | 3,862件 | **+3,862件** |
| 新旧规则都补 | 40个 | 5,134件 | 6,155件 | **+1,021件** |
| 旧规则补，新规则不补 | 3个 | 154件 | 0件 | **-154件** |
| 新旧规则都不补 | 3,252个 | 0件 | 0件 | 0件 |
| **合计** | **3,320个** | **5,288件** | **10,017件** | **+4,729件** |

计算关系为：

```text
新增4,729件
= 原来不补、现在补的3,862件
+ 新旧都补时多出的1,021件
- 原来补、现在不补的154件
```

## 三、为什么旧规则不补，新规则会补

这25个商品一共新增3,862件，其中：

- 23个商品是因为加入采购交期后，从“库存充足”提前进入计划补货或建议补货，合计新增3,562件。
- 另外2个商品合计新增300件，是同ASIN补货目标链接发生变化，不属于采购交期提前分层的直接影响。

因此，可以明确归因于“采购交期使商品提前进入补货层”的数量为：

```text
23个商品，新增3,562件
```

旧规则使用当前库存可支撑天数判断分层：

```text
当前库存可支撑天数 S = 当前库存 ÷ 日销
```

当 `S > 90天` 时，商品属于库存充足，本次不补货。

新规则使用到货时库存可支撑天数判断分层：

```text
到货时库存可支撑天数 R = 当前库存可支撑天数 S - 采购交期 L
```

例如商品当前可以支撑95天、采购交期10天：

```text
旧规则：95天 > 90天 → 库存充足 → 不补货
新规则：95 - 10 = 85天 → 计划补货 → 开始补货
```

所以这部分增量的核心原因是：**新规则把采购动作提前了，原来本次不下单的商品，现在进入了本次补货池。**

实际商品 `PP023a`：

| 指标 | 数值 |
|---|---:|
| 日销 | 10.52件 |
| 当前库存 | 1,249件 |
| 当前可支撑天数 | 118.77天 |
| 采购交期 | 45天 |
| 到货时可支撑天数 | 73.77天 |
| 旧规则补货量 | 0件 |
| 新规则补货量 | 440件 |

旧规则看到118.77天，判定库存充足；新规则扣除45天交期后只剩73.77天，因此提前进入计划补货，最终新增440件。

## 四、新旧规则都补货时为什么还会增加1,021件

有40个商品在新旧规则下都会补货：

```text
旧规则合计补货：5,134件
新规则合计补货：6,155件
合计增加：1,021件
```

这部分商品不涉及“原来不补、现在开始补”，而是补货数量的计算起点发生了变化。

旧规则按照当前库存直接补足120天：

```text
旧补货需求 = 120天销量 - 当前库存
```

新规则先扣掉采购等待期间会销售的库存，再补足120天：

```text
到货时预计库存 = 当前库存 - 采购交期 × 日销

新补货需求 = 120天销量 - 到货时预计库存
```

只要库存能够支撑到货，新规则相对于旧规则增加的基础需求约为：

```text
采购交期 × 日销
```

实际商品 `YY082a`：

| 指标 | 旧规则 | 新规则 |
|---|---:|---:|
| 日销 | 8.71件 | 8.71件 |
| 采购交期 | — | 10天 |
| 最终补货量 | 216件 | 324件 |
| 箱规 | 108件/箱 | 108件/箱 |

10天交期内预计销售约87件，使补货需求跨过了一个整箱，新规则由2箱变为3箱，最终增加108件。

## 五、交货期间预计断货怎么判断

判断公式为：

```text
到货时库存可支撑天数 R
= 当前库存可支撑天数 S - 采购交期 L
```

判断规则：

```text
R >= 0：现有库存能够支撑到新货到达
R < 0：新货到达前预计会断货
```

当 `R < 0` 时：

```text
预计断货天数 = L - S
到货时预计库存 = 0
预计损失销量 = 预计断货天数 × 日销
基础补货需求 = 120 × 日销
```

例如：

```text
当前库存可支撑9天
采购交期10天

到货时可支撑天数 = 9 - 10 = -1天
```

这表示预计会在新货到达前断货1天。负数不是数据库里的负库存，因此到货时库存最低按0计算；这1天的预计损失销量只作为风险提示，不会重复加入采购数量。

在剔除日销不一致的数据后，共有31个商品被判断为交期内预计断货，预计损失销量合计约520.98件。它们的最终补货量全部为0，原因是仍然受到现有后置规则限制：

| 不补货原因 | 商品数 | 最终补货量 |
|---|---:|---:|
| 被跟卖点不补货 | 15个 | 0件 |
| 同ASIN库存充足不补货 | 15个 | 0件 |
| 同ASIN已合并至主链接 | 1个 | 0件 |

这说明“交期内预计断货”只是风险判断，不会越过跟卖和同ASIN规则强制生成采购数量。

## 六、本次暂不考虑的数据

新旧结果中有371条商品的预测日销不一致：

```text
旧规则补货量：2,403件
新规则补货量：7,475件
差额：+5,072件
```

由于补货数量直接受日销影响，这5,072件不能直接归因于采购交期。本报告将这371条作为异常数据完全剔除，后续单独排查日销为什么不一致。

## 七、最终说明口径

排除日销异常后，新规则净增加4,729件，原因可以概括为：

1. **23个原本库存充足的商品，因为扣除采购交期后提前进入补货层，新增3,562件，这是最主要的增量。**
2. **40个新旧规则都会补货的商品，因为补回交期内预计销量，合计增加1,021件。**
3. **2个同ASIN目标链接变化的商品增加300件，不直接归因于采购交期。**
4. **3个商品由原来补货变为不补货，减少154件。**
5. **交期内预计断货通过“当前可支撑天数小于采购交期”判断，但仍服从跟卖、同ASIN合并等现有拦截规则。**
