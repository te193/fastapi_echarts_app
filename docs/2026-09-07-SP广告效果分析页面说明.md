# SP 广告效果分析页面说明

## 页面入口

- 页面地址：`/ad-performance`
- 菜单位置：经营诊断 → 广告效果分析
- 数据来源：本地 `etl_datasync_test` 库中的 `dashboard_sp_` 结果表
- 当前数据范围：2026-08-01 至 2026-09-06

页面默认使用本地最新数据日向前 30 个完整自然日，默认展示广告商品记录数最多的币种和 7 天归因窗口。金额只在当前所选币种内汇总。

## 五个分析层级

| 页面视图 | 每行统计粒度 | 主要用途 |
|---|---|---|
| MSKU 表现 | 广告账号 + MSKU | 判断单个广告商品的流量与转化表现 |
| 广告活动 | 广告账号 + 活动 | 比较活动投入、规模和产出 |
| 广告组 | 广告账号 + 活动 + 广告组 | 定位广告组，并查看当前关联 MSKU 数量 |
| 关键词 | 广告账号 + 活动 + 广告组 + 关键词 ID + 匹配方式 | 比较关键词及匹配方式表现 |
| 搜索词 | 广告账号 + 活动 + 广告组 + 投放 ID + 匹配方式 + 搜索词 | 分析用户实际搜索词及其投放来源 |

关键词和搜索词按原文区分大小写。页面显示的活动名称、广告组名称、状态、预算和竞价属于当前维度信息，不代表历史日期当天的配置。

## 指标与归因窗口

页面展示曝光、点击、CTR、花费、CPC、订单、销量、广告销售额、CVR、ACOS 和 ROAS。订单、销量、销售额、CVR、ACOS、ROAS 随 1、7、14、30 天归因窗口切换。

比例指标先汇总分子与分母再计算：

- CTR = 点击 / 曝光
- CPC = 花费 / 点击
- CVR = 订单 / 点击
- ACOS = 花费 / 广告销售额
- ROAS = 广告销售额 / 花费

分母为零或来源缺失时显示“—”。趋势中的缺失日期保留断点，不补成零。

## 筛选、下钻与导出

日期、币种、店铺、站点、自动／手动方式、对象文本和关联 MSKU 会同时作用于摘要、趋势、表格和导出。筛选标签可单独移除。

MSKU 详情可下钻到相关广告组；活动可下钻到其广告组；广告组可下钻到关键词或搜索词。MSKU 下钻通过当前广告组商品关联筛选，只统计一次广告组或投放对象指标。页面会提示“关联广告组表现，可能包含其他商品”，这些指标不能视为某一个 MSKU 独占。

CSV 导出覆盖完整筛选范围，不受当前分页限制。文件采用 UTF-8 BOM，业务 ID 和 MSKU 以文本方式保护，并对电子表格公式前缀做转义。

## 接口

- `GET /api/ad-performance/options`
- `GET /api/ad-performance/summary`
- `GET /api/ad-performance/trend`
- `GET /api/ad-performance/rows`
- `GET /api/ad-performance/detail`
- `GET /api/ad-performance/export`

接口中的业务 ID 统一返回字符串。视图、排序字段、排序方向与归因窗口使用白名单；筛选值使用数据库参数绑定。

## 广告建议页面

页面顶部增加“经营总览、竞价优化、加词建议、否词建议、产品诊断、预算管理”导航。建议页固定使用数据截止日前避开最近 7 天、再向前取 30 天的成熟窗口；当前成熟窗口为 2026-08-01 至 2026-08-30，并固定使用 7 天归因订单和销售额。

- 竞价优化直接展示当前竞价、建议竞价、提高/降低金额、调整比例和理论 CPC。提价不超过 20%，降价不超过 30%，并受毛利价格、库存、预算和 MSKU 映射保护。
- 加词建议直接展示具体搜索词以及“新增精准关键词”或“新增商品投放”。
- 否词建议直接展示具体搜索词以及“精准否定”或“否定商品投放”。
- 详情抽屉展示计算指标和中文保护原因。

所有内容仅供人工决策参考。页面没有执行、提交或同步到广告平台的按钮，后端也没有广告写接口。

建议接口：

- `GET /api/ad-performance/recommendations/options`
- `GET /api/ad-performance/recommendations/summary`
- `GET /api/ad-performance/recommendations/rows`
- `GET /api/ad-performance/recommendations/detail`
- `GET /api/ad-performance/recommendations/export`
