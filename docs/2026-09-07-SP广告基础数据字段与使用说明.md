# SP 广告基础数据字段与使用说明

## 数据范围

本数据层仅包含 Sponsored Products（SP）广告效果。首次导入范围为 2026-08-08 至 2026-09-06，共 30 个完整自然日，不包含商品自然流量、总销售和利润。

## 本地结果表

| 表名 | 原始粒度 | 用途 |
|---|---|---|
| `dashboard_sp_campaign_daily` | 日期、账号、活动 | 活动及 Portfolio 表现 |
| `dashboard_sp_ad_group_daily` | 日期、账号、活动、广告组 | 广告组表现 |
| `dashboard_sp_product_ad_daily` | 日期、账号、活动、广告组、广告商品 | MSKU/ASIN 广告表现 |
| `dashboard_sp_keyword_daily` | 日期、账号、活动、广告组、关键词、匹配方式 | 关键词表现 |
| `dashboard_sp_search_term_daily` | 日期、账号、活动、广告组、投放、搜索词 | 用户搜索词表现 |
| `dashboard_sp_ad_group_msku_current` | 广告组、广告商品 | 广告组当前关联的 MSKU |
| `dashboard_sp_etl_batch` | 一次更新任务 | 批次状态和质量检查 |

## 主要字段

- `report_date`：广告报表日期；`seller_name`、`country_code`、`currency_code`：店铺、站点和币种。
- `campaign_*`、`ad_group_*`、`portfolio_*`：广告层级 ID 和当前名称。带 `_current` 的配置是当前状态，不代表历史当天状态。
- `targeting_type`：活动投放方式，通常为 `auto` 或 `manual`。
- `keyword_text` 与 `match_type`：投放关键词和匹配方式；`search_term` 是买家实际搜索词。
- `target_expressions`：商品定位表达式 JSON。一个投放的多个表达式保存在同一字段，避免重复指标。
- `msku`、`asin`：仅在广告商品报表中作为指标的直接归属。关键词和搜索词通过 `associated_msku_count` 说明其广告组当前关联商品数量，不分摊效果。
- `impressions`、`clicks`、`cost`：展示、点击和花费。
- `orders/sales/units`：来源默认口径；后缀 `_1d/_7d/_14d/_30d` 是相应归因窗口。
- `same_orders/same_sales/same_units`：广告商品直接成交及对应窗口。
- `missing_*`：业务键或当前维度未成功关联的质量标记。数据不会因维度缺失被删除。

## 指标计算

- CTR = 点击 / 展示；CPC = 花费 / 点击。
- CVR = 对应归因窗口订单 / 点击。
- ACOS = 花费 / 对应归因窗口广告销售额。
- ROAS = 对应归因窗口广告销售额 / 花费。
- 比例应先汇总分子、分母后计算；分母为零返回 `NULL`。
- 金额按 `currency_code` 分组，不同币种不能直接合计。

## 更新命令

默认更新昨天结束的最近 30 个完整自然日：

```powershell
python -m etl.sp_advertising_update
```

指定日期或只做暂存和质量检查：

```powershell
python -m etl.sp_advertising_update --start 2026-08-08 --end 2026-09-06
python -m etl.sp_advertising_update --start 2026-08-08 --end 2026-09-06 --dry-run
```

正式更新按指定日期范围替换本地结果；失败会回滚发布事务。由于广告转化会晚到，同一日期范围可以重复更新。
