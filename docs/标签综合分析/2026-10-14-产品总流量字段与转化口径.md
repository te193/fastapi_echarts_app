# 产品总流量字段与转化口径

本次按用户要求，将标签综合分析的“流量”列组调整为产品表现的总流量及转化，保持现有页面、标签联动、国家类别／国家视角、经营周期、分页和导出。

## 当前显示字段

| 页面字段 | 产品表现来源 | 汇总方式 |
| --- | --- | --- |
| 总会话数 | `sessions_total` | 同范围对象日合计，包含产品整体会话 |
| 总浏览量（PV） | `page_views_total` | 同范围对象日合计 |
| 商品订单量 | `order_items` | 按商品累加，不能解释为跨商品去重订单数 |
| 订单转化率（CVR） | `order_items`、`sessions_total` | 同批有效对象日订单量合计÷会话合计 |
| 销量转化率 | `volume`、`sessions_total` | 同批有效对象日销量合计÷会话合计，对应销量CVR |
| 浏览器会话数 | `sessions` | 同范围对象日合计 |
| 移动端会话数 | `sessions_mobile` | 同范围对象日合计 |
| 浏览器浏览量 | `page_views` | 同范围对象日合计 |
| 移动端浏览量 | `page_views_mobile` | 同范围对象日合计 |

总会话和PV不互相替代；不把广告点击当成产品总点击，也不按“会话－广告点击”推算自然流量。广告点击、广告曝光及广告CVR仍在广告指标中。原有每次会话销量、每千次会话销售额／毛利等衍生指标保留于字段选择，不再作为流量默认列。

注册表新增 `traffic_sales_qty`（产品表现销量），作为销量CVR的分子，避免用较旧的经营销量与回补后的新会话混算。经营卡片的 `sales_qty`、销售额、利润、库存及补货计算仍取原链路；产品表现销量与经营快照销量可能因回补时点不同而存在差异，不能强行要求相等。商品侧栏的流量专题、走势图、汇总、明细和导出都使用统一数据版本。

## 来源、粒度和版本

只读 `dwd_datasync.lx_statistics_product_performance`。源库名复用每日ETL的 `DASHBOARD_DWD_SOURCE_SCHEMA`，默认 `dwd_datasync`，沿用已有源库连接；不新增数据库字段，不运行ETL或写业务数据。

- 只取 `end_date=start_date` 的单日记录，查询本期及等长上期，条件为可使用日期索引的字符串日期范围。
- 店铺前缀、MSKU标准化和国家类别映射与现行日快照ETL相同。国家视角保持国家字段；国家类别视角在同类别内汇总，不将库存池去重逻辑错误用于经营流量。
- 流量和两个CVR的原始分子、分母同取一次只读一致性事务，不平均日CVR或商品CVR。
- 保留整条日记录缺行按0的用户指定口径；已存在的源记录字段空值、负流量异常或来源连接不可用保持未知。除数为0的转化率不计算。
- 源表版本纳入分析缓存版本。字段以数组在源库按对象、日期聚合读取，准备完成后供交互使用；刷新页面不生成标签、补货或产品表现数据。

公式版本：`label-analysis-20261014-v5-product-traffic`。静态资源版本：`20261014d`。

后台测试覆盖同口径加权CVR、两国同MSKU分别映射、源记录回补不覆盖经营事实、整日无记录为0、来源不可用保持未知、零分母以及日查询范围；无界面浏览器验证流量列组、侧栏、趋势、完整CSV及窄屏展示。验收日志保存在 `.codex_tmp/label_analysis/traffic-*.log`。
