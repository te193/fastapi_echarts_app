# 断货指标与长周期查询说明

标签汇总中的“缺货”列组改为商品断货情况；销量、流量天数和库存观察天数不再占用默认列。销售角色、运营状态和其他标签继续使用同一筛选范围。

## 默认指标

| 指标 | 含义 |
| --- | --- |
| 周期断货商品数 | 周期内至少一天确认FBA可售库存为0的商品数；整期持续零库存也包含在内 |
| 周期断货发生率 | 周期断货商品数÷周期内至少一天库存有效的商品数 |
| 累计断货天数 | 各商品已确认断货天数相加；两个商品各断货3天，累计6天 |
| 缺货天数率 | 累计断货天数÷各商品库存有效天数合计 |
| 断货商品平均断货天数 | 累计断货天数÷周期断货商品数；无断货商品时不计算 |
| 当前断货商品数 | 截止日确认FBA可售库存为0的商品数 |
| 当前断货率 | 当前断货商品数÷截止日库存有效商品数 |
| 连续断货≥7天商品数 | 截止日前至少连续7天确认零库存的商品数；缺失日中断连续记录 |
| 当前已恢复有货商品数 | 周期内曾断货、截止日确认库存大于0的商品数 |
| 周期最长连续断货天数 | 商品周期内最长连续断货天数的群体最大值，改为最大值而非原中位数 |
| 库存记录完整率 | 各商品库存有效天数合计÷各商品应统计天数合计 |

专题的“缺货”页同时显示当前库存不明商品数，提供“查看周期断货商品”“查看当前断货商品”按钮。按钮追加公共数值条件，保留已有标签、店铺、国家等条件；可以返回上层。商品明细显示单商品断货天数、缺货天数率和最长连续断货天数等，群体商品数和群体发生率不作为单商品字段导出。

## 周期及数据边界

- 经营周期支持近7、14、30、60、90、180天，默认仍为30天。汇总、明细、上期对比与导出使用同一周期和数据版本。
- 新增60、180天分析复用截止日已发布的30天标签和当前状态标签；不生成60天/180天销售角色标签。其他原周期保持原标签窗口。页面注明标签口径。
- 截至本次只读核查，库存日快照覆盖2026-01-01至2026-10-13，共286个日期；这是全表日期范围，不保证每个商品每天都有记录。
- 所选周期或上期超出实际库存范围，库存缺失保持未知。产品表现当前来源以实际最早记录为边界，边界之前的流量也保持未知，不按缺行补零；响应给出来源日期和提示。
- 较长周期首次读取需要更多来源数据；已加载周期复用现有缓存，切换标签、排序和分页不重算补货或标签。

## 统计边界

以选定视角的商品对象统计商品数和商品断货天数，库存池数量指标仍另行去重。商品对象数不是跨店铺去重MSKU数。缺失、负库存和重复/映射冲突不计作零库存；有记录且可售库存为0才确认断货。默认所有运营状态，不使用今天的状态标签倒推历史经营资格。

日快照反映库存观察时点，不保证全天断货。连续记录在周期开始或缺失日后起步时，连续断货天数为已确认下限；即使商品后来恢复有货，周期最长连续断货仍保留下限标记。

## 验证

后台测试覆盖持续断货、恢复有货、正常库存、负库存、缺失库存、开边界连续断货、分母及全量/选列一致、60/180天周期、汇总/明细/导出和流量来源边界。

无界面浏览器验证默认列、两个断货下钻按钮、URL恢复、导出字段、桌面及窄屏展示。实际长周期查询的结果和耗时记录在实施记录中。
