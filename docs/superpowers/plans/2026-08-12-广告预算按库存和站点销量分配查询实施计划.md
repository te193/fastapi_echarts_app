# 广告预算按库存和站点销量分配查询实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将现有加权日销 SQL 扩展为按补货库存池和白名单站点销量占比分配月度、周度广告预算的只读查询。

**Architecture:** 继续使用产品表现和 Listing 会话临时表，新增一张库存池会话临时表。最终 CTE 先过滤白名单，再按国家类别、店铺、MSKU计算窗口汇总和分配数量，最后直接返回结果。

**Tech Stack:** MySQL 8、pytest、PyMySQL。

## Global Constraints

- 只处理德国、法国、意大利、西班牙、荷兰、美国、英国。
- 毛利率不参与计算。
- 总库存使用 `available_total + stock_up_num + local_quantity`。
- 月度按30天、周度按7天计算。
- 无销量站点预算为零。
- 当前阶段不得包含建结果表、改结果表、`insert`或结果表查询。
