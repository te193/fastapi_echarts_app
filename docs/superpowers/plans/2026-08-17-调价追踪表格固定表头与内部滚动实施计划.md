# 调价追踪表格固定表头与内部滚动实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将调价追踪页四个主表改为固定表头、表体内部纵向滚动和宽列横向滚动。

**Architecture:** 保留全局 AG Grid 的 `autoHeight` 默认值，只在调价追踪页的三个网格实例中显式启用 `normal` 布局。模板为四个主表提供语义化容器类，页面级 CSS 负责响应式高度；原生国家表复用现有 sticky 表头。

**Tech Stack:** FastAPI/Jinja2、原生 JavaScript、AG Grid Community、CSS、pytest、Playwright headless。

## Global Constraints

- SKU 明细继续使用现有每页 20 条的服务端分页。
- 不修改后端接口、筛选、排序、导出和分页口径。
- 不改变其他页面共用的 AG Grid 默认行为。
- 矩阵和展开详情中的短小辅助表不增加独立滚动区。
- 自动化测试和浏览器验收必须以无界面后台方式运行。
