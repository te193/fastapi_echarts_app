# 断货前销售角色入口与周期筛选实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在“运营状态 → 断货中”卡片内增加可展开的断货前销售角色汇总，支持7天、14天、30天、90天周期切换，并把所选周期和角色带入经营明细及CSV导出。

**Architecture:** 汇总数据由 `LabelHubDataService` 基于同一数据日期的标签事实按“国家类别 + 店铺 + MSKU”关联标签304与标签21，新增只读按需接口供面板加载。经营明细复用现有详情服务，通过专用字段筛选当前断货和标签21周期，避免错误复用首页全局 `label_period`。前端在现有运营状态子标签卡片内渲染入口与展开面板，不新增页面或独立路由。

**Tech Stack:** Python 3、FastAPI、Pydantic、pytest/unittest、原生 JavaScript、CSS。

## Global Constraints

- 不修改标签20、21的远端数据、生成 SQL 或数据库表结构。
- 标签21继续不出现在首页 MSKU 分析卡片、当前分析标签和对比选择器中。
- 当前断货固定使用父标签3、子标签304的 `current` 事实。
- 标签21周期只允许 `7d`、`14d`、`30d`、`90d`。
- 统计主键固定为“国家类别 + 店铺 + MSKU”，不得只按 MSKU 去重。
- 汇总和经营明细继承页面的数据日期、国家类别、店铺和关键词筛选。
- 复用现有经营明细及导出，不新增独立页面。
- 只修改标签中心相关文件，不改动工作区中已有广告预算文件。

@app.get("/api/label-hub/stockout-before-roles")
def api_label_hub_stockout_before_roles(
    data_date: str = "", role_period: str = "30d",
    country_category: str = "all", store: str = "all", keyword: str = "",
) -> dict:
    try:
        return label_hub_service.get_stockout_before_role_summary(
            data_date=data_date, role_period=role_period,
            country_category=country_category, store=store, keyword=keyword,
        )

    except Exception as exc:
        raise HTTPException(status_code=503, detail="断货前销售角色汇总暂不可用，请稍后重试") from exc

```javascript
function loadStockoutBeforeRoles() {
  var token = ++stockoutRoleState.requestToken;
  stockoutRoleState.loading = true;
  renderStockoutBeforeRolePanel();
  return app.apiGet("/api/label-hub/stockout-before-roles", {
    data_date: state.data_date,
    role_period: stockoutRoleState.period,
    country_category: state.country_category,
    store: state.store,
    keyword: state.keyword
  }).then(function (payload) {
    if (token !== stockoutRoleState.requestToken) return;
    stockoutRoleState.payload = payload;
    stockoutRoleState.error = "";
  }).catch(function (error) {
    if (token !== stockoutRoleState.requestToken) return;
    stockoutRoleState.payload = null;
    stockoutRoleState.error = (error && error.message) || "请稍后重试";
  }).then(function () {
    if (token === stockoutRoleState.requestToken) {
      stockoutRoleState.loading = false;
      renderStockoutBeforeRolePanel();
    }
  });
}
```
