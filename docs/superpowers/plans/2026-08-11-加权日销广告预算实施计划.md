# 加权日销广告预算实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在国家站点维度加权日销结果中增加最新 Listing 售价、原币广告预算和人民币广告预算。

**Architecture:** 从远端 Listing 当前同步表按国家、店铺和 MSKU 选取最新有效 `landed_price`，通过月度官方汇率换算人民币售价。先在独立 CTE 中计算一次未舍入的加权日销，再分别计算原币和人民币广告预算，避免重复公式及中间舍入误差。

**Tech Stack:** MySQL 8 CTE、窗口函数、远端 `dwd_datasync`/`etl_datasync` 过程表、只读数据库验证脚本。

## Global Constraints

- 只修改 `data/补货页面加权日销计算.sql`，不改应用页面、ETL 任务或数据库表结构。
- Listing 售价读取 `dwd_datasync.lx_sales_mws_listing.landed_price`，不读取本地售价快照。
- 汇率读取 `dwd_datasync.lx_basic_currency.rate_org`，按 Listing 同步月份关联。
- 原有销量、可售天数、周期日销、加权日销及新品/老品口径保持不变。
- 原币广告预算和人民币广告预算最终保留 2 位小数。
- 售价缺失时两列预算为 `NULL`；仅汇率缺失时原币预算正常返回、人民币预算为 `NULL`。

- [ ] **Step 2: 增加规范化 Listing 源 CTE**

在 `adjusted_daily_sales` 之后增加 `listing_source`，将 Listing 转换成与加权日销一致的业务键，并排除无效售价：

```sql
listing_source AS (
    SELECT
        CASE
            WHEN l.marketplace = '英国' THEN '英国站'
            WHEN l.marketplace IN ('美国', '加拿大', '巴西', '墨西哥') THEN '北美站'
            ELSE '欧洲站'
        END AS country_category,
        l.marketplace AS country,
        CASE
            WHEN LOCATE('-', l.seller_name) > 0
                THEN LEFT(l.seller_name, LOCATE('-', l.seller_name) - 1)
            ELSE l.seller_name
        END AS seller_name_new,
        l.seller_sku AS seller_sku_adj,
        CAST(NULLIF(l.landed_price, '') AS DECIMAL(18,4)) AS listing_price,
        l.currency_code,
        l.create_time,
        CASE UPPER(l.currency_code)
            WHEN 'EUR' THEN '欧元'
            WHEN 'PLN' THEN '波兰兹罗提'
            WHEN 'SEK' THEN '瑞典'
            WHEN 'TRY' THEN '土耳其里拉'
            WHEN 'GBP' THEN '英镑'
            WHEN 'USD' THEN '美元'
            WHEN 'CAD' THEN '加元'
            WHEN 'MXN' THEN '墨西哥比索'
            WHEN 'BRL' THEN '巴西雷亚尔'
            ELSE NULL
        END AS currency_name
    FROM dwd_datasync.lx_sales_mws_listing AS l
    CROSS JOIN params AS prm
    WHERE NULLIF(TRIM(l.landed_price), '') IS NOT NULL
      AND CAST(l.landed_price AS DECIMAL(18,4)) > 0
      AND l.seller_sku IS NOT NULL
      AND l.seller_sku <> ''
      AND (prm.target_msku = '' OR l.seller_sku = prm.target_msku)
)
```

- [ ] **Step 3: 每个国家站点业务键只保留最新售价**

增加 `listing_ranked` 和 `listing_latest`：

```sql
listing_ranked AS (
    SELECT
        l.*,
        ROW_NUMBER() OVER (
            PARTITION BY
                l.country_category,
                l.country,
                l.seller_name_new,
                l.seller_sku_adj
            ORDER BY l.create_time DESC, l.listing_price DESC
        ) AS price_rank
    FROM listing_source AS l
),
listing_latest AS (
    SELECT
        l.country_category,
        l.country,
        l.seller_name_new,
        l.seller_sku_adj,
        l.listing_price,
        UPPER(l.currency_code) AS currency_code,
        l.create_time AS listing_create_time,
        CAST(NULLIF(c.rate_org, '') AS DECIMAL(18,8)) AS exchange_rate_cny
    FROM listing_ranked AS l
    LEFT JOIN dwd_datasync.lx_basic_currency AS c
           ON l.currency_name = c.name
          AND DATE_FORMAT(l.create_time, '%Y-%m') = c.date
    WHERE l.price_rank = 1
)
```

`SEK` 明确映射为汇率表中的“瑞典”，不要使用不存在的“瑞典克朗”。

- [ ] **Step 4: 将最终加权日销提取为可复用 CTE**

把当前最终 `CASE` 公式移入 `weighted_metrics`，公式本身不改变且暂不舍入：

```sql
weighted_metrics AS (
    SELECT
        a.*,
        CASE
            WHEN a.is_new_product = 1 THEN
                a.daily_sales_3d * 0.5
                + a.daily_sales_7d * 0.5
            ELSE
                a.daily_sales_7d * 0.6
                + a.daily_sales_14d * 0.2
                + a.daily_sales_30d * 0.2
        END AS daily_avg_sales
    FROM adjusted_daily_sales AS a
)
```

- [ ] **Step 5: 连接最新售价并输出预算字段**

最终查询由 `weighted_metrics w` 左连接 `listing_latest lp`：

```sql
LEFT JOIN listing_latest AS lp
       ON w.country_category = lp.country_category
      AND w.country = lp.country
      AND w.seller_name_new = lp.seller_name_new
      AND BINARY w.seller_sku_adj = lp.seller_sku_adj
```

保留原字段，并在 `daily_avg_sales` 后追加：

```sql
ROUND(lp.listing_price, 4) AS listing_price,
lp.currency_code,
ROUND(lp.exchange_rate_cny, 4) AS exchange_rate_cny,
ROUND(lp.listing_price * lp.exchange_rate_cny, 2) AS listing_price_cny,
ROUND(lp.listing_price * 0.05 * w.daily_avg_sales * 30, 2) AS ad_budget_original,
ROUND(
    lp.listing_price * lp.exchange_rate_cny
    * 0.05 * w.daily_avg_sales * 30,
    2
) AS ad_budget_cny
```

MySQL 的空值传播保证：Listing 缺失时两列预算为 `NULL`；仅汇率缺失时原币预算仍可计算，人民币预算为 `NULL`。
