# 广告预算产品标识与复制交互实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在广告预算主表中明确展示市场/国家、店铺、MSKU、ASIN，并为 MSKU 和 ASIN 提供独立复制按钮及状态反馈。

**Architecture:** 继续复用 `/api/ad-budget` 的现有字段，只调整 `rowHtml` 的产品单元格模板和表格事件委托。复制行为集中在一个前端函数中，阻止事件冒泡后调用 Clipboard API，并提供兼容性回退与按钮反馈。

**Tech Stack:** FastAPI、Jinja2、原生 JavaScript、CSS、pytest、Playwright CLI。

## Global Constraints

- 站点格式固定为“市场 / 国家”。
- 复制内容只包含编码本身。
- ASIN 缺失时显示“—”且复制按钮禁用。
- 点击复制按钮不能触发详情抽屉。
- 不新增接口、数据库字段或第三方依赖。
