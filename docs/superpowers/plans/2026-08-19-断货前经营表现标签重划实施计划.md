# 断货前经营表现标签重划实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将当前断货中的产品按已确认规则划分为 8 个互斥且完备的断货前经营表现标签。

**Architecture:** 后端以当前断货事实为全集，先判断低量库存，再验证远端断货前角色证据，最后按周期销量、远端角色和毛利划分经营表现。前端只消费汇总接口，展示两组八类结果和与后端一致的规则说明。

**Tech Stack:** FastAPI、Python、原生 JavaScript、pytest

**Spec:** `docs/断货经营状态标签规则.md`

## Global Constraints

- 不修改原“断货中”和原“断货前销售角色”规则。
- 低量边界严格为剩余库存合计 `< 5`，等于 5 时继续评价。
- 销售角色直接使用远端固定结果，不在本地重算。
- 八类互斥且合计等于当前断货总数。
