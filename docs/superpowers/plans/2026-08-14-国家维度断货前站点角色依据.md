# 国家维度断货前站点角色依据 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在国家明细中展示标签 21 的站点角色，并按当前国家读取对应的断货前依据 JSON。

**Architecture:** 扩展现有依据接口，使 `country` 成为标签 20/21 的数据源路由条件；明细服务将标签 21 的四周期角色合并到国家行；前端复用现有列与弹窗，根据 `detail_view` 传入国家并切换标题。所有改动保持标签 20 的 MSKU 逻辑不变。

**Tech Stack:** FastAPI、PyMySQL、原生 JavaScript、AG Grid、unittest/pytest、Microsoft Edge Playwright headless。

## Global Constraints

- 国家明细必须按 `data_date + country_category + store + msku + country + label_period` 精确匹配标签 21。
- 默认展示 `30d`，已有明确周期时沿用明确周期。
- 不允许使用其他国家或标签 20 为国家明细兜底。
- 测试和浏览器验证只能在隐藏后台运行。
