# 加权日销国家维度实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将远端过程表计算的加权日销下钻到国家维度，同时保持新品/老品由国家类别统一判断。

**Architecture:** 在产品表现源数据中保留原始 `country`，国家明细指标按 `country + country_category + seller_name_new + seller_sku_adj` 聚合。品牌和接收次数继续按 `country_category + seller_name_new + seller_sku_adj` 聚合，随后连接到国家明细，使同一国家类别下的国家继承相同新品/老品结果。

**Tech Stack:** MySQL 8 CTE、远端 `dwd_datasync`/`etl_datasync` 过程表、只读数据库验证脚本。

## Global Constraints

- 只修改 `data/补货页面加权日销计算.sql`，不改应用页面、ETL任务或数据库表结构。
- 只读取远端过程表，不读取补货结果表。
- 不计算跟卖补偿、补货数量、库存支撑天数等其他指标。
- 国家独立计算3/7/14/30天销量、可售天数、周期日销和最终加权日销。
- 新品/老品仍按国家类别、店铺、MSKU统一判断，并下发给国家明细。

### Task 1: 增加国家维度并验证继承关系

**Files:**
- Modify: `data/补货页面加权日销计算.sql`

**Interfaces:**
- Consumes: `dwd_datasync.lx_statistics_product_performance.country` 原始国家字段，以及现有国家类别品牌和接收次数判断。
- Produces: 每行唯一粒度为 `biz_date + country_category + country + seller_name_new + seller_sku_adj` 的周期指标和 `daily_avg_sales`。

- [ ] **Step 1: 在产品源数据中保留国家字段**

在 `product_source` 的选择列表中加入：

```sql
p.country AS country
```

保持现有 `country_category` 映射不变。

- [ ] **Step 2: 将每日聚合调整为国家粒度**

在 `product_daily` 的选择和分组字段中加入 `country`：

```sql
SELECT
    dt_date,
    country_category,
    country,
    seller_name_new,
    seller_sku_adj,
    SUM(sales_qty) AS sales_qty,
    MAX(afn_fulfillable_quantity) AS afn_fulfillable_quantity
FROM product_source
GROUP BY
    dt_date,
    country_category,
    country,
    seller_name_new,
    seller_sku_adj
```

- [ ] **Step 3: 将周期指标调整为国家粒度**

在 `period_metrics` 中选择 `p.country`，并将分组改为：

```sql
GROUP BY
    p.country_category,
    p.country,
    p.seller_name_new,
    p.seller_sku_adj
```

3/7/14/30天销量和可售天数的 `CASE` 表达式保持不变。

- [ ] **Step 4: 保持新品/老品国家类别粒度**

不要给 `product_brand`、`shipment_receiving_count` 或 `receiving_metrics` 增加 `country`。`metric_base` 继续只用以下条件连接品牌和接收次数：

```sql
m.country_category = b.country_category
AND m.seller_name_new = b.seller_name_new
AND m.seller_sku_adj = b.seller_sku
```

```sql
m.country_category = r.country_category
AND m.seller_name_new = r.seller_name_new
AND m.seller_sku_adj = r.msku
```

这样同一国家类别下的所有国家获得相同 `max_brand_name`、`receiving_cnt` 和 `is_new_product`。

- [ ] **Step 5: 在最终输出中增加国家**

在最终字段中将 `country` 放在 `country_category` 后，并将排序改为：

```sql
ORDER BY
    a.country_category,
    a.country,
    a.seller_name_new,
    a.seller_sku_adj
```
