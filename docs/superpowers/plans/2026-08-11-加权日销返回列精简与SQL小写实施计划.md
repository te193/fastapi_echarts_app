# 加权日销返回列精简与 SQL 小写实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 删除最终结果中的四个周期日销展示列，并将整份 SQL 的关键字和内置函数统一为小写，同时保持加权日销及广告预算数值不变。

**Architecture:** 只修改独立 SQL 资产及其静态契约测试。周期日销继续在 CTE 内部计算并参与加权，最终 `select` 仅停止输出这四列；通过静态测试约束返回列和小写风格，再使用 `opt_db` 会话临时表进行真实集成验证。

**Tech Stack:** MySQL 8、Python、pytest、PyMySQL。

## Global Constraints

- 保留 `sales_3/7/14/30` 和对应的 `r_*_salable_days` 最终返回列。
- 删除最终返回的 `daily_sales_3d/7d/14d/30d`，保留 `daily_avg_sales`。
- 不改变新品、老品判断、加权公式、Listing、汇率和广告预算逻辑。
- SQL 关键字和内置函数使用小写；表名、字段名、别名和字符串业务值保持原样。
- 两张过程表继续使用会话级 `create temporary table`，最终结果继续直接查询，不落表。
