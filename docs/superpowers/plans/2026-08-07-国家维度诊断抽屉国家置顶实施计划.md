# 国家维度诊断抽屉国家置顶实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 国家维度点击“查看诊断”后，将点击行对应国家稳定置于抽屉国家明细首位并默认展开。

**Architecture:** 只在前端抽屉状态中保存焦点国家。渲染时复制接口返回的国家数组并执行稳定置顶，不修改接口、诊断服务或原始数据顺序。

**Tech Stack:** 原生 JavaScript、AG Grid、pytest 前端静态契约测试

## Global Constraints

- 仅在 `detailState.detail_view === "country"` 且行内存在 `country` 时设置焦点国家。
- 其他国家保持接口原有相对顺序。
- 切换诊断周期后继续置顶当前国家；找不到时回退到原顺序和首项展开。
- 不修改后端接口、分类规则、筛选逻辑和业务数据。
- 不改动工作区中已有的补货相关未提交文件。

```javascript
function prioritizeRoleDiagnosticCountry(countries, focusCountry) {
  var items = (countries || []).slice();
  var normalizedFocus = String(focusCountry || "").trim();
  if (!normalizedFocus) return items;
  var focusIndex = items.findIndex(function (item) {
    return String((item || {}).country || "").trim() === normalizedFocus;
  });
  if (focusIndex <= 0) return items;
  return [items[focusIndex]].concat(items.slice(0, focusIndex), items.slice(focusIndex + 1));
}
```

打开抽屉时仅在国家维度设置 `focusCountry`；周期切换保留该字段。渲染时使用稳定置顶后的副本，并在焦点国家存在时将其设为默认展开项，否则展开首项。
