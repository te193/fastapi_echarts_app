# 返场后截止销量动态展示实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让返场品列表和详情按事件退出状态展示返场日至正确截止日的累计销量。

**Architecture:** 保留 ETL 和数据库字段的既有含义，只在 `ReturnGoodsDataService._serialize_item` 的接口展示边界选择动态值。前端继续消费 `post_recovery_sales_qty`，但将标题统一改为“返场后截止销量”。

**Tech Stack:** Python 3、FastAPI 服务层、pytest/unittest、原生 JavaScript。

## Global Constraints

- 第 22 天正常退出展示返场后前 21 天销量。
- 第 22 天以后退出展示返场日至退出日累计销量，包含退出当天。
- 截至统计日未退出展示返场日至统计日累计销量。
- 累计字段缺失时回退到现有返场后对比销量。
- 不修改数据库字段、ETL 计算和恢复率口径。

```python
post_recovery_sales_qty = number_value(row.get("post_recovery_sales_qty"))
post_cumulative_sales_qty = number_value(row.get("post_cumulative_sales_qty"))

    post_recovery_sales_qty = post_cumulative_sales_qty
```
