# 返场品表格排序修复实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 修复返场品最新状态表格中百分比、趋势和复合信息列的错误或无意义排序。

**Architecture:** 保持后端接口不变，在前端 AG Grid 列定义中分离“用于比较的值”和“用于展示的值”。百分比列绑定原始数值，趋势列通过 `valueGetter` 返回最终展示文字，缺乏唯一排序语义的复合列关闭排序与筛选。

**Tech Stack:** 原生 JavaScript、AG Grid、pytest。

## Global Constraints

- 不改变后端恢复率计算逻辑。
- 不调整表格布局、列顺序或展示文案。
- 不为复合列新增由业务定义的排序指标。
- 只修改返场品表格列定义及其聚焦测试。
