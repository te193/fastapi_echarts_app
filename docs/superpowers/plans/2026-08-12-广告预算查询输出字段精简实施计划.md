# 广告预算查询输出字段精简实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 从广告预算查询最终结果中删除两个快照日期字段和数据状态字段，同时保留内部库存完整性保护。

**Architecture:** 只修改最终 `select` 的输出契约，不删除临时表和 CTE 中的快照字段。测试通过截取最终 `select` 片段验证三个字段不再输出，同时验证快照字段仍参与分配保护。

**Tech Stack:** MySQL 8 SQL、Python、pytest

## Global Constraints

- 最终结果不返回 `inventory_snapshot_date`、`restock_snapshot_date`、`budget_data_status`。
- 内部继续使用两个快照日期保护月度分配、周度分配和总预算池。
- 其他37个字段的名称、顺序和计算口径保持不变。
- 不增加 `insert` 或持久化结果表。
