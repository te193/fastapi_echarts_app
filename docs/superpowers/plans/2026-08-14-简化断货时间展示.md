# 简化断货时间展示 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 断货依据弹窗只突出断货开始日期和截至所选标签日期的累计断货天数。

**Architecture:** 保留 JSON 的 `oos.oos_start_date` 作为开始日期，继续使用现有 `evidenceStockoutDays(startDate, identity.data_date)` 计算累计天数。删除默认时间视图中的历史观察、库存阈值、快照和内部规则展示；审计用的原始 JSON 页签保持不变。

**Tech Stack:** 原生 JavaScript、CSS、pytest 前端契约测试、后台 Microsoft Edge。

## Global Constraints

- 所有浏览器验证必须使用后台无界面的 Microsoft Edge。
- 不弹出 CMD 或浏览器窗口。
- 不修改 JSON 数据结构或后端计算逻辑。
