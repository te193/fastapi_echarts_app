# SP 广告建议展示实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 基于成熟 30 天 SP 广告数据生成具体的竞价、加词和否词建议，并在现有广告效果分析页中快速展示、查看详情和导出。

**Architecture:** 建议构建命令从本地广告日表及经营快照读取数据，使用纯规则模块计算后写入批次化结果表。FastAPI 服务只查询已发布建议结果，不在页面请求期间扫描事实表；前端沿用 Jinja、AG Grid 和现有右侧抽屉。

**Tech Stack:** Python 3、FastAPI、PyMySQL、MySQL 8、Jinja2、原生 JavaScript、AG Grid、pytest、Playwright。

**Spec:** `docs/superpowers/specs/2026-09-07-SP广告建议展示设计.md`

## Global Constraints

- 成熟窗口固定为数据截止日前避开 7 天，再向前取连续 30 天；2026-09-06 对应 2026-08-01 至 2026-08-30。
- 建议指标固定使用 7 天归因字段，金额只在同一币种内计算。
- 首版只展示和导出建议，不调用广告平台写接口，也不提供执行按钮。
- 多 MSKU、未映射、保护字段缺失和定价异常进入人工复核，不分摊广告指标。
- 页面 API 只读取本地已发布建议结果表。
- 自动化验证、服务和浏览器截图均使用隐藏后台或 headless 模式。
