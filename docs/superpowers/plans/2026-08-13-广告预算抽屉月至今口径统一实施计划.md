# 广告预算抽屉月至今口径统一实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将广告预算详情抽屉的经营数据、广告漏斗、预算执行与累计趋势统一为本月至今口径。

**Architecture:** 继续复用 `AdBudgetService._load_rows()` 已有的月累计字段，只补充月累计广告销售占比；详情趋势查询起点改为表现日期所在月的 1 日。前端抽屉不再读取 `_7d` 指标，预算阶梯直接展示月预算、本月花费和月剩余额度。

**Tech Stack:** FastAPI、Python 3、PyMySQL、原生 JavaScript、ECharts、pytest。

## Global Constraints

- 统计区间固定为当月 1 日至最新表现日期。
- 主表近 7 天指标和异常规则保持原样。
- 分母为 0 时比例返回空值并显示“—”。
- 月预算缺失时月剩余额度显示“—”，超预算时允许显示负数。
- 不新增数据库字段或第三方依赖。
