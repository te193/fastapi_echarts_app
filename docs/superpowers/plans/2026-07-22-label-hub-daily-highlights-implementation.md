# 标签看板今日重点变化实施计划

## 目标

在不改变现有标签、经营指标和明细口径的前提下，将已确认效果图中的页内导航和“今日重点变化”落到 `/label-hub`。重点变化异步加载，不阻塞主看板；完整变化明细继续复用现有右侧抽屉。

## 实施步骤

1. 为重点变化增加轻量汇总服务与只读接口，复用已有两期变化结果，按固定阈值筛出最多 5 条事件。
2. 为接口补充契约测试，验证缺失经营数据被排除、事件阈值、方向和固定排序。
3. 在筛选区后增加页内锚点导航，在问题概览和多维联动之间增加重点变化表格。
4. 重点变化行支持“筛选该群体”和“查看变化明细”；后者继续打开已有变化抽屉。
5. 统一锚点、重点变化表格、状态徽标和窄屏样式，并静默运行标签看板相关测试与全量测试。

## 验收标准

- 首屏主数据不等待变化接口。
- 重点变化最多 5 条，不展示“暂无经营数据”。
- 排序不使用评分：先按绝对变化，再按新出现/消失、变化率和风险方向稳定排序。
- 点击页内导航能到达覆盖、问题、重点变化、联动、关系和明细区域。
- 点击重点变化可筛选对应群体或打开变化抽屉，不破坏现有 URL、分页和标签画像。
