# 补货追踪完成状态展示实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在补货追踪汇总中分别展示并筛选 FBA 已接收、本次链路全部关闭和历史 FBA 已完成 MSKU。

**Architecture:** 保持 ETL 与表结构不变，在现有汇总服务中增加一个聚合字段和一个筛选分支；前端复用状态卡渲染及点击筛选机制。测试覆盖后端 SQL 契约、筛选条件和用户可见卡片。

**Tech Stack:** FastAPI、PyMySQL、原生 JavaScript、pytest

## Global Constraints

- `fba_closed_flag = 1` 继续表示本次链路全部货件关闭。
- `fba_receiving_flag = 1` 表示本次链路至少一个货件已开始接收。
- `historical_fba_completed_count > 0` 只表示历史未归因货件已完成，不计入本次链路完成率。
- 不修改数据库表结构和 ETL 判定逻辑。
