# 标签看板筛选数据 CSV 导出实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 为标签看板经营明细增加导出当前筛选全集的 CSV 按钮，按 MSKU 或国家站点粒度输出完整中文经营字段，并包含唯一库存指标“可售库存”。

**Architecture:** 现有 `LabelHubDetailDataService` 继续作为筛选和排序的唯一口径，通过新增全量明细入口绕过分页切片。独立的导出服务负责中文列映射、数据格式化、CSV 流和文件名；FastAPI 路由只负责异常映射与下载响应，前端复用当前明细请求载荷触发下载。

**Tech Stack:** Python 3、FastAPI、Pydantic、标准库 `csv`/`io`、原生 JavaScript、pytest/unittest。

## Global Constraints

- 导出当前筛选和当前排序对应的全部数据，不受当前页和每页条数影响。
- `business_unit` 一行对应“国家类别 + 店铺 + MSKU”；`country` 一行对应“国家 + 国家类别 + 店铺 + MSKU + SKU”。
- 导出列名使用中文，CSV 使用 UTF-8 BOM，Excel 可直接打开。
- 字段视图不裁剪导出列；空值导出为空单元格；布尔值导出为“是/否”。
- 库存仅导出“可售库存”，值为经营周期末当天的 FBA 可售库存快照；不增加其他库存或派生库存指标。
- 不新增第三方依赖，不重构与本功能无关的代码。
