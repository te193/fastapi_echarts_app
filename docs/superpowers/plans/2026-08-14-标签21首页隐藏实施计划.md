# 标签21首页隐藏实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 从标签中心首页 MSKU 分析入口隐藏父标签21，同时保留下方明细筛选中的2101—2104。

**Architecture:** 复用现有 `EXCLUDED_ANALYSIS_PARENT_IDS` 分流机制。首页分类、当前分析标签和对比选择器读取分析分类；明细筛选继续合并普通分类与 `excluded_categories`，无需修改前端接口结构。

**Tech Stack:** Python 3、FastAPI 服务层、unittest/pytest、原生 JavaScript。

## Global Constraints

- 不删除或修改标签20、21的远端数据和生成规则。
- 不修改数据库表结构。
- 标签21必须保留在明细标签筛选中。
- 仅做与首页分析口径相关的最小改动。
