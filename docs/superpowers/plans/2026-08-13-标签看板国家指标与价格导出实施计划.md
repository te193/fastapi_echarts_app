# 标签看板国家指标与价格导出 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 为国家明细统一计算 ACOS/TACOS，并在国家明细 CSV 中增加精简价格字段。

**Architecture:** 在 `CountryLabelHubDataService` 的国家行收尾逻辑中计算广告比率，覆盖主日表与年度事实表兜底路径；新增按请求批量读取最新售价和限价快照的内部入口，用四字段站点键合并到国家行。`LabelHubExportService` 仅负责把国家行已有字段映射为中文 CSV 列。

**Tech Stack:** Python 3、MySQL、标准库 `csv`、pytest/unittest。

## Global Constraints

- ACOS = 广告花费 ÷ 广告销售额；TACOS = 广告花费 ÷ 销售额。
- 分母为空或小于等于 0 时比率为空。
- 价格按“国家类别 + 店铺 + MSKU + 国家站点”关联，必须批量查询，禁止逐行查询。
- 国家明细新增当前售价、售价币种、当前售价（人民币）、价格快照日期、35%毛利限价、10%毛利限价、当前毛利区间。
- MSKU 维度不新增站点价格列。
- 价格来源异常不得阻断导出；价格字段留空。
- 不新增第三方依赖，不修改页面交互，不增加其他库存列。
