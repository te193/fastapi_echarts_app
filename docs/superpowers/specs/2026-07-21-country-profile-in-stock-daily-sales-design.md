# 国家画像日均销量库存天数口径设计

## 目标

将标签汇总页国家明细画像中的“日均”从“周期销量 ÷ 周期自然天数”调整为“周期销量 ÷ 有库存天数”，并在逐国明细表上方增加一块与补货页面风格一致的 MSKU 基本信息区。本次只调整国家明细画像，不改变其他页面或销售角色周期快照的日均口径。

## 指标口径

- 有库存天数：指标周期内，当前国家、店铺、MSKU 的 `afn_fulfillable_quantity > 0` 的去重日期数。
- 日均销量：周期累计 `sales_qty / inventory_days`。
- 当 `inventory_days = 0` 时，日均销量返回 `0`，避免除零并与无库存场景保持一致。
- 页面继续沿用现有数值格式，不新增说明文字或字段。

## 数据流与改动范围

国家画像的按国家经营指标查询增加 `inventory_days` 聚合字段。服务层用该字段计算 `daily_sales`，已有前端日均字段继续复用。

同一查询同时取得一个代表 SKU，口径与补货页面一致，使用当前 MSKU 在经营明细中的 `max(local_sku)`。API 的 `identity` 增加 `sku`，前端在逐国明细表上方展示以下紧凑信息：

- MSKU
- SKU
- 店铺
- 国家类别
- 覆盖国家数
- 当前经营周期销量（默认 30 天）

各国家自己的 Listing SKU 不进入基本信息区，仍保留在逐国明细中。

## 验证

- 回归测试覆盖有库存天数小于周期天数时按库存天数计算。
- 回归测试覆盖有库存天数为零时返回零。
- 回归测试覆盖代表 SKU 和国家数量进入国家画像响应及页面基本信息区。
- 运行国家标签汇总相关测试，确认既有字段和页面行为不回归。
