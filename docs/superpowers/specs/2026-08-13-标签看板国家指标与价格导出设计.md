# 标签看板国家指标与价格导出设计

## 目标

修复标签看板“国家明细”导出中 ACOS、TACOS 大面积为空的问题，并在国家明细 CSV 中增加用户确认的精简价格字段。MSKU 维度导出保持现状。

## 指标口径

- ACOS = 经营周期内广告花费 ÷ 经营周期内广告销售额。
- TACOS = 经营周期内广告花费 ÷ 经营周期内销售额。
- 分母为空或小于等于 0 时结果留空，不以 `0%` 伪装成有效指标。
- 计算放在国家明细行的统一收尾逻辑中，使日表和年度事实表兜底两条数据路径使用相同口径。

## 价格字段

仅在国家明细导出增加：

1. 当前售价
2. 售价币种
3. 当前售价（人民币）
4. 价格快照日期
5. 35%毛利限价
6. 10%毛利限价
7. 当前毛利区间

当前售价来自 `etl_datasync.dashboard_listing_price_daily_snapshot` 最新快照；35% 和 10% 毛利限价来自 `etl_datasync.dashboard_limit_price_daily_snapshot` 最新快照。关联键为“国家类别 + 店铺 + MSKU + 国家站点”。价格快照日期明确导出，避免将快照价格误认为经营周期累计值。

“当前毛利区间”复用国家画像已有的价格阶梯判定函数。虽然 CSV 只展示 35% 和 10% 两个限价，区间判定仍使用完整的 35%、30%、25%、20%、15%、10%、5%、0% 阶梯，保证区间结果准确。

## 数据加载与性能

价格数据按当前国家明细请求范围批量查询并构建关联映射，不对每一行单独查询。价格来源异常时不阻断经营指标和标签导出，对应价格列留空。

国家明细基础行在经营指标合并后再合并价格映射。价格仅作为补充字段，不参与现有筛选、排序、问题判断和分页。

## CSV 表现

- 新价格列仅出现在国家明细维度，MSKU 维度不增加站点价格。
- ACOS、TACOS 继续按百分比文本导出，例如内部值 `0.25` 导出为 `25.00%`。
- 金额和价格保持数值，不拼接币种符号；币种单独一列，便于 Excel 分析。
- 价格缺失、限价缺失、分母为零时导出空单元格。

## 验收标准

- 国家明细行广告销售额为正时，ACOS 使用广告花费除以广告销售额。
- 国家明细行销售额为正时，TACOS 使用广告花费除以销售额。
- 两项指标的分母为零时均为空。
- 主日表与年度事实表兜底路径都返回相同的 ACOS/TACOS 口径。
- 国家明细 CSV 包含七个精简价格列并正确写入关联值。
- MSKU 维度 CSV 不包含上述站点价格列。
- 价格查询按请求批量执行，不产生逐行查询。
- 价格数据源失败时 CSV 仍可生成，价格列为空。
