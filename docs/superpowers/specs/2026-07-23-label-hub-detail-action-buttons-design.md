# 标签看板明细筛选按钮视觉优化

## 目标

让“应用筛选”和“重置”与标签看板现有的蓝灰色视觉体系保持一致，并明确主次操作层级。

## 设计

- “应用筛选”使用实心蓝色主按钮，白色文字，保留 36px 高度和 6px 圆角。
- “重置”使用白底浅灰描边次按钮，蓝灰色文字，避免与主操作竞争。
- 两个按钮统一边框、字重、横向内边距，并补充悬停、按下和键盘聚焦状态。
- 不修改按钮文案、位置、DOM 标识、事件绑定或筛选逻辑。

## 验收

- 主按钮与页面蓝色选中态协调，不再呈现黑色粗边框。
- 次按钮具备按钮轮廓，但视觉权重明显低于主按钮。
- 现有前端契约测试与全量测试通过。
