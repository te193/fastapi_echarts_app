# 标签21首页隐藏设计

## 背景

标签21“断货前销售角色（站点）”按国家站点维度生成。标签中心首页按“国家类别 + 店铺 + MSKU”经营单元汇总，因此将标签21展示为首页分类、当前分析标签或对比标签，会把站点事实误解为 MSKU 经营单元标签。

## 目标

- 标签21不出现在首页分类卡片。
- 标签21不出现在首页“当前分析标签”和对比分析选择器。
- 标签21继续出现在下方明细的标签筛选中。
- 标签21的远端事实、国家明细和数据库生成逻辑保持不变。

## 设计

将标签21加入现有的“首页分析排除标签”集合。首页分类和分析选择器使用过滤后的分类；被排除分类仍通过 `excluded_categories` 返回，明细筛选会合并普通分类与排除分类，因此继续保留标签21。

不只在前端隐藏卡片，以免标签21仍出现在首页其他分析入口。国家站点事实仍按原逻辑加载到明细服务，不改变查询和筛选能力。

## 数据流

1. 远端标签详情和标签事实照常加载。
2. 首页分类、当前分析标签和对比标签构建时排除父标签ID 21。
3. 明细标签选项仍从完整标签定义构建，因此保留父标签ID 21及其子标签2101—2104。

## 测试与验收

- 回归测试证明首页分析分类不包含父标签ID 21。
- 回归测试证明明细可筛选分类仍包含父标签ID 21。
- 其他标签分类不受影响。
- 现有标签中心测试全部通过。

## 非目标

- 不删除标签21数据。
- 不修改标签20或标签21的生成规则。
- 不修改数据库表结构。
- 不调整下方国家明细的展示与查询。
