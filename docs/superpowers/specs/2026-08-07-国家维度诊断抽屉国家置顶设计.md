# 国家维度诊断抽屉国家置顶设计

## 背景

经营明细切换到国家维度后，用户从某一国家记录点击“查看诊断”，抽屉中的“各国家子标签与问题情况”仍完全按照问题优先级排列，当前点击国家不一定出现在首位，查看成本较高。

## 目标

- 国家维度打开销售角色诊断抽屉时，将当前点击行对应的国家稳定置于国家明细首位。
- 当前国家默认展开，直接展示其子标签、未达标指标和升级差距。
- 除当前国家外，其他国家继续保持接口既有的问题优先级和相对顺序。
- 不改变诊断接口、分类规则、筛选逻辑和业务数据。

## 交互规则

1. 仅当经营明细处于国家维度，且点击行中存在国家字段时，记录该国家为本次抽屉的焦点国家。
2. 抽屉加载完成后，将焦点国家从原位置稳定移动到第一位，其余国家不重新排序。
3. 焦点国家默认展开；用户仍可折叠或展开任意国家。
4. 用户切换 7d、14d、30d、90d 诊断周期后，继续保持焦点国家置顶，并在重新加载后默认展开该国家。
5. 若新周期数据中不存在焦点国家，则保留接口原排序，并默认展开原排序第一项。
6. 从 MSKU 维度或其他不含明确国家的入口打开抽屉时，保持现有行为。

## 技术方案

- 在前端销售角色诊断抽屉状态中增加焦点国家字段。
- 打开抽屉时根据当前明细维度和行数据设置焦点国家。
- 渲染国家诊断列表前，复制接口数组并执行稳定置顶：找到焦点国家后，将该项放到首位，前后其余元素按原顺序拼接。
- 不直接修改接口返回数组，避免影响缓存数据或其他渲染逻辑。
- 周期切换只重置展开状态，不清除焦点国家；重新渲染时优先展开焦点国家。

## 验证范围

- 国家维度点击法国：法国位于首位并展开，其余国家相对顺序不变。
- 点击原本已在首位的国家：顺序不发生额外变化。
- 切换诊断周期：当前国家仍置顶；该周期无该国家时正确回退。
- MSKU 维度打开抽屉：继续按原问题优先级排列。
- 国家名称为空或缺失：不执行置顶，不产生前端异常。
