# 国家站点销售角色分布设计

## 目标

国家站点诊断不再隐式只展示“与全站角色相同”的诊断标签。页面先展示当前全站角色群体在国家站点中的角色分布，再允许点击某个站点角色展开具体诊断原因。

## 数据口径

- 基础群体继续由当前公共筛选、销售角色条件和标签周期确定。
- 国家站点角色按父标签 16 的子标签分为：
  - 明星：1601
  - 潜力：1602–1606
  - 瘦狗：1607–1613
  - 问题/异常：1614–1618
- 国家记录数按标签事实逐条统计。
- 涉及商品数按 `国家类别 + 店铺 + MSKU` 去重。
- 国家记录占比以当前基础群体的全部父标签 16 国家记录为分母，四个角色合计为 100%。
- 同一商品可在不同国家落入不同角色，因此各角色的涉及商品数不可相加。
- 毛利润在每个角色内按店铺商品去重汇总。
- 较上期按同周期、同角色的国家记录数计算。

## 交互与布局

- 国家站点诊断显示全宽层级表格，移除右侧“当前最值得关注”重复摘要。
- 第一层为站点明星、站点潜力、站点瘦狗、站点问题/异常。
- 第一层展示国家记录数、涉及商品数、国家记录占比、较上期、毛利润和证据覆盖率。
- 点击第一层行，在其下展开对应诊断子标签。
- 子标签行仍可点击，继续作为父标签 16 的筛选条件。
- 全站点诊断保留现有诊断原因表格，但同样移除右侧重复摘要。
- 空数据时保留现有空状态。

## 响应式

- 桌面端表格全宽显示。
- 窄屏保留角色、国家记录、涉及商品、占比和较上期，隐藏毛利润与证据列。

## 验证

- 纯聚合测试覆盖国家角色分组、国家记录数、涉及商品去重、占比和上期变化。
- 前端契约测试覆盖层级行、展开控制、全宽布局以及右侧摘要移除。
- 浏览器验证全部角色与单一角色、桌面与窄屏状态。
