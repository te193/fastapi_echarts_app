# 国家维度断货前站点角色依据设计

## 目标

标签看板的经营明细在 MSKU 维度继续展示标签 20 的断货前销售角色依据；切换到国家明细后，按当前行的国家展示标签 21 的站点角色和对应 `evidence_json`。

## 数据口径

- MSKU 维度：`data_date + country_category + store + msku + label_period`，标签 ID 为 `2001–2004`。
- 国家明细：`data_date + country_category + store + msku + country + label_period`，标签 ID 为 `2101–2104`。
- 默认周期为 `30d`；已有明确周期时沿用明确周期。
- 国家明细必须使用当前行 `country` 精确匹配，不允许退化为同一 MSKU 的任意国家记录。
- 数据库已核实：2026-08-13 标签 21 有 2,281 个国家组合、9,124 条四周期记录，`evidence_json` 缺失数为 0。

## 页面行为

- 复用“断货前依据”列，不新增横向列。
- MSKU 维度单元格保持“查看明细”。
- 国家明细单元格展示站点角色名称，并提供“查看明细”按钮。
- 国家明细弹窗标题显示“断货前销售角色依据（站点）”，身份区增加国家。
- 弹窗复用断货时间线、断货前表现、角色判定、计算与来源、原始 JSON 五个页签。
- 弹窗支持 `7d / 14d / 30d / 90d` 切换；每次切换都按当前国家重新读取标签 21。
- 没有精确国家依据时显示“暂无依据”，不使用其他国家或标签 20 兜底。

## 接口设计

扩展现有 `/api/label-hub/stockout-before-role-evidence`：

- 新增可选参数 `country`。
- `country` 为空时沿用标签 20 查询。
- `country` 非空时查询标签 21，并在 SQL 中增加 `country = %(country)s`。
- 响应增加 `scope: "msku" | "country"`，角色名称去掉“断货前-”和“（站点）”仅用于紧凑展示，原始标签名称仍保留在证据数据中。

## 错误处理与验证

- 周期、身份字段和 JSON 对象继续沿用现有校验。
- 国家维度缺少 `country` 时不发起标签 21 查询。
- 测试覆盖标签 20 原逻辑、标签 21 精确国家查询、默认 30 天、前端按维度传参和弹窗文案。
- Microsoft Edge 仅使用 headless 后台模式验证，不弹出浏览器或终端窗口。
