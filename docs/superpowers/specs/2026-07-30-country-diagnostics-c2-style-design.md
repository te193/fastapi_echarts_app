# 国家站点诊断 C2 样式优化设计

## 目标

在不修改数据口径、筛选行为、展开逻辑和 DOM 数据属性的前提下，提高国家站点角色展开后的父子层级辨识度。

采用已确认的 C2“连续分组轨道”方向：保持看板现有白底、蓝灰色和表格风格，仅对当前展开组使用克制的蓝色视觉提示。

## 视觉规则

### 未展开角色

- 保持白色或现有极浅灰蓝底色，不给四种角色分别着色。
- 保留当前箭头、角色名称、数量和指标布局。
- 悬停时只使用轻微浅蓝底色，不产生强阴影。

### 展开角色

- 父级行使用浅蓝背景，颜色保持低饱和。
- 行左侧增加 4px 蓝色竖轨。
- 展开箭头继续旋转，并使用蓝色方形浅底强化状态。
- 父级名称和关键记录数适度加深，不改变字号层级。

### 展开子原因

- 所有子行使用接近白色的浅蓝底，避免与父行颜色完全相同。
- 子行左侧延续父级的 4px 蓝色竖轨，形成连续分组。
- 子原因名称增加缩进，并用短横线连接到竖轨，表达父子关系。
- 最后一条子原因增加浅蓝底边，明确分组结束位置。
- 子行悬停时仅略微加深背景；已筛选子行继续沿用现有选中态。

### 数据可读性

- 为国家角色表第 4 列“国家记录占比”补充现有蓝色占比条。
- 父级占比条和子原因占比条使用同一蓝色体系。
- 数量、较上期、毛利润和证据列不改变语义颜色。

## 响应式

- 保留当前窄屏隐藏“毛利润”和“证据”两列的规则。
- 连续竖轨、缩进和占比条在窄屏继续显示。
- 不新增横向宽度，不改变现有表格最小宽度和滚动策略。

## 实现范围

- 仅修改 `app/static/css/styles.css` 中诊断表相关样式。
- 不修改 Python 服务、API、JavaScript 交互、模板结构或业务文案。
- 不新增角色专属颜色，避免与页面整体风格冲突。

## 验证

- 运行完整测试套件。
- 检查 CSS 差异格式。
- 在桌面宽屏和 768px 窄屏下分别验证：
  - 未展开状态；
  - 展开角色状态；
  - 子原因悬停和选中状态；
  - 占比条与各列对齐；
  - 浏览器控制台无错误。
