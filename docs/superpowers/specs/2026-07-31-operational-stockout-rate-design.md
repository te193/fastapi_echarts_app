# 运营状态“在营断货率”设计

## 1. 目标

在标签看板的“运营状态”分析区域增加一个整体指标，用于回答当前有效运营商品中有多少处于普通断货状态。

指标作为运营状态分布的辅助汇总，不改变现有状态卡片的主视觉层级。

## 2. 指标名称

主名称：`在营断货率`

辅助说明：`剔除返场再断货与非在营商品`

## 3. 统计粒度

沿用运营状态卡片的店铺商品记录粒度：

`国家类别 + 店铺 + MSKU`

不得用去重 MSKU 数与店铺商品记录数混合计算。

## 4. 计算公式

```text
有效断货记录数 = 断货中记录数 - 返场后再次断货记录数

在营记录数 =
    正常在售记录数
  + 测款扶持记录数
  + 返场品记录数
  + 断货中记录数

在营断货率 = 有效断货记录数 / 在营记录数
```

当前示例：

```text
有效断货记录数 = 437 - 24 = 413
在营记录数 = 748 + 0 + 360 + 437 = 1,545
在营断货率 = 413 / 1,545 = 26.73%，展示为 26.7%
```

## 5. 排除规则

- `返场后再次断货`：保留在在营分母中，但从普通断货分子中扣除，并单独展示。
- `清仓中`：不进入在营分母。
- `停售`：不进入在营分母。
- `返场被判停售`：已归入停售，因此不重复扣减。
- 分母为 0 时展示 `--`，不得展示 `0%`。

## 6. 筛选联动

指标跟随标签看板已有公共筛选条件：

- 经营周期
- 标签周期
- 国家类别
- 店铺
- MSKU
- 其他标签联动条件

指标与当前运营状态卡片使用同一批筛选后记录，保证分子、分母和卡片数量可核对。

## 7. 页面展示

采用方案 C2：卡片区底部右侧组合摘要。

展示顺序：

```text
                                  │ 在营断货率 26.7%   有效断货 413 / 在营 1,545 · 返场再断货 24 · 查看口径
```

视觉要求：

- 位于全部运营状态卡片下方，整组靠右对齐，左侧保留空白。
- 组合顺序固定为：断货率视觉锚点、“有效断货 / 在营”、“返场再断货”、“查看口径”。
- 断货率视觉锚点保持短蓝色竖线、“在营断货率”小号辅助文字，以及较大字号、加粗、品牌深蓝的 `26.7%`。
- “有效断货 / 在营”“返场再断货”和“查看口径”保持灰蓝色辅助文字，不与断货率争夺注意力。
- 不使用胶囊、整行底色或独立指标卡；只突出断货率本身。
- 整行高度控制在现有卡片底部说明区域的量级，不挤压卡片布局。
- 窄屏下整组允许自然换行，但断货率锚点保持完整视觉单元并排在详细计数之前。

## 8. 口径说明

点击“查看口径”后，以轻量浮层展示：

```text
在营断货率
=（断货中 - 返场再断货）
÷（正常在售 + 测款扶持 + 返场品 + 断货中）

清仓中、停售不计入在营分母。
```

关闭浮层不改变任何筛选状态。

## 9. 验收标准

- 当前示例数据展示为 `26.7%`。
- 有效断货展示为 `413`，在营记录展示为 `1,545`。
- 返场再断货 `24` 不进入普通断货分子。
- 清仓中和停售不进入分母。
- 公共筛选变化后指标与运营状态卡片同步更新。
- 分母为 0 时展示 `--`。
- 不改变运营状态卡片现有点击、筛选和联动逻辑。
- 页面视觉层级仍以运营状态分布卡片为主。
- 首次扫视底部右侧汇总区时能够先识别断货率，详细计数仍作为次级信息。
