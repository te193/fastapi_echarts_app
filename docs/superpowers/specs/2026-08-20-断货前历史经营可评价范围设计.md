# 断货前历史经营评价规则设计

> 状态：规则 v2 已实现，结果快照按页面数据日期读取并接入每日更新任务。
> 更新日期：2026-08-24

> **v2 日销口径变更（优先于本文后续 v1 表述）：**销售角色使用自然周期日销，计算为“周期总销量 ÷ 固定周期天数”。7/14/30/90天窗口分别固定除以7/14/30/90，滚动节点固定除以30，A/B/C/D窗口分别除以7/7/16/60；周销量稳定性使用“完整周总销量 ÷ 7”。FBA库存大于0的有效经营日仍用于可评价门槛和节点证据门槛，不再作为角色日销分母。库存为0但有销量的数据计入周期总销量，同时继续命中库存销量冲突保护标志。本文后续出现的“在营日日销”“周在营日日销”均按本段 v2 口径解释。

## 1. 文档目的

本设计用于确定：在当前断货产品中，哪些记录拥有足够的历史日级经营数据，以及如何判断其断货前“历史卖得好不好、好到什么程度、是否稳定、销售角色如何变化”。

本文定义规则和数据证据，不修改页面，也不包含实现代码。

本文已经覆盖以下四部分规则：

1. 历史数据是否可评价；
2. 历史经营水平：过去卖得有多好；
3. 历史经营稳定性：经营表现是否持续、是否大幅波动；
4. 历史角色形态和临近断货的角色变化。

历史缺货形态属于下一阶段独立规则，不混入本文已经确认的经营评价结论。

## 2. 与现有方案的关系

现有“断货前经营表现”规则继续负责第一层判断：

```text
当前断货
├─ 暂不评价经营表现
│  ├─ 低量库存边缘断货
│  └─ 断货前依据不足
└─ 可评价经营表现
```

本设计不改变上述“是否可评价经营表现”的现有规则。只有已经进入现有“可评价经营表现”的记录，才继续进行历史可评价判断。

新的处理顺序为：

```text
当前断货
└─ 通过现有可评价判断
   ├─ 历史经营可评价
   ├─ 仅缺货历史可评价
   └─ 历史依据不足
```

现有30天正式基线、7/14/30/90天走势和国家维度切换方案仍可保留，用于描述临近本次断货时的状态；本文档定义的是更长历史范围，两者暂不互相覆盖。

## 3. 本阶段已确认的原则

### 3.1 不使用远端现成销售角色

历史经营标签不直接使用远端父标签20、父标签21或2001～2004、2101～2104的现成销售角色结果。MSKU维度参考2001～2004标准重新计算，国家维度参考2101～2104标准重新计算。

原因包括：

- 远端标签当前保留的历史日期不足，不能形成从2026-01-01开始的连续角色序列；
- 断货后的自然日角色会受到断货零销量污染；
- 现有角色混合了日销、毛利和排名，不能单独回答长期水平和稳定性问题；
- MSKU汇总粒度本身不存在可直接使用的小类排名。

后续指标统一基于日级经营数据重新计算，并保留计算证据。

### 3.2 每条记录独立锚定断货日

历史窗口不能按今天向前倒推，必须以每条记录自己的断货开始日为锚点。

“当前是否断货”和“本次断货从哪天开始”是两个不同判断：

```text
当前是否断货 = 当前FBA可售库存是否等于0
本次断货开始日 = 最近一次FBA可售库存>5之后，首次FBA可售库存=0的日期
```

当前库存等于0即可进入“当前断货中”集合，不受历史回溯结果影响。事件起点只用于计算断货持续天数和断货前经营窗口。若现有断货开始日已经按上述事件口径生成，直接复用；若只取当前连续零库存区间的起点，则需要按上述口径校正。

定义：

```text
oos_start_date = 本次断货开始日
T0 = oos_start_date - 1天
历史观察区间 = 2026-01-01至T0
```

窗口固定为：

```text
[2026-01-01, T0]
```

历史开始日不随当前日期或运行日期变化，历史结束日随每条记录的断货日变化。本次断货开始日及其后的数据不得进入断货前历史经营计算。随着后续年份的数据增加，窗口持续增长，不设置最大回看天数。

若`T0 < 2026-01-01`，则历史窗口不成立，直接输出“历史依据不足：断货日早于历史规则起点”。

### 3.3 不用单一综合分替代事实

“卖得好”“卖得稳定”和“经常缺货”是不同问题，后续必须分别输出，不能先混合成一个无法解释的总分。

特别是：

- 稳定不等于经营好，可能长期稳定低销；
- 高销量不等于稳定，可能依赖少数爆发日；
- 经营水平低不等于数据不足；
- 经常缺货会压低自然日销量，不能直接被解释为市场需求差。

## 4. 统计粒度

历史可评价判断支持两个互斥粒度：

| 视图 | 记录键 | 历史数据计算方式 |
| --- | --- | --- |
| MSKU汇总 | `country_category + store + msku` | 汇总对应业务单元的日级经营数据，不使用小类排名 |
| 国家维度 | `country_category + country + store + msku` | 使用对应国家记录的日级经营数据，并按2101～2104标准加入小类排名 |

两个粒度必须独立判断历史可评价状态、独立计数。国家记录数不能与MSKU汇总记录数相加或直接同比。

两个维度使用相同的数据准入、历史经营好坏、稳定性和角色变化框架。区别只在销售角色：MSKU汇总不使用排名，国家维度加入对应历史时点的小类排名并使用2101～2104标准。

## 5. 历史数据范围

历史评价读取2026-01-01起的日级经营数据，已确认可提供的主要字段包括：

- 日期；
- 国家类别、国家、店铺、MSKU等业务键；
- 日销量；
- 销售额；
- 毛利润；
- FBA可售库存；
- 其他可用经营指标。

数据窗口不设置自然日上限。每条记录固定从2026-01-01读取到自身的T0；较晚上架、断货日较早或数据源覆盖不足的记录，仍通过历史可评价门槛判断。

日表中没有记录的日期不能默认补成销量0或库存0。缺失记录首先视为缺少证据，只有确认数据源业务口径后才允许补零。

当前版本没有使用首条日级记录自动推断上架日。若产品较晚上架但缺少可信的上架日期，2026-01-01至T0仍作为覆盖率应有区间，缺失日期按证据缺失处理；后续只有取得权威上架日期后，才能通过新规则版本调整覆盖率起点，不能在实现中直接用首条记录缩短分母。

## 6. 历史可评价门槛

### 6.1 前置条件

记录必须先通过现有“可评价经营表现”判断。现有低量库存边缘断货和断货前依据不足记录不进入本阶段历史经营评价。

完整周期零销量虽然已有临近断货结论，但只要其更早历史满足本文门槛，仍可进入历史经营评价，不能因为最后30天零销量直接排除。

### 6.2 最少历史跨度

断货日前必须至少有90个自然日可供观察：

```text
history_span_days >= 90
```

少于90天时输出“历史依据不足”，不能输出经营好、经营差或经营不稳定。

90天是准入下限，实际计算使用2026-01-01至T0的全部可用数据。

### 6.3 日级数据覆盖率

在实际可回看的历史区间内：

```text
日级数据覆盖率 = 有有效日记录的自然日数 / 应有自然日数
```

规则要求：

```text
日级数据覆盖率 >= 80%
```

低于80%时输出“历史依据不足：日级数据覆盖不足”。

有效日记录至少需要具备正确的业务键和日期。销售、库存、毛利润等具体字段的完整性要求，将在对应指标规则设计时继续补充，不能用一个字段的缺失否定其他全部维度。

覆盖率通过不代表日期序列连续。相邻两条日记录相差超过1天时，应保留缺失区间起止日和缺失天数；缺失区间不能补成库存0，也不能用其两侧记录推断断货恢复或新断货事件。

### 6.4 有效经营日

有效经营日只按FBA可售库存判断：

```text
FBA可售库存 > 0
```

规则要求：

```text
有效经营日 >= 30天
```

FBA可售库存等于0的日期直接认定为断货日，不计入有效经营日；即使当天存在销量，也不能用销量将该日恢复为有效经营日。FBA可售库存缺失表示库存证据缺失，不能自动按0处理。

该定义用于识别存在实际销售机会或实际销售结果的日期。后续如取得可靠的本地库存、采购在途或其他渠道日快照，应再评估是否扩展“可经营”定义。

### 6.5 有效经营周

仅要求30个有效经营日仍可能出现样本全部集中在一个短时段的问题，因此增加时间分布要求。

有效经营周定义为：

```text
一个自然周内有效经营日 >= 3天
```

历史经营可评价要求：

```text
有效经营周 >= 8周
```

这一门槛用于确认有效经营样本分布在多个时间段，而不是一次短促销售或集中清仓。

## 7. 历史可评价状态

### 7.1 历史经营可评价

同时满足：

1. 已通过现有“可评价经营表现”判断；
2. 历史跨度不少于90天；
3. 日级数据覆盖率不低于80%；
4. 有效经营日不少于30天；
5. 有效经营周不少于8周。

该状态允许后续计算历史经营水平、历史经营稳定性和历史缺货形态。

### 7.2 仅缺货历史可评价

满足历史跨度和日级数据覆盖率要求，但有效经营日或有效经营周不足。

这类记录不能可靠回答“正常经营时卖得多好、是否长期稳定”，但日级库存证据仍可能足以回答：

- 长时间处于无货状态；
- 是否多次出现FBA无货；
- 无货持续时间和间隔情况。

因此不能把它们全部归入普通“历史依据不足”，否则会隐藏长期或反复缺货问题。

### 7.3 历史依据不足

出现任一情况：

- 未通过现有“可评价经营表现”判断；
- 断货日前历史跨度少于90天；
- 日级数据覆盖率低于80%；
- 断货开始日缺失或不可信；
- 日期、业务键等基础数据无法对齐。

页面或明细必须保留具体原因，不能只返回一个笼统的“不可评价”。

## 8. 判定顺序

按以下顺序互斥判断：

```text
1. 现有可评价判断是否通过？
   否 → 沿用现有暂不评价原因

2. 断货锚点和至少90天历史是否成立？
   否 → 历史依据不足

3. 日级数据覆盖率是否达到80%？
   否 → 历史依据不足

4. 是否具备30个有效经营日和8个有效经营周？
   否 → 仅缺货历史可评价

5. 全部满足
   → 历史经营可评价
```

## 11. 重要限制与防误判要求

### 11.1 断货只按FBA可售库存判断

本文历史经营规则统一使用以下定义：

```text
FBA可售库存 > 0  → 有效经营日
FBA可售库存 = 0  → 断货日
FBA可售库存缺失 → 库存证据缺失
```

本地库存、采购在途和当天销量均不参与历史日期是否断货的判断。后续统计历史断货次数、断货天数和断货占比时也只使用FBA可售库存。

当前断货状态只检查当前FBA可售库存是否等于0。历史回溯不会改变一条记录当前是否属于“断货中”，只会确定本次断货事件的开始日及对应T0。

### 11.2 无货自然日不能评价正常销售能力

经营水平和经营稳定性只基于FBA可售库存大于0的有效经营日期计算。FBA可售库存等于0的日期进入缺货形态分析，不能直接以零销量拉低正常经营日销。

经营评价同时保留两种日销：

```text
自然日日销 = 历史销量 / 历史自然日数
在营日日销 = 历史销量 / 有效经营日数
```

两者分别表达实际产出和有货时销售能力，不能互相替代。

### 11.3 数据不足不能解释为经营差

所有未达到准入门槛的记录只能输出不足原因，不得默认归入低销量、问题产品或经营不稳定。

### 11.4 多次缺货会切断经营区间

计算趋势和稳定性时，不能把一次长期断货前后的数据直接连成连续销售趋势。应先识别有效经营段和断货事件，再分别计算经营表现和断货形态。

### 11.5 多次断货事件切分

有效经营日和断货事件使用两个不同阈值：

```text
FBA可售库存 > 0 → 当天可以作为有效经营日
FBA可售库存 = 0 → 触发一次断货事件
FBA可售库存 > 5 → 已触发的断货事件才算正式恢复
```

因此，产品断货后库存恢复到1～5时：

- 当天属于有效经营日，可以进入在营日日销和毛利计算；
- 但仍处于同一次断货事件的恢复过渡期；
- 只有库存首次大于5，才关闭该次断货事件。

事件切分规则：

```text
1. FBA可售库存首次变为0 → 断货事件开始
2. 后续库存处于0～5       → 同一次事件继续，不产生新事件
3. 后续库存首次大于5       → 断货恢复，事件结束
4. 恢复后再次变为0         → 新的一次断货事件开始
5. 库存缺失                → 证据缺失，既不触发恢复，也不自动开始新事件
```

对于当前断货中的记录，本次事件起点按以下顺序确定：

```text
1. 当前FBA可售库存=0，确认当前断货中
2. 向前找到最近一次FBA可售库存>5的日期
3. 取该日期之后第一次FBA可售库存=0的日期作为本次断货开始日
4. 该日期前一天作为T0
```

该算法会跨过事件中的库存1～5过渡日。例如`12 → 0 → 3 → 2 → 0`属于同一次断货，本次开始日是第一个0；`12 → 0 → 7 → 0`中库存7已经完成恢复，本次开始日是第二个0。

若从2026-01-01向后没有找到本次事件之前的`FBA可售库存>5`，则事件左边界不完整。此时可以确认当前仍在断货，但不能声称已得到精确开始日和精确持续天数：`oos_start_date`保留为空，另行输出`observed_oos_since_date`和`minimum_current_oos_days`。

定义：

```text
recovery_date = 断货开始后首次FBA可售库存>5的日期
event_end_date = recovery_date - 1天
```

最后一个尚未出现`FBA可售库存>5`且延续到当前的事件，认定为当前断货事件；此前已经恢复的事件认定为历史断货事件。当前断货事件开始日前一天仍作为`T0`。

一个断货事件内需要分别统计：

- FBA零库存天数：库存等于0的天数；
- 恢复过渡天数：断货触发后库存处于1～5的天数；
- 事件持续天数：从事件开始到`event_end_date`的自然日数；
- 恢复日期：首次库存大于5的日期。

同时增加短暂恢复诊断：若库存首次大于5后的次日立即回到0，仍按当前规则记录“前一事件已恢复、后一事件重新开始”，但必须额外标记`one_day_recovery_then_oos`，便于回测是否需要升级为连续多日恢复规则。该诊断暂不改变“首次大于5即恢复”的主规则。

每条记录汇总输出：

- 历史断货事件次数，不包含当前断货；
- 历史累计断货事件持续天数；
- 历史累计FBA零库存天数；
- 历史最长一次断货事件持续天数；
- 历史断货事件覆盖率；
- 最近一次历史断货恢复日期；
- 当前断货事件开始日；
- 角色轨迹被断货事件中断的次数。

### 11.6 多次断货对经营评价的影响

- 历史经营水平仍可汇总所有`FBA可售库存>0`的有效经营日；
- 滚动30天节点只要达到有效经营日门槛，仍可计算当期角色；
- 两个角色节点之间跨越断货事件时，不计为升级、退化、角色切换或方向反转，而标记为“断货中断”；
- 角色变化序列在断货事件处断开，只有库存恢复到大于5后才重新开始连续比较；
- 经营稳定性只评价有货时的角色、销量和毛利稳定性；断货次数和时长作为独立的供货稳定性证据；
- “仅断货历史可评价”的记录不能评价正常经营水平，但可以输出历史断货事件次数、时长和覆盖率。

### 11.7 低库存经营约束

库存1～5的日期按照已确认口径仍属于有效经营日，但对高日销产品可能无法代表完全不受库存限制的正常销售能力。因此增加：

```text
低库存经营日占比 = FBA可售库存1～5的有效经营日数 / 全部有效经营日数
```

当低库存经营日占比达到30%时，标记“历史经营数据受低库存约束”。该标记只作为结论置信度和解释证据，不取消有效经营日、不直接修改销售角色，也不改变历史经营档位。

### 11.8 库存销量冲突和日期缺口

若某日`FBA可售库存=0`但销量大于0，仍按库存规则认定为断货日，不计入在营日日销和正常经营评价。实现必须保留冲突天数、冲突销量及其占历史总销量比例，避免页面结果与原始销量无法对账。

若断货事件中存在日级数据缺口：

- 缺失日期不能补成库存0或库存大于5；
- 缺口两侧不能直接判断事件是否持续、恢复或重新断货；
- 事件标记“边界不完整”，不输出精确持续天数；
- 缺口两侧的角色变化不能直接连接。

### 11.9 MSKU汇总下的部分国家断货

MSKU汇总维度的FBA可售库存按国家类别、店铺、MSKU汇总，只要汇总库存大于0即可形成MSKU有效经营日。但这可能掩盖同一MSKU下部分国家已经断货的情况。

因此MSKU汇总结论不因部分国家断货直接失效，但应保留“部分国家断货天数及占比”；国家维度仍按各国自己的FBA可售库存、销量、毛利和排名独立评价，不能用MSKU汇总库存替代国家库存。

## 12. 双层销售角色体系

历史经营评价采用两层销售角色，分别回答“临近本次断货时是什么角色”和“2026-01-01至T0期间角色如何变化”。两层结果不能互相替代。

### 12.1 断货日前四周期角色

第一层固定计算四个嵌套周期：

```text
断货日前7天
断货日前14天
断货日前30天
断货日前90天
```

所有周期均以每条记录自己的`T0`为截止日：

```text
7天窗口  = [T0-6天, T0]
14天窗口 = [T0-13天, T0]
30天窗口 = [T0-29天, T0]
90天窗口 = [T0-89天, T0]
```

四周期角色用于回答：

- 断货前最后阶段的经营角色；
- 7、14、30、90天角色是否一致；
- 临近断货时相对较长周期是升级、降级还是反复变化。

四个周期相互嵌套，只能描述临近本次断货的差异，不能单独代表2026-01-01至T0期间完整的历史角色变化。

### 12.2 MSKU角色参考规则

MSKU汇总维度不使用小类排名。角色根据在营日日销和周期毛利率重新计算，本版采用以下第一版规则：

| 在营日日销 | 周期毛利率 | 角色 |
| ---: | ---: | --- |
| `>= 5` | `>= 15%` | 明星产品 |
| `>= 1 且 < 5` | `>= 25%` | 明星产品 |
| `>= 5` | `>= 5% 且 < 15%` | 潜力产品 |
| `>= 1 且 < 5` | `>= 10% 且 < 25%` | 潜力产品 |
| `>= 1 且 < 5` | `>= 5% 且 < 10%` | 瘦狗产品 |
| `> 0 且 < 1` | `>= 5%` | 瘦狗产品 |
| `= 0` | 不使用 | 零销量 |
| `> 0` | `< 5%` | 问题产品 |

计算方式：

```text
在营日日销 = 周期销量 / 周期有效经营日数
周期毛利率 = 周期毛利润 / 周期销售额
```

周期销售额等于0时不得强行计算毛利率。负毛利润是合法经营结果，应进入问题产品，不属于数据异常。

上述角色阈值是当前确认的设计基线。上线前必须使用历史样本分布进行回测；若回测表明角色占比失衡或边界不符合当前业务，应先更新本文档和规则版本，不能静默修改。

### 12.3 不使用自然日日销直接判断销售能力

角色判断默认使用在营日日销，不使用周期销量直接除以7、14、30或90。

原因是历史窗口内可能存在多次FBA无货。如果将无货自然日直接计入日销分母，会把供给中断错误解释为需求能力下降。

四周期仍应同时输出自然日日销：

```text
自然日日销 = 周期销量 / 周期自然日数
```

其中：

- 在营日日销用于评价有经营机会时的销售能力；
- 自然日日销用于评价包含缺货损失后的实际经营产出；
- 两者差异用于辅助识别供给中断影响，不直接生成角色。

### 12.4 周期角色独立可评价

通过总体“历史经营可评价”不代表四个周期全部具有足够证据。每个周期必须独立检查有效经营日数和销售、毛利证据。

各累计周期最低有效经营日为：

| 累计周期 | 最低有效经营日 |
| --- | ---: |
| 断货日前7天 | 5天 |
| 断货日前14天 | 10天 |
| 断货日前30天 | 21天 |
| 断货日前90天 | 63天 |

某个周期证据不足时：

```text
该周期角色 = 周期角色不可判
```

不得将其默认为零销量、问题产品或沿用远端销售角色。

上述门槛均约为周期自然日的70%，与临近断货非重叠区间的最低有效经营日口径保持一致，并在后续回测中统一校准。

### 12.5 国家维度角色

国家维度同样重新计算四周期角色和2026-01-01至T0的滚动角色轨迹，不直接复用父标签21结果，但严格采用2101～2104的角色标准。

国家角色使用：

```text
国家 + 店铺 + MSKU维度的周期在营日日销
国家 + 店铺 + MSKU维度的周期毛利率
角色窗口内最后一个有效经营日对应的小类排名
```

国家历史排名必须使用角色窗口内最后一个FBA可售库存大于0日期对应的历史小类排名，并记录为`small_rank_stat_date`。当前排名不能回填到过去的滚动节点；该日期排名缺失或无效时，按2104问题产品标准处理并保留排名无效原因。

#### 12.5.1 国家明星产品（2101标准）

同时满足小类排名为1～50，并命中以下任一销售和毛利条件：

```text
在营日日销 > 3，且周期毛利率 >= 15%
或 1 <= 在营日日销 <= 3，且周期毛利率 >= 25%
```

#### 12.5.2 国家潜力产品（2102标准）

命中以下任一条件：

```text
1. 小类排名为1～100，且：
   在营日日销 > 3，5% <= 周期毛利率 < 15%
   或 1 <= 在营日日销 <= 3，10% <= 周期毛利率 < 25%

2. 已达到国家明星产品的日销和毛利条件，
   但小类排名为51～100
```

#### 12.5.3 国家瘦狗产品（2103标准）

在营日日销大于0、周期毛利率至少5%、小类排名有效，但未命中国家明星或国家潜力。包括：

```text
小类排名为1～100，但日销和毛利组合未达到2101或2102
或 小类排名大于100且小于99999
```

#### 12.5.4 国家问题产品（2104标准）

命中以下任一条件：

```text
在营日日销 <= 0
或 在营日日销 > 0，且周期毛利率 < 5%
或 在营日日销 > 0、周期毛利率 >= 5%，但小类排名为空、<=0或>=99999
```

国家角色按2104问题、2101明星、2102潜力、2103瘦狗的互斥顺序实现，保证每个可评价周期只产生一个角色。排名无效导致的问题产品必须单独保留原因，不能与低毛利问题混为一类。

#### 12.5.5 国家维度完整评价链路

国家维度产生角色后，继续复用本文相同规则计算：

- 断货日前7、14、30、90天累计角色；
- 2026-01-01至T0的滚动30天角色轨迹；
- 历史经营好坏；
- 角色、销量和毛利稳定性；
- 2026-01-01至T0的历史角色形态；
- 断货日前非重叠区间角色变化。

国家维度所有数量、占比和节点分母均使用国家记录，不能与MSKU汇总记录混算。

国家维度每个周期或滚动节点额外保留：

| 字段 | 含义 |
| --- | --- |
| `country` | 国家 |
| `small_rank` | 用于本次角色判断的小类排名 |
| `small_rank_stat_date` | 排名对应的最后一个有效经营日 |
| `country_role_label_id` | 2101、2102、2103或2104 |
| `country_role_reason` | 命中的日销、毛利率和排名条件 |
| `country_role_rank_status` | 排名有效或排名无效；空值同样属于无效 |
| `country_role_rank_invalid_reason` | 排名空值、排名小于等于0或排名大于等于99999 |

## 13. 2026-01-01起历史角色轨迹

### 13.1 计算方式

为了识别历史销售角色变化，在2026-01-01至T0范围内计算：

```text
滚动窗口长度 = 30天
计算步长 = 7天
```

即每隔7天生成一个滚动30天角色节点。节点数量随T0向后推移持续增加，不设置最多32个节点的限制。

每个节点继续使用当时窗口内的日级数据重新计算在营日日销、毛利率和销售角色，不能使用断货后日期，也不能直接读取当前远端角色。

示例：

```text
明星 → 明星 → 潜力 → 潜力 → 瘦狗 → 明星
```

不采用每日滚动，避免相邻窗口高度重叠造成大量重复节点和虚假稳定；也不能只用7、14、30、90天四个累计角色代替历史轨迹。

### 13.2 轨迹基础指标

历史角色轨迹至少保留：

| 指标 | 定义 |
| --- | --- |
| 有效角色节点数 | 通过节点级证据检查并成功计算角色的节点数 |
| 主导角色 | 有效节点中出现次数最多的角色 |
| 主导角色占比 | 主导角色节点数 / 有效角色节点数 |
| 角色切换次数 | 相邻有效节点角色不一致的次数 |
| 跨级切换次数 | 相邻节点跨越两个及以上角色等级的次数 |
| 最近角色 | 最靠近T0且证据充分的滚动30天角色 |
| 最近角色与主导角色关系 | 升级、相同或降级 |
| 各角色占比 | 明星、潜力、瘦狗、问题和零销量各自节点占比 |
| 不可判节点数及占比 | 因有效经营日或指标证据不足而无法计算的节点 |

角色等级暂用于变化分析：

```text
问题产品 < 瘦狗产品 < 潜力产品 < 明星产品
```

零销量和周期角色不可判不直接放入上述等级：

- 零销量单独记录，后续结合FBA无货状态判断是无货导致还是有货无销量；
- 周期角色不可判只表示证据不足，不表示角色最低。

### 13.3 两层角色的职责边界

```text
断货日前7/14/30/90天角色
→ 描述临近本次断货的经营角色和周期差异

2026-01-01至T0的滚动30天角色轨迹
→ 描述长期主导角色、角色保持程度和历史变化
```

后续“经营稳定性”必须结合历史角色轨迹和日级经营指标波动共同判断，不能仅以四周期角色一致或主导角色占比高作为稳定结论。

## 14. 历史经营好坏

### 14.1 判断职责

历史经营好坏只回答：产品在2026-01-01至T0期间，整体经营水平处于什么档位。

该结论使用历史滚动角色构成和2026-01-01至T0的实际经营毛利，不混入稳定性，也不被断货日前30天或90天角色直接覆盖。

因此允许组合输出：

```text
历史优秀 + 断货前保持明星
历史良好 + 断货前降为问题
历史较差 + 断货前改善为潜力
```

这样可以同时保留长期经营水平和临近断货时的变化，避免近期一次升降覆盖整个历史。

### 14.2 基础指标

设2026-01-01至T0的滚动角色轨迹中：

```text
N = 有效角色节点数
明星占比 = 明星节点数 / N
优质角色占比 =（明星节点数 + 潜力节点数）/ N
问题角色占比 =（问题节点数 + 有货零销量节点数）/ N
历史毛利率 = 2026-01-01至T0实际毛利润合计 / 同期实际销售额合计
```

历史经营好坏至少需要8个有效滚动角色节点。`N < 8`时直接输出“历史不可判”，不继续按角色占比划分经营档位。

历史毛利率必须直接汇总非重叠的日级经营数据。滚动30天窗口彼此重叠，禁止累加各滚动节点的销售额或毛利润计算历史毛利率。

FBA无货导致的零销量节点不计入“有货零销量”，应进入缺货历史分析；只有具备有效可售证据但销量为0的节点，才属于有货零销量。

### 14.3 判断规则

历史经营结论按以下优先级互斥判断：

| 优先级 | 历史经营结论 | 规则 |
| ---: | --- | --- |
| 1 | 历史有货无销量 | 有货零销量节点占有效节点至少60% |
| 2 | 历史亏损 | 历史销售额大于0，且历史毛利率小于0% |
| 3 | 历史较差 | 历史毛利率为0%～小于5%，或问题角色占比至少50% |
| 4 | 历史优秀 | 明星占比至少60%，优质角色占比至少80%，历史毛利率至少15% |
| 5 | 历史良好 | 优质角色占比至少60%，问题角色占比小于25%，历史毛利率至少5% |
| 6 | 历史一般 | 已具备历史评价依据，但未命中以上任何结论 |
| 7 | 历史不可判 | 历史经营数据可评价门槛通过，但有效角色节点仍不足 |

其中：

- 历史优秀表示大部分时间保持明星，并且不是依赖少数窗口偶然冲高；
- 历史良好表示大部分时间处于明星或潜力，且整体具备正常盈利能力；
- 历史一般表示存在有效销售并能够评价，但多数时间可能是瘦狗，或者角色构成较混杂；
- 历史较差表示长期低毛利，或者大部分时间属于问题角色；
- 历史亏损表示2026-01-01至T0的实际经营结果为负，优先于角色占比；
- 历史有货无销量表示存在销售机会但长期没有形成销量，不能与FBA无货混淆。

### 14.4 边界处理

- 历史销售额等于0时不计算历史毛利率；
- 历史销售额等于0且有货零销量节点达到60%时，输出“历史有货无销量”；
- 历史销售额等于0但库存证据不足时，输出“历史不可判”，不能默认经营较差；
- 负毛利润是合法经营结果，不能作为数据异常过滤；
- 近期30天或90天角色只参与后续角色变化判断，不修改历史经营档位；
- 历史好坏不使用角色切换次数，角色切换属于稳定性指标；
- 所有比例只使用有效角色节点作为分母，不可判节点不得进入分母。

### 14.5 输出字段

| 字段 | 含义 |
| --- | --- |
| `historical_operating_level` | 历史经营结论代码 |
| `historical_operating_level_label` | 历史经营结论中文名称 |
| `historical_margin_rate` | 2026-01-01至T0的实际历史毛利率 |
| `dominant_role` | 历史主导销售角色 |
| `star_role_share` | 明星节点占比 |
| `quality_role_share` | 明星与潜力节点合计占比 |
| `problem_role_share` | 问题与有货零销量节点合计占比 |
| `in_stock_zero_sales_share` | 有货零销量节点占比 |
| `historical_level_reason` | 命中的具体阈值及证据 |

## 15. 历史经营稳定性

### 15.1 判断职责

历史经营稳定性回答：在具备经营机会的历史区间内，产品的销售角色、销售能力和盈利能力是否保持在相对可预测的范围内。

稳定性不等于经营优秀。例如，长期保持瘦狗角色且销量变化较小，可以是“历史经营一般 + 高度稳定”；历史优秀但依赖少数爆量周，则可能是“历史经营优秀 + 波动经营”。

稳定性采用角色、销量和毛利三个透明分项，不生成隐藏加权总分。

### 15.2 稳定性可评价条件

同时满足以下条件时，才计算最终稳定性：

```text
有效滚动角色节点 >= 8个
有效经营周 >= 8周
可计算周度销量的相邻周 >= 6组
可计算周毛利率的有效周 >= 6周
```

任一条件不满足时输出“稳定性不可判”，并保留具体不足原因。

如果全部有效周的周在营日日销均为0，不能强行计算销量波动系数，应结合“历史有货无销量”结论处理，稳定性输出不可判。

### 15.3 角色序列确认

滚动30天角色在阈值附近可能只短暂跳动一个节点。为避免把单点噪声当成角色改变，先生成确认后的角色序列：

```text
新角色连续出现至少2个滚动节点，才确认发生角色切换
新角色只出现1个节点后恢复，记为短暂波动，不计正式切换
```

角色等级仅用于计算变化幅度：

```text
问题产品 < 瘦狗产品 < 潜力产品 < 明星产品
```

零销量和角色不可判不直接进入等级序列。零销量必须先区分FBA无货、有货零销量和数据不足。

基于确认后的有效角色序列计算：

- 主导角色占比；
- 确认角色切换次数；
- 角色变化方向反转次数；
- 跨两级及以上角色变化次数；
- 单节点短暂波动次数。

“明星→潜力→瘦狗”属于单向持续退化，不属于方向反转；“明星→瘦狗→明星→问题”属于多次反转。

### 15.4 销售角色稳定性

| 分项结论 | 判断标准 |
| --- | --- |
| 角色稳定 | 主导角色占比至少70%，确认切换不超过2次，方向反转不超过1次，跨两级变化不超过1次 |
| 角色高度波动 | 主导角色占比小于50%，或确认切换至少5次，或方向反转至少3次，或跨两级变化至少3次 |
| 角色一般波动 | 已可评价，但未命中角色稳定或角色高度波动 |

角色高度波动的各条件使用“或”连接，只要命中一项即可。

### 15.5 销量稳定性

按自然周汇总有效经营数据：

```text
周在营日日销 = 周销量 / 当周有效经营日数
销量波动系数 = 周在营日日销标准差 / 周在营日日销均值
最高3周销量占比 = 销量最高的3个有效经营周销量 / 全部有效经营周销量
实际销售日数 = 有效经营日中销量大于0的日期数
最高单日销量占比 = 最高单日销量 / 全部有效经营日销量
```

周期有效经营日门槛可以防止“只有1天有库存、当天集中销售”造成日销虚高，但不能排除“有货很多天、销量只集中在1～2天”的情况。因此每个7、14、30、90天周期和完整历史窗口同时输出：

```text
实际销售日数 <= 2           → 销量集中在极少数日期
最高单日销量占比 >= 50%     → 单日销量集中
最高单日销量占比 >= 80%     → 极端单日销量集中
```

这些标记允许同时命中。它们不直接改变明星、潜力、瘦狗或问题产品角色，也不单独修改历史经营好坏；其职责是解释角色证据是否依赖少数爆量日，并作为销量稳定性的辅助证据。若命中极端单日销量集中，销量稳定性不得判为“销量稳定”。

| 分项结论 | 判断标准 |
| --- | --- |
| 销量稳定 | 销量波动系数不超过0.50，且最高3周销量占比小于40% |
| 销量一般波动 | 销量波动系数大于0.50且不超过0.80，且未命中销量高度波动 |
| 销量高度波动 | 销量波动系数大于0.80，或最高3周销量占比至少40% |

最高3周销量占比只在有效经营周至少12周时参与判断。有效经营周为8～11周时，只使用销量波动系数，避免短样本天然造成集中度偏高。

周在营日日销均值等于0时不计算波动系数；标准差和均值必须使用同一组有效经营周。

### 15.6 毛利稳定性

周毛利率只在该自然周同时满足以下条件时计算：

```text
周销售额 > 0
且 周销量 >= 5件
```

基础指标：

```text
周毛利率 = 周毛利润 / 周销售额
毛利率波动 = 有效周毛利率的标准差，单位为百分点
亏损周占比 = 周毛利率 < 0%的有效周数 / 毛利有效周数
正负毛利反转次数 = 相邻毛利有效周在正毛利与负毛利之间切换的次数
```

| 分项结论 | 判断标准 |
| --- | --- |
| 毛利稳定 | 毛利率标准差不超过5个百分点，且亏损周占比不超过10% |
| 毛利高度波动 | 毛利率标准差大于10个百分点，或亏损周占比至少30%，或正负毛利反转至少3次 |
| 毛利一般波动 | 已可评价，但未命中毛利稳定或毛利高度波动 |

毛利率极值必须保留原始证据。若确认由退货、冲销或字段异常造成，应标记异常原因，不能无解释地参与稳定性判断。

### 15.7 最终稳定性结论

最终结论直接组合三个分项，不使用加权分数：

| 最终结论 | 组合规则 |
| --- | --- |
| 高度稳定 | 角色、销量、毛利三项全部稳定 |
| 基本稳定 | 没有任何高度波动项，且至少两项稳定 |
| 高度波动 | 至少两项高度波动，或角色为高度波动 |
| 波动经营 | 已可评价，但未命中高度稳定、基本稳定或高度波动 |
| 稳定性不可判 | 有效角色节点、经营周、相邻销量周或毛利有效周不足 |

最终结果必须同时展示分项结论和主要证据。例如：

```text
最终：波动经营
角色：稳定
销量：高度波动
毛利：一般波动
原因：销量集中在少数爆量周
```

### 15.8 输出字段

| 字段 | 含义 |
| --- | --- |
| `historical_stability` | 最终稳定性代码 |
| `historical_stability_label` | 最终稳定性中文名称 |
| `role_stability` | 角色稳定性分项 |
| `sales_stability` | 销量稳定性分项 |
| `margin_stability` | 毛利稳定性分项 |
| `dominant_role_share` | 主导角色占比 |
| `confirmed_role_switch_count` | 确认角色切换次数 |

| `weekly_sales_cv` | 周在营日日销波动系数 |

## 16. 销售角色变化

### 16.1 两类变化结论

销售角色变化拆成两个独立结论：

```text
2026-01-01至T0的历史角色形态
→ 描述长期保持、逐步升级、逐步退化或反复切换

临近断货角色变化
→ 描述断货日前7天、30天或90天形成的变化方向
```

两类结论并列输出，不能互相覆盖。例如：

```text
历史角色形态：历史反复切换
断货前变化：断货日前30天持续升级
```

### 16.2 临近断货的非重叠角色区间

7、14、30、90天累计窗口互相包含，不能直接作为时间先后的角色序列。临近断货变化使用四个不重叠区间重新计算角色：

```text
A = 断货日前1～7天
B = 断货日前8～14天
C = 断货日前15～30天
D = 断货日前31～90天
```

每个区间继续使用在营日日销和毛利率计算角色，角色等级为：

```text
问题产品=0，瘦狗产品=1，潜力产品=2，明星产品=3
```

各区间最低有效经营日为：

| 区间 | 自然日数 | 最低有效经营日 |
| --- | ---: | ---: |
| A：断货日前1～7天 | 7 | 5 |
| B：断货日前8～14天 | 7 | 5 |
| C：断货日前15～30天 | 16 | 11 |
| D：断货日前31～90天 | 60 | 42 |

未达到最低有效经营日时，该区间角色不可判。零销量必须先区分FBA无货、有货零销量和数据缺失；FBA无货不能直接作为最低角色参与比较。

### 16.3 断货前角色变化规则

断货前角色变化按以下优先级互斥判断：

| 优先级 | 结论 | 规则 |
| ---: | --- | --- |
| 1 | 断货日前7天停滞 | A为有货零销量，且B或C存在有效销量 |
| 2 | 断货日前7天启动 | A产生有效销量，且B为有货零销量 |
| 3 | 断货日前90天持续升级 | `A >= B >= C >= D`，至少发生两次严格升级，且没有降级 |
| 4 | 断货日前90天持续退化 | `A <= B <= C <= D`，至少发生两次严格退化，且没有升级 |
| 5 | 断货日前30天持续升级 | `A >= B >= C`且`A > C`，但未命中90天持续升级 |
| 6 | 断货日前30天持续退化 | `A <= B <= C`且`A < C`，但未命中90天持续退化 |
| 7 | 断货日前7天升级 | `A > B`，但未命中持续升级 |
| 8 | 断货日前7天退化 | `A < B`，但未命中持续退化 |
| 9 | 断货前角色保持 | `A = B = C` |
| 10 | 断货前变化不明确 | 必要区间可评价，但各段有升有降且未形成上述明确方向 |
| 11 | 角色变化不可判 | 必要区间角色不足或证据冲突 |

“至少发生两次严格升级”表示四个相邻比较中至少两次为角色等级上升，不能仅因三个区间角色相同、一个区间高一级就宣称90天持续升级。持续退化使用同样口径。

### 16.4 2026-01-01起历史角色形态指标

对确认后的滚动30天角色序列，按时间顺序划分有效节点：

```text
前段角色水平 = 最早1/3有效节点的角色等级中位数
后段角色水平 = 最晚1/3有效节点的角色等级中位数
```

节点数不能被3整除时，中间段承接余数；前段和后段节点数保持相同。前段或后段少于3个有效节点时，历史变化不可判。

另外计算：

- 确认升级次数；
- 确认退化次数；
- 方向反转次数；
- 确认角色切换次数；
- 主导角色占比。

### 16.5 2026-01-01起历史角色形态规则

历史角色形态按以下优先级互斥判断：

| 优先级 | 历史形态 | 规则 |
| ---: | --- | --- |
| 1 | 历史变化不可判 | 前段或后段有效角色节点少于3个 |
| 2 | 历史反复切换 | 方向反转至少3次，或确认切换至少5次且同时存在升级和退化 |
| 3 | 历史角色保持 | 主导角色占比至少70%，确认切换不超过2次，方向反转不超过1次 |
| 4 | 历史逐步升级 | 后段中位角色比前段至少高1级，升级次数多于退化次数，方向反转不超过1次 |
| 5 | 历史逐步退化 | 后段中位角色比前段至少低1级，退化次数多于升级次数，方向反转不超过1次 |
| 6 | 历史角色混合 | 已可评价，但未命中以上形态 |

历史反复切换优先于历史角色保持，避免主导角色占比较高但中间多次明显反转时仍被判为保持。

### 16.6 输出字段

| 字段 | 含义 |
| --- | --- |
| `historical_role_pattern` | 2026-01-01至T0的历史角色形态代码 |
| `historical_role_pattern_label` | 历史角色形态中文名称 |
| `pre_oos_role_change` | 临近断货角色变化代码 |
| `pre_oos_role_change_label` | 临近断货角色变化中文名称 |
| `early_role_median` | 历史前1/3节点角色中位数 |
| `late_role_median` | 历史后1/3节点角色中位数 |
| `confirmed_upgrade_count` | 确认升级次数 |
| `confirmed_downgrade_count` | 确认退化次数 |
| `role_reversal_count` | 方向反转次数 |
| `segment_role_a` | 断货日前1～7天角色 |
| `segment_role_b` | 断货日前8～14天角色 |
| `segment_role_c` | 断货日前15～30天角色 |
| `segment_role_d` | 断货日前31～90天角色 |
| `role_change_reason` | 命中的变化规则和主要证据 |

## 17. 完整判断流程

### 17.1 总体顺序

所有记录按以下顺序处理：

```text
第一步：现有“是否可评价经营表现”判断
    ↓
第二步：2026-01-01起历史数据边界判断
    ↓
第三步：确认当前断货状态，统一断货事件起点并切分历史事件
    ↓
第四步：计算数据质量保护项、四周期角色和2026-01-01起滚动角色轨迹
    ↓
第五步：判断历史经营好坏
    ↓
第六步：判断历史经营稳定性
    ↓
第七步：判断2026-01-01起历史角色形态和临近断货角色变化
```

### 17.2 第一步：现有可评价判断

沿用当前页面规则，不在本设计中重新定义：

```text
低量库存边缘断货 → 沿用现有暂不评价
断货前依据不足   → 沿用现有暂不评价
现有可评价记录   → 继续历史判断
```

### 17.3 第二步：历史数据边界

```text
历史开始日固定为2026-01-01
历史结束日为每条记录的T0
历史跨度至少90天
日级数据覆盖率至少80%
有效经营日至少30天
有效经营周至少8周，每周至少3个有效经营日
```

输出：

- 历史经营可评价；
- 仅缺货历史可评价；
- 历史依据不足。

只有“历史经营可评价”继续计算经营好坏、稳定性和角色变化。“仅缺货历史可评价”只保留给后续缺货形态分析。

### 17.4 第三步：断货事件切分

先用当前FBA可售库存等于0确认“当前断货中”，再按日级FBA可售库存统一当前事件起点并切分历史事件：

```text
库存=0触发断货
库存0～5期间事件保持未恢复
库存>5关闭事件
恢复后再次为0产生新事件
当前事件开始日=最近一次库存>5之后的首次库存0日期
```

同时形成连续有效经营段。经营指标可以使用所有有效经营日，但角色变化不能跨断货事件直接连接。没有观察到前置库存大于5、存在日期缺口或出现恢复次日归零时，分别保留左边界不完整、事件边界不完整和短暂恢复标记。

### 17.5 第四步：角色计算

同时生成三组角色证据：

1. 断货日前7、14、30、90天累计角色，用于页面周期证据；
2. 2026-01-01至T0滚动30天、每7天一个节点的历史角色轨迹；
3. 断货日前1～7天、8～14天、15～30天、31～90天四个非重叠角色，用于判断变化方向。

所有角色均使用日级经营数据重新计算，不读取远端现成销售角色。MSKU角色使用在营日日销和毛利率；国家角色增加窗口内最后一个有效经营日的小类排名并采用2101～2104标准。

角色计算前同时生成低库存经营日占比、库存销量冲突、实际销售日数、最高单日销量占比和部分国家断货占比。这些字段用于解释证据质量和稳定性，不直接覆盖销售角色主结论。

### 17.6 第五步：历史经营好坏

根据有效滚动节点的角色构成和2026-01-01至T0实际毛利率，互斥输出：

```text
历史有货无销量
历史亏损
历史较差
历史优秀
历史良好
历史一般
历史不可判
```

该结论只回答整体经营水平，不使用角色切换次数，也不被断货日前30天角色覆盖。

### 17.7 第六步：历史经营稳定性

分别计算：

```text
销售角色稳定性
周在营日日销稳定性
周毛利率稳定性
```

再按透明组合规则输出：

```text
高度稳定
基本稳定
波动经营
高度波动
稳定性不可判
```

稳定性只回答经营结果是否可预测，不代表经营水平高低。

### 17.8 第七步：角色变化

并列输出两个结论：

```text
2026-01-01至T0历史角色形态
断货前角色变化
```

前者回答长期保持、逐步升级、逐步退化或反复切换；后者回答断货日前7天、30天或90天是否发生启动、停滞、升级、退化或保持。

### 17.9 最终结果示例

```text
历史数据：历史经营可评价
历史断货：3次，累计42天，最长18天
历史经营：历史良好
经营稳定性：波动经营
历史角色形态：历史反复切换
断货前变化：断货日前30天持续升级
断货日前30天角色：潜力产品
```

上述结论分别回答不同问题，禁止用其中一个字段覆盖其他字段。

## 19. 当前已确认结论

截至2026-08-21，当前规则设计基线为：

```text
历史开始日：固定为2026-01-01
历史结束日：每条记录的断货日前一天T0
历史窗口上限：不设置
历史跨度下限：90天
日级数据覆盖率：至少80%
有效经营日：至少30天
有效经营周：至少8周，每周至少3个有效经营日
有效经营日定义：仅FBA可售库存>0
断货日定义：FBA可售库存=0
当前断货状态：仅由当前FBA可售库存=0判断
断货恢复定义：断货触发后FBA可售库存首次>5
多次断货切分：恢复前库存0～5均属于同一次断货事件
当前断货开始日：最近一次FBA可售库存>5之后的首次库存0日期
短暂恢复：库存首次>5后次日归零，主规则仍切分为两次事件并额外保留标记
低库存约束：库存1～5仍为有效经营日，占比达到30%时增加受约束标记
销量集中：实际销售日不超过2天、最高单日占比达到50%或80%时分别保留集中证据
库存销量冲突：库存0但销量>0仍按断货日处理，同时保留冲突销量证据
日期缺口：不补零、不跨缺口推断事件，边界不完整时不输出精确持续天数
临近断货角色：断货日前7/14/30/90天分别重新计算
历史角色轨迹：2026-01-01至T0滚动30天、每7天计算一次
历史经营档位：历史优秀、历史良好、历史一般、历史较差、历史亏损、历史有货无销量
历史稳定性：高度稳定、基本稳定、波动经营、高度波动、稳定性不可判
历史角色形态：保持、逐步升级、逐步退化、反复切换、角色混合、变化不可判
断货前变化：按非重叠的1～7天、8～14天、15～30天、31～90天角色判断
MSKU角色：采用2001～2004的日销和毛利标准，不使用排名
国家角色：加入窗口内最后一个有效经营日的小类排名，采用2101～2104标准
```

以上是当前实现应采用的规则基线。若回测表明门槛造成明显样本偏差，必须先更新本文档和规则版本，再调整实现，不得在代码中静默变更口径。
