# 标签看板明细表点击交互设计

## 目标

解决用户选择或复制 MSKU 文本时误触整行点击、自动打开画像抽屉的问题，同时保留清晰、快捷的画像入口。

## 交互方案

- 经营明细表不再通过整行点击打开任何抽屉，MSKU 与 SKU 文本可以正常拖选复制。
- MSKU 单元格右侧增加轻量复制按钮；按钮默认弱化，悬停或键盘聚焦时突出。
- 点击复制按钮只复制当前行完整 MSKU，成功后给出短暂的“已复制”反馈，不触发抽屉。
- “标签画像”单元格是店铺商品标签画像的唯一入口，保留现有分类数量与“点击查看”提示。
- “查看国家画像”按钮仍是国家画像的唯一入口。
- MSKU 维度和国家明细视图都取消整行点击，避免同一表格在不同视图下行为不一致。

## 可访问性与异常处理

- 复制按钮使用真实 `button`，提供包含 MSKU 的 `aria-label` 和提示文本。
- 优先使用 Clipboard API；不可用时使用隐藏文本框回退复制。
- 复制失败时显示“复制失败”，不改变表格或抽屉状态。

## 验收

- 鼠标拖选 MSKU 不会打开抽屉。
- 点击复制按钮可复制完整 MSKU，且不会打开抽屉。
- 点击标签画像单元格会打开标签画像。
- 点击国家画像按钮会打开国家画像。
- 键盘可以聚焦并触发两个显式按钮。
