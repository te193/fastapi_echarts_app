# 角色诊断表格按钮设计

## 目标

将标签看板明细表“角色诊断”列中当前以蓝色摘要文本呈现的入口，改为清晰的操作按钮。

## 设计

- 列名继续使用“角色诊断”。
- 有诊断数据时显示紧凑按钮“查看诊断”。
- 诊断摘要不再直接占用单元格宽度，但继续通过单元格 tooltip 提供。
- 无诊断数据时继续显示“暂无诊断”。
- 按钮采用与页面现有浅蓝色体系一致的描边样式；悬停和键盘聚焦时增强蓝色反馈。
- 点击行为保持不变，仍打开现有销售角色诊断抽屉。

## 约束与验证

- 不修改接口、数据结构、业务逻辑和抽屉交互。
- 不增加第三方依赖。
- 增加前端回归断言，并进行 JavaScript 语法检查与页面视觉验证。
