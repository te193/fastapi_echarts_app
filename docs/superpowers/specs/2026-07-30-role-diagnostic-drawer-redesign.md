# 销售角色诊断抽屉重设计

## 目标

将现有“诊断标签清单”改造成可解释的角色升级诊断：

1. 默认跟随标签看板当前标签周期；
2. 展示全站点销售角色及其相对上一层级的主要阻塞指标；
3. 按国家展示站点销售角色、问题子标签和升级目标；
4. 展示指标当前值、目标阈值、达标状态及差距；
5. 对无有效数据的指标明确说明原因，不计算虚假差距。

## 已确认的数据基础

`dws_datasync.dws_标签表.evidence_json` 已包含：

- `window`：周期和起止日期；
- `metrics` / `product_issue.metrics_used`：日销、毛利率、小类排名等实际值；
- `product_issue.label`：销售角色问题子标签；
- `product_issue.benchmark_target`：目标角色；
- `product_issue.matched_rule`：当前命中的角色规则；
- `source_sales_role`：当前销售角色；
- `rule_version` 与 `schema_version`。

现有标签看板主列表只保留了 `evidence_available`，没有向前端返回实际证据内容。

## 数据架构

### 按需接口

新增独立的 MSKU 角色诊断接口。打开抽屉或切换周期时才请求，不把全部 `evidence_json` 塞入标签看板主接口。

请求参数：

- `data_date`
- `country_category`
- `store`
- `msku`
- `diagnostic_period`：`7d`、`14d`、`30d`、`90d`

返回结构：

```json
{
  "identity": {
    "country_category": "欧洲站",
    "store": "HUAWTONG",
    "msku": "HW065a"
  },
  "period": "30d",
  "period_follows_page": true,
  "global_diagnostic": {},
  "country_diagnostics": [],
  "meta": {
    "rule_version": "v45",
    "evidence_status": "available"
  }
}
```

### 查询范围

- 全站点判断读取父标签 15 的当前周期事实；
- 国家站点判断读取父标签 16 的当前周期事实；
- 通过标签详情表补充子标签名称和原始规则；
- 只查询当前 `data_date + country_category + store + msku + period`。

## 诊断计算

### 角色升级顺序

- 全站点：问题产品 → 瘦狗产品 → 潜力产品 → 明星产品；
- 国家站点：问题产品 → 瘦狗产品 → 潜力产品 → 明星产品。

问题产品的 JSON 目标文案“退出问题产品”保留为界面目标；指标阈值按进入瘦狗产品的最低有效条件计算。

### 规则分支

同一目标角色可能存在多个日销区间分支。服务端根据当前日销选择与当前产品最匹配的目标分支，再计算该分支所需的毛利率和排名阈值。

全站点指标：

- 日销；
- 毛利率。

国家站点指标：

- 日销；
- 毛利率；
- 小类排名。

### 差距表达

- 日销：`还差 0.47`；
- 毛利率：`还差 4.21pp`；
- 排名：`需提升 24.4 位`；
- 已满足：`已达标`；
- 无数据：`暂无有效数据`；
- 零动销导致毛利率为空：`恢复销售后再判断`。

严格大于规则使用源规则原文展示。差距数值按阈值减当前值展示，不人为增加最小步长。例如当前毛利率 10.79%、规则要求 `>15%`，显示“还差 4.21pp”，同时保留 `>15%` 阈值文案。

### 优先级

国家列表默认按以下顺序排序：

1. 问题产品；
2. 瘦狗产品；
3. 潜力产品；
4. 明星产品。

同一角色内，未达标指标数量多的优先；数量相同时，保持国家名称稳定排序。

默认自动展开排序后的第一项，其余国家折叠。

## 抽屉信息结构

### 顶部

- 标题：销售角色诊断；
- MSKU、国家类别、店铺；
- 周期切换：`7d / 14d / 30d / 90d`；
- 默认周期跟随标签看板 `label_period`；若页面周期为 `all`，使用 `30d`；
- 关闭按钮。

### 全站点判断

- 当前角色 → 升级目标；
- 主要阻塞指标；
- 诊断结论；
- 日销、毛利率指标卡；
- 当前值、目标阈值、状态和进度；
- 一句话升级差距；
- 规则版本和证据状态。

### 国家站点诊断

- 顶部显示全部、问题、瘦狗、潜力、明星数量；
- 国家按优先级排列；
- 折叠行显示国家、当前角色、问题子标签、升级目标和差距摘要；
- 展开后显示指标表：
  - 判断指标；
  - 当前值；
  - 目标阈值；
  - 差距；
- 展示本次实际匹配的升级规则分支。

## 状态处理

- 加载中：抽屉保留头部，正文显示骨架状态；
- 无诊断事实：显示当前 MSKU、周期和“暂无角色诊断证据”；
- 单条证据解析失败：该国家显示“证据格式暂不支持”，不影响其他国家；
- 接口失败：显示可重试错误，不关闭抽屉；
- 切换周期：保留抽屉，重新加载当前周期；
- 快速连续切换：只渲染最后一次请求结果。

## 实现边界

- 不修改标签生成 SQL 和现有标签规则；
- 不修改标签看板主数据统计口径；
- 不向主列表接口批量返回证据 JSON；
- 诊断差距在服务层由现有证据值和已确认的销售角色规则计算；
- 抽屉仍复用现有遮罩、关闭行为和容器；
- 只重构角色诊断模式，不影响 MSKU 画像抽屉和国家画像抽屉。

## 验证

- 服务层测试覆盖全站潜力、国家潜力、国家瘦狗、问题产品、已达标和缺失指标；
- API 测试覆盖参数传递和错误状态；
- 前端测试覆盖按需请求、周期联动、抽屉结构和国家折叠；
- 使用 HW065a 验证 30d 真实证据；
- 桌面与窄屏视觉检查；
- 浏览器控制台无错误；
- 完整测试套件通过。
