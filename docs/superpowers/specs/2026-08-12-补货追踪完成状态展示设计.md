# 补货追踪完成状态展示设计

## 目标

消除“FBA已完成为 0”造成的误解，同时保留现有本次补货链路的严格完成口径。

## 展示调整

补货追踪汇总顶部状态卡调整为：

- 新增“FBA已接收”，展示 `fba_receiving_flag = 1` 的 MSKU 数量；点击后筛选这些 MSKU。
- 将“FBA已完成”改名为“本次链路全部关闭”，仍展示 `fba_closed_flag = 1` 的 MSKU 数量；不改变统计口径。
- 新增“历史FBA已完成”，展示 `historical_fba_completed_count > 0` 的 MSKU 数量；点击后筛选这些 MSKU。

卡片说明明确区分：已接收不等于亚马逊货件关闭；历史完成货件不计入本次链路完成率。

## 数据与接口

复用汇总接口已有的 `fba_closed_count`、`historical_fba_completed_count` 字段。后端汇总增加 `fba_receiving_count`，并为 `historical_fba_completed` 增加筛选条件。数据库表结构和 ETL 判定逻辑保持不变。

## 验收标准

- 当前默认范围应展示“FBA已接收 108”“本次链路全部关闭 0”“历史FBA已完成 32”。
- 三张卡片均可点击筛选，返回数量与卡片一致。
- 原有补货追踪汇总测试全部通过。
