# 断货前可评价经营表现多周期基线设计

## 1. 目标

在现有“断货前经营表现（当前断货中）”面板中，只优化已经进入“可评价经营表现”的产品，不改变“当前断货中”和“暂不评价经营表现”的识别规则。

新设计需要回答两个问题：

1. 产品在断货发生前经营得好不好；
2. 产品在断货发生前处于稳定、加速、减速、启动、临停还是波动状态。

本期只建立断货前基线，不实现返场后的恢复判断。后续返场模块可以使用本期输出的同一组30天基准指标进行对比。

## 2. 非目标

- 不修改当前“断货中”的远端标签定义。
- 不修改MSKU汇总视图中“低量库存边缘断货”和“断货前依据不足”的现有规则、数量口径和页面联动。
- 不把国家站点小类排名强行聚合到国家类别、店铺、MSKU粒度。
- 不修改远端父标签20的断货前销售角色结果。
- 不用国家维度的记录数覆盖或替换MSKU汇总维度的当前断货口径。
- 不在本期实现到货后、返场后或补货优先级判断。
- 不引入一个无法解释的综合分数替代明星、潜力、瘦狗和问题产品。

## 3. 分析粒度与时间锚点

### 3.1 上层经营基线粒度

上层“断货前经营表现”继续使用：

```text
country_category + store + msku
```

该粒度没有唯一的小类排名，因此上层经营基线使用父标签20的全站点断货前销售角色，只采用日销和毛利相关证据。

国家站点排名属于下层：

```text
country_category + country + store + msku
```

父标签21的国家站点断货前角色继续作为国家维度评价依据，不参与MSKU汇总角色的重新计算。页面通过独立视图切换展示两种粒度，禁止把多个国家的小类排名聚合成一个虚假的MSKU排名。

### 3.2 双视图定义

面板提供两个互斥视图：

| 视图 | 统计粒度 | 角色来源 | 排名 |
| --- | --- | --- | --- |
| MSKU汇总 | `country_category + store + msku` | 父标签20，2001～2004 | 不使用 |
| 国家维度 | `country_category + country + store + msku` | 父标签21，2101～2104 | 使用小类排名 |

默认进入“MSKU汇总”。两种视图拥有各自的记录总数、可评价数、暂不评价数、一级角色数量和走势数量，所有占比均以当前视图对应分组为分母。

切换到国家维度后，同一个店铺MSKU可能展开为多个国家记录。因此国家记录数可以大于MSKU汇总记录数；页面必须同时注明“国家记录数”和“对应店铺MSKU数”，不得把两者直接同比。

国家维度的记录全集不能只从已经成功产出2101～2104角色的事实构造，否则缺失国家角色的记录会被静默丢弃。应以现有国家明细数据中能够匹配当前断货业务单元的国家记录为全集，再左连接父标签21角色事实；缺少国家角色或必要证据的国家记录进入国家维度的“断货前依据不足”。

### 3.3 断货前时间锚点

所有周期必须以每个产品自己的断货日前一天为截止日，不得使用当前日期倒推。

设：

```text
T0 = oos_start_date - 1天
```

则：

```text
断货前7天  = T0-6  至 T0
断货前14天 = T0-13 至 T0
断货前30天 = T0-29 至 T0
断货前90天 = T0-89 至 T0
```

每个周期的 `window.end` 必须等于 `T0`，`window.start` 与 `window.days` 必须形成完整闭区间。若日期不一致，不得计算经营走势。

## 4. 总体分层

MSKU汇总视图的页面第一层保持现状：

```text
当前断货
├─ 暂不评价经营表现
│  ├─ 低量库存边缘断货
│  └─ 断货前依据不足
└─ 可评价经营表现
   ├─ 完整周期零销量
   ├─ 明星产品
   ├─ 潜力产品
   ├─ 瘦狗产品
   └─ 问题产品
```

只有“明星产品、潜力产品、瘦狗产品、问题产品”继续计算断货前走势。“完整周期零销量”已经是明确经营结论，不再派生加速或减速走势。

国家维度沿用相同的两组结构和五类可评价结果，但角色来自父标签21。国家维度的明星、潜力、瘦狗和问题产品由日销、毛利率和小类排名三维规则共同决定；完整周期零销量仍优先于国家站点角色。

“低量库存边缘断货”的库存证据仍来自MSKU汇总业务单元。切换国家维度时，该状态可以投影到对应国家记录，但页面必须明确这是“继承MSKU库存状态”，不能解释为某个国家独立拥有一份库存。投影后的数量按国家记录计数，不与MSKU汇总数量相加。

## 5. 固定30天正式基线

### 5.1 基线角色

30天固定为正式断货前经营基线。MSKU汇总视图的一级角色继续使用父标签20的30天冻结结果：

- 2001：明星产品；
- 2002：潜力产品；
- 2003：瘦狗产品；
- 2004：问题产品。

国家维度使用父标签21的30天冻结结果：

- 2101：明星产品（站点）；
- 2102：潜力产品（站点）；
- 2103：瘦狗产品（站点）；
- 2104：问题产品（站点）。

国家维度的30天基线额外输出小类排名、排名统计日和排名有效性。排名只在国家维度展示和筛选。

MSKU汇总的问题产品继续按30天毛利率拆成：

- 毛利率 `< 0%`：亏损问题；
- 毛利率 `0%～5%`：低毛利问题。

国家维度的问题产品还可能由排名证据触发。完整周期零销量优先拆出后，国家问题产品的原因明细至少区分：亏损、低毛利、排名无效；原因可以多选展示，但国家问题产品本身只计数一次。

### 5.2 基线数值

每个可评价产品输出以下30天断货前基线：

- 周期销量；
- 日均销量；
- 销售额；
- 毛利润；
- 毛利率；
- 30天销售角色；
- 断货前走势；
- 30天角色与90天角色是否一致；
- 数据质量状态和不可判原因。

国家维度对应输出每条国家记录的同类指标，并额外包含国家、小类排名和30天国家站点角色。两个视图使用同名基线字段，但必须带有明确的 `scope`，禁止消费者在未知粒度时混用。

这些字段是后续返场恢复判断的候选输入，但本期只负责稳定输出，不负责计算恢复率。

## 6. 多周期走势计算

### 6.1 使用方式

- 7天：断货前最后一段的短期信号；
- 14天：确认短期信号是否连续；
- 30天：正式基线和一级角色；
- 90天：长期底盘和角色一致性，只作为增强证据，不作为进入“可评价”的硬门槛。

30天证据完整的产品即保留在可评价组。缺少完整90天历史时，只将长期一致性记为“暂不可判”，不得把产品重新降入“断货前依据不足”。

### 6.2 非重叠区间

不得直接用包含关系的两个日均值判断趋势。应从累计周期中拆出非重叠区间。

设周期销量分别为 `Q7`、`Q14`、`Q30`、`Q90`：

```text
最后7天日销   = Q7 / 7
此前7天日销   = (Q14 - Q7) / 7

最后14天日销  = Q14 / 14
此前16天日销  = (Q30 - Q14) / 16

最后30天日销  = Q30 / 30
此前60天日销  = (Q90 - Q30) / 60
```

销售额和毛利润使用相同方法拆分。区间毛利率必须使用：

```text
区间毛利率 = 区间毛利润 / 区间销售额
```

不得直接用两个累计毛利率相减代替区间毛利率。

### 6.3 变化率

```text
变化率 = (后段日销 - 前段日销) / 前段日销
```

特殊边界：

- 前段日销为0、后段日销大于0：记为“从零启动”，不计算无穷变化率；
- 前段日销大于0、后段日销为0：记为“降至零”；
- 前后均为0：不计算普通趋势，交由零销量或临停规则处理。

## 7. 断货前走势分类

走势分类按以下优先级互斥执行。

### 7.1 走势暂不可判

出现任一情况时，保留30天一级角色，但不输出六类走势：

- 7、14或30天必要证据缺失；
- 周期截止日不等于断货日前一天；
- 周期开始、结束和天数不一致；
- `Q7 > Q14`、`Q14 > Q30`，或存在明显不可能的累计指标关系；
- 销量、销售额或毛利润出现无法解释的冲突；
- 同一业务单元同一周期存在多个互相冲突的角色事实。

90天缺失本身不触发“走势暂不可判”，只影响长期一致性。

### 7.2 断货前临停

```text
Q30 > 0
且 Q7 = 0
```

表示30天内有经营记录，但断货前最后7天已经停止销售。

### 7.3 断货前启动

```text
Q7 > 0
且 Q14 - Q7 = 0
```

表示断货前此前7天没有销量，最后7天开始产生销量。

### 7.4 断货前波动

满足任一条件：

- 最后7天相对此前7天增长不低于30%，但最后14天相对此前16天下降不低于10%；
- 最后7天相对此前7天下降不低于30%，但最后14天相对此前16天增长不低于10%；
- 7、14、30、90天角色出现三个及以上不同层级；
- 相邻周期多次升降，不能形成单一方向。

### 7.5 断货前加速

同时满足：

- 最后7天日销相对此前7天增长不低于30%；
- 最后14天日销相对此前16天增长不低于10%；
- 未命中启动或波动；
- 7天角色不低于30天角色。

90天证据完整时，额外输出“长期同步向好”或“短期转强”说明，但不改变加速标签。

### 7.6 断货前减速

同时满足：

- 最后7天日销相对此前7天下降不低于30%；
- 最后14天日销相对此前16天下降不低于10%；
- 未命中临停或波动；
- 7天角色不高于30天角色。

90天证据完整时，额外输出“长期同步走弱”或“短期回落”说明，但不改变减速标签。

### 7.7 断货前稳定

未命中上述其他走势，且必要证据完整时归为稳定。稳定不表示产品经营优秀，只表示断货前没有形成显著方向变化；经营好坏仍由30天明星、潜力、瘦狗或问题角色表达。

## 8. 长期一致性

长期一致性独立于六类走势：

- `same`：30天角色与90天角色一致；
- `higher_than_long_term`：30天角色高于90天角色；
- `lower_than_long_term`：30天角色低于90天角色；
- `unavailable`：90天证据不足或异常。

角色层级只用于比较：

```text
问题产品 < 瘦狗产品 < 潜力产品 < 明星产品
```

该顺序不生成综合分，也不覆盖原角色。

## 9. 页面设计

### 9.1 面板结构

“暂不评价经营表现”区域保持不变。

“可评价经营表现”继续展示五张一级卡：

- 完整周期零销量；
- 明星产品；
- 潜力产品；
- 瘦狗产品；
- 问题产品。

明星、潜力、瘦狗和问题产品卡片增加“走势”明细入口。展开后仅展示该一级角色下数量大于0的走势：

- 断货前稳定；
- 断货前加速；
- 断货前减速；
- 断货前启动；
- 断货前临停；
- 断货前波动；
- 走势暂不可判。

走势占比以当前一级角色为分母，不重复计入可评价总数。

### 9.2 维度切换

面板标题区域增加分段切换按钮：

```text
[MSKU汇总] [国家维度]
```

建议放置在标题右侧、周期证据按钮左侧，使“统计粒度”和“时间证据”成为两个独立控制组。

按钮行为：

- 默认选中“MSKU汇总”；
- 点击“国家维度”后重新请求国家粒度汇总，不在前端复制MSKU汇总数据；
- 切换时关闭全部一级卡片下的走势明细和问题产品明细；
- 清除当前视图不兼容的一级角色、走势、依据不足原因等下钻筛选；
- 保留数据日期、国家类别、店铺和关键词等两种视图都支持的全局筛选；
- 同步把下方经营明细切换为国家明细视图；
- 切回MSKU汇总时，下方明细恢复MSKU维度；
- 视图状态可保留在当前页面会话中，但不跨数据日期复用缓存结果。

面板摘要随视图改变：

```text
MSKU汇总：当前断货353条……
国家维度：当前断货国家记录N条，对应店铺MSKU M个……
```

国家维度所有卡片数量统一显示“国家记录”，工具提示说明同一MSKU可能对应多个国家。

### 9.3 周期控件

30天明确标记为“正式基线”。

7、14、90天按钮保留为“查看周期证据”，用于查看对应的冻结指标和原始角色，不改变正式基线、不改变一级卡片统计口径，也不改变下方明细当前选中的30天基线筛选。

### 9.4 明细联动

- 点击一级角色卡：筛选下方经营明细为该30天角色；
- 点击“走势”按钮：只展开或收起二级走势，不触发筛选；
- 点击二级走势：在一级角色条件上继续增加走势筛选；
- 点击完整周期零销量：按30天零销量筛选；
- 清除筛选后恢复全部经营明细；
- 离开“运营状态”一级标签后，现有自动关闭行为保持不变。
- 国家维度点击一级角色或走势后，下方明细必须同时带上国家粒度和对应国家站点角色条件；不得退化为MSKU聚合筛选。

### 9.5 明细字段

下方经营明细至少增加：

- 30天基线角色；
- 断货前走势；
- 30天日均销量；
- 30天销售额；
- 30天毛利润；
- 30天毛利率；
- 最后7天日销；
- 此前7天日销；
- 30天与90天角色关系；
- 趋势证据状态或异常原因。

国家维度明细在上述字段前增加国家，并增加30天小类排名、排名统计日和国家站点角色；MSKU汇总明细不展示国家排名列。

## 10. 后端数据流与接口

### 10.1 数据流

现有断货经营状态查询已经一次性获取当前断货事实以及7、14、30、90天父标签20角色事实。MSKU汇总继续建立：

```text
(country_category, store, msku) -> period -> role evidence
```

国家维度另外建立：

```text
(country_category, country, store, msku) -> period -> country role evidence
```

国家维度使用国家明细全集左连接父标签21的2101～2104角色事实。当前断货、低量库存边缘和其他仅存在于MSKU粒度的状态，通过业务单元键投影到国家记录；国家角色和排名证据不得反向聚合覆盖MSKU汇总结果。

基于当前视图对应的索引完成：

1. 现有可评价判断；
2. 30天正式基线；
3. 六类断货前走势；
4. 90天长期一致性；
5. 汇总卡片和明细筛选成员集合。

不得为每个产品单独查询数据库。

### 10.2 接口扩展

现有断货经营状态响应增加：

```text
baseline_period: "30d"
scope: "business_unit" | "country"
evidence_periods: ["7d", "14d", "30d", "90d"]
trend_definitions
trend_summary_by_status
trend_evidence_quality
```

每个产品的内部派生结果至少包含：

```text
baseline_status_code
trend_code
trend_reason
long_term_consistency
baseline_metrics
interval_metrics
```

明细接口增加可选筛选条件：

```text
stockout_operating_trend
```

汇总接口增加视图参数：

```text
scope=business_unit|country
```

`scope=country` 的响应额外提供 `country_record_count`、`matched_business_unit_count`、排名覆盖率和国家维度证据覆盖率。接口必须拒绝未知 `scope`，不能静默回退。

导出接口必须复用同一派生结果，不得另写一套趋势算法。

## 11. 异常处理与数据质量

- 走势异常不得改变现有30天一级角色。
- 所有异常必须保留可追溯原因，不能静默归为稳定。
- 同一产品的各周期必须使用同一个断货开始日和同一个经营截止日。
- 国家维度同一国家记录的各周期必须使用同一个断货开始日、国家和排名口径。
- 计算前校验累计销量、销售额和毛利润的区间可拆性。
- 允许毛利润为负，不把负毛利润本身视为数据异常。
- 若退货、冲销等业务会合法造成累计销量或销售额不单调，必须先明确字段业务口径；在口径确认前统一标记“趋势证据异常”。
- 页面不得把“走势暂不可判”重复计入“断货前依据不足”，因为产品的30天经营基线仍然可评价。

## 12. 性能与缓存

- 复用现有四周期父标签20事实查询和缓存。
- 国家维度复用父标签21事实和现有国家明细来源，按需加载并单独缓存。
- 计算复杂度控制在业务单元数量乘以固定四周期，等价于 `O(n)`。
- 汇总、明细筛选和CSV导出共享同一成员索引。
- 缓存键固定包含数据日期和基线规则版本；趋势规则调整后必须更新版本，避免旧缓存混用。
- 缓存键必须包含 `scope`，禁止MSKU汇总与国家维度互相命中缓存。

## 13. 测试与验收

### 13.1 单元测试

覆盖以下互斥场景：

- 完整周期零销量不计算走势；
- 稳定、加速、减速、启动、临停、波动各至少一个边界样例；
- 30%和10%阈值的等号边界；
- 缺少90天证据仍可计算30天基线和短期走势；
- 累计销量不单调时输出走势暂不可判；
- 日期窗口未截止到断货日前一天时输出走势暂不可判；
- 同一周期角色冲突时输出走势暂不可判；
- 一级角色与二级走势成员不重复、不遗漏；
- 二级走势合计等于对应一级角色数量；
- 汇总、明细筛选和导出结果一致。
- MSKU汇总使用2001～2004，国家维度使用2101～2104，两个视图不能串用角色事实；
- 国家维度角色缺失时记录仍然存在，并进入依据不足而不是从分母消失；
- 同一MSKU展开多个国家后，国家记录数、对应MSKU数和去重数分别正确；
- 国家维度小类排名参与站点角色，MSKU汇总不读取小类排名。

### 13.2 页面测试

- 暂不评价区域数量和交互不发生回归；
- 一级五张卡数量与当前30天规则一致；
- 走势默认收起，点击明细后展开；
- 点击走势只筛选对应一级角色下的产品；
- 查看7、14、90天证据不改变30天正式基线统计；
- 切换到其他一级标签后面板立即隐藏；
- 小屏和宽屏下走势明细不遮挡数量、占比和操作按钮；
- 维度按钮与周期证据按钮在小屏和宽屏下可明确区分；
- 切换国家维度后摘要、卡片单位和下方明细同步更新；
- 切回MSKU汇总后不残留国家、排名或国家站点角色筛选。

## 14. 后续返场兼容性

本期不实现恢复判断，但30天基线输出应允许后续返场模块直接计算：

```text
销量恢复率 = 返场后日均销量 / 断货前30天日均销量
销售额恢复率 = 返场后日均销售额 / 断货前30天日均销售额
毛利润恢复率 = 返场后日均毛利润 / 断货前30天日均毛利润
```

毛利率应比较百分点差异，不计算比率。返场模块是否采用相同窗口、成熟期和恢复等级，由返场方案另行设计。
