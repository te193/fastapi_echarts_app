# 广告预算抽屉月至今口径统一设计

## 目标

将广告预算工作台详情抽屉中的经营、广告与预算执行数据统一为“本月至今”口径，避免主表按月累计、抽屉按近 7 天或近 30 天展示造成理解偏差。

统计区间固定为当月 1 日至最新表现日期。页面应明确显示该区间，最新表现日期沿用广告预算服务当前使用的数据日期。

## 页面调整

- “近 7 天经营数据”改为“本月至今经营数据”，展示经营销售额、产品销量、Sessions 和广告销售占比。
- “近 7 天广告漏斗”改为“本月至今广告漏斗”，展示曝光、点击、广告订单、广告销售额与本月广告花费。
- TACOS、ACOS、CTR 和广告 CVR 均使用同一月累计区间计算。
- 预算阶梯改为“月预算 / 本月花费 / 月剩余额度”。月剩余额度等于月预算减本月花费，允许为负数，以直接反映超预算金额。
- 趋势图从“最近 30 天累计”改为“本月累计”，横轴从当月 1 日开始，到最新表现日期结束。
- 加权日销、站点销量占比、预算库存池、库存充足状态和预算约束属于当前快照指标，保持原定义，不伪装为月累计指标。

## 数据与接口

- 详情行直接复用主表已汇总的本月字段：`sales_amount`、`sales_qty`、`sessions_total`、`month_spend`、`ad_sales`、`ad_orders`、`ad_clicks`、`ad_impressions`、`tacos`、`acos`、`ctr` 和 `ad_cvr`。
- 新增月累计广告销售占比：`ad_sales_share = ad_sales / sales_amount`；经营销售额为 0 或缺失时返回空值，页面显示“—”。
- 详情趋势查询起始日期改为当月 1 日，不再向前滚动 30 天；累计广告花费和累计广告销售额均在当月内重新从 0 累加。
- 接口继续返回已有近 7 天字段，供主表周预算相关指标及异常规则使用；本次只调整详情抽屉消费的字段，不破坏其他功能。

## 边界与状态

- 真实零值显示 `0` 或 `¥0`；分母为 0 时，比例显示“—”。
- 月预算缺失时，月剩余额度显示“—”；月预算存在且本月花费为 0 时，显示完整月预算余额。
- 趋势无数据时保留空图状态，不生成虚假折线。

## 验收

- 抽屉内所有带周期的指标均标注“本月至今”，且区间与主表一致。
- 月预算、本月花费、月剩余额度计算正确，超预算时余额可为负数。
- 详情接口趋势首日不早于表现日期所在月份的 1 日。
- 现有近 7 天主表预算、异常规则及详情外功能不发生回归。
- 数据服务测试、API/静态契约测试、全量测试与浏览器页面检查全部通过。
