# 广告预算按库存和站点销量分配查询设计

## 目标

在现有国家站点加权日销查询基础上，按补货库存池和站点加权日销占比分配月度、周度广告预算。当前阶段只返回查询结果，不建结果表、不写入结果表。

## 范围

只返回德国、法国、意大利、西班牙、荷兰、美国、英国。其他站点不返回、不参与销量合计，也不预留库存。毛利率暂不参与分配。

库存池粒度为“国家类别 + 店铺 + MSKU”，口径为：

```text
total_budget_inventory = available_total + stock_up_num + local_quantity
```

库存来自 FBA 仓库明细和补货建议各自最新同步日，先汇总到库存池粒度，再与国家站点结果连接。

## 分配公式

设站点加权日销为 `Hᵢ`，同一库存池内白名单站点加权日销合计为 `H`，库存为 `S`，人民币售价为 `Pᵢ`：

```text
sales_shareᵢ = Hᵢ / H
monthly_forecast_qtyᵢ = Hᵢ × 30
monthly_allocated_qtyᵢ = Hᵢ × least(30, S / H)
weekly_forecast_qtyᵢ = Hᵢ × 7
weekly_allocated_qtyᵢ = Hᵢ × least(7, S / H)
```

加权日销小于等于零时，占比、分配数量和预算均为零。库存不足时，各站点按销量占比共享库存；库存充足时，按周期预测销量计算，不强制消耗全部库存。

```text
monthly_ad_budget_cnyᵢ = monthly_allocated_qtyᵢ × Pᵢ × 5%
weekly_ad_budget_cnyᵢ = weekly_allocated_qtyᵢ × Pᵢ × 5%
```

国家类别总预算池使用白名单站点销量占比加权人民币售价：

```text
weighted_price_cny = Σ(Hᵢ × Pᵢ) / H
total_budget_pool_cny = S × weighted_price_cny × 5%
```

若有销量站点缺少 Listing 售价或汇率，总预算池返回空值并标记数据异常，不能把缺失值静默当成零价格。

## 查询输出和保护规则

保留原有周期销量、可售天数、加权日销、Listing 和汇率字段，新增库存同步日、库存组成、库存池、销量占比、月度/周度预测与分配数量、月度/周度预算、总预算池、库存充足标记和数据状态。

查询必须满足：

1. 同一库存池月度分配数量合计不超过总库存。
2. 同一库存池周度分配数量合计不超过总库存，并且不超过月度分配数量。
3. 有销量且价格数据完整时，库存不足情况下的月度预算合计等于总预算池；库存充足时不超过总预算池。
4. 无销量站点预算为零。
5. SQL 不包含 `insert`、持久化结果表或结果表查询。
