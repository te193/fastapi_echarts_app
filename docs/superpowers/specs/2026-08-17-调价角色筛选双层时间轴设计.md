# 调价角色筛选双层时间轴设计

## 目标

将“角色与定价迁移”页的筛选区统一为方案 C 的双层时间轴工作台，解决调前/调后周期控件精致、其余控件简陋造成的画风割裂。

本次只调整角色迁移页筛选区的 HTML、CSS 和必要的前端状态呈现，不改变接口参数、数据库、ETL、角色规则、筛选结果及“经营效果”页行为。

## 页面结构

筛选区使用一个连续容器，内部拆为上下两层，不再平铺为一排相互竞争的表单控件。

### 上层：时间窗口

- 左侧显示调价批次日期，并保留现有日期切换能力。
- 中间使用横向时间轴表达“调前角色基准 → 调价日 → 调后角色表现”。
- 调前和调后周期仍分别支持 3、7、14、30、90 天。
- 时间轴直接显示两个实际计算窗口；调价日节点明确标注“当天不计入”。
- 右侧以低权重状态块显示站点角色口径、角色快照日期和财务快照日期。
- 调前使用蓝色语义，调后使用青绿色语义；颜色只作辅助，文字必须完整表达方向。

### 下层：查询条件

- 国家、店铺和关键词组成一条紧凑筛选带。
- 高级筛选保持行内展开逻辑，并继续显示已选数量和可移除条件标签。
- “应用筛选”是唯一高权重主按钮；“高级筛选”为次按钮；“重置”降为轻量文字操作。
- 应用、重置和页签间状态保存逻辑保持现状。

## 视觉规则

- 只保留一个外层圆角容器，不使用卡片套卡片或字段图标墙。
- 上层使用轻微蓝到青绿的渐变，建立调前、调后语义；下层使用白色或极浅灰背景。
- 输入控件统一高度、圆角、边框、字号和悬停/聚焦状态。
- 时间轴是主视觉，但不得比整个筛选容器明显更高或形成嵌入式异物感。
- 沿用当前看板的字体、蓝色主按钮、边框和阴影体系，不引入新的设计语言。

## 响应式

- 宽屏：上层为“日期 / 时间轴 / 数据状态”三段；下层筛选条件保持单行。
- 中等宽度：数据状态移到上层第二行，国家、店铺、关键词允许等宽压缩。
- 窄屏：日期与时间轴纵向排列，下层变成两列或单列；页面本身不得出现横向溢出。
- 时间轴在窄屏仍保持调前、调价日、调后的阅读顺序，不隐藏实际窗口。

## 交互和状态

- 保留现有元素 ID 和查询参数，优先通过包裹结构与 CSS 类完成改造。
- 选择日期或周期后，实际窗口文字即时更新。
- 加载、空数据和接口异常沿用现有反馈；加载时禁止重复提交。
- 高级筛选展开后属于同一外层容器，不新增弹窗或抽屉。

## 验收标准

- 筛选区看起来是一个完整的分析工作台，不再是一枚精致周期控件与普通表单的拼接。
- 用户能在第一眼识别调前窗口、调价日和调后窗口。
- 国家、店铺、关键词和操作按钮视觉统一且权重低于时间窗口。
- 所有现有筛选参数、状态保存、高级筛选和重置行为保持兼容。
- 桌面和窄屏均无控件挤压、文本重叠或页面横向溢出。
- 前端自动化测试通过，并使用无头浏览器完成桌面与窄屏截图验收。

## 明确不做

- 不修改角色计算规则或远端、本地数据来源。
- 不修改角色迁移矩阵、KPI、摘要和明细表结构。
- 不重做“经营效果”筛选区。
- 不增加动画、弹窗、抽屉或新的前端依赖。
