# 调价角色筛选栏紧凑布局设计

## 目标

缩短角色迁移页第一排筛选控件的横向占用，把高频角色条件提升到常显区域，并将“高级筛选”改为语义更自然的“更多筛选”。本次仅调整前端结构和响应式布局，不修改筛选状态、接口参数或查询逻辑。

## 布局

- 第一排依次显示：国家、店铺、关键词、调前角色、调后角色、角色变化。
- 操作区继续显示：更多筛选、查看结果、重置条件。
- 展开区只保留：财务区间变化、数据状态。
- 国家、店铺和关键词使用紧凑宽度；角色筛选使用相对均衡的短宽度。
- 操作区靠右但保留内边距，避免贴边和溢出。
- 窄屏沿用现有三列、两列和单列降级规则，不产生横向滚动。

## 交互与兼容

- 保留所有现有元素 ID，现有 JavaScript 状态读写逻辑无需改变。
- “更多筛选”的展开、收起、计数徽标和已选条件标签行为保持不变。
- 应用、重置、页签切换状态保存以及接口查询参数保持不变。

## 验收

- 桌面宽度下第一排控件紧凑且按钮不贴边。
- 调前角色、调后角色、角色变化无需展开即可操作。
- 展开区只显示财务区间变化和数据状态。
- 固定文案为“更多筛选”。
- 常用桌面宽度和窄屏均无横向溢出。
