# 广告预算查询输出字段精简设计

## 目标

精简 `data/补货页面加权日销计算.sql` 的最终查询结果，不再向使用方返回以下字段：

- `inventory_snapshot_date`
- `restock_snapshot_date`
- `budget_data_status`

## 设计边界

- 只删除最终 `select` 中的三个输出字段。
- `inventory_snapshot_date` 和 `restock_snapshot_date` 继续保留在临时表及中间 CTE 中，用于判断两类库存快照是否完整。
- 缺少任一库存快照时，月度和周度分配数量仍按 0 处理；总预算池仍返回 `null`。
- 库存池、销量占比、月度/周度分配、售价、汇率及预算公式均不调整。
- 查询仍不创建持久化结果表，也不执行 `insert`。

## 输出变化

最终结果由 40 列减少为 37 列。除删除的三个字段外，其他字段名称、顺序和计算口径保持不变。

## 验证

- 自动化测试断言三个字段不再出现在最终输出列中。
- 自动化测试继续断言两个快照字段参与月度、周度和总预算池的内部保护逻辑。
- 运行目标 SQL 测试和项目全量测试，确保没有回归。
