# 加权日销国家维度设计

## 目标

将现有按国家类别计算的加权日销下钻到国家维度。德国、法国、意大利等国家分别计算自己的周期销量、可售天数、周期日销和最终加权日销；新品/老品判断仍沿用所属国家类别的统一结果。

## 数据来源

- `dwd_datasync.lx_statistics_product_performance`：国家、销量、每日 FBA 可售库存。
- `etl_datasync.etl_dispose_lx_product_local_product_info`：国家类别维度的品牌年份。
- `etl_datasync.etl_dispose_lx_fba_shipment`：国家类别维度的接收次数。

不读取补货结果表，也不计算跟卖补偿、补货数量、库存支撑天数等其他指标。

## 维度设计

### 国家明细计算维度

产品表现日聚合和周期指标统一使用以下业务键：

```text
country + country_category + seller_name_new + seller_sku_adj
```

每个国家独立计算：

- 3、7、14、30 天销量；
- 3、7、14、30 天可售天数；
- 3、7、14、30 天调整后日销；
- 最终加权日销。

### 新老品判断维度

新品/老品判断保持以下业务键：

```text
country_category + seller_name_new + seller_sku_adj
```

判断条件保持现有口径：

```text
品牌包含 2025 或 2026，且 receiving_cnt <= 1 或为空 => 新品
其他 => 老品
```

国家明细通过国家类别、店铺和 MSKU 连接该判断。同一国家类别下的所有国家继承相同结果。例如欧洲站判为新品时，德国、法国和意大利明细均使用新品权重。

## 加权公式

周期日销的销量除数、可售天数不足时的下限和平滑规则保持不变。

新品：

```text
daily_avg_sales = daily_sales_3d * 0.5 + daily_sales_7d * 0.5
```

老品：

```text
daily_avg_sales = daily_sales_7d * 0.6
                + daily_sales_14d * 0.2
                + daily_sales_30d * 0.2
```

## 输出字段

最终结果返回：

- `biz_date`
- `country_category`
- `country`
- `seller_name_new`
- `seller_sku_adj`
- `max_brand_name`
- `receiving_cnt`
- `product_type`
- 各周期销量、可售天数、调整后日销
- `daily_avg_sales`

## 验证标准

1. SQL 只能读取远端过程表并成功执行。
2. 同一国家类别、店铺和 MSKU 下，各国家的 `product_type` 完全一致。
3. 各国家的周期销量和可售天数独立聚合。
4. 国家明细汇总后的周期销量应等于同口径国家类别汇总销量。
5. 最终输出同时包含 `country_category` 和 `country`。
