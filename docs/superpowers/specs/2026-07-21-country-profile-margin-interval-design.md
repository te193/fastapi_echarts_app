# 国家画像当前价格毛利区间展示设计

## 目标

国家明细画像的“国家”单元格中，国家名称下方不再展示远端定价标签（如“健康利润区”），而是展示当前 listing 价格在毛利定价阶梯中所处的区间，例如 `30%–35%`。

## 数据与计算口径

- 当前价格使用国家画像已有的 `price.value`。
- 毛利价格阶梯使用同一国家已有的 `limit_prices.margin_prices`，标准档位为 0%、5%、10%、15%、20%、25%、30%、35%。
- 当价格大于等于某一档毛利价、且小于上一档毛利价时，展示这两个档位组成的区间。例如价格大于等于 30% 毛利价且小于 35% 毛利价时，展示 `30%–35%`。
- 价格大于等于 35% 毛利价时展示 `≥35%`；价格低于 0% 毛利价时展示 `<0%`。
- 当前价格或有效毛利阶梯缺失时展示 `--`，不回退到“健康利润区”等文字标签。
- 边界值归入以该值为下限的区间：价格恰好等于 30% 毛利价时显示 `30%–35%`。

## 实现边界

- 后端负责计算并返回每个国家的 `price_margin_interval`，保证区间口径可测试且不依赖前端重复推导。
- 前端国家单元格只渲染该字段，保持现有国家名称、居中方式、行高与整体样式不变。
- 不调整“毛利定价”列中的价格阶梯快照，也不修改远端国家定价标签本身。

## 验收标准

- 自动化测试覆盖普通区间、档位边界、`≥35%`、`<0%` 和缺失数据。
- 国家名称下方显示计算后的毛利区间，原“健康利润区/基础利润区”等文案不再出现在该位置。
- 重启服务后，以后台浏览器打开国家画像，确认页面展示与接口字段一致且控制台无新增错误。
