# 标签看板筛选数据 CSV 导出设计

## 背景与目标

标签看板的“经营明细与问题定位”区域已经支持公共筛选、明细筛选、两种明细维度、服务端排序和分页。本次新增 CSV 导出能力，导出当前筛选和当前排序对应的全部明细，而不是仅导出当前页。

导出文件需使用中文列名，并尽量覆盖已具备数据来源的经营、标签、诊断和问题字段。CSV 使用 UTF-8 BOM 编码，保证 Excel 直接打开时中文正常显示。

## 交互设计

- 在明细筛选工具栏的“应用筛选”按钮旁新增“导出 CSV”按钮。
- 点击导出时，前端先采集当前控件中的筛选值，确保尚未再次点击“应用筛选”的控件内容也会进入本次导出。
- 导出过程中按钮禁用并显示“导出中…”，避免重复提交。
- 成功后由浏览器下载 CSV，文件名包含标签看板、当前维度和导出日期。
- 失败时恢复按钮状态，并向用户展示服务端返回的中文错误信息或通用失败提示。
- 分页页码和每页条数不影响导出范围；当前排序字段和排序方向影响导出顺序。
- “综合视图 / 标签视图 / 指标视图”只控制页面展示，不裁剪导出字段。导出始终采用完整字段集合。

## 数据粒度

### MSKU 维度

一行代表一个“国家类别 + 店铺 + MSKU”经营单元。该维度不展开到具体国家站点，身份列至少包含国家类别、店铺和 MSKU。

### 国家明细

一行代表一个“国家站点 + 国家类别 + 店铺 + MSKU + SKU”经营单元。该维度沿用当前国家明细数据源及筛选规则，并增加国家和 SKU 等站点身份字段。

## 导出字段

导出字段从当前明细行真实具备的数据中选择，不为不存在的数据新造口径。字段按以下顺序组织：

1. 身份与范围：数据日期、经营周期、维度、国家、国家类别、店铺、MSKU、SKU。
2. 标签与诊断：当前标签、销售角色、角色诊断、标签画像、标签数量、是否标签冲突。
3. 问题与趋势：问题提示、问题代码、动销趋势、趋势变化率、指标状态。
4. 经营指标：日均销量、周期销量、销售额、订单毛利润、订单毛利率，以及明细行已提供的其他库存、流量、广告、价格、排名等字段。

最终中文列映射在服务端集中维护。两种维度共享公共字段，国家明细追加国家、SKU、排名及其数据源实际返回的站点经营字段。空值保留为空单元格，不用“暂无”等页面展示文案污染数据值；布尔值统一导出为“是/否”；列表或标签集合使用稳定分隔符拼接。

金额和数值导出原始数值，比例导出为便于分析的百分数文本或项目既有统一口径，不使用页面的紧凑缩写格式。字段名称需明确周期，例如“30天销量”“30天销售额”；周期由请求中的经营周期生成。

## 服务端设计

新增标签看板明细 CSV 导出接口，接收与 `/api/label-hub/details` 相同的请求结构。接口复用同一套参数校验、数据获取、筛选、问题计算和排序逻辑，但跳过分页切片，再将全部结果写入流式 CSV 响应。

为避免页面明细与导出口径分叉，明细服务会把“筛选并排序后的行”提取为内部共用流程：

- 页面接口：共用流程 → 分页 → 公共行序列化。
- 导出接口：共用流程 → 全量公共行序列化 → 中文字段映射 → CSV。

接口响应设置 `text/csv; charset=utf-8` 和带文件名的 `Content-Disposition`。CSV 内容开头写入 BOM，并使用标准 CSV 转义，正确处理逗号、双引号和换行。

## 前端设计

前端复用 `buildDetailPayload()` 构建请求，导出前调用现有 `collectDetailFilters()`。请求成功后读取 Blob，从 `Content-Disposition` 获取文件名（缺失时使用前端兜底文件名），创建临时下载链接并在触发下载后释放对象 URL。

导出按钮状态独立于“应用筛选”按钮，避免导出请求阻断页面已有明细请求。维度切换、筛选、排序之后，导出请求始终读取最新的 `detailState`。

## 边界与错误处理

- 当前筛选无数据时，返回只含表头的合法 CSV，便于用户确认导出口径。
- 请求参数非法时返回 400，并沿用现有中文校验信息。
- 数据源不可用时返回 503 或现有映射状态，前端显示失败信息，不下载错误内容。
- 国家经营指标不可用且使用了指标型筛选时，沿用明细接口的拒绝规则。
- 导出不受页面最大 `page_size` 取值限制，也不通过伪造超大页长绕过分页。
- 本次不新增异步任务、导出历史、压缩包或自定义选列功能。

## 测试与验收

按测试驱动方式覆盖：

- API 将与明细页相同的筛选参数完整传给导出服务。
- MSKU 维度导出到国家类别/店铺/MSKU 粒度，不包含虚构的国家站点展开。
- 国家明细导出到国家/国家类别/店铺/MSKU/SKU 粒度。
- 导出包含筛选后的全部行，行数不受当前页和每页条数影响。
- 导出顺序遵守当前排序字段和方向。
- 表头为中文，包含主要经营指标、标签、诊断和问题字段。
- 中文、逗号、引号和换行可被标准 CSV 解析器正确还原，且文件包含 UTF-8 BOM。
- 空结果仍有表头。
- 前端模板包含导出按钮，脚本使用当前明细请求载荷、处理 Blob、下载文件并正确恢复按钮状态。
- 现有标签看板 API、服务和前端测试全部通过。

## 成功标准

用户在任一明细维度设置筛选和排序后，点击一次“导出 CSV”，即可获得与当前筛选口径一致的全量数据文件；MSKU 维度止于国家类别经营单元，国家明细止于国家站点经营单元；中文列名清晰，经营字段足够完整，并可直接由 Excel 正常打开。
