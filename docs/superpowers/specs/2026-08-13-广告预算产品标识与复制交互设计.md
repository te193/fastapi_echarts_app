# 广告预算产品标识与复制交互设计

## 目标

优化广告预算工作台主表的“产品”列，让运营人员无需打开详情即可识别市场、国家、店铺、MSKU 和 ASIN，并能快速复制 MSKU 或 ASIN。

## 展示结构

产品单元格按以下层级展示：

1. 商品名称，单行省略，悬停可查看完整名称。
2. 站点，格式为“市场 / 国家”，例如“欧洲站 / 西班牙”。
3. 店铺，例如“MuuWei”。
4. MSKU 与 ASIN，各自带明确标签和独立复制按钮。

缺失值统一显示“—”。ASIN 缺失时复制按钮禁用。

## 复制交互

- 点击 MSKU 或 ASIN 旁的“复制”按钮，只复制编码本身，不复制标签或空格。
- 复制成功后，当前按钮短暂显示“已复制”，随后恢复“复制”。
- 复制失败时短暂显示“复制失败”。
- 点击复制按钮必须阻止表格行点击事件，不能意外打开产品详情抽屉。
- 优先使用 Clipboard API；不可用时使用兼容性回退方案。

## 视觉与响应式

- 保持现有工作台颜色、字体和表格密度。
- 商品列适度加宽，标识信息使用弱化文字，编码使用等宽或数字友好的字形。
- 复制按钮使用轻量描边样式，不与异常标签争夺视觉注意力。
- 小屏幕下标识行允许换行，但按钮仍紧邻对应编码；表格整体继续使用横向滚动。

## 数据与接口

复用现有 `/api/ad-budget` 返回的 `country_category`、`country`、`seller_name_new`、`seller_sku_adj` 和 `asin` 字段，不新增接口或数据库字段。

## 验收

- 主表能明确显示“欧洲站 / 西班牙”、店铺、MSKU 和 ASIN。
- MSKU 和 ASIN 复制内容准确。
- 缺失 ASIN 显示“—”且不可复制。
- 复制按钮不会触发详情抽屉。
- 成功、失败状态可见并能自动恢复。
- 桌面端及窄屏布局无新增溢出，浏览器控制台无错误。
