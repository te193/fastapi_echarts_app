# 加权日销广告预算指标设计

## 目标

在现有国家站点维度的加权日销 SQL 基础上，增加 Listing 最新售价、原币广告预算和人民币广告预算。销量、可售天数、周期日销、加权日销及新品/老品判断口径均保持不变。

## 数据来源

- `dwd_datasync.lx_sales_mws_listing`：Listing 当前同步数据，提供国家、店铺、MSKU、售价、币种和同步时间。
- `dwd_datasync.lx_basic_currency`：月度汇率，使用官方汇率 `rate_org` 将原币换算成人民币。
- 原加权日销 SQL 已使用的三张远端过程表保持不变。

不读取本地 `dashboard_listing_price_daily_snapshot`，确保完整 SQL 仍然只依赖远端过程表。

## Listing 最新售价

Listing 数据统一转换为以下关联键：

```text
country_category + country + seller_name_new + seller_sku_adj
```

其中：

- `country_category` 沿用产品表现数据的国家类别映射；
- `country` 使用 `marketplace`；
- `seller_name_new` 取 `seller_name` 第一个连字符之前的店铺名；
- `seller_sku_adj` 使用 `seller_sku`，与加权日销结果中的调整后 MSKU 匹配；
- 售价使用 `landed_price`，排除空值和非正数；
- 每个业务键按 `create_time` 倒序取最新一条有效记录。

Listing 表是当前同步快照，因此“最新售价”不限制必须早于加权日销的 `biz_date`。

## 币种和汇率

原币币种直接输出 Listing 的 `currency_code`，例如 `EUR`、`SEK`、`GBP`。

人民币汇率按 Listing 同步月份关联：

```text
DATE_FORMAT(listing_create_time, '%Y-%m') = lx_basic_currency.date
```

币种代码转换为汇率表中文名称后关联 `lx_basic_currency.name`，使用 `rate_org`：

| 币种代码 | 汇率表名称 |
| --- | --- |
| EUR | 欧元 |
| PLN | 波兰兹罗提 |
| SEK | 瑞典 |
| TRY | 土耳其里拉 |
| GBP | 英镑 |
| USD | 美元 |
| CAD | 加元 |
| MXN | 墨西哥比索 |
| BRL | 巴西雷亚尔 |

其中 SEK 必须关联“瑞典”；汇率表中不存在“瑞典克朗”这一名称。

## 计算公式

人民币 Listing 售价：

```text
listing_price_cny = listing_price * exchange_rate_cny
```

原币广告预算：

```text
ad_budget_original = listing_price * 5% * daily_avg_sales * 30
```

人民币广告预算：

```text
ad_budget_cny = listing_price * exchange_rate_cny * 5% * daily_avg_sales * 30
```

计算时使用未提前舍入的加权日销和人民币售价，最终售价、汇率及预算展示字段再统一舍入，避免中间舍入扩大误差。

## 输出字段

在原结果字段之后增加：

- `listing_price`：最新 Listing 原币售价；
- `currency_code`：原币币种代码；
- `exchange_rate_cny`：原币兑人民币官方汇率；
- `listing_price_cny`：人民币 Listing 售价；
- `ad_budget_original`：原币广告预算；
- `ad_budget_cny`：人民币广告预算。

`listing_price` 保留 4 位小数，`exchange_rate_cny` 保留 4 位小数，人民币售价和两列预算保留 2 位小数。

## 缺失值规则

- 找不到有效 Listing 售价时，售价、币种、汇率和两列预算均返回 `NULL`。
- 找到售价但找不到对应月份汇率时，原币售价、币种和原币广告预算正常返回；人民币售价、汇率及人民币广告预算返回 `NULL`。
- 加权日销为 0 时，只要售价存在，广告预算返回 0，而不是 `NULL`。

## 验证标准

1. SQL 只读取远端过程表并能完整执行。
2. 同一国家、店铺、MSKU 只关联一条最新有效 Listing 售价，不放大结果行数。
3. 原币广告预算符合 `售价 × 5% × 加权日销 × 30`。
4. 人民币广告预算符合 `原币预算 × 官方汇率`。
5. EUR、PLN、SEK、GBP、USD 等主要币种均能正确关联汇率，特别验证 SEK 对应汇率表的“瑞典”。
6. Listing 或汇率缺失时遵循约定的 `NULL` 规则。
