# MOQ 预警卡去重设计

## 目标

“测算范围分布”中只保留带感叹号的 MOQ 预警卡，不再显示由层级汇总生成的重复“低于最小起订量”卡片；预警卡副标题由“计算补货量”改为“补货数量”。

## 设计

- 前端生成普通测算范围卡片时，同时排除层级名称为“低于最小起订量”或层级排序为 `7` 的行，避免旧数据、文本差异或缓存状态造成重复展示。
- 保留现有 `moq-warning-chip` 作为唯一 MOQ 入口，继续展示预警 MSKU 数和 `moq_warning_calculated_qty`，只将可见文案改为“补货数量”。
- 更新补货页 JavaScript 静态资源版本，使浏览器强制获取去重后的代码。
- 不修改 API、数据库字段、MOQ 计算、汇总口径、明细、导出或追踪数据。

## 验收

- 页面中“低于最小起订量”预警卡只出现一次。
- 唯一卡片显示“补货数量 50”（以当前数据为例）。
- 点击卡片仍能筛选 MOQ 预警明细。
- 前端静态测试、JavaScript 语法检查和完整测试套件通过。
- 使用后台无界面浏览器验证，避免影响用户当前工作。
