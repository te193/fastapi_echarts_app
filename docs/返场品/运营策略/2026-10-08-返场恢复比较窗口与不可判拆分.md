# 返场恢复比较窗口与具体原因拆分

本次更新新版“返场品运营策略”页面的恢复判断、展示及候选建议前置条件。进入仍为连续3天0库存后首次恢复到5件及以上；退出同步使用对应窗口：D7稳定提前退出；D8起按N／21／30天角色连续3天达到本轮目标，最早D10。原返场页不切换。

## 比较窗口

| 返场天数 | 当前窗口 | 历史窗口 |
|---|---|---|
| D1—D6 | 返场至今N天 | 断货前有效N天 |
| D7—D21 | 返场至今N天 | 断货前有效N天 |
| D22—D29 | 最近21天 | 断货前有效21天 |
| D30及以后 | 最近30天 | 断货前有效30天 |

历史优先取断货前紧邻的完整连续有货窗口，不满足时取断货前最后有效的同长度窗口。每种长度的来源由本轮断货前历史确定，保留真实日期，不借用断货期或返场后数据。更长窗口不能形成时不拿短窗口冒充。销量窗口只要求销量和库存完整且连续有货，不要求历史订单毛利率可计算；历史角色30天／14天证据独立保存。

销量恢复率为当前窗口日销÷对应历史窗口日销。历史日销为0时恢复率不适用，不填0或无穷大。80%仍为试算分流线；订单毛利率按当前主窗口毛利总额÷销售额总额，不能平均每日比例。销量、财务、库存分别核对，缺一个指标不隐藏其他已知指标。

## 原不可判分类拆分

| 主分类 | 判断与处理 |
|---|---|
| 历史数据不足 | 未找到对应长度完整连续有货销量窗口；当前销量和利润仍展示 |
| 历史零销量 | 有有效历史窗口但日销为0；恢复率不适用，当前出单情况独立判断 |
| 返场经营数据缺失 | 当前窗口缺销量记录；保留缺失日期，不按0填充 |
| 库存数据缺失 | 当前窗口库存无法确认；暂不进行正常拉量 |
| 库存中断 | 当前评价窗口内连续至少3个自然日可售库存为0；先解决库存，不把缺货影响归为需求恢复差 |
| 当前评价窗口无销量 | 当前窗口销量完整且总销量为0；D8起检查商品及已有广告，不编造0%毛利率 |
| 利润无法评价 | 当前销量可计算，但销售额≤0或财务字段缺失；销量恢复照常展示，利润未确认不加投 |

商品可同时存在历史、库存、财务等问题。主分类仅计一次，优先顺序为库存中断、库存缺失、销量缺失、可核实利润风险；D1—D7在其余条件下仍归自然观察；D8起再区分零销量、利润无法评价、历史不足、历史零销量及正常恢复分流。详情保留全部原因和缺失日期，财务缺数不会删除已知销量。

2026-10-08本次调整仅放宽“库存中断”的分类：连续1—2天为0或零散多次为0不触发该标签；缺失日期、库存为空和任一非0库存记录均打断连续计数，不把缺数补成0。只统计当前N／21／30天评价窗口，不借窗口之前的日期凑3天。仍保存所有无可售日期与窗口最长连续0库存天数。返场事件进入条件、再次断货形成新轮次的条件不变；正式退出仍要求评价窗口每日有货，短暂0库存也不能通过稳定退出。当前无可售库存时的拉量限制不因标签放宽而取消。

已用业务日期2026-10-07重新计算成功批次11（`return-v5-20261008-three-day-stock-interruption`）。干预期仍为371个商品，“库存中断”由70个降为60个；原分类中的另外10个重新归入库存数据缺失3个、利润风险3个、当前窗口无销量2个、恢复不足1个、历史零销量1个。975个最新返场事件保持一致，全部退出状态及首次退出日期与批次10一致。85项回归测试通过，覆盖连续1／2／3天、零散0库存、缺失日期、空库存、窗口边界及退出稳定性。广告不可判的进一步拆分留待下一阶段，本次未变更其判断规则。

### 无销量的显示说明

顶部将无销量商品拆为两张可分别点击筛选的卡片：“返场至今未出单”和“近期窗口无销量”。从D1到当前每天销量记录完整且每天为0，计入前者；其余当前N／21／30天评价窗口无销量的商品计入后者。两类互不重复。经营判断下拉筛选仍可合并查看“当前评价窗口无销量”，不改变原有恢复及退出判断。商品行及详情显示“返场至今未出单”或“近N天无销量”，有返场后出单记录时补充“返场后曾有销量”。返场早期记录缺失时，不推断一直未出单。此处只读返场事件的逐日销量记录，不修改业务源数据或既有结果快照。

业务日期2026-10-07、批次10的63个无销量商品中，59个可确认返场至今一直无销量，4个仅属于当前评价窗口无销量。两张卡片分别筛出59个和4个商品，卡片数量与列表一致；页面筛选、商品标签及详情说明已通过后台无界面浏览器验证，相关33项回归通过。

正常分流：恢复率≥80%且利润安全时保持；不足80%且符合改善条件时可观察至D14结束，D15起不再以改善为由延期；其他恢复不足进入广告诊断。未知历史可以核查已有投放和当前订单经济性，但没有可靠恢复及利润依据时不恢复试投、加竞价或申请新增预算。库存中断或关键销量缺失时仅列核查，不生成正常广告或调价动作；P10独立风险可保留人工提示。

## 近7天变化提醒

主判断使用N／21／30天。另展示近7天日销、订单毛利率及相对前7天的变化，前后窗口都必须位于本轮返场后；不足14天不从断货期补齐对照。日销或毛利率下降时提示复核，暂不设未经验证的下降幅度动作阈值。前段日销为0不算增长率；缺数或缺货提示不可直接归因经营下滑。

近7天提示不自动触发调价或广告动作，不代替主恢复分类；近期订单毛利率低于5%时不增加投放。广告归因和国家站点调价仍使用各自原有评价口径，动作后的复评从实际生效时间单独计算。
