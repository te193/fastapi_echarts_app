# 新版返场品页面实施与验收记录

依据：本目录整体运营策略与销售角色退出方案，以及本轮确认的页面实施计划。

## 实施边界

新增独立页面、真实数据计算与只读建议，保留旧页面。仅新版结果表允许写入，不执行价格或广告动作。

## 已实现内容

- 新入口：`/return-goods-strategy`，侧栏“返场品运营策略”；原 `/return-goods` 页面保留。
- 从经营日表重新识别连续3天断货、恢复到5件及以上的事件，不以旧返场池作为全集。最近180天内的每个商品只展示最新轮次。
- D7每日及整体稳定达标提前退出；未提前退出者从D14评价近14天角色，连续3天达到最低潜力退出。首次退出日期和当时依据按事件、规则版本保留。
- 自然观察、恢复较好、改善中、恢复不足、利润风险、数据不足分别展示；时间阶段和退出状态独立。
- 站点价格按P10—P35相邻档位给候选金额，显示当前值、目标档位、涨跌幅及待核条件。价格冲突、币种不一致、缺档时不拼接或猜测金额。
- 已完成调价记录与同站点、同币种当前价格核对；能对上且间隔未满7天时，阻止正常调价。P10或利润风险保留单独人工审核，上一轮复评结论仍须核实。
- 广告展示具体对象和返场后的成熟数据；可计算的零单止损给出条件式竞价候选，未通过成本、归因保护及操作记录核验时维持待核。自动匹配方式采用自身投放对象及默认竞价继承，不能用整组效果替代。
- 新版结果写入独立批次与商品结果表；网页只读取完整成功批次。列表和详情使用同一个批次编号，防止更新途中混用。
- 已接入每日更新脚本，在原返场数据完成后计算；失败时保留上一成功批次。

## 页面怎样使用

默认查看未退出商品。点击顶部“待核建议”或选择建议类型定位商品，进入详情依次查看退出差距、各国家价格与广告建议、每日恢复过程。

“待核建议”可以显示候选金额，但不等于所有条件已通过。“保持”“暂不调整”及缺少数据的原因单独显示。页面没有执行、审批、预算划拨、调价或广告回写入口。

## 数据来源与明确限制

| 内容 | 实际读取来源与处理 |
| --- | --- |
| 进入、退出、恢复情况 | `dashboard_product_performance_daily`，按店铺、国家类别、MSKU重建；日期缺失和字段空值不当成0 |
| 当前站点价 | `dashboard_listing_price_daily_snapshot`，不读取评价日之后的快照 |
| P10至P35 | `dashboard_limit_price_daily_snapshot`，整套档位同日期、同币种；同站点多条冲突记录待核 |
| 已完成调价 | `price_review_adjustment_source`，仅取评价日及之前近30天已完成、实际价格发生变化的记录；最新记录调后价须与Listing同币种价格一致，不能拿建议当执行 |
| 广告对象元信息 | `dws_datasync.dws_sp_bid_object_snapshot_daily`，只复用日期和对象设置，不复用通用策略建议及效果汇总 |
| 返场后广告表现 | ODS关键词逐日报表；以共同报表截止日向前扣7天，再截取最多14个返场后的成熟日期，排除无库存日和缺失数据 |
| 自动匹配方式 | ODS targets与自身搜索词汇总；没有该历史日可用的对象设置时不借用未来快照。搜索词汇总覆盖完整性另列待核 |
| 月周预算 | `dashboard_ad_budget_snapshot`；展示配置和数据日期，不把配置额度当作真实剩余额度 |

已核实：本地通用广告报表只更新到2026-09-09，本次没有直接用它判断9月29日广告效果。源库广告报表可形成2026-09-29共同日期，成熟截止日为9月22日。自动targets当前表的记录来自9月30日，不能作为9月29日已知的设置使用。

**以下条件尚没有完成可靠的数据核验，因此首批具体动作全部保留为待核，条件已满足的商品数为0：**

- 同站点可承受ACOS、获客成本和包含全部广告消耗的预测利润。
- 尚未匹配上的实际调价、竞价变更、暂停原因、原设置及动作复评记录；已有价格变更记录不等于已完成动作复评。
- Listing实际经营与可投放状态、其他共享库存成员、未来基础花费及已承诺预算占用。

预算上限、池内不重复试算及明确检查通过／失败／待核的规则函数已实现；在效率和真实余额没有核实前，不输出可分配金额、不虚构竞价增加后的花费。当前尚无条件完整的预算申请对象。

## AG Grid与干预期快捷判断

商品处理清单使用项目现有AG Grid组件，支持列排序、列筛选、调整列宽和分页；商品列及详情入口固定。页面加载当前查询条件下的全部商品，再由表格排序和筛选，避免只在接口第一页内操作。原接口默认分页行为保留；页面通过`all_rows=true`读取全集。百分比列按百分数输入筛选值，例如5表示5%。

按用户反馈，删除“先查利润／先补数据”等互斥处理卡，改为原策略的三个决策步骤。只展示D8起尚未退出商品：

| 步骤 | 可点击的具体分支 | 进入下一步的条件 |
|---|---|---|
| 1. 判断自然恢复情况 | 恢复较好，保持；改善中，继续观察；恢复不足，检查广告 | 恢复不足才进入广告恢复判断；利润风险单独诊断 |
| 2. 先检查广告，再决定怎么调 | 检查广告是否开启及正常投放；恢复已有广告；提高竞价；降低竞价；申请池内预算 | 需要调广告时先处理并复评；没有适用动作或广告正常时才审核价格 |
| 3. 广告核清后，再判断价格 | 价格升一档；价格降一档 | 广告未核清或仍在复评时暂缓，且须满足P10底线、P35上限等约束 |

“利润风险”“恢复情况暂无法判断”改为旁侧提示及筛选入口，不作为独立运营步骤。2026-09-29快照的501个干预期商品中，恢复较好35个、改善中0个、恢复不足37个、利润风险166个、无法判断263个。恢复较好、改善中或无法判断的商品，不因快照里存在候选金额就被推入广告／调价分支；独立风险仍可在商品详情查看。

广告及价格分支从恢复不足或利润风险商品的既有建议中读取，只纳入条件已满足或待核的候选，暂不调整的建议不作为动作候选。后一步有候选不等于前一步已完成；例如广告尚未核清时，仅列候选价格。一个商品可能包含多个国家站点和广告对象建议，跨步骤或动作方向可重复出现，数量不能相加作为商品总数。没有依据时不虚构“广告未开启”或“已完成复评”。

点击分支直接筛选商品，表内显示“恢复决策”；查看观察期或已退出商品时隐藏干预步骤。分支随国家、店铺、商品搜索、经营判断和建议类型变化，阶段、天数及分支本身只筛选清单。分类从已发布快照读取，不修改事件、退出规则、运营动作或源数据。

## 实施决定

- 在用户指定的现有开发分支中增加独立模块，保留工作区其他未提交修改；不复制尚未提交的业务资料到另一个工作区。

- 数据缺失不能默认为零；数据日期与规则版本随批次保存。
