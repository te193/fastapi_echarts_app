## 整体运营与进入退出

### 1. 主流程与适用范围
- 连续3天零库存 → 恢复≥5件记D1 → D1—D7观察 → D7稳定提前退出或D8进入干预判断 → 稳定达标常规退出
- 进入、经营判断、操作建议、退出独立计算
- 干预期不代表必须调广告或价格；退出不要求已经执行动作
- 事件粒度：店铺＋国家类别＋MSKU；欧洲共享库存只建立一个事件
- 广告和调价只判断德国、法国、意大利、西班牙、荷兰、英国、美国
- 各国家独立判断；一个类别有提价建议，不代表类别下所有国家一起提价

### 2. 什么时候进入返场
- 连续3个完整自然日有有效库存记录，FBA可售库存每天均为0
  - 断货首日记第一个零库存日；第三天是确认日
  - 1—2天零库存不足以确认断货
  - 缺失日期不填0、不跨缺失拼连续3天
- 已确认断货后，首次恢复到5件及以上的当天记D1
  - 恢复1—4件继续等待，不开始7天观察
  - 0、0、0、4、5：最后一天才是D1
- 每个商品保留最新返场轮次；恢复日位于最近180天
  - 库存取数必须往前覆盖断货首日及历史基准，不能只读180天
  - 源表起点已经为0：提示真实断货首日证据不完整
- 为什么使用3天
  - 减少单日库存波动造成的误入，同时保留真实恢复事件
  - 依据历史门槛验证；是运营折中，不宣称统计最优

### 3. 断货前和返场后怎么比较
- 历史角色基准：断货首日前的有效连续30天；没有有效30天时用14天
  - 每天有货、关键数据完整、毛利可计算；不拼离散有货日
  - 30天优先，即使有效30天比有效14天更早
  - 保存实际起止日期、历史日销、订单毛利率、角色和依据
  - 另保留紧邻断货前30天原始每日表现，基准缺失也能查看原始数据
- 当前恢复与退出角色采用同一个主评价窗口
  - D1—D21：返场多少天就用多少天，与断货前同长度有效窗口比较
  - D22—D29：当前最近21天，对比断货前有效21天
  - D30及以后：当前最近30天，对比断货前有效30天
  - D5比较5天；D22比较最近21天；D75比较最近30天
- 计算公式
  - 日销＝窗口销量合计÷自然日天数
  - 订单毛利率＝窗口订单毛利合计÷销售额合计；分母须大于0
  - 恢复率＝当前日销÷对应长度历史日销
  - 历史日销为0或缺失时恢复率为空，不填0%或100%
- 国家广告价格诊断仍有独立窗口
  - 降价转化看国家N／21／30天访问和销量；历史转化用断货前有效30／14天基准
  - 既有利润修复、提价和保持分支仍看近7天，不与降价样本混用
  - 广告只用本轮返场后归因成熟的对象报表
  - 近7天与前7天变化作为趋势提示，不代替退出主窗口

### 4. 观察期：D1—D7
- 统一动作说明：处于观察期，暂不进行人工干预
- 每天更新库存、销量、毛利和角色，保留风险事实
- D1—D6不提前退出；D7完整数据形成后检查稳定提前退出
- 不因毛利低就提前生成正常提价或加广告动作
- 未提前退出的D8再判断是否需要干预

### 5. 干预期：先判断当前情况
- 库存问题优先
  - 主窗口内连续≥3天零库存：库存中断，暂停正常拉量
  - 主窗口库存缺失：说明缺哪些日期，不能认定恢复不足
  - 库存恢复与经营证据完整后重新判断
- 当前销量数据缺失
  - 明确缺字段或日期，不把缺数当0销量
- 完整窗口销量为0
  - D1至今每天记录完整且均为0：返场至今未出单
  - 当前N／21／30天无销量，其他返场阶段有单或记录不完整：近N天无销量
  - 先判断广告，不凭零销量直接降价
- 主窗口日销不足1件：先修复销量
  - 可以判断适用广告加投或有转化依据的降价
  - 暂不以利润不足阻止拉量；库存、预算、样本、档位和复评仍限制
  - 日销达到1件后恢复正常利润修复判断
  - 此例外不降低角色和退出的毛利要求
- 日销≥1且订单毛利率<5%：利润修复
  - 先查成本、售价和广告消耗；只考虑止损、修复或适用提价
  - 不直接增加投放
- 恢复率≥80%且通过前置条件：恢复较好
  - 当前角色达到本轮目标：保持，继续稳定退出判断
  - 角色尚有差距：复核销量或利润差距，不机械加广告
- 恢复率不足但改善成立且D≤14：继续观察
  - 每天复核，最长观察到D14
  - 近7天和两段3天均完整有货；近7天、近3天毛利率≥5%
  - 近3天毛利不低于前3天，至少2天出单
  - 前3天销量为0则近3天≥3件；否则增长≥20%且至少增加2件
- 其他恢复不足：先广告，再独立审核价格
- 毛利不可算、历史缺失或历史为0：分别说明
  - 不强填恢复率或销售角色
  - 当前角色完整达标仍可退出；历史恢复率不是退出门槛

### 6. 销售角色标准
- 明星
  - 日销>5，订单毛利率>15%
  - 或1≤日销≤5，订单毛利率>25%
- 潜力：排除已属于明星的情况
  - 日销>5，订单毛利率≥5%
  - 或1≤日销≤5，订单毛利率≥10%
- 瘦狗
  - 0<日销<1，订单毛利率>5%
  - 或1≤日销≤5，5%≤订单毛利率<10%
- 问题：数据可算但未满足以上角色条件
- 不可判：日销或订单毛利率不可计算
  - 零销售额不填0%毛利；零销量不判为瘦狗
  - 判定用原始精度，不使用显示四舍五入后的数值

### 7. 本轮退出目标
- 断货前为明星或潜力 → 恢复到潜力或明星即可
- 断货前为问题、瘦狗或不可判 → 恢复到瘦狗、潜力或明星即可
- 不要求恢复历史销量100%，也不要求恢复率达到80%
- 不要求先调整广告或价格；退出每天独立判断

### 8. 提前退出和常规退出
- D7稳定提前退出
  - D1—D7每一天的单日角色都达到本轮目标
  - 7天整体日销和整体毛利率对应角色也达到目标
  - 每天关键数据完整、每天可售库存>0
  - 单日角色看当天销量与当天订单毛利率；有一天0单或不达标即不通过
  - D7完整后记录退出，数据任务可能在D8才看见D7结果
- 常规退出：D8起每天评价主窗口整体角色
  - D8用8天，D9用9天，D10用10天；连续3个评价日达目标，最早D10退出
  - D22起用最近21天；D30起用最近30天
  - 每个评价窗口数据完整、每天可售>0
  - 失败、缺数或窗口含无货日，当天连续次数归零
  - 换窗口不自动归零：新窗口也达标则继续累计
  - 连续3次是3次窗口整体判断，不是只看最后3个单日
- 保存首次退出日期、退出类型、窗口和证据
  - 同轮已确认退出不因后续指标变差撤销
  - 已退出停止本轮新建议，转日常运营

### 9. 再次断货怎么处理
- 恢复后只有1—2天零库存：不新建轮次，原D1保留
  - 主状态不直接写连续断货；但无货日仍影响退出窗口完整有货要求
- 恢复后再次连续3天零库存并恢复≥5件：形成新轮次
  - 新事件、新D1、新历史基准；不复用上一轮动作
  - 预算余额不随新轮次自动重置

## 广告对象决策

### 1. 先明确是否需要广告干预
- 仅D8起未退出、且经营分支需要处理的商品进入正常广告判断
- 观察期、已退出、改善观察、恢复良好且角色达标：不强制干预
- 库存缺失、连续断货或经营数据缺失：先说明经营边界
- 七个国家分别看真实广告对象，不以类别汇总代替国家判断

### 2. 先检查真实对象与当前状态
- 活动、广告组、关键词或自动匹配target逐对象判断
- 必须确认该对象只关联一个MSKU；多商品共用对象不得归给单商品
- 当前有效竞价：正的对象竞价优先，否则继承正的默认竞价
- 自动广告必须有具体匹配方式，不能拿广告组汇总代替target
- 对象快照日期、状态和竞价保存来源；缺失不伪造

### 3. 没有广告、暂停或归档
- 快照成功读取、该经营国家没有广告对象：建议开启广告
  - 核实投放资格、可售状态及是否漏映射，不虚构初始竞价或预算
  - 没有Listing且近7天既无访问又无销量：先核实是否实际经营
- 已有对象或其上层暂停：恢复已有广告候选
  - DOS至少14天；不足或未知则受限
  - 暂停原因、原设置、预算和近期操作待核；不直接恢复高花费异常对象
- 已归档、归属不清或缺自动target：说明具体无法判断原因

### 4. 成熟归因与样本
- 只统计本轮返场后的对象级表现，完成7天归因
- 无货、库存未知、报表缺失不能充作有效评价日
- 归因未成熟：暂不按0单止损，等待成熟再评
- 无点击或无花费：检查资格、状态、预算和同步，不连续抬价
- 已成熟但样本不足：暂不调整，继续积累；不归成广告正常或已调整

### 5. 提高竞价：拉量
- 单商品对象正常投放，当前有效竞价存在
- 至少7个成熟有效报表日、点击≥20、订单≥3
- DOS≥7天
  - ACOS≤20%、7≤DOS<14：库存限制后候选提高3%
  - ACOS≤20%、DOS≥14：候选提高10%；10%—20%同样提高10%
  - 20%<ACOS≤30%：仅低日销修复且DOS≥14候选提高3%，其余保持
  - 30%<ACOS≤40%：保持，不加竞价或预算
  - 调整比例先看固定ACOS档位，再受库存覆盖限制
- 主窗口日销<1：暂不以利润不足拦截拉量，但固定ACOS分档仍有效
- 非低日销：恢复不足、近期利润安全且对象ACOS≤20%才正向加投
- 真实预算、平台竞价限制和近期操作未核实：金额候选仍是待核

### 6. 降低竞价：止损
- 有订单但低效
  - 成熟报表≥7天、订单≥3，40%<ACOS≤50%：候选降低10%
  - ACOS>50%：候选降低20%，禁止加投，不直接恢复原高消耗设置
  - 此分支不另要求点击≥20；上限至1.2倍之间不自动降价
  - 低日销也不能绕过高ACOS止损；20%—30%谨慎测试，30%—40%保持
- 成熟零订单
  - 归因成熟且0订单，按这个关键词或自动匹配方式自己的点击数
  - 不足20次点击：保持，继续观察
  - 20—39次点击：候选降低竞价10%
  - 40次及以上：候选降低竞价20%，不追加新档位
  - 所有商品日销统一，不计算CPA、利润额度、参考价格或预算消耗
  - 其他对象点击和花费不触发本对象降价；自动方式分别统计
  - 20／40点击与10%／20%降幅为试算参数，不是已验证最优
  - 订单归因未成熟或对象报表日期覆盖不足：待核，不补0
  - 不另加7个报表日要求；最多最近14个成熟报表日且不早于本轮返场
  - 调整后用新的成熟数据复评，不拿同一批旧点击每天重复降
  - 核实其他归因订单和保护对象；不能对暂停或归档对象继续降价

### 7. 申请预算与同对象互斥
- 只有成熟样本、经营准入通过，ACOS≤20%、DOS≥14且预算受限已确认，才以申请预算替代提高竞价
- ACOS超过20%不新增预算；同对象加竞价和预算二选一
- 配置上限＝月预算10%与周预算25%的较小值
- 正常申请额＝配置上限、真实池余额、利润容量三者最小值
- 低日销修复只豁免利润容量，仍须真实池余额
- 同池按本次批次逐条扣减可分配额，不能重复分配
- 不限制国家、商品或批次的总动作和正向动作数量，达标对象都给建议
- 同一价格或竞价对象不同时涨降；不同对象、不同国家可不同方向
- 相反方向冲突转为一条人工核查，重复对象去重；排序先呈现止损不代表限额
- 真余额与批次分配尚未完整接通，缺数不生成虚构额度

### 8. 建议金额与结果状态
- 按币种最小单位取整：加价向下、降价向上
- 取整后必须大于0且不同于当前竞价，否则说明无法形成有效变化
- 保存当前竞价、目标竞价、名义比例及实际比例
- 保存ACOS、分档、固定目标20%和上限50%；不能把零销售额当ACOS0%
- 条件已满足：必要检查全部通过，仍是建议层
- 待核：数据或核验未知，逐项说明；不计条件已满足
- 暂不调整：已知库存、金额或其他限制失败
- 保持：未命中动作或本轮无需干预

### 9. 复评与接入价格
- 建议记录不代表已执行；只有真实操作日志才支持复评间隔
- 近期广告操作及成熟效果未核实时明确待核，不编造等待期
- 本国家有具体适用广告动作：先核验广告，价格候选留作后续
- 只有广告缺数、没有适用动作、样本不足保持或广告受限：独立审核价格
- 广告无法判断不等于广告正常；也不单独阻止所有价格判断

## 国家调价决策

### 1. 当前情况与基础边界
- 七国逐国家、店铺、MSKU、币种判断，不按国家类别统一调价
- 用当前Listing与当前价格阶梯，不参考断货前售价或促销优惠
- 观察期、已退出、库存或经营关键数据缺失：不生成正常调价动作
- 当前金额、档位或币种缺失时说明待核，不虚构目标金额

### 2. 先确定广告与价格的关系
- 先完成本国家广告对象判断，再独立计算价格候选
- 有具体适用广告动作：价格标为广告优先后的候选，不算当前可审核调价
- 只是广告缺数、无适用动作或广告受限：可以独立审核价格自身条件
- 价格自身已受限：保留原限制，不覆盖成广告尚未核清
- 没有实际操作记录不写已经调整或等待复评

### 3. 调价判断的先后顺序
- 当前价<P10：先审核恢复到P10底线
- 主窗口日销<1：优先销量修复，转化下滑等条件满足才候选降档
- 非低日销且国家近7天数据或利润不可算：待核，不先指定涨降
- 非低日销、国家有销量且毛利率<5%：核实低价原因后候选升档
- 近7天角色≥潜力，或D<14且恢复较好：保持
- 未被保持分支截获、国家日销1—5且毛利率5%至不足10%：候选升档
- 恢复不足等适用情形：满足转化下滑与利润余量才候选降档
- 其他保持，说明未命中哪项条件

### 4. 降价必须同时满足
- 给够断货前卖3件所需的访问机会，不固定50次
  - 国家、店铺、MSKU单独算；历史是本轮断货前有效有货30天或14天
  - 历史访问>0、销量至少5件、数据完整；不借其他国家或返场后表现
  - 所需访问＝向上取整（3×历史访问÷历史销量）
  - 例：历史100访问卖10件，门槛30；100访问卖5件，门槛60
- 返场后按对应窗口累计访问和销量
  - D8—D21：D1至当天N天；D22—D29：最近21天；D30起：最近30天
  - 窗口每天有货，日期与销量访问完整；不从断货期补数或退回近7天
- 当前预期销量＝对应窗口访问×历史销量÷历史访问
  - 预期至少3件，实际严格低于预期70%，才审核降一档
  - 等于70%不达标；3件与70%均为试算参数，不证明价格归因
  - 样本不足继续观察，历史或日期缺失待核，不用50兜底
- DOS≥14天
- 当前价格和六档完整、币种一致、严格递增，可生成向下相邻金额
- 不低于P10，未被正常7天调价间隔限制
- 主窗口日销<1：暂不要求利润余量，先修复销量
- 非低日销：国家订单毛利率≥10%，还须核验调后预测毛利率≥5%
- 不满足流量或历史样本时不直接降价，先诊断流量和广告

### 5. 提价哪些情况适用
- 当前价<P10：审核到P10，属于底线修复
- 非低日销、国家有销量且毛利率<5%：相邻升档候选
  - 核实利润缺口是否由低价造成，不能用提价掩盖成本或广告异常
- 非低日销、国家日销1—5且毛利率5%至不足10%：相邻升档修复角色差距
  - 受前面保持分支和预测利润核验限制
- 普通提价目标不超过P35，不因返场身份统一提价

### 6. 每次只调一个相邻档位
- 阶梯：P10、P15、P20、P25、P30、P35；编号不是涨跌百分比
- 恰在P20：降到P15或升到P25
- 在P15与P20之间：降到P15或升到P20
- 恰在P10：不能再降；低于P10先审核到P10
- 恰在P35：不能再升；高于P35向下最近档为P35
- 六档必须完整且严格递增，不跳过缺档
- 目标按币种最小单位向上取整，取整后仍在P10—P35且有真实变化
- 实际涨跌幅＝目标金额÷当前金额−1，不把档位差写成固定5%

### 7. 真实调价记录与复评
- 成功实际调价记录与当前Listing对应，保存生效日期与币种
- 上次实际调价至评价日不足7天：普通下一次调价受限
- 没有记录：操作与复评间隔待核，不默认已经满足
- 当前价<P10或非低日销毛利率<5%：可单列人工风险审核，不自动执行例外
- 降价拉量仍遵守正常7天间隔
- 当前代码按自然日期差；满7日期差不必然代表7个完整生效日，接手时核对

### 8. 数量与原因怎样留档
- 区分方向命中、广告优先暂缓、自身受限、待核、全部条件已满足
- 商品数按店铺＋国家类别＋MSKU去重；国家建议和广告对象另算
