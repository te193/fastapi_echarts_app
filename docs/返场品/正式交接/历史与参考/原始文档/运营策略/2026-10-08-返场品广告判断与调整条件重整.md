# 返场品广告判断与调整条件重整

> 2026-10-09更新：广告与调价只判断德国、法国、意大利、西班牙、荷兰、英国、美国七个国家。恢复和退出仍按店铺＋国家类别＋MSKU判断，各国家广告和价格建议独立生成。有广告记录的国家继续判断已有对象的恢复、竞价、预算及保持；没有匹配到广告记录的经营国家显示“建议开启广告”，不再仅因此把整个商品判为广告无法判断。开启建议是待核建议，不自动新建活动、不虚构竞价或预算，开启前确认没有遗漏的已有广告，库存、预算和复评限制仍保留。同一国家存在待处理开启建议时，正常调价等待该国家广告处理与复评；其他国家的广告、价格结果不被连带阻止。下文与此项更新冲突的旧“无广告仅核查”表述以本更新为准。

> 页面实施：同时适配已保存快照和后续计算，旧快照原始记录保留；按新七国范围重新整理展示和建议数量。2026-10-08数据快照下，177个商品至少有一个范围内国家建议开启广告，另有39个商品仍因报表、匹配方式或必要条件不足无法判断。数量按商品去重，开启广告不等同于所有国家都要开启。88项相关测试及8001、8766两个端口无界面验收通过，具体国家建议和筛选联动已核对。

状态：整体广告方案尚未完整实施；低日销优先修复销量分支已接入新版独立页面、计算代码及专用结果快照。其余数据核验差距见第九节，不能把看板数量视为全部广告条件已经核清。所有结果仅为建议，不执行广告或价格调整。

> 实施补记：低日销优先修复销量分支已接入独立页面与真实结果快照；其他广告来源及核验差距仍按下文说明保留。见[低日销实施与验收](2026-10-08-低日销优先修复销量实施与验收.md)。

## 一、先明确这部分要交付什么

系统先判断，再给运营具体结论。每个国家站点、每个已有广告对象分别输出：当前是什么情况、需要不要调整、调整哪个层级或对象、当前设置到建议设置、理由，以及没有通过的条件。

主流程：需要返场干预的商品 → 确认站点可售和已有广告 → 判断是否正常投放 → 判断具体对象效果 → 给出恢复、竞价、预算或保持结论 → 衔接价格。

不要求为了进入价格判断先做一次广告动作。原本没有广告、广告无需调整、样本不足但投放状态明确，均可以继续独立审核价格；仍需通过价格自己的条件。广告状态确实无法确认，或已经有需要先处理的广告动作时，才暂缓正常价格调整。独立利润风险仍保留人工核查。

## 二、哪些商品需要进入广告判断

### 日销低于1件，先修复销量

**新增已确认业务选择，已接入新版独立页面计算：日销低于1件时先恢复销量，达到1件及以上后再判断利润修复。**此项优先于本文原有统一利润限制。

日销使用店铺＋国家类别＋MSKU当前N／21／30天主评价窗口的总销量÷自然日数。不能用欧洲某个小站点日销不足1件，让整个商品绕过利润判断；具体广告与价格动作仍按国家站点给出。

| 当前日销 | 优先处理 | 利润限制 |
| --- | --- | --- |
| 0≤日销＜1件 | 先恢复销量，按条件恢复已有广告、提高竞价、申请池内额度，或审核降一档价格 | 不因订单毛利率低于5%、为负或暂不可计算而禁止拉量；暂不要求角色利润目标，也暂不以预计计入广告后的5%底线拦截 |
| 日销≥1件 | 重新检查利润，必要时修复 | 订单毛利率低于5%时查广告消耗、价格及成本；角色利润差距另看退出目标，不统一套10% |
| 日销缺失、窗口销量不完整或销量异常 | 核查销售数据 | 不把缺失当零销量，不自动进入低销量例外 |

D1—D7仍自然观察；D8起低于1件且未退出的商品，可以进入销量修复判断，即使对历史的销量恢复率已达到80%。满足改善观察的仍可观察至D14，不要求统一调整。已退出商品停止本轮新建议，退出条件不变。

低销量分支不以利润额度作为拉量准入，但必须遵守固定ACOS分档：目标≤20%、上限50%，不再用利润倒推ACOS。提高竞价仍须正常投放、至少7个成熟报表日、20次点击和3单；恢复已有广告须核实断货暂停原因、原设置和可靠历史转化。2026-10-12起零单简化为[成熟点击分档](../../../01-返场品完整运营决策.md)。有单幅度见[固定ACOS规则](../../../01-返场品完整运营决策.md)。

低销量分支可审核降价，不再要求先达到订单毛利率门槛，也不因毛利率低于5%就自动提价。降价仍须有转化偏弱等原定依据，以及真实当前价格和完整档位；一次只降一档、最低P10。日销达到1件后再审核利润修复提价，一次只升一档、最高P35。价格数据缺失时不编造金额。

库存、真实预算余额、批准花费上限、对象归属、当前有效竞价和复评条件继续保留，动作数量上限已取消。先判断需要调整的广告，再核验价格，不默认同时加广告和降价。每次复评重新计算同一口径日销；达到1件即恢复利润判断，回落到1件以下也不能重置预算占用或绕过上一轮复评。订单毛利率和日均毛利额持续展示，并明确标注“低日销，先修复销量”。

| 商品情况 | 是否进入及处理方向 |
| --- | --- |
| D1—D7自然恢复 | 记录状态，保持已有有效广告；不主动加投 |
| D8起恢复较好，或满足改善观察且未结束D14 | 保持，不因进入干预期就统一调整 |
| D8起恢复不足 | 进入以下完整判断，先查有没有投放恢复问题 |
| 日销≥1件且订单毛利率低于5% | 优先判断浪费和止损，不直接恢复试投、涨竞价或加预算 |
| 触及批准花费上限 | 所有分支均停止追加，审核止损；低日销也不能突破上限 |
| 当前不可售、库存不足以承接新增投放 | 不生成拉量动作；已有充分依据的降低竞价止损可独立审核 |
| 主评价窗口连续3个自然日可售库存为0 | 标记库存中断，不把断货影响当成需求恢复差；不一律禁止有依据的止损 |

缺少历史销量不等于不能读取当前广告状态，也不等于可以加投。恢复程度、对象表现、库存、利润分别判断，不用一个“不可判”吞掉全部信息。

## 三、先判断有没有广告、有没有投出去

| 场景 | 系统必须判断的内容 | 可以给出的结论 |
| --- | --- | --- |
| 有暂停层级 | 活动、广告组、商品广告及投放对象分别是什么状态；哪个层级暂停；暂停原因、断货前效果和原设置是否可靠 | 确认因断货暂停且符合限制，建议恢复对应层级原设置；原因不清或原本因低效暂停，不建议直接恢复 |
| 没匹配到对象 | 是否确实无广告，还是店铺、国家、MSKU、商品广告或对象关联缺失；对象来源是否完整且覆盖暂停对象 | 只有完整来源确认无广告，才写“无已有广告，本版不新建”；否则写具体关联缺失，不把未匹配当无广告 |
| 显示开启，但无曝光或花费 | 商品是否可投、各层级状态是否齐全、预算是否用完、报表是否更新；曝光、点击、花费分别有多少 | 找到明确原因就输出对应处理；没有证据证明竞价不足，不建议统一涨竞价 |
| 有曝光、点击少 | 投放相关性和点击表现，商品展示是否发生变化 | 列人工诊断，不把点击少直接归因竞价或售价 |
| 正常投放且有点击 | 归因是否完整、对象归属、点击订单花费销售额是否可靠 | 进入下一节竞价判断 |

空状态不当作开启；“未暂停”不等于商品广告具备投放资格；只读到关键词快照也不代表已读到所有商品广告。已归档对象不建议直接恢复。

## 四、哪些对象可以给出竞价调整建议

手动关键词、自动匹配方式分别使用自己的表现。一个广告组有多个商品时，不把整组或共用对象的成交直接归给单个MSKU；归属无法分清，保留已知表现并说明无法单品判断。

| 对象情况 | 必须同时满足 | 调整结论 |
| --- | --- | --- |
| 成交有效，商品仍需拉量 | 正常投放；至少7个成熟有效报表日、点击≥20、订单≥3；ACOS≤20%，经营、库存、预算和复评允许 | 单轮＋10%；DOS7至不足14天最多＋3% |
| 谨慎拉量 | 同样样本、20%<ACOS≤30%，主窗口日销<1、DOS≥14 | 单轮＋3%，不新增预算；非低日销保持 |
| 中间档观察 | 30%<ACOS≤40%，数据和样本可靠 | 保持，不新增消耗 |
| 有成交但广告费过高 | 正常投放；至少7个成熟有效报表日、订单≥3；40%<ACOS≤50%或ACOS>50%；对象和有效竞价可核 | 分别−10%／−20%；不另要求20点击，低日销也遵守 |
| 零成交止损 | 对象成熟0单；点击、日期覆盖、币种及归属可靠；其他归因订单和保护条件、有效竞价可核 | 不足20点击保持、20—39降10%、40次及以上降20%；不区分日销，不另加7个报表日 |
| 有效报表天数、点击或订单尚不足以命中动作 | 广告状态及已知数据明确 | 暂不调整竞价，显示实际样本及还差什么；不把样本不足写成所有广告都无法判断 |
| 缺少对象归属、有效竞价或归因销售额；零单成熟点击／订单或日期覆盖缺证据 | 对应动作依赖的数据未核实；零单不依赖每单成本 | 说明具体缺项，不虚构金额或ACOS0% |

固定边界：有单20%进入＋10%档、30%属于低日销谨慎档、40%保持、50%降10%、严格超过50%降20%。成熟零单点击恰为20次降10%、恰为40次降20%，均为试算参数。低日销不忽略固定ACOS、预算证据或批准花费上限。

自动匹配方式竞价为空或0时，核实是否继承广告组默认竞价；不直接把0当实际竞价。调整金额按同币种最小单位和平台上下限计算，取整后没变化则不生成有效调整建议。

上述点击、订单、倍数和涨跌幅沿用V1候选参数，仍待试算验证，不声称已经证明最优。

## 五、哪些可以恢复投放或增加预算

**恢复投放：**确认因本轮断货暂停、当前可投、断货前设置与效果可靠；库存覆盖至少14天；预算及实际操作记录检查通过；日销≥1件时还须通过利润检查。只恢复对应暂停层级的有效设置，不同时机械涨竞价；非断货原因暂停、原设置缺失或已归档，不直接恢复。

**增加预算：**先满足广告成熟成交及样本条件、固定ACOS≤20%、库存覆盖≥14天，再确认确实由预算限制投放；20%以上不申请增量。不是销量差就申请预算，也不是花完配置预算就必然值得加钱。单轮额度取商品原月配置10%、周配置25%的较低值，再受池内真实余额、站点／活动容量及批准花费上限限制；日销≥1件时还须利润额度允许，低于1件不因利润额度未知或不足直接拦截。与涨竞价二选一，总池不增加。无法计算真实可用预算时，不输出虚构金额。

**确认无已有广告：**首版不自动新建，不输出恢复广告；需要新建时另列人工方案。当前零销量且没有可靠历史转化，不新增测试预算；低日销分支不把利润依据不足单独当作禁投理由。

## 六、动作共同受哪些限制

| 条件 | 对动作的影响 |
| --- | --- |
| 日销≥1件且订单毛利率低于5% | 禁止直接增加投放；有依据的止损另判；日销低于1件优先恢复销量 |
| 联合预测利润 | 日销≥1件时，预计计入全部广告消耗后的毛利率不得低于5%；低于1件暂不作为硬门槛。有数据仍记录预测值，与订单毛利率分开，不重复扣费 |
| 无可售、库存覆盖未知或不足7天 | 不恢复试投、不提高竞价、不加预算；有依据的止损可保留 |
| 库存覆盖7至不足14天 | 所有效率及样本合格的对象可列加价候选，每个幅度最多+3%；不恢复试投、不增加预算 |
| 库存覆盖14至不足28天 | 不限制拉量对象数量，合并检查共享库存和资金，仍按先广告后价格流程判断 |
| 库存覆盖至少28天 | 所有达标对象均可列建议，不设数量名额，不代表必须调整 |
| 预算不够或额度不明 | 不增加消耗；池内申请也须先计算余额，不能重复占用同一份额度 |
| 近期已调整、尚未完成复评 | 不叠加新一轮正常调整，不拿同一批旧报表每天重复降竞价 |

库存仅用FBA可售、不加在途；共享库存只计一次，包含同池实际销售成员的消耗。最近零销量不视为库存覆盖无限。

不设置国家、商品或批次的广告总动作、正向动作及库存分档数量名额；所有达标对象保留。同一价格或竞价对象涨降互斥，不同对象可不同方向；保护条件、真实操作、共享资金和复评独立核验。见[数量与互斥规则](../../../01-返场品完整运营决策.md)。

## 七、结果怎么给运营

每个对象只输出一个当前主结论，同时保留全部限制原因：

| 结果 | 何时使用 | 必须显示 |
| --- | --- | --- |
| 可以给出调整建议 | 该动作必需的数据、门槛和限制都核清 | 国家、活动、广告组、对象、当前设置→建议设置、幅度、理由及复评日期；仅建议，不自动执行 |
| 暂不调整 | 已有可靠依据，未命中动作或样本不足 | 明确保持原因、实际样本及下次复核条件 |
| 暂不能调整 | 已知触及库存、利润、预算或复评限制 | 对应限制及实际值；区分拉量被限制与止损可继续判断 |
| 暂无法判断 | 必要数据缺失、对象归属不明或状态不明 | 已确认的事实、具体缺失字段、影响哪些动作；不冒充保持 |
| 只需人工诊断 | 展示、相关性、资格或暂停原因需要人工确认 | 已发现的问题，不先附上没有依据的涨跌数字 |

商品层可同时包含不同国家、不同对象的结果。看板统计应明确“涉及商品数／站点数／对象数”；同一商品存在其他未核清对象，不应删除已经有充分依据的对象结论，也不表示该商品全部广告都已核清。

## 八、复评与价格衔接

动作实际生效后第3天确认是否生效及风险；第7天看商品恢复、订单毛利率、库存和花费；首个完整7天动作后广告窗口的订单补齐后，再判效率、保留或撤回。期间不机械追加。第14天看持续效果和独立退出条件。

确认无需广告动作，或者状态明确、仅效果样本不足时，可以继续独立审核价格。需要先恢复或调整广告时，待复评后再做正常价格调整。缺失对象归属、状态或影响价格诊断的广告成本时，价格不能假定广告正常；只保留人工诊断或参考试算，不提前给确定方向。

| 主要靠已有竞价对象快照查商品广告 | 没匹配到对象无法证明原本无广告 | 补齐商品广告、层级状态及商品关联覆盖检查 |
| 自动广告部分只有广告组汇总，匹配方式搜索词汇总完整性未核实 | 不能可靠归为一个匹配方式的效果 | 核实具体方式及完整对象报表，不整组代替 |
| 实际预算限制、可分配余额、操作与复评证据未全面接入 | 恢复、加预算和重复调价检查不完整 | 接入真实依据；按动作输出缺失或限制，不统一贴“待核”后给出金额 |
| 当前读接口主要整理已保存建议，未完成上述完整重新计算 | 看板改名不能证明策略落实 | 数据与规则一起修复，按典型案例和真实快照验收 |

## 十、下一次实现的验收案例

新增边界：主窗口日销0、0.99和恰为1件；低日销且负毛利、毛利未知、预测利润低于5%；小站点不足1件但国家类别日销已达到1件；销售数据缺失；达到1件后利润修复；预算已满或库存不足时不能借例外加投；低利润降价仍受P10限制；处于观察期及已退出时不生成新动作。

至少验证：因断货暂停与非断货暂停；真实无广告与对象关联缺失；状态为空；开启但无曝光；预算确实受限与只是配置低；ACOS20%／30%／40%／50%两侧、低日销高ACOS不加投；零单20点击但花费不足、缺成本、存在其他归因订单；归因未完成；默认竞价继承；多商品广告组；同商品一个对象可以调而另一个未知；库存仅断1—2天与连续3天；库存及利润只限制拉量、不自动屏蔽可靠止损；动作复评未完成。

广告效果取本轮返场后已归因的对象数据，断货前表现只支持判断原设置是否值得恢复。采用7天归因时，共同完整报表日期往前扣7天作为截止日，最多取最近14个成熟报表日，排除断货日期；缺报表不补0。竞价效果窗口与商品N／21／30天恢复比较分别保存。
