## 1. 从断货确认到干预退出的完整流程

### 1.1 先确认连续断货，再确定返场D1（已确认）

按**店铺＋国家类别＋MSKU**判断：**连续3个自然日都有有效库存记录，且FBA可售库存均为0，确认本轮断货；之后首次恢复到5件及以上，生成返场记录，当天记为D1。**

- 断货日期记为这段连续3天中第一天，不记为第3天；本轮历史基准取这个断货日之前的数据。
- 满3天前出现正库存（包括1—5件），连续计数归零；以后再出现0，从新的0库存日重新计数。
- 缺失日不能当作0，也不能跨缺失日拼接连续天数。满3天前出现缺失记录，需从后续连续、有效的0库存日重新计数。
- 已经确认本轮断货后，库存恢复到1—4件仍不进入返场，继续等待首次达到5件及以上；期间缺失数据保留待核提示。
- 每轮新返场均按相同进入条件判断。进入后沿用7天自然恢复期，D8再判断是否需要干预。
- 这3天用于确认断货，不能抵扣返场后的7天观察期；也不替代正式退出要求的“连续有货”。进入后哪怕只再次断货1天，也不能把这一天算作有货日。

| 每日FBA可售库存变化 | 是否进入返场品 |
| --- | --- |
| 0 → 8 | 不进入，只有1天为0 |
| 0 → 0 → 8 | 不进入，只有2天为0 |
| 0 → 2 → 0 → 8 | 不进入，没有连续3天为0 |
| 0 → 0 → 0 → 4 → 5 | 进入，恢复到5件当天为D1 |
| 0 → 缺失 → 0 → 8 | 不能确认连续3天断货，不直接进入 |

现行系统仍使用“出现一次0库存，之后恢复到大于5”的识别方式。本节是已确认、待实施的新方案，不代表系统已经切换。

### 1.2 进入之后，什么情况下继续观察或干预

**第1.1节决定能否进入本轮返场，第2节决定进入后需不需要干预，第3、4节决定具体调什么，退出按断货前角色设定最低目标：原问题、瘦狗或历史不可判为瘦狗，原潜力、明星为潜力；历史明星不再要求恢复明星。**后面的广告和价格条件都必须接在这条流程之后，不能仅凭“库存恢复了”直接生成返场调整建议。

| 当前走到哪一步 | 判断与下一步 |
| --- | --- |
| 尚未满足连续3天断货 | 不新建本轮返场，不新启7天观察，也不生成本轮返场广告或价格建议；销量、利润、库存问题仍走日常运营 |
| 已确认连续3天断货，但库存尚未恢复到5件 | 等待补货恢复，不开始返场观察，不做返场拉量动作 |
| 首次恢复到5件及以上 | 记为本轮D1，固定断货前基准，开始7天自然恢复 |
| D1–D7 | 记录销量、订单毛利率、库存、流量和广告状态，不主动调价或加投；库存、利润与预算风险仍需核查 |
| D8起，恢复率≥80%、订单毛利率≥5%，数据完整且连续有货 | 保持价格和有效广告，继续检查退出条件 |
| D8起，恢复率不足80%，但符合改善条件且尚未结束D14观察 | 每天复核，最多继续观察至D14结束 |
| D8起，恢复不足且不符合改善条件；或D14观察结束仍不足 | 进入广告诊断。需要调广告时先调并复评；广告正常或没有适用动作时，直接审核价格 |
| D7结束，D1—D7每天及7天整体均达到本轮目标，数据完整且每天有货 | D7提前退出，转日常运营，不进入D8干预分流；实际取数须等待D7完整更新 |
| 未提前退出，D8起对应N／21／30天窗口角色连续3天达到本轮目标，且满足连续有货等要求 | 常规退出，最早D10；原明星达到潜力同样通过，不为追平历史销量继续留在返场池 |

数据不足或再次断货时，先核查，不因到了D8或D14强行进入广告／价格调整。订单毛利率低于5%或花费触及上限时，优先处理风险；这不等于允许在观察期提前加投。

干预的目标是恢复断货前的经营表现，并争取更好表现。正式退出沿用独立的[返场品销售角色达标退出方案](2026-09-28-返场品销售角色达标退出方案.md)，原问题、瘦狗或历史不可判至少达到瘦狗，原潜力、明星至少达到潜力；N／21／30天对应窗口及连续3天确认作为常规路径，同时保留已确认的D7稳定达标提前退出路径：D1—D7每天及7天整体均达到本轮目标、数据完整且每天有货。新轮次是否生成，统一先按本文件第1.1节的3天入口判断。

经营分流统一使用**订单毛利率**。含全部广告消耗的预测利润用于动作审核，单独记录。进入返场、恢复不足、允许动作是三次不同判断；即使进入广告或价格诊断，也必须通过库存、利润、预算及复评限制。

### 1.3 用本轮确认的断货日确定历史来源

历史来源以第1.1节确认的连续断货首日为界。历史角色基准仍采用该日之前的有效30天窗口，必要时采用有效14天兜底；销量恢复比较按第2.1节另取N／21／30天有效销量窗口，不要求历史毛利数据完整。**不能继续沿用此前孤立的一次0库存日期，也不能以第3个0库存日或返场日作断货起点。**分别保存实际来源日期、窗口起止和证据状态，不能混入断货期或用返场后的表现补历史。

同一轮固定的历史日销用于第2节销量恢复率，历史Sessions用于第4节转化比较，断货前角色用于恢复程度对比，退出最低目标按断货前角色分别为瘦狗或潜力；正常调价只使用最新当前价及同站点的有效定价档位，不再使用断货前售价。这样进入判断、是否干预和调价都对应同一轮断货。

同时保留历史订单毛利率、日均订单毛利额，以及可核实的广告设置和投放表现。广告资料保存真实来源时点，不能把当前设置当作断货前设置；价格数据保存当前快照和模型档位日期，不要求断货前价格可用。本版不要求提供促销、优惠券记录。

- 恢复判断粒度：店铺＋国家类别＋MSKU＋本轮事件。
- 价格与广告动作粒度：具体国家站点＋店铺＋MSKU，再定位广告对象。
- 不能要求欧洲每个国家分别达到整个欧洲MSKU的销量门槛；跨国家金额先统一币种，多商品广告组不能直接当作单个MSKU表现。
- 历史日销为0或无有效基准时，恢复率不可算；缺失不填0。仍可核查Listing、广告和预算，但不能标记恢复良好。

### 1.4 为什么定为3天

依据[2026-09-30返场品连续断货天数历史验证](2026-09-30-返场品连续断货天数历史验证.md)，按2026-09-29快照核验近180天的**1,281轮返场事件、987个商品组合**。其中855轮具备完整比较条件，525轮在返场后7天日销仍低于断货前历史日销的80%。

| 连续0库存门槛 | 过滤事件数 | 过滤事件中已知7天销量恢复不足的数量 | 已知恢复不足事件保留比例 |
| --- | --- | --- | --- |
| 1天，现行规则 | 0 | 0 | 100% |
| 2天 | 77 | 16 | 97.0% |
| **3天，本次确认** | **119（约9.3%）** | **25** | **95.2%** |
| 5天 | 192 | 48 | 90.9% |
| 7天 | 242 | 72 | 86.3% |

**选择3天，是为了过滤一两天的短期缺货，同时尽量保留恢复不足的商品。**从3天提高到5天，多排除73轮，其中23轮仍恢复不足；提高到7天，多排除123轮，其中47轮仍恢复不足。继续提高门槛虽然能减少跟踪数量，但会漏掉更多可能需要关注的商品。

3天是根据这次历史对比和业务取舍确认的门槛，不是已证明的唯一最优值。上表是事件轮次，不是当前页面在池商品数；“保留比例”的分母是525轮已知销量恢复不足事件，不包括无法完整评价的426轮，也不代表正式角色退出达标率。

**短于3天不代表经营正常。**被过滤的119轮中，25轮可确认销量恢复不足，另有42轮在返场后7天内再次断货。它们不自动进入专门返场流程，但仍需保留日常销量异常、库存不足和反复断货检查。原始查询、样本、分组结果和验证局限保存在上述验证文档及其关联明细中。

### 1.5 恢复到5件及以上开始观察，是否能加投另看库存

本次将恢复门槛从6件调整为**5件及以上**。在已有1,162轮满足连续3天断货的事件中对照：82轮会提前开始观察，提前天数中位数1天，1,080轮不变；可评价样本首7天再次断货比例为5件门槛5.82%、6件门槛5.64%。具体取数、比较方法及样本限制见[恢复库存门槛对照](2026-09-30-返场恢复库存5件与6件门槛对照.md)。这不代表5件是已证明的最优值，也不是全部商品新事件的完整回算。

**达到5件只表示开始7天自然恢复，不代表库存足够支持拉量。**D8需要干预时，继续按第5.1节的共享库存可售天数判断是否允许恢复广告、涨竞价、增加预算或降价。历史销量可辅助判断库存承接能力，本版不以“必须补够历史若干天销量”作为返场入口，避免已恢复销售但补货不足的商品长期无法进入观察。

## 2. 自然恢复分流：D8要不要干预

### 2.1 评价窗口与公式

本节只评价已满足第1.1节进入条件的返场事件。D1从确认断货后首次库存达到5件及以上的当天开始；此前连续3天断货及等待补货的时间都不计入观察期。

D8首判使用完整D1–D7；D1—D21用返场至今N个完整自然日与断货前有效N天比较；D22—D29用最近21天与历史21天比较；D30起用最近30天与历史30天比较。不使用当天未完成数据。

销量历史窗口优先取本轮断货前紧邻的同长度完整连续有货窗口，不符合时沿用断货前最后有效同长度窗口并显示真实日期；不依赖历史毛利率是否可计算，不混入断货后数据。历史30天／14天角色基准继续独立保存，不能用销量基准替代角色证据。历史日销为0时恢复率不适用，当前表现仍单独评价。窗口发生缺数或再次断货时说明原因，不用缺货造成的销量下降触发正常拉量。

```text
返场评价日销 = 评价窗口总销量 ÷ 窗口自然日数
销量恢复率 = 返场评价日销 ÷ 对应同长度历史窗口日销
订单毛利率 = 窗口订单毛利总额 ÷ 窗口订单销售额
日均订单毛利额 = 窗口订单毛利总额 ÷ 窗口完整自然日数
```

订单毛利率从总额计算，不平均每日比率；销售额不大于0时不可计算。订单来源费用口径保持一致，不另扣广告后再用作经营分流。

### 2.2 分流结果

先识别异常和可核实的利润／花费风险，再判断恢复程度。已满足正式退出条件的，直接按退出方案处理。某指标缺失不等于没有风险，已核实的花费触顶等事实仍需单独提示。

| 状态 | 判断条件 | 本轮处理 |
| --- | --- | --- |
| 历史数据不足／历史零销量 | 找不到同长度有效窗口／历史日销为0 | 恢复率不可计算／不适用；当前销量、利润和退出继续评价 |
| 返场经营数据缺失／库存数据缺失 | 缺销量日记录／缺库存记录 | 逐项列出日期，不按0填充，不生成正常拉量 |
| 库存中断 | 主评价窗口内连续至少3个自然日可售库存为0 | 先处理库存，不直接认定需求恢复差；零散或连续1—2天为0不触发此分类，缺失日期不算0 |
| 当前评价窗口无销量 | 当前窗口销量完整且总销量为0 | 明确当前窗口无销量，不据此断言返场以来从未出单，检查商品与广告，不填0%毛利率 |
| 利润无法评价 | 销量仍可计算，销售额≤0或财务指标缺失 | 销量恢复继续展示，利润未核实前不加投 |
| 利润风险 | 订单毛利率＜5%，或触及批准花费上限 | 优先查广告消耗、价格与成本，不直接加投 |
| 恢复较好 | 销量恢复率≥80%，订单毛利率≥5%，数据完整且连续有货，无上述风险 | 保持价格和有效广告，继续跟踪退出条件 |
| 恢复中 | 销量恢复率＜80%，满足第2.3节改善条件，且尚未结束D14观察 | 继续观察，每天复核 |
| 恢复不足 | 销量恢复率＜80%，改善条件不满足；或D14观察结束后恢复率仍不足80% | 进入第3节广告诊断 |

**日均订单毛利额只作提示，不增加“恢复80%”的硬门槛。**恢复率恰为80%、订单毛利率恰为5%时，满足对应边界；低于5%不等于立即关闭全部广告。

D8起，销量恢复良好但对应窗口角色尚未达到退出目标，单独复核角色差距，不自动判为流量不足或继续加广告。进入诊断也不等于一定有动作，证据不足、没有适用动作或受到限制时仍可保持／待核。

**退出判断优先于是否干预：**所有返场品原问题、瘦狗或历史不可判至少达到瘦狗，原潜力、明星至少达到潜力。D7完整结束后，D1—D7每天及7天整体均达到本轮目标、数据完整且每天有货即可提前退出。未提前退出的，从D8起每日按N／21／30天对应窗口评价角色，连续3天达到本轮目标即常规退出，最早D10。D21／22和D29／30切换窗口长度时，当天重新评价，达标延续计数，否则归零。详见独立退出方案第5节。

### 2.3 恢复中可以再观察多久

以下为已有的V1候选参数，仍需试算验证；共同满足才允许改善观察：

- 最近7天数据完整、连续有货。
- 最近3个完整日与紧接此前3个完整日比较，销量提高至少20%，且增加至少2件；最近3天至少2天出单。
- 前段销量为0时不算增长率，后段改为至少3件、至少2天出单。
- 最近3天及近7天订单毛利率均≥5%；此前3天可比时，最近3天订单毛利率不得恶化；未触及批准花费上限。

每天复核，D14仍允许符合条件的改善观察，D15起结束额外观察。改善证据不足标记待核，不把缺数写成改善失败；观察结束后仍不足则进入诊断，不强制生成调价或广告动作。

### 2.4 长周期判断与近7天提醒

主恢复状态使用N／21／30天窗口。另展示返场后最近7天日销与订单毛利率，对比前7天；返场不足14天不借用断货期补齐前段。任一日销或毛利率下降时给出提醒，变化幅度如实展示，未设未经验证的下降比例动作门槛。缺数、库存中断、前段日销为0时，不虚构增长率。近7天订单毛利率低于5%时禁止直接增加投放；提醒不能代替主窗口或自动追加动作。广告归因、站点调价依据及实际动作后的复评周期单独保留。

## 3. 恢复不好时，广告怎么调

**先满足第1.1节返场进入条件，再到D8以后经第2节判为恢复不足，才进入本节广告恢复判断。**未满连续3天断货而被过滤的商品，不能绕过入口以“恢复投放”为由使用本轮返场动作；其广告问题走日常运营。恢复较好或改善中继续观察的商品，保持有效投放，不因为到了D8就调广告。利润风险另按第2节优先处理，不直接加投。

这一轮只处理已有广告。新建活动、加词、否词另列人工建议；原来没有广告的商品，不直接套“恢复投放”。以下点击、订单和涨跌幅仍是待试算参数。

### 3.1 广告没开：原来有效的开回来，原因不清的先不动

| 当前情况 | 运营怎么做 |
| --- | --- |
| 断货前正常出单，因为断货关了广告，返场后还没开 | 商品已能正常销售、历史转化及利润可核，库存和剩余预算允许时，**恢复原来有效的广告设置**。这轮不同时涨竞价或增加预算 |
| 原来就因为花费高、效果差而暂停 | **不因到货直接重开**，先核实原来停投的问题是否解决 |
| 不清楚为什么暂停，或找不到原来的竞价、预算设置 | 先查暂停原因和原设置，查清前不恢复 |
| 断货前没有广告 | 先看自然流量和转化；如需新广告，单独提出人工方案，本版不直接创建 |

恢复前须通过第5节库存、预算和利润限制。库存不足14天，不执行恢复试投；不能把以前的预算原样恢复后，突破现在的可用额度。

### 3.2 广告开着，但没什么流量：先把没投出去的原因找出来

| 看到的情况 | 运营怎么做 |
| --- | --- |
| 完全没有曝光、点击或花费 | 查活动、广告组和商品广告有没有暂停，商品能否投放，预算是否用完；同时确认报表正常更新。**查到哪个环节没恢复，就处理哪个环节，不先统一涨竞价** |
| 广告预算确实用完，而且已有广告能稳定出单、符合第3.3节加投条件 | 申请池内可用额度，按第5.2节计算；**加额度和涨竞价二选一**，不增加站点总预算 |
| 有曝光，但点击少 | 看广告是否投给了合适的人，以及主图、标题、评价等是否影响点击；先列明具体问题，**不直接降售价，也不整组涨竞价** |
| 设置正常、没有预算限制，但仍缺流量 | 看有没有符合下一节条件的有效关键词或自动匹配方式；没有就保持，不每天试着加一次竞价 |

“广告显示开启”不代表已经正常投放；报表没更新，也不代表广告真的没有花费。

### 3.3 广告能出单：固定ACOS分档，目标20%、上限50%

分别看每个关键词、每种自动匹配方式的表现，**只调符合条件的那一项，不整组一起调**。先有至少7个完整投放日，且这些天的广告订单已补齐，再使用下表。

| 具体表现 | 本轮怎么调 |
| --- | --- |
| 至少20次点击、3单，ACOS≤20%，商品仍需拉量 | **候选提高10%**，10%—20%同样提高10%；库存仅够7至不足14天时最多提高3% |
| 同样样本，20%<ACOS≤30% | 仅主窗口日销<1且库存覆盖≥14天的销量修复候选提高3%；其他保持，不增加预算 |
| 30%<ACOS≤40% | 保持竞价，不增加预算 |
| 至少3单，40%<ACOS≤50% | **降低10%候选**，不另加20点击门槛 |
| 至少3单，ACOS>50% | **降低20%候选**，禁止加投，不直接恢复原高消耗暂停设置 |
| 点击、订单不足，或订单还没补齐 | 保持原竞价，先继续积累数据；不能把刚恢复几天的表现当最终效果 |

2026-10-10起按用户确定的固定政策判断，不再按售价成本倒推ACOS上限。20%为积极拉量档上边界，30%为谨慎档上边界，40%恰好保持，50%恰好降10%，严格超过50%才降20%。低日销利润例外不豁免ACOS分档；预算、库存、操作复评及适用利润保护仍检查。完整规则见[固定ACOS分档](../../../01-返场品完整运营决策.md)。

**竞价例子：**原竞价0.60，提高10%是0.66，降低10%是0.54，降低20%是0.48。最终仍须检查货币最小单位、平台范围、库存和预算；不是看到有单就一定加。

### 3.4 成熟零单：按点击数直接判断

同一个关键词或真实自动匹配方式，订单归因成熟后仍然0单：

| 成熟点击数 | 建议 |
| --- | --- |
| 不足20次 | 保持，继续观察 |
| 20—39次 | 降竞价10% |
| 40次及以上 | 降竞价20% |

所有商品日销统一，不计算CPA、试错成本、价格参考或预算消耗比例；20／40点击及10%／20%降幅为试算参数。只用该对象点击，不加广告组或其他对象的合计。

须唯一归属MSKU、对象正在投放、报表与库存日期覆盖可靠、其他归因订单及品牌／核心词保护可核。当前完整报表日减7天、最多最近14个成熟报表日且不早于返场；未成熟或缺记录不当零单。零单不额外要求7个报表日。有效竞价、币种、平台范围和实际操作记录未知仍为待核。

调整后用新的成熟数据复评，不拿同一批点击第二天再降。建议不代表已执行。详见[零单成熟点击规则](../../../01-返场品完整运营决策.md)。

### 3.5 调完怎么看，什么时候再考虑价格

| 时点／情况 | 运营怎么做 |
| --- | --- |
| 恢复或调整后第3天 | 确认广告是否开始曝光、点击和花费，检查设置是否生效；不急着再涨竞价 |
| 第7天 | 看商品销量有没有继续恢复、订单毛利率有没有变差，检查花费和库存；没改善就停止追加，先核原因 |
| 调整后的首个7天广告订单已补齐 | 再判断这次广告调整是保留还是撤回。广告订单可能过几天才补进来，不能刚跑满7天就按“没出单”认定失败 |
| 有已核实实际广告调整，仍在观察或缺调整后的复评数据 | 先保持，暂缓正常调价；只有广告专属数据缺失且无适用动作时，不据此挡住价格审核 |
| 广告已经正常，或没有符合条件的广告动作 | **可以直接进入第4节价格判断，不需要为了“先广告”硬调一次竞价** |
| 广告调整已完成复评，商品仍恢复不足 | 进入第4节，结合订单毛利率、销量和转化判断涨降方向，再按当前价格走相邻档位 |

第14天再看恢复是否持续，并按独立退出方案核对角色。若缺数或再次断货，先标记效果待核，不急着归因。独立利润风险另行人工处理。

**不设置广告总动作或正向动作数量上限，符合条件的对象均给出建议。**同一竞价对象不同时提高和降低；库存、资金、样本和复评仍逐项检查，本文件不直接执行广告操作。

## 4. 价格逐档调整：先判断涨、降还是保持，再选相邻档位

本节替换此前参考断货前价格、按当前价上下调整5%的方案。**已确认的调整方式：不使用历史价格判断高低；按当前售价与现有定价档位的关系，每轮只升或降一档；P10为降价底线，P35为涨价硬上限，涨价目标不得超过P35。**下述涨价、降价触发条件为本次建议，尚未完成返场历史试算，不表示已证明有效。

本节只适用于尚未退出的本轮返场品。正常调价从D8起，先判断广告：有具体适用动作时优先核验并处理；没有适用动作，或只有广告专属数据缺失时，独立审核价格。不为了调价强行制造广告动作。只有已核实实际价格或广告调整仍在复评期，才按真实生效记录暂缓追加正常调价；未执行的建议不算实际调整。D1—D7仍自然恢复；独立的利润或价格底线风险另列人工核查。

### 4.1 当前价和档位怎么取

| 数据 | 本版取法 |
| --- | --- |
| 当前售价 | 同一国家站点、店铺、MSKU、币种，截至判断时最新完整Listing快照的`价格`，保留备份日期；不读取断货前价格作为条件或目标 |
| 本版价格档位 | P10、P15、P20、P25、P30、P35，分别是定价模型的10%、15%、20%、25%、30%、35%毛利润价格；按金额从低到高排列 |
| 档位来源 | 参照现有定价资料，后续按`temporary_dwd.在库节点_输出定价表`同一最新有效记录的对应毛利润价格字段取值；不得把不同日期、币种或商品的档位拼在一起 |

现有问题产品价格档位定义（原项目参考：`../../问题产品与瘦狗产品运营策略/问题产品运营决策框架.md`，不作为本包运行依赖）和潜力产品定价表来源（原项目参考：`../../潜力产品运营策略/2026-09-28-潜力产品运营策略数据开发说明.md`，不作为本包运行依赖）仅用于核对字段含义，不照搬其经营分流、调价方向或广告动作。P10至P35逐档调整，P35涨价上限已确认，完整返场样本的字段覆盖、金额和映射仍待取数核实。

同一商品的档位应满足：0＜P10＜P15＜P20＜P25＜P30＜P35。当前价或必要档位缺失、非正、倒挂、重复金额、最新日期记录冲突，或者币种不一致时，先核查，不越过缺失档位、不自行插值、不切换到含广告定价列。P10是价格金额，不是当前价打九折，也不是实际订单毛利率一定达到10%的承诺。

### 4.2 哪些涨价、哪些降价、哪些保持

**新增低日销例外（已接入新版独立页面）：先用N／21／30天主评价窗口判断日销是否低于1件。低于1件时优先修复销量，不因利润不足触发正常提价，也不以订单毛利率至少10%或预测利润5%拦截降价。价格最低P10、转化依据、库存、预算与广告复评要求仍保留。下表原利润分支仅在主窗口日销达到1件及以上时适用；站点近7天数据仍用于利润及提价；降价转化改为对应N／21／30窗口。**

先判断数据与风险，再判断方向。同一轮只能选一个价格方向。判断优先级为：价格底线及低于5%的利润风险 → 符合保持条件的先保持 → 尚未达潜力的利润短板 → 降价条件 → 其他保持／待核。命中前面的分支后不再命中后面分支。销量和订单毛利率使用近7个完整自然日：日销＝7天总销量÷7，订单毛利率＝7天订单毛利总额÷销售额总额。销售额不大于0或关键数据缺失时，毛利率不可算，不把零销量当成0%毛利率。

| 看到的情况 | 建议方向 | 还要满足什么 |
| --- | --- | --- |
| 当前价低于P10 | 优先审核提到P10，不再降价 | 核对最新价格、P10和成本确实有效，目标价通过预测利润检查；属于底线修复，不要求先满足恢复率不足80%。即使跨越其他更低模型线，本版最低目标仍只能是P10 |
| 主窗口日销≥1件，订单毛利率低于5% | 审核升一档，先修复利润 | 广告浪费及成本异常已排查，核算显示售价不足是利润缺口原因，下一档能改善利润并通过广告后5%的预测利润检查；否则先止损或查成本，不无依据提价 |
| 近7天日销1—5件、订单毛利率5%至不足10% | 审核升一档，补足潜力要求的利润短板 | 尚未退出；D8后恢复不足需诊断，或D8起销量恢复尚可但对应窗口角色仍未达标；广告和成本已核清，价格不足有依据。不是一看到8%毛利率就提价 |
| 未命中风险、保持或提价分支；销量恢复不足80%，或D8起对应窗口仍因日销不足1件未达到潜力；订单毛利率至少10%，且站点转化明显偏弱 | 审核降一档，尝试改善成交 | 没有适用广告动作或实际广告调整已完成复评，满足下述转化样本条件，库存至少够14天，下一档不低于P10且通过预测利润检查 |
| 没有利润或价格底线风险，且近7天角色已为潜力／明星；或者对应窗口已达最低潜力、仍待连续3天确认 | 保持价格，等待退出确认 | 不为追平历史明星或历史销量继续调价。D8起对应窗口仍有利润短板的，不因销量恢复80%就永久保持，应按利润短板分支审核 |
| 主要缺流量、广告还没恢复，或访问量不足以判断转化 | 保持价格，先处理广告／流量 | 不能用“销量低”直接推出“售价高” |
| 主窗口日销不足1件，尚未退出且需要销量修复 | 没有适用广告动作或实际广告调整已完成复评后，有转化依据则审核降一档；缺流量时先处理广告 | 不设利润前置门槛，不因利润薄机械提价；仍须转化样本达标、库存至少14天、目标不低于P10，并完成已有动作复评 |
| 其他条件未命中、原因不清、调整尚待复评，或没有合适的相邻档位 | 保持／待核 | 不要求每个干预期商品必须调价 |

**“利润不足”分清两种情况：**订单毛利率低于5%是利润风险；日销1—5件时，订单毛利率低于10%是尚未达到潜力的利润要求。日销大于5件、订单毛利率已经达到5%时，已满足潜力的利润门槛，不因低于10%而单独提价。日销不足1件时，即使提高毛利率也不能直接达到潜力，需要同时诊断销售规模。

**降价所需转化依据（2026-10-12更新）：**每个国家商品用本轮断货前有效有货30天／14天基准，计算卖3件所需访问量＝向上取整（3×历史访问÷历史销量），历史访问>0且销量仍至少5件。返场后D8—D21用D1至当天N天、D22—D29最近21天、D30起最近30天；当前预期销量＝窗口访问×历史销量÷历史访问，预期至少3件且实际销量严格低于预期70%才候选降一档。当前和历史均不固定50次访问。缺历史或对应窗口数据待核，不退回近7天，不借其他国家。3件和70%是试算参数，不证明价格原因；库存、利润例外、P10、一档、广告优先及真实7天调价间隔继续检查。详见[动态访问门槛规则](../../../01-返场品完整运营决策.md)。

主窗口日销达到1件及以上时，降价要求订单毛利率至少10%，作为利润余量条件；日销不足1件时不适用此要求。最终涨价是否改善利润、降价是否提升销量，都须通过调整后的真实经营数据复评。

### 4.3 一档具体怎么走

**涨价到当前价上方紧邻的有效档位，降价到当前价下方紧邻的有效档位；价格恰好在档位上时，不能停在原档，须移到相邻档。**下表只确定目标金额，先通过第4.2节方向判断后才适用。

| 当前售价位置 | 降一档目标 | 升一档目标 |
| --- | --- | --- |
| 低于P10 | 禁止降价 | P10，先修复底线 |
| 等于P10 | 禁止降价 | P15 |
| P10与P15之间 | P10 | P15 |
| 等于P15 | P10 | P20 |
| P15与P20之间 | P15 | P20 |
| 等于P20 | P15 | P25 |
| P20与P25之间 | P20 | P25 |
| 等于P25 | P20 | P30 |
| P25与P30之间 | P25 | P30 |
| 等于P30 | P25 | P35 |
| P30与P35之间 | P30 | P35 |
| 等于P35 | P30 | 已到涨价上限，禁止继续提价 |
| 高于P35 | P35 | 已超过涨价上限，禁止继续提价 |

本版不再采用“偏离历史价格10%才启动”或“每次最多上下5%”的价格规则。一个档位的实际价差可能大于5%，每次须展示当前价、目标档位金额及实际涨跌幅，供人工审核；不把一档误写成固定涨跌5%。高于本版最高档的价格降到P35是先回到已定义的最近档位，不直接跨降到P25或P10。

目标档位按站点货币最小单位向上取整，避免落到P10以下；取整后重新核对方向、P10、P35及预测利润；若取整后的涨价目标超过P35，标记待核，不输出超上限价格，不以最小货币单位为理由突破上限。若目标价与当前价相同或方向改变，保持，不额外加减最小单位，也不再跳一档。原始档位冲突或取整后相邻档位合并时，标记待核，不把两档合并后继续跳档。

### 4.4 档位不能通过限制时，就不调

- **最终建议价不得低于P10；涨价最高只能到P35，每轮只升一档，不能从P20直接升到P35。计入全部广告消耗后的预测毛利率不得低于5%。**分别校验，不能认为达到P10就自动通过广告利润检查。
- 下一低档不能通过利润检查时，保持或转人工；不取“档位价与利润底价的较高值”拼出一个中间价，也不继续往下试其他档位。
- 下一高档仍不能通过预测利润检查时，转人工查成本、广告和定价模型；不在同一轮继续跳第二档。
- 降价继续受共享库存可售天数限制，至少14天才允许审核；利润修复提价仍按原风险处理规则审核，不把缺货当成经营亏损证据。
- 不限制涉及商品或国家的价格建议数量；同一国家商品售价本轮只有一个相邻目标，不同时涨降。正常调价至少间隔7个完整日，并完成上一轮复评；先判断广告再评价格，不机械每天调一档。
- 页面第二步直接给出广告判断结果：需要调整、暂不调整、无需干预、受到限制或无法判断；明确的样本不足可以得出暂不调整竞价的结论，缺少必要映射或利润依据则不能冒充正常。第三步按国家站点衔接，只展示无待处理广告事项的调价方向；广告判断未完成或调整待复评时显示“价格暂不能判断”，参考金额与原因仅在详情折叠项查看。候选仍需核实利润、库存和调价记录，不等于可以执行。同商品不同国家分别判断。当前价低于P10仍保留独立底线风险提示。
- 达到P10只表示没有继续降价空间，不触发清仓，也不改变角色退出要求。达到P35不代表利润已修复；已经等于或高于P35时停止提价，改查广告消耗、成本和定价模型，不通过人工审核继续突破P35。当前价高于P35也不因此强制降价，仍须满足降价条件。
- 下一轮重新读取当前价与同一最新有效版本的整套档位；若价格线或成本已变，先说明变动，不机械重复上次方向。
- 风险撤回可不受7天间隔限制，但须核对实际生效价、当前设置、最新P10、P35和预测利润，避免覆盖后来另做的调整；历史动作原价只用于核验撤回，不作为正常调价参考；撤回会形成涨价且目标超过最新P35时不直接恢复原价，改为核查处理。

### 4.5 看得懂的例子

假设同一商品当前有效档位为：P10＝18元、P15＝20元、P20＝22元、P25＝24元、P30＝27元、P35＝30元。以下均须先满足方向条件及共用限制。

| 情况 | 建议 |
| --- | --- |
| 当前23元，利润有空间、恢复不足且转化偏弱 | 降到下方紧邻的P20，即22元，不直接降到20元 |
| 当前23元，价格不足造成利润缺口 | 升到上方紧邻的P25，即24元 |
| 当前恰为P20的22元，需要降价 | 降到P15的20元；实际降幅约9.09%，不再限定最多5% |
| 当前恰为P20的22元，需要提价 | 升到P25的24元 |
| 当前18元，已经在P10 | 不再降价；如命中提价条件，目标为P15的20元 |
| 当前16元，低于P10 | 核实底线修复后，审核提到18元；不先提到17元等中间价 |
| 当前23元，降到P20的22元后预测利润不足5% | 不给出降价建议，也不凑一个22.50元的中间价格 |
| 当前27元，恰为P30，命中提价且限制通过 | 只升到P35的30元，到上限停止 |
| 当前30元，恰为P35，利润仍不足 | 不继续涨价，查广告消耗和成本 |
| 当前超过30元，已经高于P35 | 不再涨价；仅在命中降价条件时审核回到P35 |
| 当前23元，但主要问题是广告未恢复 | 保持价格，先处理广告 |
| 当前24元、订单毛利率8%，日销大于5件且恢复较好 | 已满足潜力利润门槛，保持价格，不因低于10%提价 |

本节是方案重设计，不执行实际调价；方向条件、候选阶梯覆盖及调价后效果仍待历史试算和人工审核。

## 5. 共用限制、复评与退出衔接

### 5.1 库存条件与涨降互斥

共享物理库存只计一次，只用FBA可售，不加入在途；消耗量包含共享池所有实际销售成员。优先用最近7个完整日实际日销计算DOS，并观察最近3天是否加速，不用包含断货期的30天日销放大库存覆盖。

```text
共享池近7天实际日销 = 同池实际销售成员近7天总销量 ÷ 7
DOS = 共享池当前FBA可售库存 ÷ 共享池近7天实际日销
```

近期零销量不视为无限DOS；只能用可核实的历史实际消耗作带标记的参考，否则承接能力待核。

| DOS | 保留的库存限制 |
| --- | --- |
| 未知、无可售或＜7天 | 不降价、不加投；有依据的止损、利润修复仍可审核 |
| 7–不足14天 | 所有符合ACOS及样本条件的对象可列加bid候选，每个幅度最多+3%；不降价、恢复试投或增加预算 |
| 14–不足28天 | 不设拉量对象数量限制；汇总检查共享库存消耗，广告与价格仍按原流程衔接 |
| ≥28天 | 达标对象均给建议，不设动作名额；仍检查共享库存、预算及复评 |

恰为7、14、28天分别进入以该值为起点的档位。多个国家同时拉量时合并检查共享库存，高库存不自动触发降价。

不设置国家、商品或批次的动作数量名额。同一国家商品售价提价与降价互斥；同关键词或自动target提高和降低竞价互斥。不同对象、不同国家可以方向不同。若同对象出现相反结果，合并核查，不任意选方向。详见[数量与互斥规则](../../../01-返场品完整运营决策.md)。

**本版不默认生成降价与加投联动包。**取消动作名额不改变广告与价格的判断、核验及复评顺序；没有适用广告动作时可独立审核价格。

自动target的bid为空或0时，核实是否继承广告组默认bid；保留原始值、有效值及继承来源，负值作异常。bid上涨向下、下降向上按有效最小单位取整，检查平台范围；无变化就保持，不强行补0.01。多商品共用对象须核查所有受影响商品与共享预算，不能把整组表现直接算给单个MSKU。

### 5.2 池内预算

站点／国家总预算不增加。自然月、自然周预算都要扣除实际花费、未来基础消耗和已承诺但未发生的动作占用。

```text
单轮测试额度的配置上限
= 原商品月配置预算的10%与原商品周配置预算的25%两者中的较低值
```

额度同时受共享池真实余额、站点／活动容量及可承受利润空间限制；配置上限不是可直接使用的余额。

商品额度不足时可提出池内分配申请，试算后重新检查月周预算。只有已实现、已确认的释放额度可再分配，不能预用“预计降bid省下的钱”。每批申请汇总并预留，防止重复占用；跨周、跨月重新核验，不自动延续。

只有成熟样本与经营准入通过、ACOS≤20%、库存覆盖≥14天且预算限制确认，才可申请增量预算。月周配置为零、缺失或映射不清时待核，不套“日2欧元”等兜底。bid+10%不等于花费+10%，增量消耗无法合理估计时，不输出伪精确预算值。

### 5.3 动作的预测利润审核

```text
预计计入广告后的毛利率
=（预计销售额－已核实的非广告成本－预计广告总花费）÷预计销售额
```

预测结果不得低于5%，必须计入已有和新增广告消耗，并核清订单毛利的费用组成，避免重复扣费。该预测约束与实际订单毛利率分开记录，不保证实际利润。

任何调价建议还必须通过第4.4节P10价格底线与P35涨价上限；通过预测利润检查不能豁免价格上下限，处于档位范围内也不能豁免预测利润检查。

价格与广告即使分步处理，也不能重复占用同一份利润空间。收入、成本、广告、预计销量须同站点、同币种、同期间且有依据。预计销售额不大于0或关键输入不可核时不判通过；相邻目标档位须用同一模型复核利润；不通过则保持或转人工，不另造中间价格，不用固定历史模型线替代当前成本。

### 5.4 复评时间和退出衔接

复评日龄按动作实际生效计算，与返场D1、D8、D14分别记录。前后比较均用完整自然日，不混入生效当天；新动作发生后重新计时，不把两轮效果混算。

| 时点 | 核查内容 | 本轮出口 |
| --- | --- | --- |
| 每天 | 库存、预算、订单毛利率及数据异常 | 必要时停止未执行的正向动作，核查风险 |
| 动作后第3天 | 是否生效，是否出现库存、预算异常 | 不因短期波动追加 |
| 动作后第7天 | 对比动作前后各7个完整日的销量恢复率、订单毛利率、流量与转化 | 无改善或恶化时停止追加，核实原因并审核撤回 |
| 首个完整7天动作后广告窗口成熟 | 对象归因订单、效率及花费 | 决定保留、审核撤回或进入下一轮；此前不提前判广告无效 |
| 动作后第14天 | 持续表现及角色退出条件 | 达标退出；否则按新证据复核恢复状态与动作 |

归因未成熟、缺数或再次断货时，标记“效果待核”，不能硬判成功／失败；不依据同一旧窗口重复降bid。常规角色退出判断从D8起按N／21／30天对应窗口每日进行；观察期提前退出按D1—D7稳定条件判断，不必等动作后第14天。

**返场途中又出现0库存时，先核查库存风险，再判断是否连续3天断货及形成新一轮：**

| 再次断货的情况 | 与干预、观察和退出怎么衔接 |
| --- | --- |
| 出现0库存，但尚未确认连续3天 | 暂停新增拉量建议，原动作效果标记待核；正式退出的连续达标计数中断，不等待满3天才处理风险 |
| 只连续0库存1—2天便恢复，未形成新一轮 | 保留原事件和原D1，不重新开始7天自然恢复期；恢复后仍须满足完整、有货的评价窗口及库存、利润、预算条件，再按原阶段复核 |
| 再次连续3天库存为0，但尚未恢复到5件 | 确认新一轮断货，等待恢复；不继续执行上一轮待执行的拉量建议 |
| 新一轮断货后首次恢复到5件及以上 | 建立新事件，重新固定本轮历史基准与目标，从新的D1开始7天自然恢复；旧轮次动作保留记录并核对实际设置，不自动重复执行，也不凭新事件重置预算余额 |

因此，3天门槛决定“是否新建返场轮次”，并不代表已经进入返场的商品可以忽略1—2天再次断货。原轮次进入常规评价后，也不能用包含断货日的对应窗口达标退出。

### 5.5 试算设计与文档验收

已完成进入条件中连续1、2、3、5、7天断货门槛的历史对比，并于2026-09-30确认采用3天，依据见第1.4节。**尚未完成整套新版分流、广告、价格与退出策略的联合回算或实际动作效果验证。**入口验证数量和旧方案快照数量不能直接代表本版最终干预对象或动作候选数量。

后续先只读取数，按同一快照逐步输出：连续3天断货是否成立 → 是否已恢复到5件及以上并生成本轮事件 → 本轮D1与历史基准 → 7天自然恢复 → D7稳定达标则提前退出 → 未退出的进入D8恢复分流。只有需要干预的分支继续输出广告状态、是否需复评、价格候选、库存／预算／利润限制及人工审核建议；未通过前置条件不能直接生成后续动作。

未提前退出的商品，从本轮D8起按N／21／30天窗口并行评价常规退出，不以“已调整过广告或价格”为前提，也不等待动作复评结束才判断退出。事件、站点和广告对象分别统计，不能把一对多关联后的行数当产品数。

价格建议另保留当前价、当前价来源日期、整套档位金额及版本日期、涨降方向及原因、目标档位、取整后金额、实际涨跌幅和未通过的限制。每条记录保留连续0库存天数、连续断货首日、确认满3天的日期、库存恢复日、本轮事件编号与D1、基准及证据日期、近7天指标、恢复率、订单毛利率、毛利额提示、分流原因、广告核清状态、动作原值／建议值、预算占用、限制原因、实际生效时间和复评日期。字段可用性标记“已核实可用／待核实／缺失”，不将需求清单当作已有能力。

验收案例及预期：

| 场景 | 预期判断 |
| --- | --- |
| 连续2天库存为0，第三天恢复到5件 | 不生成新返场事件 |
| 连续3天库存为0，之后首次恢复到5件 | 生成返场事件；连续0库存第一天为断货日，恢复到5件当天为D1 |
| 满3天前出现1—5件库存或缺失日 | 中断连续计数，不拼接前后两段0库存 |
| 已确认连续3天断货，之后恢复到4件 | 继续等待，尚未达到返场门槛 |
| 未满足3天进入条件，但当前价格偏高或广告暂停 | 不生成返场动作；如有经营问题，走日常运营 |
| 已进入返场但仍在D1–D7，即使恢复率不足80% | 不提前套D8正常干预条件；符合观察期提前退出规则的可退出，其余继续观察 |
| D8恢复不足且需调整广告，广告尚未完成复评 | 先处理广告并复评，暂缓正常调价 |
| 已入池后短暂断货1—2天 | 不重建事件、不重置D1；暂停拉量，退出确认中断，按原阶段及有货窗口重新复核 |
| 已入池后再次连续3天断货，随后恢复到5件 | 新建轮次，重定历史基准并从新D1观察；不自动重复旧动作或重置预算 |
| D1—D7每天及7天整体稳定达到潜力或明星，数据完整且每天有货 | D7提前退出，不再进入D8分流；原明星同样适用 |
| D7未满足稳定提前退出，但恢复率达到80%、订单毛利率≥5% | D8保持，不因未提前退出强制干预；D8起按对应窗口评估常规退出 |
| 恢复率恰为80%、订单毛利率恰为5%，其他条件完整 | 恢复较好，保持 |
| 销量恢复80%，日均订单毛利额未恢复80%，订单毛利率仍≥5% | 毛利额下降提示，不增加硬门槛 |
| 历史日销为0或缺失 | 恢复率不可判，不填0、不填100% |
| 确认因断货暂停，与断货前就无广告 | 前者核查恢复条件，后者另列新建人工方案 |
| 广告开启但无投放 | 查资格、状态、预算和同步，不机械涨bid |
| 返场早期零单，归因未成熟 | 不套零单止损 |
| 当前价介于P15与P20之间，分别命中降价／提价 | 分别到P15／P20，不再按当前价百分比计算 |
| 当前价恰为P20，分别命中降价／提价 | 分别到P15／P25，不停在P20，也不多跳一档 |
| 相邻档位实际价差超过5% | 展示真实涨跌幅供人工审核，不截断成5%的中间价格 |
| 当前价恰为P10 | 不再降价，不因返场未达标突破底线 |
| 当前价低于P10 | 标记底线修复，核验后目标P10，不提出低于P10的中间价 |
| 当前价高于P35且命中降价 | 先到P35，不跨降至P25或更低档 |
| 当前价等于或高于P35且需要提价 | 禁止继续提价，转查广告、成本和定价模型，不以人工审核突破上限 |
| 日销大于5、订单毛利率8%，恢复较好且没有底线风险 | 保持，不因未到10%而提价 |
| 日销1—5、订单毛利率8%，广告及成本核清且低价原因成立 | 按相应阶段审核升一档，不再要求订单毛利率低于5%才修复 |
| 主要流量不足、转化样本不够 | 不因销量低而降价 |
| 转化比恰为历史70% | 不满足严格低于70%的降价筛选条件 |
| 历史Listing价格缺失，但当前价、全部档位及必要经营数据有效 | 不因历史价格缺失阻断调价判断 |
| 当前快照或档位缺失、同日冲突、币种不一致、档位倒挂 | 待核，不跳过缺失档、不生成价格 |
| 下一低档预测利润不足5% | 保持或转人工，不凑中间价，不继续往下跳 |
| 下一高档预测利润仍不足5% | 转人工，不同轮连续升两档 |
| 撤回原调价的价格低于最新P10 | 转人工，不机械恢复原价 |
| 再次断货或缺失日 | 标记异常／待核，不能声称连续有货 |
| 改善观察到D14结束，恢复仍不足 | 进入诊断，不强制动作 |
| 角色正式达标，但销量未完全恢复 | 按独立退出方案退出，移交日常运营 |
| 销量恢复良好，但对应窗口角色仍未达标 | 单独复核角色差距，不自动继续加广告 |

区分三类内容：已确认业务边界（连续3天断货且恢复到5件及以上才进入、7天自然恢复、销量80%与订单毛利率5%的干预判断、按历史角色设置的瘦狗／潜力目标、D7稳定提前退出及D8起对应窗口连续3天常规退出、广告先核清、逐档调价且P10保底与P35涨价封顶）；保留的库存预算限制；待试算参数（改善20%且增加2件、涨降价方向条件、降价所需10%订单毛利率余量、P10至P35候选阶梯覆盖、转化样本、广告点击／订单与涨跌幅、可承受成本算法）。连续3天断货的历史依据已保存；恢复库存由6件调整为5件及以上是本次方案选择，不代表旧回算已验证新库存门槛最优；其他候选参数仍需检验各分支数量和典型案例，不直接执行运营动作。

### 5.6 广告取数与计算说明（供后续试算使用）

本节只说明第3节动作怎样取数，不增加新的运营门槛。

- 广告表现只取本轮返场后的完整报表，排除断货期。采用7天归因时，共同完整报表日减7天作为可评价的最后一天，最多取最近14个订单已补齐的报表日。有单涨／降竞价须至少7个完整报表日，零单按第3.4节条件判断，不另添天数门槛。
- 调价或广告调整后，从实际生效后的完整日期重新计算；D8的返场后广告数据通常还不足以判定效果。断货前表现只支持恢复原设置，不能与返场后数据混算。
- 关键词和自动匹配方式各取自身点击、订单、花费及销售额；先求和再算ACOS，不平均每日比率。对象归属不清、其他归因期有订单或保护信息缺失时，不直接套零单止损。
- 有单ACOS＝成熟对象花费合计÷归因销售额合计，固定目标20%、上限50%，不以利润倒推上限。归因销售额缺失或≤0时不可算，不当作0%。成熟零单不足20点击保持、20—39点击降10%、40次及以上降20%。不区分日销，不依赖成本或预算消耗比例。
- 金额必须同站点、同币种，ACOS的收入分母与每单净销售额的税费、退款计算方式一致；不能重复扣除已含广告的成本，也不能借其他商品客单价。该算法仍待数据验证，商品整体须另通过第5.3节预测利润审核。
