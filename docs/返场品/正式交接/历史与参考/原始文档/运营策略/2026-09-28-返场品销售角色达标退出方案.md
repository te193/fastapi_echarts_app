# 返场品销售角色达标退出方案

更新日期：2026-10-08。规则已确认并接入新版独立页面；完整回算与页面验收结果见文末。旧返场品页面维持原行为，不执行调价或广告操作。

## 1. 从进入到退出

连续3个完整自然日FBA可售库存为0，之后首次恢复到5件及以上，记为D1。D1—D7自然恢复；每天及7天整体都稳定达到本轮退出目标的，在D7提前退出。未提前退出的，从D8起每天按返场天数对应窗口评价销售角色，连续3天达到本轮目标即可常规退出，最早D10。

**退出目标按本轮断货前有效角色确定：**

| 断货前有效角色 | 本轮最低退出目标 | 可以达标的当前角色 |
| --- | --- | --- |
| 问题、瘦狗 | 至少瘦狗 | 瘦狗、潜力、明星 |
| 历史不可判／无法确认 | 至少瘦狗 | 瘦狗、潜力、明星 |
| 潜力、明星 | 至少潜力 | 潜力、明星 |

历史角色使用本轮断货前有效30天窗口，必要时采用有效14天兜底，保存真实来源日期。未找到可靠角色时按历史不可判处理，目标也是至少瘦狗。不是把问题角色视为成功；不要求销量恢复到历史80%或100%，也不要求先完成广告、调价或动作复评。

## 2. 角色与销量恢复使用同一窗口长度

| 评价日 | 当前销售角色使用的数据 | 销量恢复比较的历史数据 |
| --- | --- | --- |
| D1—D21 | 从D1到评价日的N个完整自然日 | 断货前有效N天 |
| D22—D29 | 截至评价日的最近21个完整自然日 | 断货前有效21天 |
| D30及以后 | 截至评价日的最近30个完整自然日 | 断货前有效30天 |

例如：D8用8天角色，D9用9天角色，D10用10天角色；D21用21天，D22仍用最近21天；D29用最近21天，D30改用最近30天，D31则用D2—D31的30天。

**角色判定与历史比较共用窗口长度，但用途不同。**当前角色决定是否退出，历史对比说明恢复差距。找不到历史销量窗口、历史零销量或历史毛利缺失，不阻止当前窗口完整且达标的商品退出。历史角色仍独立保留断货前有效30天、必要时14天兜底的基准，用于确定本轮最低退出目标，不要求恢复原明星。

## 3. 当前窗口数据和库存要求

评价窗口必须覆盖相应数量的连续自然日，每天有销量、销售额、订单毛利和可售库存记录，且每天可售库存大于0。不能跳过缺失日、缺货日，也不能把缺失记录补0。

库存恢复到5件及以上用于确认D1；退出只要求窗口每天有货，不要求每天库存都达到5件。窗口内再次断货、关键字段缺失或角色不达标，当天连续确认计数归零。库存或数据问题从滚动窗口移出后，重新开始确认。

历史和返场窗口均保留开始、结束日期及完整性证据。历史截止日严格早于本轮连续断货首日，禁止使用未来价格、广告设置或经营记录补历史。

## 4. 角色怎么算

```text
窗口日均销量 = 窗口总销量 ÷ 窗口自然日数
窗口订单毛利率 = 窗口订单毛利总额 ÷ 窗口销售额总额
窗口日均订单毛利额 = 窗口订单毛利总额 ÷ 窗口自然日数
```

毛利率用合计相除，不平均每日毛利率。销量为0且记录完整时保留0；销售额不大于0时不编造0%毛利率。采用已核实的订单毛利字段，广告预测利润另作动作审核，不替代订单毛利率。

| 角色 | 日均销量 | 订单毛利率 |
| --- | --- | --- |
| 明星 | ＞5件 | ＞15% |
| 明星 | 1—5件，含边界 | ＞25% |
| 潜力 | ＞5件 | 5%—15%，含边界 |
| 潜力 | 1—5件，含边界 | 10%—25%，含边界 |
| 瘦狗 | 1—5件，含边界 | 5%至不足10% |
| 瘦狗 | ＞0且＜1件 | ＞5% |
| 问题 | 数据有效但不满足以上条件 | 按现有分类器 |
| 不可判 | 关键数据不足，无法形成角色 | 不填成问题角色 |

判断使用原始精度。日销恰为5件属于1—5档，毛利率恰为10%可达到潜力；日销＞5件且毛利率恰为5%可达到潜力。

目标为瘦狗时，日销大于0但不足1件，订单毛利率必须严格高于5%；日销1—5件时，订单毛利率达到5%即可。日销超过5件且订单毛利率达到5%属于潜力，同样通过瘦狗目标。销量为0、负数或角色不可判不通过；不能因存在毛利调整额把零销量判成瘦狗。

## 5. 两种退出方式

### D7稳定提前退出

同时满足D1—D7每天有完整数据、每天有货、每天角色均达到本轮目标，并且7天整体角色也达到本轮目标，于D7退出。不得仅因7天平均达标而提前退出，也不在D1—D6退出。

### D8起常规退出

D7未提前退出的，从D8开始评价对应窗口的整体角色，不要求窗口内每天各自达到本轮目标；每天有货和数据完整仍必须满足。

D8、D9、D10均通过，D10退出。失败则计数归零，之后重新累计；目标瘦狗时，瘦狗／潜力／明星可以交替；目标潜力时，潜力／明星可以交替。每个评价日的窗口整体角色都必须达到本轮目标。

**D21切换到D22、D29切换到D30，不因窗口长度变化自动重置计数。**切换当天用新窗口重新判断，达标继续累计，不达标、缺数或断货则归零。例如D28用21天、D29用21天、D30用30天，三次均达标则D30退出。

## 6. 页面显示与事件边界

未退出时展示当前对应窗口的起止日期、天数、日销、订单毛利率、角色、连续达标天数及所有未满足条件。状态区分：自然观察、数据不足、库存中断、角色未达标、连续确认中、已退出。

已退出时保存首次退出日期、提前／常规路径、退出窗口及最近连续确认记录，不因后续变差撤销本轮退出。重新形成连续3天断货并恢复到5件及以上后，按新事件重新判断。

本次规则版本为`return-v4-20261008-history-role-target`。由于退出条件已改变，新版首次发布按新规则回算，不沿用旧版本统一潜力目标的退出日期；旧批次保留为历史记录。后续仅冻结同一规则版本的首次退出结果。

## 7. 与干预策略衔接

D8起，未退出商品再按自然恢复情况判断是否需要广告诊断、价格审核；进入干预期不等于一定调整。退出检查每日独立进行，已退出商品不再生成本轮新建议。

销量恢复率仍为当前对应窗口日销÷断货前同长度有效日销，用于恢复较好／不足判断；近7天趋势仅作提醒。价格逐档调整、P10底线、P35上限以及利润、库存、预算限制沿用[整体运营策略](2026-09-28-返场品观察期转干预期运营判断方案.md)。
