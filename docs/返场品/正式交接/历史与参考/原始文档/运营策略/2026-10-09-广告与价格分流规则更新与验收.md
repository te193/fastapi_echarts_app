# 广告与价格分流规则更新与验收

规则版本：`return-v8-20261009-ad-price-routing`。页面只提供建议，不执行广告或调价。

## 分流规则

按德国、法国、意大利、西班牙、荷兰、英国、美国分别判断。

| 广告结果 | 价格处理 |
| --- | --- |
| 有恢复、开启、有效竞价金额或预算金额的具体建议 | 优先核验并处理广告，价格试算折叠保留，不声称已执行或已进入复评 |
| 成熟样本未达到调整门槛，暂无适用动作 | 独立审核价格 |
| 缺有效竞价、匹配方式、归因或广告效率依据 | 明示缺失，不当作广告正常；不单独阻止价格审核 |
| 广告动作被明确限制 | 不能调整广告；价格独立通过自身条件，共同库存或经营问题仍会限制价格 |
| 价格自身受库存、近期实际调价等限制 | 直接展示价格自身限制，不用广告优先文案遮盖 |

竞价或预算没有有效目标金额的，只记为广告判断缺数据，不计入具体广告调整。恢复或开启广告属于状态建议，不虚构竞价与预算金额。

进入价格审核不等于应该调价。价格仍按转化条件、相邻档位、P10底线、P35涨价上限、库存、币种和近期实际调价记录计算。未命中条件保持；限制已知不满足暂不调整；必要核验缺失仍为待核。

## 操作记录与复评边界

广告计算结果是建议，不是平台执行记录。本次取数尚未完成广告实际操作记录核验，页面保留这个缺项；不因出现建议就宣称已调整并等待复评，也不宣称已完成复评。已核实实际广告动作生效后，运营仍须遵守复评再进行正常调价。后续接入可靠操作记录时，应按实际生效时间单独判断，不能用同步时间或历史建议代替。

价格已有真实完成调价记录，因此原有7天调价间隔继续有效。不能因为取消广告缺数据拦截就把刚调过价的商品算成可以降价。
