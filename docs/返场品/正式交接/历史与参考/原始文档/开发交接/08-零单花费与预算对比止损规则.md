# 零单花费与预算对比止损规则（已停用历史版本）

> 2026-10-12已由[零单成熟点击分档规则](../../../01-返场品完整运营决策.md)替代。以下仅保存v10/v11历史口径，不参与当前开发或计算。

更新日期：2026-10-12；规则版本：`return-v11-20261012-no-action-quota`。用户确认采用50%／100%两档，替代此前可承受CPA及花费2倍CPA门槛。有单对象的固定ACOS20%目标、50%上限和分档幅度保持不变；所有达标零单对象均给建议，不设数量名额。

## 1. 当前情况 → 直接建议

一个广告对象已归因成熟、点击至少20次、订单为0、确有花费，单商品归属和有效竞价可靠，按其所属国家＋店铺＋MSKU的同周期预算消耗判断：

| 同周期花费／预算 | 该零单对象建议 |
| --- | --- |
| <50% | 保持，继续观察 |
| ≥50%且<100% | 候选降低竞价10% |
| ≥100% | 候选降低竞价20% |
| 预算、花费覆盖、日期或币种无法核实 | 待核，说明缺项，不生成确定降价金额 |

50%恰好降10%，100%恰好降20%。零单分支不另加至少7个报表日要求；仍须完整成熟归因、20次点击及同周期预算证据。没有实际花费的零单对象，不因其他对象花费多就降价。暂停、归档、多商品共用及保护对象按原限制核查。

## 2. 为什么先在国家商品层比较预算

现有月周预算是国家＋店铺＋MSKU额度，不是关键词或自动匹配方式各自的独立预算。先把这个范围内已核实、可归属单商品的广告对象去重，汇总同一成熟日期范围的花费；有单对象的花费也参与国家商品预算消耗统计。

再定位其中符合成熟20点击零单条件的对象。一个正常出单对象不能仅因为商品预算消耗高而套零单降价；它继续按有单ACOS分档判断。商品部分对象出单，也不掩盖另一个对象成熟零单。

同一份预算只计算一次，不平均虚构分给各关键词，也不让每个对象各自消耗完整一份预算。对象归属不清、只有广告组汇总或必要报表缺失时，该国家商品预算比较待核；不将不可靠明细当成0花费。

## 3. 同周期预算怎么形成

只比较本轮返场后、已成熟且有货的共同日期。广告花费、对象点击订单和预算折算使用这些相同日期；缺库存或报表日期不补0。

- 周预算按7天折算，使用评价日当时已有、属于同自然周的预算快照。
- 月预算按该日所在月份的实际自然日天数折算，使用当时已有、属于同自然月的快照。
- 两种预算都有效时，当日额度取较低值；只有一种有效时使用该种并保留来源。明确为0或负数的同周期预算不视为“缺省”，比较待核并核查预算。
- 汇总评价窗口内每日额度，形成窗口预算。不把14天花费直接与一周预算相比。
- 同日预算冲突、缺记录或币种不一致，比较待核。未来预算不能倒填历史；调整后的额度仅适用于其快照日期之后。

例：商品国家周预算70欧元，月预算310欧元，10月份有31天；近7个成熟有货日的折算预算为70欧元。同窗实际花费35欧元，消耗50%，符合条件的零单对象候选−10%；花费70欧元时为100%，候选−20%。

计算使用Decimal，先按相同预算额度与周期天数合并天数再相除，避免循环日除法的舍入误差把恰好50%判成49.9999%。分档使用原始比例，不使用显示四舍五入后的数值。

## 4. 数据与证据

预算仍取`dws_datasync.dws_monthly_ad_budget_detail`的`biz_date`、`currency_code`、`monthly_ad_budget_original`、`weekly_ad_budget_original`。保留历史快照，不只用最新一行。现有本地镜像计算也读取预算历史。

花费取本轮成熟对象日报，并保存同范围对象去重、归属、共同窗口及逐日报表覆盖证据。当前对象快照只覆盖可核实的SP对象；历史对象缺失、其他广告类型或不支持的汇总不能自动宣称完整覆盖，接手方需核实覆盖范围，必要时继续待核。

结果包含`budget_comparison`：`scope/verified/spend/budget/ratio/currency/start/end/days/source_dates/object_count/issues`。预算为配置额度的同周期折算，不是预算池真实剩余额度；本条用于控费，不授权增加预算或消耗资金。

## 5. 当前建议的达标边界

预算比例通过只是零单止损门槛通过；近期实际操作、复评、平台上下限、其他归因订单和保护条件仍需核验。未知为待核，明确限制为受限；金额不能算时不虚构金额。没有证据时也不保留“无条件−10%”兜底候选。

先广告后价格的顺序不变：存在具体适用降竞价建议时广告优先；预算比较无法核实、没有适用广告动作时，独立审核价格自身条件。

本轮仍交付计算代码和专用结果表开发材料，不开发页面，不执行平台动作；旧版样例与历史验收数量不冒充新规则实跑。
