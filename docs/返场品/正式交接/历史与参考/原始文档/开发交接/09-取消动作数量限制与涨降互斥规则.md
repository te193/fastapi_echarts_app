# 取消动作数量限制与涨降互斥规则

更新日期：2026-10-12；规则版本：`return-v14-20261012-dynamic-price-visits`。

## 1. 不限制动作数量

取消国家、国家类别、商品和批次的广告总动作及正向动作数量上限，也取消库存分档中的“仅一个拉量对象”等数量限制。符合条件的关键词、自动匹配方式、恢复投放或预算候选都可以同轮给出建议，不截取前几个、不因名额已满标成受限。

四种自动匹配方式各自达标时可以同时列出四条提高竞价建议；多个对象需要降低竞价时也不只留两条。排序仍可以优先呈现止损，但排序不是数量准入。

## 2. 同一对象不能同时涨和降

- 同一商品同一国家的售价：本轮只形成一个相邻档位目标，不同时提价和降价。
- 同一活动＋广告组＋关键词或自动target：本轮不同时提高和降低竞价。
- 不同对象可以不同方向：关键词A提高、关键词B降低，或者德国提价、法国降价都可以。
- 若已有结果或外部输入对同一对象同时命中两方向，合并为一条人工核查，保留冲突证据，不输出两个相反金额，不任意挑一个方向。
- 对象重复采集仍去重，不能把同一对象复制多条当作“数量不限”。

代码在`ad_for_country()`中去除计数拦截，保留对象去重；`resolve_direction_conflicts()`在国家商品范围内检查相反方向，`order_country_suggestions()`用于新计算及已保存结果的方向整理。

## 3. 数量不限仍遵守哪些条件

进入退出、观察期、成熟样本、固定ACOS分档、零单20／40成熟点击分档、库存覆盖、真实可用资金、同币种、价格P10／P35、逐档幅度、近期实际操作与复评继续生效。

取消的是“能给几条建议”的上限，不表示单个对象可以叠加多轮涨幅或同时恢复、涨竞价、加预算。预算与竞价增加依然按原判断二选一，先广告后价格的分流不变。

真实余额未知时保留待核，不能把一份池余额用于多条完整申请。预算申请仍需按国家商品汇总去重并在批次内核对可分配总额；已有`allocate_budget()`提供余额逐条扣减，未完整接通真余额及批次分配的现状仍明确保留，不宣称已完成真实划拨。

## 4. 交付与验收

同步现行代码、独立交接代码、运营文档、思维导图和压缩包；历史样例不篡改为新规则结果。本轮只计算建议，不执行广告或价格动作，最终开发交付仍到专用结果表。

验证四个正向对象全部保留、四个止损对象全部保留、不同对象方向可不同、同对象相反方向转核查、重复对象去重，以及库存和金额限制、共享预算余额不因取消名额而失效。
