# 降价动态访问门槛与对应窗口规则

更新日期：2026-10-12；规则版本：`return-v14-20261012-dynamic-price-visits`。本文件替代降价的“当前近7天50次访问＋历史50次访问”条件。广告零单20／40点击分档、有单ACOS分档、角色退出及价格一档边界继续保留。

## 1. 运营一句话

**先给商品断货前卖3件所需的访问机会；返场后的对应窗口已经有这么多访问，实际销量仍明显低于以前，再考虑降一档。**

同一个国家、店铺、MSKU单独计算，不把国家类别合计转化复制到各国家。这里的“以前”指本轮断货前，有库存、正常销售时的有效基准；是商品访问和销量件数，不是广告点击和订单数。

例如：以前100次访问卖10件，卖3件需要30次访问；以前100次访问卖5件，卖3件需要60次访问。每个国家商品的访问门槛随历史表现变化，不再统一卡50次。

## 2. 返场后看哪段时间

| 返场天数 | 降价转化判断窗口 |
| --- | --- |
| D1—D7 | 观察期，暂不人工调价 |
| D8—D21 | 本轮D1至当天，共N天 |
| D22—D29 | 最近21天 |
| D30起 | 最近30天 |

窗口结束于完整评价日期，不早于本轮返场日期；窗口内每天销量、访问和库存记录可靠且有货。缺记录或无货日不补0，不从断货期补足天数，也不退回近7天来生成候选。

## 3. 历史怎么取

沿用本轮已选定的断货前有效有货基准：优先30天，可靠14天兜底。国家访问和销量只在该基准日期内重新汇总；基准结束日期早于连续断货首日，不能拿返场后的销量补历史，也不能借其他国家的表现。

历史访问量只要求正且完整，不再要求≥50；历史销量仍至少5件，保留原来的成交样本保护。历史访问或销量缺失、零销量、无法确认每天有货时为待核；已知正历史销量不足5件为样本不足、保持。不填统一历史转化率或50次兜底。

**历史转化基准仍是30／14天，不改成N／21／30天。**本轮变更是返场后访问／销量判断窗口及动态门槛；销量恢复的历史同长度窗口、销售角色基准和退出规则各自保留。

## 4. 三步计算

1. 动态访问门槛＝向上取整（3×历史访问量÷历史销量）。
2. 当前预期销量＝当前对应窗口访问量×历史销量÷历史访问量。达到3件预期销量，才进入转化判断。
3. 当前实际销量严格小于预期销量×70%，进入降一档候选；等于70%不通过。

例如历史100访问、10件销量，当前14天40访问：门槛30次，当前预期4件。实际2件时进入降一档候选；实际3件时保持。访问只达到29次则继续观察。

3件和70%都是试算参数，不代表已验证最优收益，也不证明价格造成了销量差。销量／访问量可能包含一单多件，不当成购买概率或统计置信度。

## 5. 代码与数据协议

`enrich()`新增国家级`price_comparison`：

- `current`：`comparison_metrics(by_day, cutoff, comparison_days(age))`，N／21／30天访问和销量。
- `history`：`comparison_metrics(by_day, baseline.end, baseline.days)`，同国家断货前30／14天基准。
- 继续保留`recent`近7天及`historical`基准字段，供既有价格利润、保持和展示使用；不会用它们替代缺失的降价对应窗口。

`price_conversion_evidence(country, age)`校验数据并计算门槛；`price_candidate()`在销量修复／恢复不足降价分支使用该证据。没有新版`price_comparison`时待核，不静默用旧近7天字段重算。

```python
required_sessions = ceil(3 * historical_sessions / historical_qty)
expected_qty = current_sessions * historical_qty / historical_sessions
enough_visits = current_sessions * historical_qty >= 3 * historical_sessions
weak_conversion = current_qty * historical_sessions < 0.70 * current_sessions * historical_qty
```

代码使用Decimal；先乘后除。3件与70%边界直接比较乘积，不对显示的百分比或预估销量取整后判定。例如历史99访问、9件，门槛精确为33次，不因循环小数误判34次。

输出`price_conversion`保存：`is_trial_rule/expected_unit_target=3/required_sessions/expected_qty/conversion_ratio/enough_visits/weak_conversion/status/reason`；同时保存当前及历史的窗口起止、天数、访问量和销量。输入、门槛、差距和最终限制均可读回解释。

## 6. 仍需检查什么

达到动态门槛只是满足降价样本条件，还要符合适用经营分支、库存覆盖≥14天、完整同币种价格阶梯、向下相邻一档不低于P10、真实调价间隔及广告先行规则。

主窗口日销<1件继续豁免利润门槛；非低日销仍需国家近7天订单毛利率≥10%，联合预测利润≥5%待核。原有利润修复提价、近7天角色保持分支及P10底线修复优先级维持原状，不因新访问门槛强制降价。

未达到动态访问门槛为“继续观察”，不是“价格正常”。数据或历史基准缺失为待核，有库存、价格或操作限制则保留具体限制。已退出和观察期不生成本轮正常调价建议。

## 7. 验收与交付

- 历史20%／10%／5%／2%的门槛分别15／30／60／150次；每档前1次与恰好达到。
- 历史和当前访问均不足50但动态门槛成立；删除两个固定50门槛。
- 历史99访问9件的33次精确边界；预期3件和实际恰为预期70%边界。
- D21／22、D29／30窗口切换、D75只用最近30天；不借断货日期或未来数据。
- 访问／销量缺失、历史零销量、历史不足5件、库存缺失及再断货；不借其他国家转化。
- 近7天访问很少但主窗口样本足够，正常进入候选；近7天很多但对应窗口未满足时不偷换窗口。
- P10、库存14天、利润例外、实际7天调价间隔、相邻一档及广告优先继续成立。
