# 独立数据代码使用说明

这份代码可以单独复制给开发人员。只依赖Python标准库和PyMySQL；测试另外使用pytest。没有原项目`app/etl`导入，也没有HTTP路由。

最新交付要求为[计算结果落到专用远端数据表](../../../../04-结果数据表与落库要求.md)。本包当前CLI只输出JSON，接手方需要补批量落库与读回验收；统计函数是参考，不要求做页面。

广告采用[固定ACOS分档](../../../../01-返场品完整运营决策.md)：目标20%、上限50%，不再依赖旧`affordable_acos`输入。有单与零单分别判断，库存、预算、操作和适用利润核验仍保留。

零单采用[成熟点击分档](../../../../01-返场品完整运营决策.md)：不足20保持、20—39次降10%、40次及以上降20%。所有日销统一，无需价格／成本／预算比较。`ad_candidate()`直接判断并保存`zero_order_clicks`，`ad_for_country()`接入对象成熟统计。旧`country_budget_usage()`只保留历史核查用途。

降价采用[动态访问门槛](../../../../01-返场品完整运营决策.md)：`enrich()`提供国家`price_comparison`，`price_conversion_evidence()`算断货前卖3件所需访问及返场N／21／30窗口预期销量；`price_candidate()`保留原价格约束。当前与历史均不固定50次。

## 安装与配置

建议Python3.11以上，在本`代码`目录：

```powershell
python -m pip install -r requirements.txt
Copy-Item config/database.example.ini config/database.ini
```

由开发人员在本机填`database.ini`的source段host、port、user、password，使用只读账号；不要提交真实配置。也可提供`RETURN_GOODS_DB_HOST/PORT/USER/PASSWORD`环境变量或以`RETURN_GOODS_DB_CONFIG`指定配置路径。

包不会下载或同步远端业务数据到业务源表。会话只读仍应配合数据库只读账号；文档中的只读不等于已经替开发人员设置账号权限。

## 运行

```powershell
python -m return_goods_data.remote_sources --store CHOOJEE --msku CJ057b --snapshot-date 2026-10-08 --output result.json
```

输出包括完整商品决策和`page_data`。执行成功才写本地结果文件，读取失败直接报错，不覆盖为“没有广告”。业务日必须是完整自然日；历史设置不晚于评价日。

## 供批量计算调用

```python
from datetime import date
from return_goods_data.remote_sources import calculate
from return_goods_data.presentation import prepare_page_data

products = []
warnings = []
for store, msku in candidate_products:
    result = calculate(store, msku, date(2026, 10, 8), date(2026, 10, 8))
    products.extend(result['products'])
    warnings.extend(result['warnings'])

page_data = prepare_page_data(products, {'data_date': '2026-10-08'},
                              exit_status='tracking', all_rows=True)
limited = prepare_page_data(products, {}, focus='ad_limited', all_rows=True)
price_down = prepare_page_data(products, {}, focus='price_down_review', all_rows=True)
```

这里是最小串行接入示例，`candidate_products`由远端库存枚举，须先去重；全量生产任务应复用共同日期及快照、分片读取、统一批次发布。当前CLI不是已优化的全量调度任务。

如需持久化首次退出，读取上次成功同事件记录并调用`retain_exit()`后再形成新建议；不要仅靠当前结果文件覆盖不可变退出事实。详见第05份接手步骤。

## 复制说明

`rules.py`完整复制当前纯规则；`enrichment.py`和`presentation.py`只提取计算与统计函数；`remote_sources.py`替换原项目导入、连接适配并补`page_data`；没有复制建表、发布批次或业务操作代码。

函数原位置及源码哈希保留在[代码来源清单](../../../../验收资料/当前版本/代码来源与校验清单.json)。接手后修改规则应更新版本和验收，不能把本副本长期当作自动同步生产代码。
