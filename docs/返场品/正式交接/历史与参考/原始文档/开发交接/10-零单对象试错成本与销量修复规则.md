# 零单对象试错成本与销量修复规则（已停用历史版本）

> 已由[零单成熟点击分档规则](../../../01-返场品完整运营决策.md)替代。以下仅保存v12历史方案，不参与当前开发或计算。

更新日期：2026-10-12；规则版本：`return-v12-20261012-object-trial-cost`。本规则替代08中的预算消耗50%／100%止损。恢复按具体广告对象自身的试错花费判断；有单对象ACOS目标20%、上限50%、无动作数量限制及同对象涨降互斥保持不变。

## 1. 场景 → 建议 → 待核 → 复评

仅D8起未退出且需要干预的商品进入判断。每个关键词或真实自动匹配target须唯一关联MSKU、正在投放、归因成熟、点击至少20次、0订单且有实际花费；只有该对象自己的同窗花费用于触发，不加上其他对象花费。零单归因销售额大于0、报表或库存日期覆盖不完整时先核查。不额外要求7个报表日，但已有报表日必须完整成熟；缺日期不补0。

| 场景 | 单次试错成本 | 对象自身花费与建议 |
| --- | --- | --- |
| 主评价窗口日销<1件，销量修复 | 同站点销售参考金额×30% | 花费<2倍额度：保持；≥2倍额度且<参考金额：降竞价10%；≥参考金额：降20% |
| 日销≥1件或低日销条件无法可靠确认 | 每单净收入－每单非广告成本－净收入×5%，再取净收入×50%的较小值 | 正额度下，花费<2倍额度：保持；≥2倍额度：降10% |
| 正常分支的可承受成本≤0 | 额度归零，说明利润限制 | 受限，先修复利润；不生成负额度或无条件降价金额 |
| 对应参考金额、成本、币种或归属未核实 | 不填0、不借其他商品数据 | 待核，不输出确定竞价金额 |

低日销30%额度及两倍止损、加重止损幅度均为**试算规则**，尚无运营效果回测。“单次”是额度的计量基准，不是每次计算新发一份预算；不实际拨款或锁定资金。

比如同站点参考金额20欧：单次额度6欧；该对象花费不足12欧继续观察，达到12欧候选降10%，达到20欧候选降20%。正常分支每单净收入20欧、非广告成本14欧：额度为20－14－1＝5欧，达到10欧候选降10%。所有边界用Decimal原值比较，不用显示舍入值。

## 2. 为什么低日销选30%，怎么理解50%

有单目标仍是ACOS≤20%。低日销先恢复成交，不要求当前利润达标，因此零单测试允许用30%的参考成本，给恢复留出一定空间；50%作为单次参考成本最高档，其2倍即参考金额本身，触发加重止损。不是让每个对象无限试错，也不是承诺降低竞价后ACOS必然≤50%。

零单没有有效ACOS分母，30%和50%仅用于定义测试成本额度，不能显示成实际ACOS30%或50%。达到1倍参考金额的对象花费也不能解读成已产生100%ACOS。

## 3. 当前取数和可靠性

低日销准入沿用`sales_repair_first(event)`：商品主评价窗口销量完整、日均销量<1件；日销恰为1件进入正常利润分支。不是按该关键词零单或国家近7天0单把商品判成低日销。

低日销当前用该国家已有日期的Listing价格作**单件销售参考金额**，来源为远端`dwd_datasync.lx_sales_mws_listing.landed_price`及`currency_code/create_time`。这不是已验证的每订单净收入：多件订单、折扣、税费、退款和价格变动需复核，建议保持待核。没有同币种正价格、日期晚于评价日或同日价格冲突时不算金额。历史查询只读截至评价日已存在的快照，不拿未来价格。

正常分支仅接受已核实的`order_economics`：同国家、店铺、MSKU的每订单净收入和不含广告费的非广告成本、币种、来源日期、核实标记。不能用`amount/volume`冒充每订单金额，不能把`predict_gross_profit`直接当广告前利润，不能用P10档位反推真实成本。当前远端适配器没有可靠的每单非广告成本供给，该分支会待核；接手方须补接经过验证的订单收入、订单数及成本明细，税费退款与收入分母一致、广告费不重复扣减，并保存证据。


`zero_order_trial()`负责额度，`ad_candidate()`用对象成熟花费比较，`ad_for_country(..., listing=listing)`接入来源并保留核验项。`country_budget_usage()`仅保留为v10/v11历史核查工具，当前决策不调用。

建议保存`zero_order_trial`：`policy/verified/is_trial_rule/reference_amount/reference_source/source_date/currency/non_ad_cost/allowance/stoploss_threshold/hard_threshold/issues`。`stats`保存对象自身点击、订单、花费、窗口及`zero_order_coverage_verified`。未达到阈值为保持；未知为待核；明确限制为受限。金额存在仍不等于可以执行。

## 5. 预算、保护与价格分流

预算只用于总体投入、真实可用资金和增量预算申请，不作为零单竞价的质量判断。预算为0、缺失或其他对象消耗改变，都不能单独改变该零单对象的方向；恢复投放和加竞价仍须核实真实资金。所有达标对象均输出建议，不增设数量名额。

品牌／核心词保护、其他归因订单、近期实际操作、复评间隔、平台范围及自动target搜索词覆盖继续核验。未核实不能标ready；没有操作记录，不把历史建议当已执行，也不根据同一旧窗口每日重复降价。实际执行后用生效后的新成熟窗口复评。

本国家有具体适用广告建议时优先核验广告，再审价格；广告只是缺试错依据或没有适用动作时，价格独立审核自身条件。不得把预算缺失又变成统一挡住调价的条件。

## 6. 验收

- 日销不足1、恰好1及日销不可确认的分支边界；低日销不依赖利润成本输入。
- 20欧参考价的11.999／12／19.999／20欧花费；正常5欧额度的9.999／10欧花费。
- 成熟20点击0单、19点击、未成熟、零花费、缺报表日期和币种不一致。
- 同一对象表现不变，仅改变预算或其他对象花费，建议不变。
- 正常成本缺失、负成本、可承受额度≤0和50%单次上限。
- 默认竞价、最小单位取整、暂停／归档、多商品归属、重复对象和同对象相反方向。
