# 固定ACOS分档与广告调整规则

最近更新：2026-10-12。规则版本：`return-v14-20261012-dynamic-price-visits`。本文件覆盖旧版“按利润倒推可承受ACOS”以及“低日销不看ACOS直接加投”的判断。进入、观察、退出和价格自身门槛维持现行规则。零单按[成熟点击规则](../../../01-返场品完整运营决策.md)判断。对象数量不限，同对象涨降互斥。

用户确定目标ACOS≤20%、最高容忍边界50%，并明确10%—20%单次竞价可加10%。其余分档幅度是本轮采用的运营参数，尚未验证最优，不承诺调一次即可把真实ACOS降至目标。ACOS＝同一对象成熟窗口广告花费合计÷归因广告销售额合计；不是商品总销售额，也不是每日ACOS平均。

## 1. 每档直接怎么处理

| 当前成熟对象ACOS | 调整方向与单轮幅度 | 条件与限制 |
| --- | --- | --- |
| 0%—20%，包含20% | 需要拉量时竞价候选＋10% | ≥7个成熟有效报表日、≥20点击、≥3单；DOS≥14天。DOS为7至不足14天只＋3%；不足7天不加 |
| >20%—30%，包含30% | 只有主评价日销<1件的销量修复，可候选＋3%；其余保持 | 同样样本要求，DOS≥14天；不新增预算，不因低利润豁免ACOS分档 |
| >30%—40%，包含40% | 保持竞价、控制消耗，暂不增加投放 | 观察下一轮成熟效果；不新增预算 |
| >40%—50%，包含50% | 竞价候选−10% | ≥7个成熟有效报表日、≥3单；不另加20点击要求，不加竞价或预算 |
| >50% | 竞价候选−20%，标记超限止损 | 同样成熟订单要求；禁止加投，不能直接恢复原高消耗暂停对象；不自动暂停全部广告 |

即：20%属于积极档；30%属于谨慎档；40%属于保持档；50%属于−10%档；严格超过50%才−20%。用原始精度分档，不能先把20.0001%显示为20%再当达标。

“积极拉量”只改变单次幅度，不取消商品是否需要干预、对象归属、成熟样本、库存、平台上下限、预算、操作记录和正常复评。日销≥1件的利润风险仍限制正向投放；日销<1件的利润例外仍有效，但高ACOS先控费。

## 2. 样本缺失和零单如何判断

- 归因未成熟、多个商品共用对象、有效竞价缺失：分别说明，不套ACOS档位生成金额。
- 有订单但销售额为空或≤0：ACOS无法计算，不当作0%。负点击、订单、花费或销售额需核对。
- 有效报表不足7天或订单不足3单：不能把当前ACOS分档直接当竞价达标；继续积累样本。可靠数值及超限事实可以保留，但不自动加投。
- 零订单单独处理：成熟且对象覆盖可靠，0—19点击保持、20—39点击降10%、40次及以上降20%。不另要求7个报表日，不区分商品日销。
- 零单不使用CPA、参考价格、成本额度或预算消耗。有单继续固定ACOS；点击／订单／日期覆盖缺项待核，具体金额仍检查有效竞价与币种。
- 没有点击：查投放资格、状态、预算及同步，不循环抬价；未取得当前经营国家广告对象时，按现行开启广告／映射核查规则处理。

## 3. 申请预算

只在成熟样本及经营准入通过、对象ACOS≤20%、DOS≥14天、真实预算限制已确认时，才用申请预算替代加竞价；同对象不同时加竞价和预算。

申请额仍取月配置10%、周配置25%、真实池余额以及正常商品利润容量的较小值。低日销修复豁免利润容量，不豁免真实余额、ACOS和库存。20%以上不申请增量预算。配置金额不是可用余额，同池不可重复分配。

## 4. 金额、状态和价格衔接

当前有效bid优先对象正值，否则继承正的默认bid。加价向下取整、降价向上取整；金额不变不强凑一个最小单位。实际变化比例用目标／当前−1，名义＋10%不等于取整后恰好＋10%。

结果保存`acos`、`acos_band`、`acos_band_label`、`acos_target=0.20`、`acos_max=0.50`、名义幅度、金额、样本及限制。字段均采用小数比例，不填20或50代表20%／50%。

固定分档已经确定，不再附加“可承受ACOS待核”。零单点击与归因证据、真实可用余额、平台范围、近期操作或适用预测利润未核实时仍为待核；已知限制失败为受限。能计算金额不代表全部条件已满足。

先广告、再独立审核价格的分流保留：存在具体适用广告动作才暂缓价格；广告只是缺数、无适用动作或受限时，价格独立判断自身门槛。

## 5. 复评和交付

每次只给本轮建议，不自动向平台执行。实际操作生效后，按现行复评记录及归因成熟判断下一轮，不用同一旧窗口每天重复＋10%或−20%。竞价涨幅不等于花费涨幅，也不能保证未来ACOS≤50%。

新Codex最终交付专用远端结果数据表，不做页面。代码、XMind、文字大纲及交接压缩包须采用同版分档。旧版真实样例和验收数量保留历史版本，不改成虚构的新规则实跑记录。

验收覆盖20%／30%／40%／50%两侧、10%—20%＋10%、低日销高ACOS不加投、DOS7／14、零单、缺归因销售额、默认竞价取整、预算≤20%及暂停高ACOS对象。
