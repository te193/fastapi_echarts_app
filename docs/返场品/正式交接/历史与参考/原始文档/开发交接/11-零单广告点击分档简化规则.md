# 零单广告点击分档简化规则

更新日期：2026-10-12；规则版本：`return-v14-20261012-dynamic-price-visits`。本文件是现行零单规则，替代08预算比较及10试错成本版本。有单ACOS分档、进入退出和调价策略继续保留。

## 1. 运营只需解释这一张表

同一个关键词或自动匹配方式，订单归因成熟后仍然0单：

| 成熟点击数 | 建议 |
| --- | --- |
| 0—19次 | 保持竞价，继续观察 |
| 20—39次 | 降竞价10% |
| 40次及以上 | 降竞价20% |

日销不足1件和正常日销统一用这张表。零单不计算CPA、单次试错额度、销售参考金额、利润预留或预算消耗比例。20／40点击及10%／20%降幅为**试算规则**，尚未验证最优收益。

## 2. 三个必要条件

1. 分关键词、分具体自动匹配方式统计，不把整组或其他对象点击加在一起。多商品共用对象不归给单个MSKU。
2. 等订单归因成熟再判断。当前仍按完整报表日减7天，最多取最近14个成熟报表日，并且不早于本轮返场日期；排除无货日，缺库存、缺报表或缺订单不能补0。零单不额外要求7个报表日。
3. 调整后用新的成熟数据复评，不用同一批旧点击每天重复下调。建议记录不代表实际执行，必须核实真实操作记录和保护条件；未核实仍为待核。

没点击且数据完整时保持竞价，可另查投放资格和同步。暂停对象判断恢复，归档对象核查，不按点击分档继续降；品牌／核心词保护、其他归因订单及平台竞价上下限仍保留。订单为0但归因销售额>0时先核对数据。

## 3. 代码和取数

远端对象与报表来源维持原适配器：`dws_datasync.dws_sp_bid_object_snapshot_daily`、`ods_datasync.lx_advertising_sp_targets`、关键词及搜索词逐日报表。具体字段和去重方式见[远端取数文档](../../../02-远端取数与指标口径.md)。自动方式仍须真实target和可靠对象覆盖，不用广告组汇总代替。

`aggregate_ad_days()`生成对象的成熟`clicks/orders/cost/sales`、日期窗口及`zero_order_coverage_verified`。花费和销售额仍作数据完整性检查、展示及有单ACOS输入，但**花费金额不再决定零单降幅**；可靠的0花费也不阻断点击分档。

```python
# 纯规则示例；20点击0单不需要价格、成本或预算输入。
ad = dict(mapping_count=1, enabled=True, mature=True, days=1,
          clicks=20, orders=0, cost=1, sales=0, current_bid=1,
          zero_order_coverage_verified=True)
result = ad_candidate(ad, dos=28)
# target = 0.90；40点击时target = 0.80。
# 有金额仍只是建议，必要操作核验完成前保持pending。
```

`ad_candidate()`直接判断点击档位；`ad_for_country()`不再接入Listing参考价格或订单经济性。`zero_order_trial()`已移除。预算只参与恢复、加竞价和预算申请的资金判断，旧`country_budget_usage()`只保留历史核查用途。

当前有效竞价优先对象正竞价，否则继承正默认竞价。降低竞价按币种最小单位向上取整，取整后大于0且发生变化；缺币种、金额或取整无变化时不造目标价。不同对象可分别调整，不设动作条数限制，同对象不能同时涨降。

## 4. 输出证据和价格联动

建议保存`zero_order_clicks`：`clicks/orders/click_band/first_threshold=20/second_threshold=40/is_trial_rule/coverage_verified`。`stats`保留成熟窗口、报表日及来源；继续保存对象身份、当前竞价、目标竞价、调整比例、具体原因和检查项。

不再输出`zero_order_trial`或`budget_comparison`作为零单依据。旧结果、旧验收样例不伪装成v13重算。正常日销零单不再因为缺每单成本而无法判断。

本国家有具体适用广告动作时广告优先；仅广告缺数、保持或受限时，价格独立审核原有门槛。有订单的对象继续按固定ACOS20%目标、50%上限判断，不套零单点击分档。

## 5. 验收和交付

- 19／20／39／40次点击边界；0点击保持，100点击仍为−20%，不追加新档位。
- 未成熟、订单或点击缺失、报表日期缺失、多商品共用、暂停及归档。
- 日销、价格、非广告成本、预算和其他对象花费改变，不改变相同点击／订单对象的降幅。
- 手动词和两个不同自动target分别20／40点击时，分别降10%／20%；对象去重。
- 继承默认竞价、币种取整、有效金额及真实操作复评。

代码与自动化验收只给建议和解释，不执行广告。最终开发仍只交付专用远端结果表，不做页面或路由，见[落库验收要求](../../../04-结果数据表与落库要求.md)。
