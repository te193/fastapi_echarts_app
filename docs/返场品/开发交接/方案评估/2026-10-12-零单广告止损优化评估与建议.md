# 零单广告止损优化评估与建议

日期：2026-10-12。状态：**历史评估，未整体采用**。当前规则已更新为`return-v13-20261012-zero-order-clicks`，见[成熟点击分档规则](../11-零单广告点击分档简化规则.md)。采用20／40成熟点击分档，本文CVR／CPC参考与否定建议未作为现行自动规则，不代表回测或广告动作已完成。

## 1. 建议怎样改

把当前“国家商品花费／预算达到50%或100%，就降低零单对象竞价”改为：

**先确认成熟与投放正常 → 看搜索词是否相关 → 按对象点击、预期转化及实际CPC判断 → 选择保持、降竞价、否定无效搜索词或人工暂停。预算只检查新增花费是否允许。**

评估适用于七国返场品D8起需要干预的分支；D1—D7观察期、已退出不因此生成正常新动作。保持现行有单ACOS目标20%、上限50%，数量不限、同对象涨降互斥，以及库存、预算真实余额和实际操作复评约束。

## 2. 当前预算触发器为什么有偏差

预算表达愿意投入的额度，不能独立测量目标的转化效率。

- 同一零单对象表现没有变化，预算调大后会更晚触发降价；预算调小则更早触发。决策可能由配置变动驱动。
- 当前分子包含其他出单对象花费。优质对象投入增加，可能触发对一个仍在测试的零单对象降价。
- 商品预算高时，昂贵零单对象可能拖很久才触发；商品预算低时，便宜但尚未充分采样的对象可能被过早处理。
- 周月额度折算、历史快照及币种校验解决了可比性问题，但不能使预算比例变成对象效果指标。

说明性例子：零单对象本身成熟25点击、花费10欧元，预算20欧元时现规则消耗50%、降10%；预算100欧元时消耗10%、保持。这是固定表现的数学例子，不是真实业务样本。

## 3. 传统运营动作要分开

| 当前情况 | 建议动作 | 判断要点 |
| --- | --- | --- |
| 归因未成熟，或对象样本不足 | 保持／继续积累 | 最近点击可能晚些出单，不把缺数当零单 |
| 明确不相关的购物搜索词或ASIN | 否定精准搜索词／产品目标候选 | 核对商品用途、规格和相关性；不要自动否定品牌词、核心词、替代或互补关系 |
| 流量相关，但点击成本高 | 降低该关键词或自动匹配方式竞价 | 用对象自己的CPC及可靠参考转化率，不能由其他对象花费触发 |
| 自动或广泛匹配中，少数搜索词浪费，其他词出单 | 优先处理浪费的搜索词 | 不直接降整个广告组，也不将有单搜索词的结果平均分给所有目标 |
| 点击不贵，但明显超过正常出单要求仍零单 | 检查转化问题，必要时继续减投／人工暂停 | 区分搜索意图和商品售价、详情页、可售及Featured Offer问题 |
| 多个高度相关对象都不出单 | 商品转化诊断和适用价格审核 | 这是诊断线索，不证明价格一定有错；避免把商品问题全部处理成广告降bid |
| 本轮已实际调整，复评数据尚未成熟 | 等待复评 | 不用同一批点击每天连续降价；只保存当前一轮建议 |

Amazon官方支持按搜索词与投放对象表现调整竞价、筛选否定流量，也建议检查低销售商品的详情页、价格、库存和Featured Offer。官方“至少20次点击后评估否定目标”是评估时点建议，并未给出20点击零单必降竞价的统一规则。

## 4. 20次点击应作为开始检查，不是证明无效

假设真实转化率为5%，且每次点击独立、转化率稳定，20次点击仍零单的概率为`0.95^20≈35.8%`；60次零单的概率为`0.95^60≈4.6%`。

因此同样“20点击零单”，对高转化商品和低转化商品的含义不同。这是说明性概率模型，不是返场商品的实测结论；返场期间流量和转化可能变化，不能将其概率称为对象无效的确定证明。

建议基准优先采用同对象断货前成熟有货表现，次选同国家、同店铺、同MSKU且匹配方式相近的成熟广告表现。基准覆盖和样本不足时说明未知；不把当前零单对象的CVR=0直接作为期望转化率，也不随意借全国家所有商品平均值。

## 5. 先将固定ACOS目标转为点击成本参考

在同对象、同周期、同币种的口径下：

`ACOS = 平均CPC ÷ (平均每单广告成交额 × CVR)`。

因此可用可靠历史预计每单成交额和参考CVR，形成：

- 目标平均CPC参考＝预计每单成交额×参考CVR×20%。
- 最高平均CPC参考＝预计每单成交额×参考CVR×50%。

这是固定运营ACOS目标的推导，不使用生产成本或利润倒推。CPC是实际平均点击花费，bid是出价；参考CPC不能直接当最终bid，仍要检查当前出价、投放位置和竞价策略。

例：预计每单成交20欧元、参考CVR5%，目标平均CPC为0.20欧元、最高参考为0.50欧元。

| 成熟零单且流量相关 | 首版可试算的处理 |
| --- | --- |
| 点击≥20，实际CPC高于目标参考、未超过最高参考 | 候选降bid10% |
| 点击≥20，实际CPC超过最高参考 | 候选降bid20%，优先控费 |
| CPC不高且点击仍不足以反映参考转化 | 继续观察，不因预算消耗而降bid |
| CPC不高，但点击已明显超过历史正常出单要求 | 转化诊断；检查具体搜索词，复评后仍低效再考虑减投或人工暂停 |
| 参考成交额／CVR不可靠 | 不伪造目标CPC；仍可核查明确无关搜索词、投放异常和价格转化 |

10%／20%为拟议首轮幅度，不是官方标准或已证明最优参数。对“明显超过正常出单要求”的点击门槛，需要按本项目历史CVR与误伤率回算后定，不再直接指定所有商品统一20／30／50点击。

## 6. 预算保留在哪里

预算用于判断能否开启、恢复、加竞价、申请增量，以及资金使用进度；真实余额未知时不宣称能增加投入。同池资金不重复分配。

降低竞价或建议否定已核实的无效流量，不再等待国家商品预算消耗50%／100%。缺预算不等于无法判断一个对象明显不相关或点击成本过高。实际执行和保护条件仍保留，仅输出建议。

## 7. 怎样验证后再改代码

先读取真实历史并按严格时间切分回放，基准数据只用当时可见的成熟、有货记录；检查近14／30天对象覆盖、同SKU归属、国家币种及搜索词归因。

比较当前预算法、简单成熟点击法、预期CVR与CPC法：各自产生多少对象建议；被提前处理的对象随后是否成熟出单；节省花费与可能丢失成交；基准不足和搜索词不完整的覆盖率。历史回放只验证识别与后续自然表现，不能证明实际降bid后的因果效果。

再进行受控的小范围人工复评，检查实际生效后的新成熟窗口。预算和数量限制的改变不替代这一步。本文本轮未查询全量远端广告数据，未完成以上回测，未修改当前代码或平台设置。
