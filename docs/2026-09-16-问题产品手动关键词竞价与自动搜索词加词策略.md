# 问题产品手动关键词竞价与自动搜索词加词策略

## 1. 结论

本策略适用于同时满足以下条件的商品：

~~~text
销售状态标签 = 正常在售
站点销售角色标签 = 问题产品
站点销售角色周期 = 30d
~~~

本次只新增两类建议：

1. SP 手动广告关键词竞价调整；
2. SP 自动广告自然语言搜索词加为手动精准关键词。

已经确认的自动广告匹配方式竞价和搜索词否词继续沿用，不在本策略中修改。手动关键词涨价和搜索词加词还须执行《问题产品 SP 手动关键词调价与自动搜索词加词决策》第 3 节的商品预算与活动预算限制；不设置库存限制。所有结果只生成待审核建议，不自动写回广告平台。

截至 2026-09-15 最新标签快照，当前范围为 2,963 个“国家 + 店铺 + MSKU”。广告表现使用 2026-08-10 至 2026-09-08 的成熟 30 天，订单和销售额统一使用 7 天归因。该范围会随最新标签快照变化，不把 2,963 作为固定常量。

## 2. 数据来源与归属规则

### 2.1 数据来源

`dws_datasync.dws_标签表`只用于圈定“正常在售 + 问题产品”的产品范围。手动关键词和自动搜索词的配置、状态、表现及冲突判断全部从 ODS 原始同步表重新计算，不读取以下两张 DWS 广告宽表：

- `dws_datasync.dws_sp_bid_object_snapshot_daily`；
- `dws_datasync.dws_sp_search_term_analysis_daily`。

广告侧使用以下 ODS 表：

| 数据用途 | ODS 表 | 主要字段 |
|---|---|---|
| 账号、国家和币种 | `lx_advertising_account_list` | `profile_id`、`country_code`、`currency_code`、`status` |
| 活动类型与当前状态 | `lx_advertising_sp_campaigns` | `targeting_type`、`state`、`serving_status`、`daily_budget`、`bidding` |
| 广告组与默认竞价 | `lx_advertising_sp_ad_groups` | `ad_group_id`、`default_bid`、`state`、`serving_status` |
| 商品广告当前归属 | `lx_advertising_sp_product_ads` | `ad_group_id`、`sku`、`asin`、`state` |
| 商品广告成熟期归属 | `lx_advertising_sp_product_ad_reports` | `report_date`、`ad_group_id`、`sku` |
| 手动关键词当前配置 | `lx_advertising_sp_keywords` | `keyword_id`、`keyword_text`、`match_type`、`bid`、`state` |
| 手动关键词表现 | `lx_advertising_sp_keyword_reports` | 曝光、点击、花费、7 天归因订单和销售额 |
| 自动投放对象配置 | `lx_advertising_sp_targets` | `target_id`、`expression`、`bid`、`state` |
| 自动广告搜索词表现 | `lx_advertising_sp_query_word_reports` | `query`、`target_id`、点击、花费、7 天归因订单和销售额 |
| 已有否词 | `lx_advertising_sp_negative_targets_or_keywords` | `negative_text`、`negative_match_type`、`state` |
| 商品语义复核资料 | `lx_sales_mws_listing` | 标题、品牌、类目、ASIN、上架时间等 |

数值校准窗口内，关键词日报、搜索词日报和商品广告日报均覆盖完整 30 个业务日期。

### 2.2 安全归属

一个广告组只有同时满足以下条件，才允许归属于某个 MSKU：

- 当前启用商品广告只有 1 个 MSKU；
- 成熟 30 天商品广告日报中只有 1 个 MSKU；
- 当前 MSKU 与成熟期 MSKU 完全一致；
- Profile 国家、店铺主体和 MSKU 能唯一命中标签产品。

当前多商品、成熟期多商品、MSKU 发生变化或账号无法唯一匹配时，只输出“归属待核对”，不生成竞价或加词建议。

## 3. 最终执行口径

- 所有动作按最新成熟 30 天窗口滚动计算，排除最近 7 天归因未成熟数据，不固化历史结论；
- 手动关键词统一采用第 4 节的 ACOS、CVR、订单和点击阈值，暂不按国家或匹配方式拆分；
- 手动关键词 `+15%`档只生成待审核建议，不自动执行；
- 自动搜索词只将自然语言词纳入关键词加词，ASIN 单独作为商品投放候选；
- 加词前必须完成跨广告组聚合、已有精准词去重、否词冲突检查和商品语义复核；
- 新精准词的初始竞价不得高于来源自动投放当前竞价与成熟期实际 CPC 两者中的较小值。

## 4. 手动关键词竞价调整策略

### 4.1 前置条件

关键词必须同时满足：

- 手动 SP 活动、广告组和关键词当前均为启用状态；
- 当前竞价大于 0，币种与账号国家一致；
- 满足第 2.2 节的单 MSKU 安全归属；
- 关键词日报与商品广告日报完整覆盖成熟 30 天；
- 涨价候选的产品 TACOS 必须低于 10%，并执行最终决策文档第 3 节的商品预算与活动预算限制；不再额外设置 CPC 容量或库存护栏。

通用前置条件不满足时，只输出观察或待核对，不生成建议竞价。只有涨价护栏不满足时，取消涨价、改为保持或待核对；它本身不触发降价，降价仍按 ACOS、CVR、点击和订单规则判断。

### 4.2 有订单关键词

| 建议 | 必须同时满足 |
|---|---|
| 涨价 5% | 点击至少 15、订单至少 2、ACOS不高于40%、CVR至少5% |
| 涨价 10% | 点击至少 40、订单至少 3、ACOS不高于30%、CVR至少7% |
| 涨价 15% | 点击至少 80、订单至少 5、ACOS不高于20%、CVR至少7% |
| 降价 5% | 点击至少 20、订单至少 2、ACOS为40%–50%、CVR低于3% |
| 降价 10% | 点击至少 20、订单至少 2、ACOS高于50%且不高于65% |
| 降价 20% | 点击至少 20、订单至少 2、ACOS高于65% |

ACOS 高于 50%的关键词禁止涨价。同一关键词命中多个涨价档位时取最大涨幅；风险控制优先于涨价。

### 4.3 仅 1 单关键词

| 成熟 30 天点击 | 表现 | 建议 |
|---:|---|---|
| 少于 34 | 任意 | 保持观察 |
| 34–62 | ACOS高于50%或CVR低于3% | 降价5% |
| 至少 63 | ACOS高于50%或CVR低于3% | 降价10% |

仅 1 单时不涨价，避免单个订单使 ACOS 和 CVR 大幅波动。

### 4.4 零订单关键词

| 成熟 30 天点击 | 建议 |
|---:|---|
| 少于 34 | 继续观察 |
| 34–62 | 降价10% |
| 至少 63 | 降价20% |

零订单时 ACOS 不定义，不得写成无穷大后参与判断。

### 4.5 建议竞价计算

~~~text
理论建议竞价 = 当前竞价 × (1 + 建议涨跌幅)
最终建议竞价 = 理论建议竞价按常规四舍五入保留两位小数
~~~

若取两位小数后仍等于当前竞价，才按原方向修正 0.01；最终建议不得越过站点最低或最高竞价。输出同时保留规则档位和真实涨跌幅，不能把最小单位修正后的实际比例反写成新档位。

## 5. 自动广告搜索词加词策略

### 5.1 聚合、类型和去重

自然语言搜索词统一大小写、首尾空格、连续空格和常见符号，同时保留原文。指标先跨同一商品的全部自动活动和广告组聚合，再判断订单、ACOS 和 CVR，避免同一个词被拆散后低估证据。

生成候选前依次检查：

1. 数据窗口、账号、状态和 MSKU 归属有效；
2. 搜索词不是 ASIN；
3. 同一 Profile + MSKU 下不存在相同标准化文本的启用精准关键词；
4. 已有相同精准词处于暂停或归档状态时，建议“复核恢复原词”，不重复新建；
5. 现有 Broad 或 Phrase 同文本不视为精准词重复，但在建议中标明已有其他匹配方式；
6. 与启用的否定精准或否定词组发生冲突时，不加词，转人工核对；
7. 商品标题、品牌、类目、型号和兼容性不存在明确硬冲突。

### 5.2 加词门槛

| 级别 | 必须同时满足 | 建议 |
|---|---|---|
| 高置信 | 7 天归因订单至少3、ACOS不高于30%、CVR至少7% | 候选加为手动精准关键词 |
| 标准 | 7 天归因订单至少2、ACOS不高于40%、CVR至少5% | 候选加为手动精准关键词 |
| 单单观察 | 订单=1、ACOS不高于40% | 不立即加词，等待累计到标准门槛 |
| 其他 | 未命中以上条件 | 继续观察 |

高置信和标准候选仍须人工确认搜索意图与商品一致；明显不相关、信息不足或兼容性冲突时不加词。

单单观察不能通过每天滚动同一个 30 天窗口来重复计数。它只有在后续累计到至少 2 个订单，或在一个不重叠的成熟 30 天窗口再次产生订单后，才重新进入标准候选判断。

### 5.3 新精准词的落点与初始竞价

- 默认加入同一 Profile、同一国家、同一 MSKU 的专用手动精准广告组；不得加入多 MSKU 共享广告组。
- 已有合格的单商品精准广告组时优先复用；没有时只输出“缺少承接广告组”，不擅自新建活动。
- 初始精准竞价上限为 `min(成熟30天实际CPC, 来源自动投放当前竞价)`，按向下取整保留两位小数。
- 取整后低于站点最低竞价、来源竞价缺失或实际 CPC 不可计算时，不输出数值，转人工设置。
- 新词首次建成后至少观察 7 个成熟表现日，再进入常规手动关键词竞价规则。

加词后不自动在原自动广告中做精准否定。现有否词策略已经规定“有订单搜索词不否词”，因此新增精准词与原自动搜索词先并行观察；是否做流量隔离需要另立测试规则，不能借加词动作绕过已确认的否词保护。

## 6. 决策优先级与输出

### 6.1 手动关键词优先级

~~~text
数据或归属异常
→ 零单/高 ACOS 风险控制
→ 保持
→ 涨价
→ 观察
~~~

### 6.2 自动搜索词加词优先级

~~~text
数据或归属异常
→ 已有精准词或原词待恢复
→ 已有否词冲突
→ 明确语义冲突
→ 高置信加词
→ 标准加词
→ 单单观察
→ 继续观察
~~~

### 6.3 审核清单字段

手动关键词竞价清单至少包含：国家、店铺、MSKU、Profile、活动/广告组/关键词 ID、关键词及匹配方式、当前竞价、建议竞价、规则档位、真实涨跌幅、成熟 30 天曝光/点击/花费/CPC/订单/销售额/ACOS/CVR、TACOS、归属状态、命中规则和人工结论。

自动搜索词加词清单至少包含：国家、店铺、MSKU、Profile、来源活动/广告组/Target ID、原始词与标准化词、聚合来源数、成熟 30 天指标、总订单、ACOS、CVR、实际 CPC、来源竞价、已有精准/其他匹配方式/否词冲突、语义核对结果、候选等级、承接广告组、建议初始竞价和人工结论。

## 7. 验收与复盘

- 标签产品范围与最新快照一致，国家 + 店铺 + MSKU 不重复。
- 广告配置和表现不读取两张 DWS 广告宽表，所有字段可追溯到本策略列出的 ODS 表。
- 关键词日报、搜索词日报和商品广告日报均完整覆盖同一成熟 30 天。
- 当前归属和成熟期归属不唯一时不生成动作。
- 每次动作按最新成熟窗口重算，不固化历史结论；`+15%`档必须人工审核，不自动执行。
- 手动关键词涨价时产品 TACOS 必须低于 10%，并通过最终决策文档规定的预算限制；不再额外使用 CPC 容量或库存护栏。
- ACOS 大于 50%、仅 1 单或零订单关键词不得进入涨价。
- 自动搜索词先跨广告组聚合，再做精准词全局去重和否词冲突检查。
- 只有自然语言搜索词进入关键词加词；ASIN 单列商品投放候选。
- 仅 1 单不立即加词，继续等待订单证据达到标准门槛。
- 加词后不自动否定原自动搜索词，不与已确认的否词策略冲突。
- 首次上线审核全部加词候选，并抽查单单观察、否词冲突和归属异常记录；确认误加率和归属准确性后再决定是否扩大自动化程度。

## 8. 解释边界

本策略用于生成待审核的调价和加词建议，不保证竞价变化会带来同比例的流量、销售或 ACOS 变化。国家或匹配方式未单独定义阈值，后续若拆分规则，应另行校准后再上线。
