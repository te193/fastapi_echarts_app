# 返场品看板指标字典

更新时间：2026-07-15

## 1. 页面总口径

### 数据源

- 返场事件结果表：`dashboard_return_goods_events`
- 断货池结果表：`dashboard_return_goods_stockout_pool`
- 阶段每日汇总表：`dashboard_return_goods_stage_daily_summary`
- 底层日明细来源：`dashboard_product_performance_daily`

### 统计粒度

所有核心指标按以下粒度去重：

```text
店铺 + 国家类别 + MSKU
```

系统字段中对应 `item_key = seller_name_new + country_category + seller_sku_adj`。

### 排除规则

排除 Amazon 自动生成 MSKU：

```text
seller_sku_adj not like 'amzn.gr.%'
```

### 库存去重规则

产品表现表存在同一国家类别下多国家共享库存的问题，因此 ETL 聚合库存时不做直接求和：

```text
同一天 + 店铺 + 国家类别 + MSKU
FBA可售 = max(afn_fulfillable_quantity)
销量 = sum(sales_qty)
```

### 页面主口径

当前页面顶部、矩阵、明细列表均以“最新一轮返场状态”为主：

```text
同一个 item_key 多轮返场时，只取截至统计日最新一轮：
order by return_start_date desc, return_round desc
```

这样避免同一个 MSKU 多轮返场在总览里重复计数。

## 2. 时间口径

### 统计日

页面选择的快照日期，即 `snapshot_date`。

### 识别窗口

断货池默认识别最近 180 天：

```text
source_start_date = snapshot_date - 179 天
source_end_date = snapshot_date
```

返场事件仍只保留最近 180 天内开始的事件，但 ETL 会读取更长的历史上下文，用于追溯长断货段的真实起点和断货前 21 天基准：

```text
event_source_start_date = snapshot_date - (180 × 2 + 21 - 1) 天
```

扩展读取范围不扩大页面统计口径，也不会把 180 天以外开始返场的事件纳入看板。

### 周期维度

页面保留周期筛选用于流转、明细和同比较：

```text
start_date = snapshot_date - period_days + 1
end_date = snapshot_date
上一周期 = start_date - period_days 到 start_date - 1
```

顶部“截至目前总览”不受阶段、预警、点击筛选污染，只受统计日、国家类别、店铺、关键词影响。

## 3. ETL 基础指标

| 指标 | 说明 | 计算逻辑 / 判定 |
| --- | --- | --- |
| 断货池 MSKU | 最近 180 天内发生过断货且有销量的 MSKU | `stockout_days > 0 and period_sales_qty > 0` |
| 断货天数 | 最近 180 天内 FBA 可售为 0 的天数 | `sum(case when FBA可售 = 0 then 1 else 0 end)` |
| 首次断货日期 | 最近 180 天内第一次 FBA 可售为 0 的日期 | `min(dt_date where FBA可售 = 0)` |
| 最近断货日期 | 最近 180 天内最后一次 FBA 可售为 0 的日期 | `max(dt_date where FBA可售 = 0)` |
| 返场事件 | 断货后恢复到可售库存大于 5 的事件 | 先出现 `FBA可售 = 0`，后续首次出现 `FBA可售 > 5` |
| 断货日期 | 生成返场事件时对应的断货开始日期 | 当前事件中首次进入 `FBA可售 = 0` 的日期 |
| 返场开始日期 | 断货后首次恢复到可售库存大于 5 的日期 | `first dt_date after stockout where FBA可售 > 5` |
| 断货天数（事件） | 从断货日期到返场开始日期的间隔 | `datediff(return_start_date, stockout_date)` |
| 返场轮次 | 同一 MSKU 第几次断货后返场 | 同一 `item_key` 内按事件顺序递增 |

## 4. 销量和恢复率

| 指标 | 说明 | 计算逻辑 / 判定 |
| --- | --- | --- |
| 断货前 7 天销量 | 断货发生前 7 天总销量 | `sum(sales_qty) where stockout_date - 7 <= dt_date <= stockout_date - 1` |
| 断货前 7 天可售日销 | 断货前 7 天内，按有可售库存天数计算的日销 | `断货前7天销量 / count(FBA可售 > 0 的天数)`；如果可售天数为 0，则为空 |
| 观察期 7 天销量 | 返场开始后最多 7 天销量 | `sum(sales_qty) where return_start_date <= dt_date <= min(return_start_date + 6, snapshot_date)` |
| 观察期 7 天可售日销 | 观察期内按有可售库存天数计算的日销 | `观察期7天销量 / count(FBA可售 > 0 的天数)`；如果可售天数为 0，则为空 |
| 返场后近 7 天销量 | 截至统计日往前最多 7 天的销量 | `sum(sales_qty) where max(return_start_date, snapshot_date - 6) <= dt_date <= snapshot_date` |
| 返场后近 7 天可售日销 | 返场后近 7 天内按有可售库存天数计算的日销 | `返场后近7天销量 / count(FBA可售 > 0 的天数)`；如果可售天数为 0，则为空 |
| 恢复统计天数 | D1-D21 当前恢复率使用的对比天数 | `min(已返场天数, 21)` |
| 断货前对比销量 | 恢复率分母 | `sum(sales_qty) where stockout_date - 恢复统计天数 <= dt_date <= stockout_date - 1` |
| 返场后对比销量 | 恢复率分子 | `sum(sales_qty) where return_start_date <= dt_date <= return_start_date + 恢复统计天数 - 1` |
| 销量恢复率 | D1-D21 当前返场恢复程度 | `返场后对比销量 / 断货前对比销量`；未满 21 天按已过天数对比 |
| D21恢复率 | 第21天形成的固定结论 | `返场D1-D21总销量 / 断货前21天总销量` |
| 断货前基准日销 | D22后持续追踪的基准 | `断货前21天总销量 / 21` |
| 累计平均恢复率 | D21未达标产品截至统计日的动态恢复程度 | `(返场开始至统计日累计销量 / 已返场天数) / 断货前基准日销` |
| 单日恢复率 | D22后某一天相对断货前基准日销的恢复程度 | `当天销量 / 断货前基准日销` |
| 恢复率为空 | 无法计算恢复率，不等于恢复率为 0 | 断货前对比销量为 0 或缺失 |
| 21 天可售销量 | 返场开始后 21 天内，有可售库存日期的销量合计 | `sum(sales_qty where FBA可售 > 0 and return_start_date <= dt_date <= return_start_date + 20)` |

说明：页面经营对比区展示销量合计；ETL 内部恢复率也已改为总销量口径，不再使用“近 7 天可售日销”作为退出依据。

## 5. 产品角色分类

产品角色基于本轮断货前 7 天的可售日销和毛利率判定。

| 角色 | 判定逻辑 |
| --- | --- |
| 明星产品 | 日销 > 5 且毛利率 > 15%；或 1 <= 日销 <= 5 且毛利率 > 25% |
| 潜力产品 | 日销 > 5 且 5% <= 毛利率 <= 15%；或 1 <= 日销 <= 5 且 10% <= 毛利率 <= 25% |
| 瘦狗产品 | 1 <= 日销 <= 5 且 5% <= 毛利率 < 10%；或 日销 < 1 且毛利率 >= 5% |
| 问题产品 | 日销为空、日销 = 0、毛利率为空；或不满足以上条件 |

页面“角色 × 当前状态”矩阵按该角色分组。

## 6. 返场阶段

| 阶段 | 说明 | 判定逻辑 |
| --- | --- | --- |
| 观察期 | 刚返场，观察恢复情况 | 未退出，且 `1 <= 已返场天数 <= 7` |
| 运营干预期 | 进入需要运营动作介入的阶段 | 未退出，且 `8 <= 已返场天数 <= 21` |
| 持续干预期 | D21未达标后继续追踪恢复 | 未退出、`已返场天数 > 21`，且 `D21恢复率 < 70%` 或为空 |
| 已退出 | 已生成退出结果 | `exit_reason is not null` |

已返场天数：

```text
return_days = snapshot_date - return_start_date + 1
```

## 7. D21结论与持续恢复追踪

新规则只约束 D21 恢复率未达到 70% 的产品，D1-D21 阶段规则不变。

| 状态 | 说明 | 判定逻辑 |
| --- | --- | --- |
| D21达标退出 | 21天内完成恢复 | `D21恢复率 >= 70%`，D22生成退出结果 |
| 截至目前严重恢复不足 | D21未达标且后续仍明显偏低 | 持续追踪中且 `累计平均恢复率 < 50%` |
| 恢复提升中 | 已有提升但尚未达到退出线 | 持续追踪中且 `50% <= 累计平均恢复率 < 70%` |
| 数据不足持续关注 | 没有可计算的断货前基准 | `断货前21天销量 = 0`，不自动退出 |
| 21天后恢复达标 | D21未达标，后续恢复到目标 | 累计平均恢复率首次 `>= 70%`，当日退出并冻结结果 |

### 稳定恢复

稳定恢复仅从 D22 开始识别，缺失自然日按销量 0 处理：

```text
连续3个自然日的单日恢复率均 >= 50%
```

- `开始稳定恢复日期`：首次满足连续3天条件的区间第一天。
- `当前稳定恢复`：最近3个自然日仍全部达到50%。
- `恢复后回落`：历史上满足过稳定恢复，但最近3天未保持。
- 稳定恢复是运营趋势信号，不是退出的强制条件；累计平均恢复率达到70%即可退出。

## 8. 顶部四个模块指标

### 8.1 截至目前总览

| 指标 | 说明 | 计算逻辑 / 判定 |
| --- | --- | --- |
| 已返场 MSKU | 断货后已经恢复到 FBA 可售大于 5 的去重 MSKU | 最新一轮事件中 `return_start_date <= 统计日` 的 `count(distinct item_key)` |
| 触发断货 MSKU | 最近 180 天内出现过断货且有销量的去重 MSKU | 来自 `dashboard_return_goods_stockout_pool`，满足 `stockout_days > 0 and period_sales_qty > 0` |
| 观察中 | 最新一轮处于观察期且未退出 | 最新一轮 `stage = '观察期'` 且 `return_start_date <= 统计日` 且未退出 |
| 干预期 | 最新一轮处于运营干预期且未退出 | 最新一轮 `stage = '运营干预期'` 且 `return_start_date <= 统计日` 且未退出 |
| 已退出 | 最新一轮已经退出 | 最新一轮 `exit_date <= 统计日` |

未退出判定：

```text
exit_date is null or exit_date > 统计日
```

### 8.2 D21持续追踪

| 指标 | 说明 | 计算逻辑 / 判定 |
| --- | --- | --- |
| D21持续追踪总数 | 第21天未达到70%且截至统计日仍未退出 | `recovery_followup_flag = 1 and exit_date is null` |
| 严重恢复不足 | 当前累计平均恢复率低于50% | `cumulative_avg_recovery_rate < 50%` |
| 恢复提升中 | 当前累计平均恢复率达到50%但未达到70% | `50% <= cumulative_avg_recovery_rate < 70%` |
| 数据不足 | 断货前21天销量为0，无法计算累计平均恢复率 | `cumulative_avg_recovery_rate is null` |

三个子项互斥，必须满足：

```text
D21持续追踪总数 = 严重恢复不足 + 恢复提升中 + 数据不足
```

### 8.3 截至目前严重恢复不足

| 指标 | 说明 | 计算逻辑 / 判定 |
| --- | --- | --- |
| 严重恢复不足总数 | D21未达标且当前累计平均恢复率仍低于50% | `recovery_followup_flag = 1 and exit_date is null and cumulative_avg_recovery_rate < 50%` |
| 返场后始终无销量 | 返场开始至统计日没有产生销量 | 严重恢复不足且 `post_cumulative_sales_qty = 0` |
| 极低恢复 | 已产生销量，但恢复程度接近于零 | 严重恢复不足且 `0 < cumulative_avg_recovery_rate < 10%` |
| 低恢复 | 有少量恢复，仍与断货前水平差距较大 | 严重恢复不足且 `10% <= cumulative_avg_recovery_rate < 30%` |
| 恢复仍不足 | 已有一定改善，但仍低于50%持续追踪线 | 严重恢复不足且 `30% <= cumulative_avg_recovery_rate < 50%` |

四个恢复程度子项互斥归类，必须满足：

```text
严重恢复不足总数
= 返场后始终无销量
+ 极低恢复
+ 低恢复
+ 恢复仍不足
```

模块底部另外展示两个近期趋势信号：

- `近期持续改善`：最近3个自然日单日恢复率均达到50%。
- `改善后回落`：历史上曾连续3天达到50%，但最近3天没有保持。

趋势信号可以与上述恢复程度分层重叠，仅辅助判断运营动作是否开始见效，不参与严重恢复不足总数的加总。

### 8.4 退出细分

| 指标 | 说明 | 计算逻辑 / 判定 |
| --- | --- | --- |
| D21达标退出 | 最新一轮在D21达到70% | `recovery_followup_flag = 0 and exit_reason = '达标退出'` |
| 21天后恢复达标 | D21未达标，后续累计平均恢复率达到70% | `recovery_followup_status = '21天后恢复达标'` |

## 9. 角色 × 当前状态矩阵

矩阵行是断货前产品角色，列是当前状态。

| 列 | 说明 | 判定逻辑 |
| --- | --- | --- |
| 断货未到货 | 当前没有可售库存，但已有在途 | `current_fba_sellable = 0 and current_fba_inbound > 0` |
| 观察中 | 最新一轮处于观察期且未退出 | 未退出且 `stage = '观察期'` |
| 干预中 | 最新一轮处于运营干预期且未退出 | 未退出且 `stage = '运营干预期'` |
| 恢复提升中 | D21未达标，累计平均恢复率50%-70% | 持续追踪中且 `50% <= cumulative_avg_recovery_rate < 70%` |
| 严重恢复不足 | D21未达标，累计平均恢复率低于50% | 持续追踪中且 `cumulative_avg_recovery_rate < 50%` |
| 数据不足 | 断货前21天销量为0，无法计算累计平均恢复率 | 持续追踪中且 `cumulative_avg_recovery_rate is null` |

“当前稳定恢复”和“恢复后回落”是可与主状态并存的趋势信号，因此不作为矩阵互斥列，统一在顶部持续追踪模块和右侧详情中展示。

矩阵占比：

```text
单元格 MSKU 数 / 当前筛选下最新一轮返场 MSKU 总数
```

高优先级标记：

```text
角色 in (明星产品, 潜力产品)
and 状态 in (断货未到货, 干预中, 严重恢复不足)
```

## 10. 观察期 / 干预期经营对比

| 指标 | 说明 | 计算逻辑 |
| --- | --- | --- |
| 观察期 MSKU 数 | 当前处于观察期的去重 MSKU | 最新一轮未退出且 `stage = '观察期'` |
| 观察期基准销量 | 观察期对比断货前 7 天销量 | `sum(pre_7d_sales_qty)` |
| 观察期当前销量 | 返场后近 7 天销量 | `sum(post_7d_sales_qty)` |
| 观察期销量差值 | 当前销量和基准销量差异 | `sum(post_7d_sales_qty) - sum(pre_7d_sales_qty)` |
| 观察期销量恢复率 | 观察期整体恢复比例 | `sum(post_7d_sales_qty) / sum(pre_7d_sales_qty)` |
| 干预期 MSKU 数 | 当前处于运营干预期的去重 MSKU | 最新一轮未退出且 `stage = '运营干预期'` |
| 干预期基准销量 | 干预期对比观察期 7 天销量 | `sum(observe_7d_sales_qty)` |
| 干预期当前销量 | 返场后近 7 天销量 | `sum(post_7d_sales_qty)` |
| 干预期销量差值 | 当前销量和观察期销量差异 | `sum(post_7d_sales_qty) - sum(observe_7d_sales_qty)` |
| 干预期销量恢复率 | 干预期相对观察期变化 | `sum(post_7d_sales_qty) / sum(observe_7d_sales_qty)` |

## 11. 优先处理队列

优先处理队列用于从当前看板口径中挑出最需要运营跟进的 MSKU 池，点击后会联动筛选明细表。

| 指标 | 说明 | 计算逻辑 / 判定 |
| --- | --- | --- |
| 截至目前严重恢复不足 | 累计平均恢复率仍低于50%，需要优先复盘动作和补量 | 持续追踪中且 `cumulative_avg_recovery_rate < 50%` |
| 恢复提升中 | 已提升至50%-70%，继续跟踪动作承接 | 持续追踪中且 `50% <= cumulative_avg_recovery_rate < 70%` |
| 恢复后回落 | 曾稳定恢复但最近3天未保持 | `recovery_fallback_flag = 1` |
| 高价值持续低恢复 | 明星 / 潜力产品仍低于50% | 高价值角色且命中“截至目前严重恢复不足” |

## 12. 右侧抽屉阶段明细

阶段明细用于观察“处于某阶段的 MSKU 池”在返场 Day 上的出单和销量情况。

### 观察期

```text
观察段 = 返场 Day 1 到 Day 7
```

### 干预期

```text
干预期 MSKU 同时展示：
观察段 = 返场 Day 1 到 Day 7
干预段 = 返场 Day 8 到 Day 21
```

干预段展示时重新标记为：

```text
返场 Day 8 = 干预 Day 1
返场 Day 21 = 干预 Day 14
```

| 指标 | 说明 | 计算逻辑 |
| --- | --- | --- |
| 处于该 Day MSKU | 当前阶段池中，返场天数等于该 Day 的 MSKU 数 | `return_days = return_day` |
| 当天出单 MSKU | 该返场 Day 当天销量大于 0 的 MSKU 数 | `sales_qty > 0` |
| 当天销量 | 该返场 Day 当天销量合计 | `sum(sales_qty)` |
| FBA 可售 | 该返场 Day 当前 MSKU 池的 FBA 可售合计 | `sum(fba_sellable)` |
| 累计销量 | 从返场 Day 1 到当前 Day 的销量累计 | `sum(sales_qty where return_day <= 当前Day)` |
| 仍未出单 | 当前阶段池中截至该 Day 仍未产生销量的 MSKU 数 | `池内 MSKU 数 - 累计出单 MSKU 数` |

## 13. 明细表字段

| 字段 | 说明 |
| --- | --- |
| MSKU / SKU | 展示 `seller_sku_adj` 和 `local_sku` |
| 店铺 | `seller_name_new` |

## 14. 容易误解的点

1. 触发断货 MSKU 和已返场 MSKU 不是同一个池。
   - 触发断货：最近 180 天出现过 `FBA可售 = 0` 且周期销量 > 0。
   - 已返场：触发断货后，后续恢复到 `FBA可售 > 5` 并生成返场事件。

2. 页面明细现在不是历史事件列表，而是最新一轮 MSKU 状态列表。
   - 同一 MSKU 多轮返场，只展示截至统计日最新一轮。

3. “断货未到货”不是返场池里的必然状态。
   - 它的业务含义是当前 `FBA可售 = 0` 且 `FBA在途 > 0`，用于提醒确认到货上架。

4. “恢复率为空”不是恢复率为 0。
   - 它表示断货前对比销量为 0 或缺失，无法计算恢复率。

5. D21未达标不再永久冻结为“未达标退出”。
   - 这些产品从D22进入持续追踪，累计平均恢复率后续达到70%时可自动转为“21天后恢复达标”。

6. “开始稳定恢复”不等于“已经退出”。
   - 它只说明连续3天单日表现达到50%；是否退出仍看累计平均恢复率是否达到70%。
