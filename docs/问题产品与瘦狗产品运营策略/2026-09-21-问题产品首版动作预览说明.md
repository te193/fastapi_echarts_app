# 问题产品首版动作预览说明

本轮按用户要求，仅生成问题产品的本地动作预览，不建表、不写表、不操作广告平台。所有最终建议均为人工审核状态，不代表已执行。瘦狗产品不参与计算；效果评估、历史复盘和第二轮调价不在本轮范围。

## 本轮重要口径

1. **调价**：使用2026-09-21定价，售价向上取整到分，复核低于原价且不低于P10。985条已满足这些检查。定价异常、价格线缺失、断货或可售待核不生成调价。294个产品因断货/库存待核暂不出价格；这是当前尚未明确的断货价格测试分支，不能解释为永久禁止断货调价。
2. **销量与库存**：补取 `dws_datasync.ops_product_site_metric_period` 的2026-09-20、30天指标，保留其实际库存时间。该来源是本次额外核实的经营指标表。没有把不同源日期伪装为同一天。
3. **广告归因**：对象及搜索词观察区间为2026-08-15至2026-09-13，快照2026-09-20。来源只跳过7天，搜索词30天归因成熟标志为0、7天为1。本轮明确采用“30天观察期＋同产品7天归因”的实现口径，不能宣称30天归因已经成熟；若后续固定采用30天归因，必须重新提取更早的成熟观察窗口并重算。否词额外检查已观测到的总30天订单仍为0，任何已观测订单都保护。
4. **开启广告**：另查 `ods_datasync` 下广告账号、商品广告、活动、广告组当前实体；按profile和实体ID保留最新记录，再判断删除及开启状态。604条均有可定位的停用结构，明细保留广告、活动、广告组ID和状态，执行前仍需人工核验。252个仅能确认当前查询没有商品广告记录，缺少账号同步完整性证明，放入候选而不直接判为未开启；另有映射缺失记录单独诊断。
5. **否词**：按广告组＋标准化词收口。任一来源有订单或保护条件不通过均不输出；本轮仅1条文字精准否定，保留profile、活动、广告组和词。ASIN否定需全店自有ASIN核对，暂不输出。
6. **动作上限**：同一执行对象去重，风险收缩优先；最多每产品1条价格、2条广告动作。固定action_type用于筛选，护栏和缺失原因不成为动作标签。

## 尚未进入最终动作的分支

| 分支 | 本轮处理 |
|---|---|
| 自动对象降bid | 源对象是广告组默认bid，不是独立自动target；尚未核实是否被独立bid覆盖，留候选。 |
| 手动关键词降bid | 已明确门槛可识别，但上下限字段全部为空，未硬编码平台金额限制；20条留候选，无建议金额。 |
| 手动零单100303—100305 | 缺60天SP搜索广告客单价，且问题产品分档仍有待明确项；109条对象诊断，不套用瘦狗规则。 |
| 自动100203 | 条件括号解释未确认；13条对象诊断，不擅自发布。 |
| 常规涨bid、新增精准 | 未核实扣除未来基础消耗后的预算，或TACOS等条件不满足；加精准还缺目标组、相关性及已有精准/否词冲突核验。 |
| 零花费曝光 | 预算、库存测试适用条件和一次性测试状态不全；不把零花费视为ACOS=0放量。 |
| 产品预算100702/100703 | 独立预算动作名额及预算池口径未明确，本轮不产生最终预算动作。 |

因此，本次已完成首批**可支持动作的预览**，不是全部规则都已具备上线条件。明细没有混入尚不能计算的执行金额。
