# 两组问题产品广告调整完整规则

## 1. 目的与执行边界

本规则用于给两组问题产品生成**待审核**的 SP 广告调整建议，包括广告开启提示、竞价、活动预算、加词和否词。规则只产生建议，不直接写入广告平台或数据库。

规则分成两层：

1. 思维导图定义“何时可以动”的命中条件、暂停优先级和竞价边界。
2. 产品、广告对象、广告活动的实际表现决定“具体调整多少”。因此，除预算规则表中已明确的预算幅度外，不使用思维导图中的固定竞价涨跌百分比。

## 2. 产品范围

产品名单固定取 `2026-09-13` 的 `dws_datasync.dws_产品策略命中结果表`，解析每条记录的 `evidence_json.metrics`，不以策略规则码、原广告建议或预算分配表决定是否纳入。

### 2.1 第一组：无销量且售价不高于 P15

同时满足：

```text
daily_sales_30d = 0
current_price <= p15_price
```

### 2.2 第二组：低日销、低毛利

同时满足：

```text
0 < daily_sales_30d < 1
margin_rate_30d < 5%
```

`daily_sales_30d = 1` 不属于第二组。两组产品必须互不重叠；`p15_price` 缺失时，不将无销量产品自动纳入第一组。

## 3. 数据口径与通用约束

### 3.1 广告对象与当前配置

- 国家、规范化店铺、MSKU 必须精确关联到 ODS SP 广告商品。
- 当前广告状态、当前竞价和当前活动日预算，均读取运行时 ODS 值，并在输出中记录读取时间。
- 竞价表现使用已完成 7 天归因的近 30 天窗口；同时读取此前 30 天作为趋势和稳定性参照。
- 预算表现使用已完成归因的近 7 天窗口。
- 思维导图中的欧元花费门槛，必须用同月、可追溯的汇率转换至活动币种；汇率缺失或不一致时，标记待复核。

### 3.2 竞价表现窗口：当前成熟 30 天为主

竞价判断不再以近 60 天汇总 ACOS 为主口径。当前成熟 30 天是所有竞价条件和调价幅度的主数据窗口；此前 30 天只用于判断趋势是否稳定。

当前成熟 30 天按每天的广告报表相加，但订单和销售额使用已经完成归因的 `7d` 字段：

```text
当前30天花费 = sum(每日 cost)
当前30天点击 = sum(每日 clicks)
当前30天广告订单 = sum(每日 orders_7d)
当前30天广告销售额 = sum(每日 sales_7d)
当前30天直接订单 = sum(每日 same_orders_7d)

当前30天ACOS = 当前30天花费 / 当前30天广告销售额
当前30天直接CVR = 当前30天直接订单 / 当前30天点击
```

不平均每日 ACOS，也不直接使用单日的 `orders_30d` 或 `sales_30d` 字段。以最新报表日期为 `2026-09-13` 为例，当前成熟 30 天为 `2026-08-08` 至 `2026-09-06`；`2026-09-07` 至 `2026-09-13` 尚未完成 7 天归因，不进入当前决策窗口。

前 30 天为 `2026-07-09` 至 `2026-08-07`，同样按日汇总 `cost`、`clicks`、`orders_7d`、`sales_7d` 和 `same_orders_7d`，仅用于趋势校验。所有指标均在每个**竞价对象**粒度计算，不在产品、店铺或活动层面混合计算。

### 3.3 竞价安全边界

- 降价时：单次最多下降 50%。
- 降价时：当前竞价小于或等于 `0.10`，不再下降；若计算价低于 `0.10`，建议价取 `0.10`。
- 提价时：单次最多上涨 20%。
- 提价时：建议竞价不得超过 `MaxBid`。
- `0.10` 仅是**降价下限**，不是提价下限；低于 `0.10` 的对象满足提价条件时可以上涨。
- 缺少当前竞价、MaxBid、汇率、对象安全归属或必要表现数据时，不填写可执行竞价新值。

### 3.4 MaxBid 定义

```text
当前30天广告客单价 = 当前30天归因销售额 / 当前30天归因订单数
当前30天直接CVR = 当前30天同款直接归因订单 / 当前30天点击

MaxBid = 当前30天广告客单价 × 当前30天直接CVR × 当前价位可用毛利率
```

MaxBid 是竞价的财务上限近似值，不等于实际 CPC。实际 CPC 还受竞价环境、广告位、相关性和竞争对手影响。当前 30 天客单价或直接 CVR 缺失时，不用前 30 天数据直接替代为 MaxBid；该对象保留为待复核。

对第二组低毛利产品尤其要注意：`20% ACOS` 只是广告投放效率判断线，不是利润平衡线。即使 ACOS 低于 20%，产品也可能仍然亏损；提价必须同时受 MaxBid 限制。

## 4. 广告状态分流

先完成广告状态分流，再决定是否进入后续规则。

| 状态 | 判定 | 后续动作 |
|---|---|---|
| 待开启广告 | 无精确 SP 商品对象，或商品、广告组、活动任一配置未启用 | 标记待开启广告，不生成竞价或预算执行值 |
| 待排查投放状态 | 配置均启用，但商品投放状态不是 `AD_STATUS_LIVE` | 标记待排查投放状态，不生成竞价或预算执行值 |
| 待核对 | 多账号匹配、仅 ASIN 疑似匹配、MSKU/站点/店铺不唯一 | 标记待核对，不误判为未开启 |
| 可投放 | 商品、广告组、活动已启用，且对象处于可投放状态 | 进入竞价、预算、加词否词试算 |

## 5. 竞价规则

### 5.1 决策优先级

同一竞价对象按以下顺序处理：

```text
暂停 > 维持 > 降价 > 提价 > 观察
```

若活动被预算规则判为“暂停活动”，该活动下对象不再给可执行竞价新值，原因标为“活动暂停建议优先”。

### 5.2 暂停条件

| 命中条件 | 建议 |
|---|---|
| 点击 >= 50，销售额 = 0，花费 >= 20 欧元等值 | 暂停竞价对象 |
| 曝光 = 0，花费 > 0 | 暂停竞价对象 |

### 5.3 维持条件

| 命中条件 | 建议 |
|---|---|
| 花费 = 0 | 维持 |
| 销售额 = 0，点击 < 10，且花费 < 5 欧元等值 | 维持 |
| 销售额 > 0，ACOS <= 20%，但未命中提价条件 | 维持 |
| 证据不足、映射不稳定或汇率缺失 | 待复核，不自动调整 |

### 5.4 超 MaxBid 降价

命中条件：

```text
当前竞价 > MaxBid × 1.2
且（销售额 = 0 或 ACOS > 20%）
```

调整公式：

```text
建议竞价 = max(0.10, 当前竞价 × 50%, MaxBid)
```

含义是向 MaxBid 修正，但单次不允许下降超过 50%。当 MaxBid 远低于当前竞价时，可能需要多个观察周期才会逐步回到 MaxBid。

### 5.5 高 ACOS 降价

命中条件：

```text
ACOS > 20% / 30% / 40% / 50%
```

这些档位只决定是否进入降价计算，不直接套用固定跌幅。实际降幅为：

```text
基础降幅 = 20% / 当前30天ACOS - 1
实际降幅 = max(-50%, 基础降幅)
建议竞价 = max(0.10, 当前竞价 × (1 + 实际降幅))
```

计算依据是：在点击率、转化率和竞价环境短期稳定的近似下，ACOS 大致会随 CPC、竞价同比变化。将当前 ACOS 从现状压向 20%，应按目标 ACOS 与当前 ACOS 的比例缩减竞价。

前 30 天趋势校验：

| 当前30天与前30天表现 | 最终处理 |
|---|---|
| 当前30天 ACOS >20%，且前30天有效 ACOS 也 >20% | 使用完整计算降幅 |
| 当前30天 ACOS >20%，但前30天有效 ACOS <=20% | 计算降幅减半后执行，仍受 -50% 和 0.10 约束 |
| 前30天没有有效销售额，无法形成 ACOS | 当前30天满足样本和条件时，按当前30天计算；输出“趋势数据不足” |

“减半”只用于当前表现与历史表现方向相反时，避免旧周期明显盈利、当前周期短暂波动时一次性大幅降价。

示例：

| 当前30天 ACOS | 计算降幅 | 受上限后的建议降幅 |
|---:|---:|---:|
| 21% | `20% / 21% - 1 = -4.8%` | -4.8% |
| 25% | `20% / 25% - 1 = -20.0%` | -20.0% |
| 30% | `20% / 30% - 1 = -33.3%` | -33.3% |
| 40% | `20% / 40% - 1 = -50.0%` | -50.0% |
| 50% | `20% / 50% - 1 = -60.0%` | -50.0% |

### 5.6 零销售降价

执行顺序：若对象满足“点击 `>=50`、销售额=`0`、花费`>=20` 欧元等值”的暂停条件，优先给出暂停建议，不再同时下发竞价降价。其余零销售对象再按本节计算。

命中条件：

```text
销售额 = 0，且满足任一：
- 点击 >= 40
- 点击 >= 25
- 点击 >= 15
- 花费 >= 15 欧元等值
```

零销售时 ACOS 没有有效分母，不能直接按 ACOS 降价。因此先估算该对象可承受 CPC：

```text
当前CPC = 当前成熟30天花费 / 当前成熟30天点击

可承受CPC = 20% × 估计客单价 × 估计直接CVR
```

```text
基础降幅 = 可承受CPC / 当前CPC - 1
公式降幅 = max(-50%, min(0, 基础降幅))
实际降幅 = max(证据强度允许的最低降幅, 公式降幅)
建议竞价 = max(0.10, 当前竞价 × (1 + 实际降幅))
```

若 `可承受CPC >= 当前CPC`，公式降幅为 `0`，即不因“零销售”自动提价或降价，改为维持并复核相关性、Listing 和投放设置。

点击门槛不再对应固定降幅，而是作为低样本情况下的**单次降价安全阀**：

| 当前成熟30天证据 | 允许的最大单次降幅 | 说明 |
|---|---:|---|
| 点击 `15–24`，或仅因花费 `>=15` 欧元等值进入 | -15% | 证据较弱，防止同行估计造成过度调整 |
| 点击 `25–39` | -30% | 中等证据强度 |
| 点击 `>=40` | -50% | 可按公式完整计算，但仍受全局单次降价上限约束 |

例如公式降幅为 `-37.5%`：点击 `20` 次时实际降幅取 `-15%`；点击 `30` 次时取 `-30%`；点击 `45` 次时取 `-37.5%`。因此点击档位约束的是风险暴露，而不是替代数据计算的固定调价建议。

估计直接 CVR 的证据优先级：

1. 对象自身前 30 天直接订单和点击；累计点击 `>=20` 且直接订单 `>0` 时使用。
2. 同国家、同店铺、同 MSKU 的其他已转化广告对象；累计点击 `>=20` 且直接订单 `>0` 时使用。
3. 同国家、同店铺、同 ASIN 的其他已转化广告对象；累计点击 `>=20` 且直接订单 `>0` 时使用。
4. 同国家、同店铺、同品牌、同叶类目、售价在目标产品 `70%–130%`、且同匹配组的已转化对象；有效对象数 `>=5` 且累计点击 `>=100` 时使用。
5. 同国家、同品牌、同叶类目、售价在目标产品 `70%–130%`、且同匹配组的已转化对象；有效对象数 `>=5` 且累计点击 `>=100` 时使用。

第 4、5 层的匹配组仅分为 `Exact / Phrase` 与 `Broad / close-match / complements`；不把“同国家+币种+匹配方式”的宽泛对象池用于自动竞价。该口径仅可作为人工排查参考。

借样计算：

```text
同行直接CVR = 同行样本直接订单合计 / 同行样本点击合计

估计直接CVR =
  (对象前30天直接订单 + 同行直接CVR × 同行稳定权重点击)
  / (对象前30天点击 + 同行稳定权重点击)
```

其中“同行稳定权重点击”取同行累计点击与 `100` 的较小值；它只用于让有历史直接数据的对象与同行证据平滑合并，并不把同行样本冒充为该对象自身订单。第 2、3 层的产品级证据可直接使用；第 4、5 层借样池少于 5 个有效转化对象，或累计点击少于 100 时，不输出数值建议。输出中必须记录借样层级、样本数和累计点击。

估计客单价的证据优先级：

1. 该产品当前有效 Listing 售价。
2. 与估计直接 CVR 使用同一严格同行层级的当前 30 天广告客单价中位数。
3. 以上均缺失时不估算，不输出数值建议。

零销售对象本期没有广告销售额，不能从自身当前 30 天广告数据计算客单价；因此必须明确标注售价或同行客单价来源。

### 5.7 提价条件

仅当销售额 > 0 且 ACOS <= 20% 时，继续检查下列匹配类型条件。

| 匹配组 | 命中条件 |
|---|---|
| Exact / Phrase | ACOS <= 10%，直接CVR >= 18%，点击 >= 50 |
| Exact / Phrase | ACOS <= 15%，直接CVR >= 15%，点击 >= 35 |
| Exact / Phrase | ACOS <= 20%，直接CVR >= 12%，点击 >= 20 |
| Exact / Phrase | 销售额 > 0，ACOS <= 20%，直接CVR >= 12%，点击 >= 2 |
| Broad / Close Match / Complements | ACOS <= 10%，直接CVR >= 18%，点击 >= 50 |
| Broad / Close Match / Complements | ACOS <= 15%，直接CVR >= 15%，点击 >= 35 |
| Broad / Close Match / Complements | 销售额 > 0，ACOS <= 20%，直接CVR >= 12%，点击 >= 3 |
| Loose / Substitutes / 未知 | ACOS <= 15%，直接CVR >= 15%，点击 >= 30 |
| Loose / Substitutes / 未知 | ACOS <= 20%，直接CVR >= 12%，点击 >= 15 |

提价计算：

```text
基础涨幅 = (20% - 当前30天ACOS) / 20%
实际涨幅 = min(20%, 基础涨幅)
建议竞价 = min(当前竞价 × (1 + 实际涨幅), MaxBid)
```

该公式不直接一次将 ACOS 推到 20%，而是用当前 ACOS 盈利空间的一部分作为小步试验幅度，并由 `+20%` 和 MaxBid 双重约束风险。

前 30 天趋势校验：

| 当前30天与前30天表现 | 最终处理 |
|---|---|
| 当前30天 ACOS <=20%，且前30天有效 ACOS 也 <=20% | 使用完整计算涨幅 |
| 当前30天 ACOS <=20%，但前30天有效 ACOS >20% | 计算涨幅减半后执行，仍受 +20% 和 MaxBid 约束 |
| 前30天没有有效销售额，无法形成 ACOS | 当前30天满足提价条件时，按当前30天计算；输出“趋势数据不足” |

例如：当前 30 天 ACOS 为 18%，基础涨幅为 10%；当前竞价为 0.50，则初始建议价为 0.55。如果 MaxBid 为 0.53，则最终建议价为 0.53。

当当前 30 天 ACOS 正好为 20% 时，即使满足导图的“ACOS <= 20%”门槛，也没有可计算的盈利空间，因此维持而不提价。

## 6. 加词与否词规则

搜索词按“Profile、广告组、标准化搜索词”去重，并先核对已有正向投放、已有否词和保护词。

### 6.1 加词

| 命中条件 | 建议 |
|---|---|
| 搜索词有订单，ACOS <= 15%，且没有相同正向投放 | 候选加词 |
| 搜索词有订单，15% < ACOS <= 20%，且没有相同正向投放 | 加词待复核 |
| ACOS > 20%，无订单，或证据不足 | 不加词 |
| 已存在相同关键词/商品投放 | 已有投放，不重复加词 |
| 搜索词 MSKU 归属不唯一 | 待核对归属 |

### 6.2 否词

| 命中条件 | 建议 |
|---|---|
| 点击 >= 100，广告总订单 = 0，未保护，且没有已有否词 | 候选否词 |
| 已有否词 | 已有否词，不重复处理 |
| 品牌词、核心类目词、新品词、保护资料不完整 | 否词待复核 |
| 其他情况 | 不否词 |

同一搜索词出现“候选加词”和“候选否词”时，统一改为“方向冲突待复核”，不得自动执行任一方向。

## 7. 活动预算规则

预算建议只以 ODS 中的**活动当前日预算**为基数，不引用旧的产品预算分配表。同一活动只生成一条预算建议。

### 7.1 预算准入条件

以下任一条件不满足，只保留分析和复核原因，不给可执行预算新值：

```text
1. 活动连续启用满 10 天，且当前为启用状态。
2. 成熟 7 天点击 >= 10。
3. 近 3 天没有预算、状态或相关广告对象改动。
4. 成熟 7 天广告报表完整。
5. 可以依据活动变更日志逆推出历史 7 天预算。
6. 活动不包含范围外产品；包含时，预算新值留空待复核。
```

```text
预算饱和度 = 成熟7天实际花费 / 成熟7天历史预算之和
ACOS偏差 = 成熟7天实际ACOS - 生命周期目标ACOS
```

### 7.2 生命周期与目标 ACOS

| 生命周期 | 启用天数 | 目标 ACOS |
|---|---:|---:|
| 新品期 | <=14 天 | 28% |
| 成长期 | 15–30 天 | 23% |
| 成熟期 | >30 天 | 20% |

### 7.3 零订单活动

| 条件 | 预算建议 |
|---|---|
| 成熟期，成熟 7 天订单 = 0 | 暂停活动 |
| 新品期或成长期，启用 <=20 天 | 维持 |
| 新品期或成长期，成熟 7 天花费 <=100 元等值 | 维持 |
| 新品期或成长期，成熟 7 天点击 <50 | 维持 |
| 新品期或成长期，订单 = 0 且不满足以上任一保护条件 | 暂停活动 |

100 元门槛必须按该活动币种的同月、可验证汇率转换。缺汇率时，非成熟期零订单活动不自动给暂停或维持的新预算值。

### 7.4 降预算

以下条件按优先级从高到低命中；同一活动只取一个基础调整幅度：

| 命中条件 | 基础预算调整 |
|---|---:|
| ACOS 偏差 >12 个百分点 | -45% |
| ACOS 偏差 >10 个百分点 | -35% |
| ACOS 偏差 >7 个百分点 | -25% |
| ACOS 偏差 >5 个百分点 | -15% |
| ACOS 偏差 >3 个百分点 | -8% |
| 未命中上述条件，且 CVR <5% | -12% |
| 未命中上述条件，且 CTR <0.2% | -10% |

```text
建议日预算 = max(1, 当前日预算 × (1 + 最终调整幅度))
```

`1` 为活动原币种最低日预算，不是人民币。

### 7.5 加预算

以下条件按从高到低的档位判断：

| ACOS 相对目标 | 附加条件 | 基础预算调整 |
|---:|---|---:|
| 低于目标 >=8 个百分点 | 订单 >=10，预算饱和度 >=95% | +35% |
| 低于目标 >=6 个百分点 | 订单 >=10，预算饱和度 >=90% | +28% |
| 低于目标 >=4 个百分点 | 订单 >=10，预算饱和度 >=85% | +22% |
| 低于目标 >=3 个百分点 | 预算饱和度 >=90% | +18% |
| 低于目标 >=2 个百分点 | 预算饱和度 >=85% | +15% |
| 低于目标 >=1 个百分点 | 预算饱和度 >=80% | +12% |
| ACOS 偏差在 ±1 个百分点 | 预算饱和度 >=75% | +10% |
| ACOS 偏差在 ±2 个百分点 | 预算饱和度 >=70%，且 ACOS 改善 | +8% |
| ACOS 偏差在 ±3 个百分点 | 预算饱和度 >=65% | +5% |

### 7.6 CVR 修正

CVR 修正是在基础预算调整之后叠加。高 CVR 应增强加预算或收窄降预算；低 CVR 应收窄加预算或扩大降预算。

| 成熟 7 天 CVR | 基础加预算的修正 | 基础降预算的修正 |
|---:|---:|---:|
| >=11% | 增加 5 个百分点 | 降幅收窄 5 个百分点 |
| 8%–11% | 增加 3 个百分点 | 降幅收窄 3 个百分点 |
| 5%–8% | 不修正 | 不修正 |
| <5% | 减少 3 个百分点 | 扩大降幅 3 个百分点 |

示例：基础调整为 `-25%`，但 CVR >=11%，最终调整为 `-20%`；基础调整为 `+35%`，但 CVR <5%，最终调整为 `+32%`。

### 7.7 竞价联动

同一活动中存在竞价提价对象时，只增加“竞价提价联动待复核”提示。不得因该提示在预算规则的计算结果上额外叠加涨幅。

## 8. 审核、观察与复盘

### 8.1 不自动执行的情形

以下情形必须留空或标记待复核：

- 广告对象映射不唯一。
- 汇率缺失或同币种汇率不一致。
- 当前竞价、当前活动日预算、MaxBid、客单价或直接 CVR 缺失。
- 零销售对象未满足任一直接 CVR 证据层级：自身/同 MSKU/同 ASIN 层需累计点击 `>=20` 且直接订单 `>0`；产品特征同行层需有效对象 `>=5` 且累计点击 `>=100`。
- 活动包含范围外产品。
- 历史预算无法由日志可靠还原。
- 成熟归因窗口报表缺日。
- 加词与否词方向冲突。

### 8.2 调整后的观察原则

- 竞价调整后，至少等待一个完整归因观察周期，再判断是否继续调整。
- 预算调整后，观察完整成熟 7 天表现，避免在近 3 天内重复改动。
- 暂停建议优先于同一对象的提价、降价、加词或预算放大建议。
- 所有建议保留当前值、建议值、调整幅度、命中条件、表现窗口、证据来源和复核原因。

## 9. 规则解释边界

本规则中的竞价幅度是基于 ACOS、CPC、客单价、直接 CVR、毛利率和同行样本得出的**风险受限试算值**，不是广告平台的因果预测。

尤其需要避免以下错误理解：

- 低 ACOS 不等于产品一定盈利。
- 提高竞价不一定按相同比例提高 CPC、点击或销售。
- 降低竞价不一定按相同比例降低 ACOS。
- 同行借样只用于低样本补充，不可当作该对象自身的历史表现。

因此，所有数值建议都应作为下一轮可控试验的起点，并在完整归因数据回收后复核。
