# 标签看板返场规则对齐部署说明

## 交付文件

执行文件：

```text
sqlcode/标签表数据插入_返场规则对齐正式版_20260728.sql
```

该文件写入正式库 `dws_datasync`，并继续使用远端现有过程名：

```sql
dws_datasync.sp_dws_标签表_一体化_v45
```

## 本次仅修改的范围

- 运营状态中的“返厂品”。
- “返厂品阶段下钻”的观察期、运营干预期、持续干预期和达标退出。
- 返场事件识别、21天恢复率及D22以后的持续追踪。
- 运营状态优先级调整为“返厂品 > 断货中 > 停售 > 测款扶持 > 正常在售”。已进入返场流程的MSKU再次出现FBA可售为0时，仍保留返厂品状态。

生命周期、销售角色、库存水平及其他标签逻辑保持原样。

## 核心口径

统计粒度：

```text
店铺 + 国家类别 + MSKU
```

识别范围为统计日前最近180天。产品表现源数据从2026年1月1日起读取，用于补齐窗口边界前的断货过程和断货前销量基准。

同一国家类别下多个国家共享FBA库存，每天库存取最大值，不跨国家累加。

返场事件：

```text
先出现 FBA可售库存 = 0
后续首次出现 FBA可售库存 > 5
```

页面和标签主口径只保留每个MSKU最新一轮完整事件。

阶段：

```text
D1-D7：观察期
D8-D21：运营干预期
D22以后且未达标：持续干预期
```

恢复率：

```text
D1-D21恢复率
= 返场后对应天数累计销量 / 断货前对应天数累计销量

D21恢复率
= 返场后D1-D21总销量 / 断货前21天总销量
```

退出规则：

```text
D21恢复率 >= 70%：D22达标退出
D21恢复率 < 70%：D22起持续跟踪
D22以后累计平均恢复率首次 >= 70%：当天达标退出
断货前21天销量 = 0：数据不足，继续跟踪
```

## 部署方式

1. 在远端MySQL完整执行交付SQL文件。
2. 手工重算需要核对的业务日期：

```sql
CALL dws_datasync.sp_dws_标签表_一体化_v45('2026-07-27');
```

3. 日常执行使用产品表现表最新业务日期：

```sql
CALL dws_datasync.sp_dws_标签表_一体化_v45(NULL);
```

SQL文件会同步更新每日事件 `dws_datasync.evt_标签表`，使其继续调用该过程。

两边总量及MSKU明细已经完全对应。以下2个MSKU曾因本地与远端产品表现源表的历史FBA可售库存不同产生差异，现已从远端DWD定向回填本地产品表现表并重算返场快照：

MYT1009a

## 两个历史差异MSKU的修复记录

返场判断按同一国家类别下各国家当日FBA可售库存的最大值计算：

```text
国家类别当日FBA可售 = MAX(各国家FBA可售)
```

因此，只要任意国家仍记录为1，当天就不会被判断为库存等于0。

### MYT1009a

统计组合：

```text
店铺：MyiTong
国家类别：欧洲站
MSKU：MYT1009a
```

修复前关键日期对比：

| 日期 | 本地同步表 | 远端DWD表 | 判断结果 |
|---|---:|---:|---|
| 2026-05-05 | 最大库存4 | 最大库存3 | 均为1-5 |
| 2026-05-06 | 最大库存1 | 最大库存1 | 均未断货 |
| 2026-05-07 | 意大利为1，其他国家为0，最大库存1 | 所有国家均为0，最大库存0 | 仅远端判定断货 |
| 2026-05-08至2026-05-27 | 最大库存持续为1-5 | 所有国家库存持续为0 | 本地始终没有形成断货段 |
| 2026-05-29 | 最大库存29 | 最大库存28 | 均恢复到大于5 |

所以远端形成：

```text
2026-05-07断货 -> 2026-05-29返场
```

修复前本地在关键期间始终至少保留1件库存，没有出现国家类别最大库存等于0，因此没有形成该返场事件。

### PC035a

统计组合：

```text
店铺：PENGCHENGA
国家类别：欧洲站
MSKU：PC035a
```

修复前关键日期对比：

| 日期 | 本地同步表 | 远端DWD表 | 判断结果 |
|---|---:|---:|---|
| 2026-04-21至2026-04-22 | 德国、法国为1，最大库存1 | 德国为1，最大库存1 | 均未断货 |
| 2026-04-23 | 德国、法国仍为1，最大库存1 | 所有国家均为0，最大库存0 | 仅远端判定断货 |
| 2026-04-24至2026-05-20 | 最大库存持续为1 | 所有国家库存持续为0 | 本地始终没有形成断货段 |
| 2026-05-21 | 最大库存14 | 最大库存13 | 均恢复到大于5 |

所以远端形成：

```text
2026-04-23断货 -> 2026-05-21返场
```

修复前本地在这段时间始终保留1件库存，因此没有形成该返场事件。本地虽然从2026-06-29以后出现过库存等于0，但截至2026-07-27未再次恢复到大于5，尚不构成新的完整返场事件。

### 原差异结论与处理结果

这2个MSKU的差异不是：

- 国家共享库存被错误相加。
- 180天窗口不同。
- 恢复率或退出规则不同。

实际原因是本地同步表与远端DWD表在关键日期的国家库存值不一致：

```text
远端最大库存 = 0
本地最大库存 = 1
```

处理方式是按现有产品表现ETL转换规则，从远端DWD定向重载这2个MSKU在2026-01-01至2026-07-27的历史数据，并幂等重算2026-07-27返场结果。

处理后核对结果：

| MSKU | 断货日 | 断货日最大库存 | 返场日 | 返场日最大库存 |
|---|---|---:|---|---:|
| MYT1009a | 2026-05-07 | 0 | 2026-05-29 | 28 |
| PC035a | 2026-04-23 | 0 | 2026-05-21 | 13 |

返场页面最新状态总数由564更新为566，与远端标签规则测试结果一致。
