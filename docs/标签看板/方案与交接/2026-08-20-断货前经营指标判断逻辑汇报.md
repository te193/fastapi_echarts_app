# 断货前经营指标判断逻辑汇报

## Executive Summary（汇报摘要）

- **这套规则用于回答产品断货前经营得好不好、是否稳定，以及临近断货时有没有明显变化。**它建立的是断货前经营基线，不判断补货优先级，也不判断返场后是否恢复。
- **判断以每条记录自己的断货日为锚点。**历史数据固定从2026-01-01读取到断货日前一天，避免断货后的零销量污染经营结论，也不限制最大回看天数。
- **有货状态只看FBA可售库存。**FBA可售库存大于0才是有效经营日，等于0直接认定断货；有效经营日用于评价门槛，但角色日销统一按周期总销量除以固定周期天数。
- **历史多次断货按事件识别。**库存等于0触发断货，之后只有库存恢复到大于5才算结束，避免库存短暂回升到1～5时把一次断货拆成多次。
- **当前是否断货与断货开始日分开判断。**当前库存等于0决定产品现在是否断货；最近一次库存大于5之后的首次库存0，决定本次断货从哪天开始以及断货前评价截止日。
- **最终不输出一个难解释的综合分。**每条记录分别给出历史经营水平、经营稳定性、历史角色形态和断货前角色变化，便于说明产品到底是“卖得差”，还是“卖得好但不稳定”。

## 一、整体判断顺序

```text
当前断货记录
→ 现有是否可评价判断
→ 历史数据是否足够
→ 确认本次断货开始日并切分历史断货事件
→ 计算低库存、销量集中和数据冲突等保护项
→ 重新计算销售角色
→ 判断历史经营好坏
→ 判断经营稳定性
→ 判断历史角色形态和断货前变化
```

这套顺序先解决“数据能不能用”，再回答“经营表现怎么样”，避免把数据不足或断货造成的零销量误判成经营差。

## 二、先确定哪些历史数据可以评价

每条记录独立使用：

```text
历史开始日：2026-01-01
历史结束日：本次断货日前一天
```

进入历史经营评价需要满足：

- 历史跨度至少90天；
- 日级数据覆盖率至少80%；
- FBA可售库存大于0的有效经营日至少30天；
- 有效经营周至少8周，每周至少3个有效经营日。

根据证据情况分成：

- **历史经营可评价**：可以继续判断经营水平、稳定性和角色变化；
- **仅断货历史可评价**：可以看断货情况，但正常经营样本不足；
- **历史依据不足**：不输出经营好坏，避免把数据不足解释成经营差。

## 三、多次断货怎么处理

历史中可能存在多次断货，因此先按FBA可售库存切分事件：

```text
库存=0   → 断货事件开始
库存1～5 → 当天可以经营，但同一次断货仍未正式恢复
库存>5   → 断货事件结束
```

库存恢复到大于5后，如果再次变成0，才算新的一次断货。最后一个尚未恢复并延续到当前的事件是当前断货，之前已经恢复的都是历史断货。

其中两个日期要分开：

```text
当前是否断货 = 当前FBA可售库存是否等于0
本次断货开始日 = 最近一次FBA可售库存>5之后，首次FBA可售库存=0的日期
```

例如`12 → 0 → 3 → 2 → 0`仍是同一次断货，开始日是第一个0；`12 → 0 → 7 → 0`中库存7已经完成恢复，当前断货开始日是第二个0。历史回溯只影响断货开始日、断货天数和T0，不改变当前库存为0的产品仍属于“断货中”。

若2026-01-01以来没有找到本次断货前的库存大于5，或者事件中存在日期缺口，只能标记“事件边界不完整”和“至少已断货N天”，不能输出精确开始日或持续天数。库存首次大于5后次日立即归零时，仍按当前主规则切成两次事件，但额外标记“短暂恢复”，供回测判断是否需要连续多日恢复规则。

历史经营的有效性仍由库存大于0的有效经营日约束；角色日销和周期毛利率使用周期内全部经营记录，但角色变化不能跨断货事件直接相连，避免把断货前后的角色差异误判为自然升级或退化。

最终同时保留历史断货次数、累计持续天数、最长持续天数和FBA零库存天数。

## 四、销售角色怎么判断

销售角色主要使用两个经营指标：

```text
角色日销 = 周期总销量 / 固定周期天数
周期毛利率 = 周期毛利润 / 周期销售额
```

7/14/30/90天窗口分别固定除以7/14/30/90；滚动30天节点固定除以30。FBA可售库存大于0的天数继续用于5/10/21/63天证据门槛。库存为0但有销量时，销量仍进入周期总销量，同时保留库存销量冲突标志。

### MSKU汇总维度

MSKU汇总不使用排名，参考2001～2004标准，根据日销和毛利率分为：

| 角色 | 主要含义 |
| --- | --- |
| 明星产品 | 日销较高且毛利表现达到较高标准 |
| 潜力产品 | 有一定销量，但毛利或销量尚未达到明星标准 |
| 瘦狗产品 | 有销量和正毛利，但销售能力偏弱 |
| 问题产品 | 有货零销量、低毛利或亏损 |

### 国家维度

国家维度在日销和毛利率基础上增加小类排名，并参考2101～2104标准：

- **2101国家明星**：达到明星日销和毛利标准，且小类排名1～50；
- **2102国家潜力**：达到潜力标准且排名1～100，或者达到明星经营标准但排名51～100；
- **2103国家瘦狗**：有销量、毛利率不低于5%、排名有效，但未达到明星或潜力；
- **2104国家问题**：无销量、毛利率低于5%，或者排名为空、无效。

历史排名取角色窗口内最后一个有效经营日的排名，不能用当前排名回填过去。

## 五、为什么同时看四个周期和历史轨迹

断货日前分别计算7天、14天、30天和90天角色，用于查看临近断货时不同周期的经营表现。

同时，从2026-01-01开始使用滚动30天窗口、每7天计算一次角色，形成历史角色轨迹，例如：

```text
瘦狗 → 潜力 → 潜力 → 明星 → 问题
```

四个固定周期适合看断货前状态，滚动角色轨迹适合看长期变化。两者结合，既不会只看最后几天，也不会因为每天计算造成过多噪声。

## 六、历史经营好坏怎么判断

历史经营水平主要看：

- 历史角色中明星、潜力和问题产品各自占比；
- 从2026-01-01到断货日前的整体毛利率；
- 是否长期处于有货但没有销量的状态。

最终分为：

| 结论 | 判断重点 |
| --- | --- |
| 历史优秀 | 大部分时间为明星或潜力，明星占比较高，整体毛利率不低于15% |
| 历史良好 | 大部分时间为明星或潜力，问题角色较少，整体毛利率不低于5% |
| 历史一般 | 有正常销售和评价依据，但整体未达到良好标准 |
| 历史较差 | 长期低毛利，或者问题角色占比较高 |
| 历史亏损 | 历史整体毛利率低于0% |
| 历史有货无销量 | 大部分有效窗口有货但没有形成销量 |

这样可以区分“销量低但赚钱”“销量高但亏损”和“长期有货卖不动”等不同情况。

## 七、经营稳定性怎么判断

稳定性不等于经营好。产品可能长期稳定低销，也可能历史经营优秀但销量高度波动。

因此稳定性分别检查：

1. **角色稳定性**：主导角色是否长期保持、角色切换是否频繁；
2. **销量稳定性**：周日销（完整周总销量÷7）是否大幅波动，是否依赖少数爆量周；
3. **毛利稳定性**：周毛利率是否频繁变化，亏损周是否过多。

销量稳定性还会保留单日集中证据：实际销售日不超过2天时标记“销量集中在极少数日期”；最高单日占周期销量50%以上标记“单日销量集中”，达到80%标记“极端单日销量集中”。这些标记不直接修改销售角色，但极端集中时销量稳定性不能判为稳定。

最终分为：

- 高度稳定；
- 基本稳定；
- 波动经营；
- 高度波动；
- 稳定性不可判。

分项结果会同时保留，因此可以直接解释波动来自角色、销量还是毛利。

### 已确认的数据保护项

- 库存1～5仍属于有效经营日；若其占全部有效经营日达到30%，标记“历史经营数据受低库存约束”，但不直接修改销售角色；
- 库存等于0但当天销量大于0时，仍按断货日处理，同时保留冲突天数和被排除销量，方便对账；
- 日级数据缺口不补成库存0，也不跨缺口推断恢复、再次断货或角色变化；
- MSKU汇总库存大于0不代表所有国家都有库存，因此保留部分国家断货占比，国家维度继续独立评价；
- 国家排名为空、等于0、小于0或大于等于99999均视为排名无效，按2104问题产品处理，并单独保留“因排名无效命中”的原因。

## 八、销售角色变化怎么判断

角色变化分成两部分。

### 历史角色形态

根据从2026-01-01开始的滚动角色轨迹，判断：

- 历史角色保持；
- 历史逐步升级；
- 历史逐步退化；
- 历史反复切换；
- 历史角色混合。

### 临近断货变化

为避免7天、14天、30天、90天累计窗口互相重叠造成误判，将断货前拆成：

```text
断货日前1～7天
断货日前8～14天
断货日前15～30天
断货日前31～90天
```

根据四段角色的先后变化，判断断货前是保持、启动、停滞、升级、持续升级、退化还是持续退化。

## 九、最终输出示例

```text
历史数据：历史经营可评价
历史断货：3次，累计42天，最长18天
历史经营：历史良好
经营稳定性：波动经营
历史角色形态：历史逐步升级
断货前变化：断货日前30天持续升级
断货日前30天角色：潜力产品
```

国家维度还会补充国家、小类排名、排名日期和2101～2104国家角色。

## 十、为什么采用这套设计

- **断货日锚定**：保证评价的都是断货前数据；
- **状态和事件起点分离**：当前库存0决定是否断货，历史事件规则决定从哪天开始断货；
- **只看FBA可售库存**：明确区分正常经营日和断货日；
- **库存大于5才认定恢复**：避免低库存短暂回升把一次断货错误切成多次；
- **使用固定周期日销**：与既有销售角色保持一致，7/14/30/90天分别使用固定自然日分母；
- **滚动30天、每7天计算**：兼顾历史连续性和信号稳定性；
- **经营水平与稳定性分开**：避免“卖得好但波动大”被一个综合分掩盖；
- **国家维度增加排名**：只有国家记录具备可解释的小类相对位置，MSKU汇总不强行使用排名。

## 十一、下一步建议

在正式实现前，使用历史可评价样本进行一次规则回测，重点查看：

- 各经营标签的数量和占比是否合理；
- 是否大量记录集中在同一个角色或稳定性档位；
- 低销量产品是否被波动指标系统性放大；
- 销量集中、低库存经营和短暂恢复标记的样本占比是否合理；
- 当前断货开始日按统一事件口径回溯后是否符合典型商品历史；
- 国家维度历史排名覆盖是否充分；
- 典型商品的判断结果是否符合业务认知。
