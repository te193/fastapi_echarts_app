# 断货前经营表现标签规则

## 目的

该标签只分析标签表中当前命中“断货中”的产品，回答两个问题：

1. 这条记录是否适合评价断货前经营表现；
2. 如果适合，断货前属于哪一种经营表现。

它不会改动“断货中”标签，也不会重新计算原“断货前销售角色”。销售角色直接采用远端标签表中已经按断货日前一天固定好的 7、14、30、90 天结果。

## 基础口径

“断货中”沿用原规则：

```text
FBA 可售 = 0
且
FBA 在途 + local_quantity > 0
```

当前证据中的 `local_quantity` 已包含本地可用、采购在途、采购计划和本地质检，因此不得再重复叠加采购数量。

```text
剩余库存合计 = FBA 在途 + local_quantity
```

页面支持 7、14、30、90 天。每条断货记录在每个周期只归入一个标签，八类合计必须等于当前断货总数。

## 标签划分与判断顺序

| 顺序 | 分组 | 标签 | 判断条件 |
| --- | --- | --- | --- |
| 1 | 暂不评价经营表现 | 低量库存边缘断货 | FBA 可售 = 0，且剩余库存合计 `< 5` |
| 2 | 暂不评价经营表现 | 断货前依据不足 | 未命中上一项，并且库存证据缺失或冲突、所选周期角色缺失、角色证据不完整、历史覆盖不足、计算状态异常或角色与指标冲突 |
| 3 | 可评价经营表现 | 完整周期零销量 | 断货前证据完整，所选完整周期销量 = 0 |
| 4 | 可评价经营表现 | 明星产品 | 周期销量 > 0，远端断货前销售角色 = 2001 |
| 5 | 可评价经营表现 | 潜力产品 | 周期销量 > 0，远端断货前销售角色 = 2002 |
| 6 | 可评价经营表现 | 瘦狗产品 | 周期销量 > 0，远端断货前销售角色 = 2003 |
| 7 | 可评价经营表现 | 亏损问题 | 周期销量 > 0，远端断货前销售角色 = 2004，毛利率 < 0 |
| 8 | 可评价经营表现 | 低毛利问题 | 周期销量 > 0，远端断货前销售角色 = 2004，毛利率为 0%–5% |

边界必须严格按以下方式处理：

```text
剩余库存合计 < 5  → 低量库存边缘断货
剩余库存合计 = 5  → 继续判断断货前依据和经营表现
```

## 断货前依据完整的标准

远端角色事实存在，并且至少满足：

- 证据类型为 `pre_oos_sales_role`；
- `window.period` 与所选周期一致，`window.days` 等于 7、14、30 或 90；
- 周期起止日期存在，且结束日不晚于断货日前一天；
- 周期销量和日销存在，数值不为负；
- 历史回溯模式的 `calculation.status = matched`，且历史起始日不晚于周期开始日；
- 复制断货前一天角色的模式存在有效来源角色，可直接采用固定结果；
- 问题产品存在毛利率，且毛利率落在问题产品应有的 `< 0` 或 `0%–5%` 范围。

不满足时统一归入“断货前依据不足”，同时在接口中保留具体原因数量，不另外增加第九个页面标签。

## 统计口径

页面分组：

```text
暂不评价经营表现 = 低量库存边缘断货 + 断货前依据不足
可评价经营表现 = 完整周期零销量 + 明星产品 + 潜力产品 + 瘦狗产品 + 亏损问题 + 低毛利问题
```

“完整周期零销量”是一种明确经营结论，因此属于可评价，不得混入“断货前依据不足”。

页面顶部的“暂不评价”和“可评价”比例均以全部当前断货记录为分母。后端仍按上表八类互斥计算，但页面一级只展示七张卡：将“亏损问题”和“低毛利问题”合并为“问题产品”。一级“问题产品”数量等于两类之和，其比例表示其占全部可评价记录的比例。

“断货前依据不足”在页面上只继续展示“历史数据不足”这一项，用于说明断货前历史覆盖不足的记录数量；其比例以“断货前依据不足”记录为分母，不额外增加页面标签，也不重复计入当前断货总数。其他证据异常原因仍保留在接口诊断明细中，但不在看板展开。

“历史数据不足”默认收起，仅在用户点击“断货前依据不足”卡片中的“明细”后展示；切换统计周期后重新收起。

“问题产品”的“亏损问题”和“低毛利问题”明细也默认收起。点击“问题产品”旁的“明细”后展开这两项；两项比例均以“问题产品”总数为分母，切换统计周期后重新收起。

七个一级标签卡均可点击。点击后按照当前 7、14、30 或 90 天周期筛选下方“经营明细”；点击一级“问题产品”时联合筛选“亏损问题”和“低毛利问题”。“明细”按钮只负责展开或收起子项，不会触发筛选；展开后点击“历史数据不足”“亏损问题”或“低毛利问题”本身，才会筛选对应记录。若下方明细已选中某个断货经营状态，切换周期时应同步按新周期刷新明细。

## 实施约束

- 原“断货中”定义和原“断货前销售角色”面板保持不变。
- 新面板标题为“断货前经营表现（当前断货中）”。
- “断货前销售角色”和“断货前经营表现”仅在当前分析标签为“运营状态”时展示；切换到任意其他一级标签后立即关闭并隐藏。
- 页面问号说明、接口状态名称和后端判断逻辑均以本文档为准。
- 任何异常都必须落入八类之一，且保留可追溯原因。
