# 断货前经营判断规则

## 1. 判断对象与时间基准

本规则只分析当天仍处于断货中的商品。

- 断货开始日期：库存从可恢复状态进入库存为 0 的日期。
- `T0`：断货开始日期的前一天，也是所有断货前窗口的截止日。
- 库存恢复到大于 5 后，后续再次变为 0，视为一次新的断货事件。
- 库存只恢复到 1～5，不视为断货事件结束。

利润率统一按以下方式计算：

```text
利润率 = 订单毛利 ÷ 销售额
```

## 2. 什么情况下可以评价

评价分为两层。两层都通过后，才生成历史经营等级、稳定性和角色变化结论。

### 2.1 当前评价门槛

需要同时满足：

1. 当天命中“断货中”，且 FBA 可售库存为 0；
2. FBA 在途和本地/采购库存数据完整，且不存在负数；
3. `FBA 在途 + 本地/采购库存 ≥ 5`；严格小于 5 时属于低库存边缘断货，不进入深层评价；
4. 存在完整、有效且与断货起点一致的断货前 30 天销售角色证据。

### 2.2 历史可评价门槛

通过当前评价门槛后，还需要同时满足：

| 条件 | 标准 |
| --- | ---: |
| 历史跨度 | 不少于 90 天 |
| 日数据覆盖率 | 不低于 80% |
| 有效经营日 | 不少于 30 天 |
| 有效经营周 | 不少于 8 周 |

有效经营日是指 FBA 库存大于 0 且库存数据有效的日期；一周至少有 3 个有效经营日，才算一个有效经营周。

任一条件不满足，就标记为“历史证据不足”，不强行判断历史等级和稳定性。

## 3. 销售角色怎么判断

分别计算断货前 7 天、14 天、30 天和 90 天角色。每个周期都以 `T0` 为截止日。

```text
角色日销 = 周期总销量 ÷ 周期自然天数
```

不是除以有货天数。例如断货前 30 天共销售 60 件，角色日销就是 `60 ÷ 30 = 2`。

### 3.1 周期是否有效

| 周期 | 最少有效经营日 |
| --- | ---: |
| 7 天 | 5 天 |
| 14 天 | 10 天 |
| 30 天 | 21 天 |
| 90 天 | 63 天 |

有效经营日不足时，该周期显示“周期角色不可判”。

### 3.2 MSKU 销售角色

按以下顺序判断，命中后不再继续向下判断：

| 角色 | 判断标准 |
| --- | --- |
| 有货零销量 | 周期总销量为 0 |
| 问题产品 | 有销量，但利润率缺失或低于 5% |
| 明星产品 | 日销≥5且利润率≥15%；或者日销≥1且＜5、利润率≥25% |
| 潜力产品 | 未命中明星，且日销≥5、利润率≥5%；或者日销≥1且＜5、利润率≥10% |
| 瘦狗产品 | 有销量、利润率≥5%，但未达到明星或潜力标准 |

### 3.3 国家销售角色

国家维度独立计算销售、利润和排名，并增加最近有效经营日的小类排名限制：

- 明星产品：排名≤50，并且日销＞3、利润率≥15%，或者日销为1～3、利润率≥25%；
- 潜力产品：未命中明星，排名≤100，并且日销＞3、利润率≥5%，或者日销为1～3、利润率≥10%；
- 排名缺失、排名≤0或排名≥99999：判为问题产品；
- 其他有销量且利润、排名有效的商品：判为瘦狗产品。

## 4. 历史经营等级怎么判断

历史等级不直接取某一个固定周期角色，而是使用历史滚动节点：

- 每个节点观察连续 30 天；
- 每隔 7 天生成一个节点；
- 每个节点至少需要 21 个有效经营日；
- 至少需要 8 个有效角色节点，才能判断历史经营等级。

判断顺序如下，命中前面的结果后不再继续向下判断：

| 历史等级 | 判断标准 |
| --- | --- |
| 历史有货无销量 | 有货零销量节点占比≥60% |
| 历史亏损 | 未命中有货零销量，且历史利润率＜0 |
| 历史较差 | 历史利润率≥0且＜5%，或者问题类节点占比≥50% |
| 历史优秀 | 明星节点≥60%，明星+潜力节点≥80%，且历史利润率≥15% |
| 历史良好 | 未命中优秀，明星+潜力节点≥60%，问题类节点＜25%，且历史利润率≥5% |
| 历史一般 | 证据充足，但未命中以上任何等级 |
| 历史不可判 | 有效滚动节点少于 8 个 |

其中“问题类节点”包括问题产品和有货零销量节点。

## 5. 稳定性怎么判断

稳定性由角色、销量和利润三个分项共同组成。

### 5.1 角色稳定性

角色变化连续出现 2 个滚动节点才确认，单个节点变化只视为短期波动。

- 稳定：主导角色占比≥70%，确认切换≤2次，方向反转≤1次，跨级切换≤1次；
- 高度波动：主导角色占比＜50%，或确认切换≥5次，或方向反转≥3次，或跨级切换≥3次；
- 其他情况：一般波动。

角色等级从低到高为：

```text
问题产品 < 瘦狗产品 < 潜力产品 < 明星产品
```

### 5.2 销量稳定性

按自然周计算周日销：

```text
周日销 = 一周总销量 ÷ 7
```

- 稳定：周销量变异系数≤0.50，且销量最高的 3 周占比未达到 40%；
- 高度波动：周销量变异系数＞0.80，或有效周不少于 12 周且最高 3 周销量占比≥40%，或最高单日销量占比≥80%；
- 其他情况：一般波动；
- 周销量证据不足：不可判。

### 5.3 利润稳定性

只使用销售额大于 0 且周销量不少于 5 的利润周：

- 稳定：周利润率标准差≤5个百分点，且亏损周占比≤10%；
- 高度波动：周利润率标准差＞10个百分点，或亏损周占比≥30%，或利润正负反转≥3次；
- 其他情况：一般波动；
- 有效利润周少于 6 周：不可判。

### 5.4 三项怎么组合

| 最终稳定性 | 组合标准 |
| --- | --- |
| 高度稳定 | 角色、销量、利润三项全部稳定 |
| 基本稳定 | 没有高度波动项，并且至少两项稳定 |
| 高度波动 | 角色高度波动，或者三项中至少两项高度波动 |
| 波动经营 | 证据完整，但未命中以上结果 |
| 稳定性不可判 | 判断所需的角色节点、有效周或利润周证据不足 |

## 6. A、B、C、D 代表什么

A、B、C、D 是断货前四个互不重叠的时间窗口，只用于判断商品临近断货时是在升级、退化、保持、启动还是停滞。

| 窗口 | 时间范围 | 最少有效经营日 |
| --- | --- | ---: |
| A | 断货前 1～7 天 | 5 天 |
| B | 断货前 8～14 天 | 5 天 |
| C | 断货前 15～30 天 | 11 天 |
| D | 断货前 31～90 天 | 42 天 |

时间顺序是：

```text
D → C → B → A → 断货
```

A 最接近断货，D 距离断货最远。

主要变化判断如下：

| 变化结论 | 判断方式 |
| --- | --- |
| 近 7 天停滞 | A 为有货零销量，B 或 C 原本存在有效角色 |
| 近 7 天启动 | A 存在有效角色，B 为有货零销量 |
| 近 7 天升级/退化 | 比较 A 与 B 的角色等级 |
| 近 30 天持续升级 | A≥B≥C，且 A＞C |
| 近 30 天持续退化 | A≤B≤C，且 A＜C |
| 近 90 天持续升级 | D→C→B→A 不下降，并且至少两个阶段升级 |
| 近 90 天持续退化 | D→C→B→A 不上升，并且至少两个阶段退化 |
| 角色保持 | A、B、C 的角色等级相同 |
| 变化不明确 | 证据完整，但未命中以上变化 |
| 变化不可判 | A、B、C 中存在证据不足，且未命中启动或停滞 |

## 7. 页面上的结果怎么组合

页面不使用综合评分，而是把“历史经营等级”和“稳定性”并列组合展示。

### 7.1 经营等级归并

| 页面分组 | 包含结果 |
| --- | --- |
| 表现较好 | 历史优秀、历史良好 |
| 经营一般 | 历史一般 |
| 经营风险 | 历史有货无销量、历史亏损、历史较差 |

### 7.2 稳定性归并

| 页面分组 | 包含结果 |
| --- | --- |
| 经营稳定 | 高度稳定、基本稳定 |
| 非稳定 | 波动经营、高度波动 |
| 稳定性不可判 | 稳定性证据不足 |

两个维度相互独立。例如：

- “表现较好 + 经营稳定”表示历史经营结果较好，而且波动较小；
- “表现较好 + 非稳定”表示历史结果较好，但销量、利润或角色变化较大；
- “经营风险 + 经营稳定”表示商品长期稳定地处于低利润、亏损或较差状态，不能因为稳定就理解为表现好。

固定周期角色、历史经营等级和稳定性不能互相替代：

- 7/14/30/90 天角色说明对应固定窗口内的经营位置；
- 历史经营等级说明整个历史滚动区间的总体表现；
- 稳定性说明历史过程是否持续、是否存在明显波动；
- A/B/C/D说明临近断货阶段的角色变化方向。
