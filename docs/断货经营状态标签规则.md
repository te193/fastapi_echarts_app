# 断货经营状态标签规则

## 目的

该标签用于分析当前已经处于“断货中”的产品：现有的在途、本地或采购补给，是否能够与断货前的经营表现相对应。

它不是原“断货前销售角色”的重复展示。原销售角色只在经营历史可判断、补给量有意义且存在销量时，作为后续细分依据。

## 分析范围

仅统计标签表中当前命中“断货中”的国家类别、店铺、MSKU 记录。

“断货中”定义保持原规则不变：

```text
FBA 可售 = 0
且
FBA 在途 + 本地/采购补给 > 0
```

补给总量统一定义为：

```text
补给总量 = FBA 在途 + 本地/采购补给
```

经营表现支持按 7、14、30、90 天周期查看。每条记录只归入一个经营状态，按下文顺序命中即停止。

## 判断顺序

| 顺序 | 经营状态 | 判断条件 | 业务含义 |
| --- | --- | --- | --- |
| 1 | 历史不可判 | 无对应周期的断货前销售角色；或缺少日销、周期起止；或日销为 0 且历史未覆盖完整周期 | 无法确认“0 销量”是真实经营结果，还是数据覆盖不足 |
| 2 | 低量补给待观察 | 历史可判断，且补给总量 ≤ 5 | 补给量过小，不能据此认定是因历史销售表现而补货 |
| 3 | 补给与动销不一致 | 历史完整、日销 = 0、补给总量 > 5 | 完整周期没有动销，但仍存在相对明确的补给 |
| 4 | 明星产品 | 有销量、补给总量 > 5、断货前角色为明星产品 | 补给与较好的断货前经营表现相符 |
| 5 | 潜力产品 | 有销量、补给总量 > 5、断货前角色为潜力产品 | 存在一定经营价值 |
| 6 | 瘦狗产品 | 有销量、补给总量 > 5、断货前角色为瘦狗产品 | 有销量，但经营效率偏弱 |
| 7 | 亏损问题 | 有销量、补给总量 > 5、断货前角色为问题产品、毛利率 < 0 | 有动销但亏损 |
| 8 | 低毛利问题 | 有销量、补给总量 > 5、断货前角色为问题产品、毛利率为 0%–5% | 有动销但利润不足 |

## 历史不可判的边界

“历史不可判”不等于“历史销量为 0”，它只表示无法确认零销量是否覆盖完整周期。

| 历史情况 | 日销 | 是否归入历史不可判 | 后续处理 |
| --- | --- | --- | --- |
| 完全没有历史数据 | 任意 | 是 | 历史不可判 |
| 历史只覆盖部分周期 | 0 | 是 | 历史不可判 |
| 历史覆盖完整周期 | 0 | 否 | 按补给总量进入低量补给待观察或补给与动销不一致 |
| 历史只覆盖部分周期 | 大于 0 | 否 | 仍可基于已发生动销判断，优先检查补给量后再看销售角色 |

完整周期的判定方式：历史起始日期不晚于所选周期的开始日。

因此，完整历史且日销为 0 的产品不能归入“历史不可判”：

```text
补给总量 ≤ 5  → 低量补给待观察
补给总量 > 5  → 补给与动销不一致
```

## 销售角色的使用边界

原“断货前销售角色”不是新标签的入口，而是最后一层细分条件。只有同时满足以下条件才使用销售角色：

```text
经营历史可判断
且
补给总量 > 5
且
所选周期内存在销量
```

这样可以避免把“补给只有 1–2 个”的产品，误解为因过往卖得好而正常补货。

## 统计口径

页面的“可评价”仅包含：

```text
明星产品、潜力产品、瘦狗产品、亏损问题、低毛利问题
```

页面的“不可直接评价”包含：

```text
历史不可判、低量补给待观察、补给与动销不一致
```

“不可直接评价”不表示没有结论，而表示这些记录不适合直接套用原销售角色来评价经营表现。

## 实施约束

- 不修改“断货中”原有定义。
- 原“断货前销售角色”面板保持原样，继续独立输出。
- 新“断货经营状态”面板仅面向当前断货中产品。
- 页面中的问号说明、接口返回的状态名称与实现逻辑均以本文档为准。
- 若出现缺少角色、日销或周期字段等技术数据异常，应保留可追溯原因；不得把“完整历史 0 销量”混入历史不可判。
