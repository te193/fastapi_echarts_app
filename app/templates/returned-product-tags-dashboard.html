标签定义标准

前置条件：最近 180 天内曾连续 FBA 可售库存为 0 不少于 14 天，并排除 `amzn.gr.%` 这类 Amazon 自动生成 MSKU。FBA可售达到 10 才视为进入可运营返场周期。

已退出返场

  • 已过 D21 观察期。
  • D0-D21 累计销量 > 0。
  • 当前 FBA 可售库存 >= 10。

已返场销售

  • 当前 FBA 可售库存 >= 10。
  • 近 21 天销量 > 0。
  • 尚未达到退出返场条件。

返场观察期

  • 当前 FBA 可售库存 >= 10。
  • 近 21 天销量 = 0。
  • 返场 Day0 后处于 D0-D3。

返场运营期

  • 当前 FBA 可售库存 >= 10。
  • 近 21 天销量 = 0。
  • 返场 Day0 后处于 D4-D21。

返场接收中

  • 0 < 当前 FBA 可售库存 < 10。
  • FBA 在途 > 0。
  • 未进入 D0-D21 队列计算。

返场未到货

  • 当前 FBA 可售库存 = 0。
  • FBA 在途 > 0。
  • 已计划返场，但还未恢复可售。

返场 D0-D21 队列表现

Day0 是连续缺货不少于 14 天后，FBA 可售库存首次恢复到 >=10 的日期。返场未到货和返场接收中尚未达到可运营库存，不进入本段队列分析；已退出返场已经完成闭环，也不再纳入 D0-D21 队列计算。
